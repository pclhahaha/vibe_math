〇、从一个具体问题开始——"数方格"算出抛物线下的面积

先忘掉所有公式，只看一个问题：有一块地，左边是直线 x=0，右边是直线 x=1，下面是 x 轴，上面是抛物线 y=x²。这块地的面积是多少？没有现成的"抛物线面积公式"，长方形、三角形的公式都不认识这条弯曲的边界。

但我们有个笨而可靠的办法：数方格。把 x 轴从 0 到 1 切成 10 根等宽的细条（每根宽 0.1），每根细条上方立一个长方形，高度取函数在这根条上的某个代表值，然后把 10 个长方形的面积加在一起。

  • 取每根条左端点当高度（估得偏小）：面积 ≈ 0.285；
  • 取每根条右端点当高度（估得偏大）：面积 ≈ 0.385。

真实的面积被夹在这两个数之间，夹缝宽 0.100。把条数加到 100（每根宽 0.01）：左端点估 ≈ 0.32835，右端点估 ≈ 0.33835，夹缝缩到 0.010。再加到 1000 根（每根宽 0.001）：面积被夹在 0.3328335 与 0.3338335 之间，夹缝只有 0.001。

看到规律了吗？每加密十倍，夹缝就缩窄十倍，而且从上面和从下面估的两个数都在朝同一个目标挤：0.3333…，也就是 1/3。我们几乎可以确信，这块地的面积就是 1/3。

这一整章要做的事情，就是把"切得更细 → 估得更准 → 极限就是精确面积"这套动作用严格的语言写下来。那个极限——在细条无限变细时，所有长方形面积和收敛到的数——就叫黎曼积分。

核心洞察：积分 ＝ 把图形切成无数细条，每条用长方形近似，再把它们全部加起来。条切得越细，答案越准；让细条无限变细，长方形面积和的极限就是精确面积。如果你只想理解核心思想，看到这里就够了。

一、我们唯一的精确武器——长方形面积

在面积理论里，我们手里只有一件精确的工具：长方形的面积 ＝ 宽 × 高。三角形的面积可以把它补成一个长方形再除以 2 得到；多边形的面积可以剖分成若干个三角形得到。这些例子说明一个原则：任何"规整"图形的面积，最终都能化成长方形的面积之和。

但抛物线下方的区域不是"规整"图形——它的边界是弯的，不能剖分成有限个长方形，我们不可能用"有限步操作"得到它的面积。于是我们改走另一条路：用无限多个越来越窄的长方形去逼近它，再对"逼近值"取极限。

这个想法有更深的背景。设 f 非负连续，记 A(x) 为 [a,x] 上曲线下方的面积。A(x) 满足两条显然的性质：

（1）A 随 x 单调不减；（2）区间可加：A(x₂)−A(x₁)＝[x₁,x₂] 上曲线下方的面积。

第二条"区间可加性"是积分的灵魂——它说明"面积"是一种随区间累积的量。这也解释了为什么许多"总量"本质上都是面积：速度曲线下的面积＝走过的路程，功率曲线下的面积＝消耗的能量。它们都没有简单公式，唯一的通用算法就是"切碎、近似、取极限"。

只有一个数值得专门命名。分划的细度（norm，或 mesh）‖P‖ 定义为最宽那段子区间的长度：

细度才是"切得够不够细"的正确度量。请特别注意它与"段数 n"的区别：n 很大并不保证每段都细——分点可以全都挤在 a 附近，留下一根几乎覆盖整个区间的大段。反过来，只要细度趋于 0，就保证每一段都无限变细。所以后面严格定义里，我们让 ‖P‖→0，而不是简单地 n→∞。

等分是分划里最常用的特例：n 等分时 Δxᵢ＝(b−a)/n 全部相等。初学者可以从等分入手，但头脑里要清楚：等分只是特权，一般分划才是规则——因为"面积"这个概念本身绝不应该依赖我们恰好选了哪种刀法。

三、黎曼和——在每一段上挑一个代表高度

有了分划，切条就完成了。现在每根细条都要配一个"高度"。我们的做法是：在第 i 段 [xᵢ₋₁,xᵢ] 内任意挑一个点 xᵢ*，把它当作这一段的代表，立一个高为 f(xᵢ*)、宽为 Δxᵢ 的长方形。把所有 n 个长方形加起来：

这个和就叫分划 P 与取样 {xᵢ*} 对应的黎曼和（Riemann sum）。注意三个要点：

  • xᵢ* 可以取段内任何一点——左端点、右端点、中点、随便哪个点都行；
  • 不同的取法得到不同的黎曼和，但它们都是"面积的可信近似"；
  • 分划可以不是等分——每段宽度 Δxᵢ 一般互不相同。

为什么"样本点可以随便取"如此重要？因为面积概念本身不该依赖于我们碰巧看了哪个点。如果换一种取法就换一个答案，那我们测的就不是同一个东西。黎曼的洞见恰恰是：把"极限与样本点无关"写进定义，就能同时排除这类病态。

先算一个具体的黎曼和，体会一下"近似"。取 f(x)=x²，区间 [0,1]，均分 4 段（Δx=0.25），每段取中点 xᵢ*＝0.125, 0.375, 0.625, 0.875：

它离真值 1/3≈0.3333 只差约 0.005。而如果取左端点，同样 4 段给出 0.21875；取右端点给出 0.46875——三种取法在粗分划下差得很远。可一旦把段数加到 100、1000，三种取法就都挤到 1/3 附近了（见开篇的表格）。

于是整件事归结为一个问题：当分划无限变细，这些黎曼和是否都挤向同一个数？答案是否定的，这个函数就"测不出面积"；答案是肯定的，这个公共极限就是积分。下一节我们引入一把精确的"卡尺"来测量黎曼和之间的分歧。

黎曼和＝"切条—取高—求和"这一套动作算出的近似数。它允许在每段里任意取样，因此同一个分划可以对应很多个黎曼和。可积性要回答的正是：这些和是否在细度趋于 0 时汇聚到同一个极限。

证明。只需处理"多切一刀"的情形，其余由归纳即得。设 P 的分点为 x₀<x₁<…<xₙ，P′ 在 [x_{k−1},x_k] 内插入了一点 c。切开前，这一格对下和的贡献是 m_k(x_k−x_{k−1})；切开后两格的 inf 都在更小的集合上取值，只能 ≥ m_k，所以这一格对下和的贡献不减少。对称地，两格的 sup 都 ≤ M_k，对上和的贡献不增加。其它格子原样未动，故 L 不减、U 不增。∎

这条引理就是"分割越细越准"的严格版本：加刀越多，下和只升不降、上和只降不升，误差带只会被收紧。但请注意：引理只保证"不恶化"，并不保证 U−L 一定能压到 0——那是可积性要回答的问题。

五、正式定义——黎曼积分

加细把所有下和堆成一个单调上升的"台阶"，把所有上和堆成一个单调下降的"台阶"。于是所有下和有一个上确界，所有上和有一个下确界，分别称为下积分与上积分：

常识告诉我们，下积分不可能超过上积分（任何下和都不超过任何上和，取 sup/inf 后大小关系保持）。当它们相等时，上下两把卡尺完全咬合，被夹在中间的那个唯一的数就是面积。这正是定义：

定义（黎曼可积）。有界函数 f 在 [a,b] 上黎曼可积，若下积分等于上积分；这个公共值记作

并称为 f 在 [a,b] 上的黎曼积分。

与它等价的判定法（Darboux 判据）更常用：

意思是：能找到一个分划，让上下和之间的夹缝比任何给定的正数还窄。这与原始定义等价，因为夹缝被压到任意小，正说明下积分与上积分被同一个数夹住；反过来，若二者相等为 A，则存在分划让 L(P)、U(P) 都落在 A 的 ε/2 邻域内，夹缝即小于 ε。

黎曼最初的表述（也是开篇"数方格"故事的严格版）则强调黎曼和本身：若对任意取样与任意分划，只要细度 ‖P‖→0，黎曼和就趋于同一个极限，这个极限就是积分。三种说法讲的是同一件事，区别只是从哪个角度量误差——用上/下和这把卡尺（Darboux），还是直接看黎曼和（Riemann）。

在左侧画布拖动滑块：n=4 时矩形和是粗糙的近似，n=50 时几乎看不出和曲线的差别。黎曼可积的要义是——夹缝 U−L 能被压到任意小，从而所有黎曼和收敛到同一个数，且与分划、样本点的取法无关。

七、为什么分割越细越准——把直觉钉死

前面的例题已经在算，但"为什么细度→0 能把夹缝压到任意小"还不完整。这一节把机制讲透，分两层。

第一层：加细只会收紧夹缝。这是第四节引理的内容：多切一刀，下和不降、上和不增，误差带 U−L 绝不加宽。所以"越细越准"在"不恶化"的意义上是铁的。但光靠加细还不够——它不保证最终能压到零。

第二层：为什么对连续函数，细度→0 就能把夹缝压到零。关键在一致连续性（Heine–Cantor 定理：闭区间上的连续函数必一致连续）。直觉上：一条连续的曲线，在任何一个很短的小区间里几乎是平的，最高点与最低点差不了多少。用 ε-δ 说，对任意 ε>0，存在 δ>0 使整个区间内任意两点相距小于 δ 时，函数值之差小于 ε/(b−a)。取细度 ‖P‖<δ 的分划，每个小区间上

八、哪些函数黎曼可积？

把第七节的机制盘点一遍，可以得到三条逐渐放宽的可积性结论。

结论一（连续即可积）。f 在闭区间 [a,b] 上连续 ⟹ f 黎曼可积。这正是第七节证明的内容，核心工具是 Heine–Cantor 一致连续性 + Darboux 判据。连续函数是最重要的一族可积函数。

结论二（单调即可积）。f 在 [a,b] 上单调 ⟹ f 黎曼可积。证明见工作题 4。有趣的是，单调函数的跳跃点可以稠密地分布（例如跳跃函数 Σ2⁻ⁿ 型），却仍然可积——"可积"远比"连续"或"有限个间断点"宽容。

结论三（Lebesgue 判据）。有界函数 f:[a,b]→ℝ 黎曼可积 当且仅当 f 的不连续点集有 Lebesgue 测度 0（1904，Lebesgue）。用大白话说：可积 ⟺ 函数"几乎处处连续"。这是黎曼可积性的完整刻画，也是通往 Lebesgue 积分的桥梁。

但黎曼框架仍有天花板。两个著名的病态例子预告在后面：一个（Dirichlet 函数）处处震荡、一个（Volterra 函数）导数处处存在却不可积，它们共同说明"可积"与"处处连续"之间隔着一道不可逾越的鸿沟——这正是 Lebesgue 积分登场的动机。

十、为什么需要 Lebesgue 积分？

黎曼积分有两个结构性弱点，迫使数学在 1902 年后换了一种"切法"。

弱点一：极限与积分不能随便交换。存在一列黎曼可积函数 fₙ 逐点收敛到 f，却成立 lim ∫fₙ ≠ ∫lim fₙ。极限符号不能自由穿过积分号，这对概率论、傅里叶分析和物理都是灾难。

弱点二：可积的门槛既苛刻又错位。Dirichlet 函数 D(x)＝1（x 有理数）、0（x 无理数）在黎曼框架下不可积——它在每个小区间里都取到 1 和 0，上下和永远差 1；可它实在"应该"积分为 0（有理数在 [0,1] 里"几乎没有"）。

Lebesgue 积分的治疗方案是改变切法：黎曼"竖切"定义域（按 x 分划），Lebesgue"横切"函数值（按函数值分划，再用量集合"大小"的测度替代长度）。由此 Dirichlet 函数变得可积且积分为 0，极限与积分在控制收敛定理（DCT，dominated convergence theorem，当一列函数都被同一个可积函数"罩住"时极限与积分可以交换的定理）下可以交换——代价是需要一套完整的测度论（见关联课程）。

更精确地说，Lebesgue 积分包含了所有黎曼可积函数，并且更多：凡是黎曼可积的（有界且几乎处处连续），Lebesgue 都可积且值相同；反过来 Lebesgue 还能处理黎曼完全无能为力的病态函数。积分理论的世界，从此换了一副底盘。

前沿：路径积分与Feynman-Kac

Feynman路径积分至今没有严格数学定义——但Feynman-Kac公式将Schrodinger方程的解表示为Brownian运动的泛函积分。这是将"物理直觉"严格化的最成功案例。仍开放:非微扰QFT的路径积分严格定义(Yang-Mills千禧年问题)。

严格定义——上/下和、Darboux判据与Lebesgue判据

设分划P: a=x₀<x₁<…<x_n=b。上Darboux和U(f,P)=ΣM_iΔx_i,下Darboux和L(f,P)=Σm_iΔx_i。Darboux判据: f可积 ⟺ ∀ε>0,∃P使U(f,P)−L(f,P)<ε。Lebesgue的Riemann可积性判据(1904): 有界函数f:[a,b]→ℝ是Riemann可积的 当且仅当 f的不连续点集有Lebesgue测度0。这给出了从Riemann积分到Lebesgue积分过渡的最优雅桥梁——可积性恰由f"几乎处处连续"刻画。

微积分基本定理——严格表述与反例

第一部分: F(x)=∫_a^x f(t)dt,若f在x₀连续,则F'(x₀)=f(x₀)。第二部分: 若F在[a,b]上可微,且F'是Riemann可积的,则∫_a^b F'=F(b)−F(a)。Volterra反例(1881): 构造了一个处处可微、导数有界却非Riemann可积的函数——可见微积分基本定理第二部分在Riemann框架下不是"全自动的"。这给出了推广积分概念的动机之一→Lebesgue积分解决了此缺陷: 若F绝对连续,则F'必Lebesgue可积。

广义Riemann积分——条件收敛与绝对收敛

无穷限广义积分: ∫_a^∞ f = lim_{b→∞}∫_a^b f。无界函数的广义积分: ∫_a^b f(t)/(t−a)^α。Dirichlet积分∫_0^∞ sin(x)/x dx = π/2 (围道积分计算)——是条件收敛的: ∫_0^∞ |sin(x)/x|dx = ∞ 发散。条件收敛与绝对收敛的区别在Riemann框架下意义明确: 条件收敛时重排级数可改变极限值(Riemann重排定理的积分版本)。

与测度的桥梁——测度零的不连续点集

Riemann可积⇔不连续点集有零Lebesgue测度。Cantor集(零测度、不可数、完全不连通)上的特征函数1_C是Riemann可积的(不连续点在C上,测度=0)→说明可积性比"有限个不连续点"宽得多。注意: 在测度论中, Riemann可积函数⇔有界且a.e.连续。这之后所有基本定理(可积性和代数性质、微积分基本定理的条件)都有了透明解释。

历史文献

Cauchy(1823, "Résumé des leçons sur le calcul infinitésimal"——连续函数积分的第一个严格定义)。Riemann(1854, Habilitationsschrift "Über die Darstellbarkeit einer Function…"——扩展到具有稠密不连续点的函数)。Riemann给出的经典示例: f(x)=Σn⁻² B(nx),其中B(t)=t−⌊t⌋当t非整数,否则0——该函数在任意区间内有无穷多个不连续点,而仍然是Riemann可积的。

证明一：连续函数在闭区间上黎曼可积

定理：若 f: [a,b] → ℝ 连续，则 f 黎曼可积。用一致连续性 + Darboux 判据证明。

一致连续性。 f 在紧集 [a,b] 上连续，由 Heine–Cantor 定理，f 一致连续：对任意 ε > 0，存在 δ > 0，使得 |x − y| < δ 时 |f(x) − f(y)| < ε/(b−a)。（这里取 ε/(b−a) 是有意为之，稍后见分晓。）

构造分划。 取细度（最大子区间长）< δ 的分划 P：a = x₀ < x₁ < … < xₙ = b。在每个子区间 [xᵢ₋₁, xᵢ] 上，因 f 连续，可达到最大最小值：Mᵢ = max f，mᵢ = min f。由于区间长度 Δxᵢ < δ，区间内任意两点 x, y 满足 |x−y| < δ，故 Mᵢ − mᵢ < ε/(b−a)。

上减下。

对任意 ε > 0 存在分划使 U − L < ε，由 Darboux 判据 f 黎曼可积。∎

关键洞察：一致连续性把"函数局部变化"控制得与区间长度成比例，从而上下和的差可被任意压小。若只假设逐点连续，函数可能在某个点附近震荡得足够剧烈而破坏可积性；但闭区间紧致性恰好保证了这种控制的均匀性。

定理：设 f 黎曼可积，F(x) = ∫ax f(t)dt。若 f 在 x₀ 连续，则 F'(x₀) = f(x₀)。

Volterra 函数（1881）。 Volterra 构造了一个处处可微、导数有界但导数不黎曼可积的函数 F。方法：对 Smith–Volterra–Cantor 集（"胖 Cantor 集"：正测度、无处稠密）构造一个处处可微的"平滑化"函数，使 F' 在一个正测度集合上不连续。由 Lebesgue 判据（Riemann 可积 ⟺ 不连续点集测度为零），F' 不可积。因此微积分基本定理第二部分的假设（F' 可积）绝非自动满足——这正催生了 Lebesgue 积分：若 F 绝对连续，则 F' 必 Lebesgue 可积。

工作题：Darboux 上下和与可积性判断

题1。 用 Darboux 上下和计算 ∫01 x dx。

显示解答

f(x) = x 单调递增，故每个子区间上 Mᵢ = 右端点值、mᵢ = 左端点值。取均匀分划 Δx = 1/n，xᵢ = i/n：U = Σᵢ₌₁ⁿ (i/n)(1/n) = (n+1)/(2n)，L = Σᵢ₌₀ⁿ⁻¹ (i/n)(1/n) = (n−1)/(2n)。n → ∞ 时 U → 1/2、L → 1/2，且 U − L = 1/n → 0，故积分存在且 ∫₀¹ x dx = 1/2。

题2。 用黎曼和计算 ∫02 x² dx。

显示解答

取均匀分划 xᵢ = 2i/n、Δx = 2/n，样本取右端点 f(xᵢ) = (2i/n)²。黎曼和 = Σᵢ₌₁ⁿ (4i²/n²)(2/n) = (8/n³)Σᵢ₌₁ⁿ i² = (8/n³)·n(n+1)(2n+1)/6 = (8/6)(1+1/n)(2+1/n) → 8/3。故 ∫₀² x² dx = 8/3。核对原函数法：x³/3 在 0 到 2 上取值 8/3。✓

题3。 判断下列函数在 [0,1] 上是否黎曼可积：(a) f(x) = sin(1/x)（x > 0），f(0) = 0；(b) f(x) = 1/x（x > 0），f(0) = 0；(c) f(x) = 1 若 x 属于 Cantor 集，否则 0。

显示解答

(a) 可积。f 有界（|f| ≤ 1），不连续点只有 x = 0（单点集，测度为零），由 Lebesgue 判据可积。(b) 不可积：f 在 [0,1] 上无界，任何分划中靠近 0 的子区间上 f 无上界，上 Darboux 和 = ∞。作为广义积分 ∫₀¹(1/x)dx 也发散；有界截断则不属于经典黎曼可积范畴。(c) 可积：f 的间断点集 ⊆ Cantor 集，测度为零，由 Lebesgue 判据可积，且 ∫ = 0（在稠密的补集上 f = 0）。

题4。 证明：单调函数在 [a,b] 上黎曼可积。

显示解答

设 f 单调递增（递减同理）。给定 ε > 0，取均匀分划 Δx = (b−a)/n，n 足够大使 Δx < ε/(f(b)−f(a)+1)（若 f 为常数则 trivially 可积）。因单调，Mᵢ = f(xᵢ)、mᵢ = f(xᵢ₋₁)。于是 U − L = Σ[f(xᵢ) − f(xᵢ₋₁)]Δxᵢ = Δx·(f(b) − f(a)) < ε。由 Darboux 判据可积。注意：单调函数可有稠密分布的跳跃点（如跳跃函数 Σ2⁻ⁿ），仍可积——比"连续"或"有限个间断点"宽得多。

关联课程

→ 导数：微积分基本定理F'(x)=f(x)将微分和积分绑定为互逆运算——这是分析学最重要的单一桥梁，在每一步都依赖黎曼积分的定义。

→ ε-δ语言：黎曼可积的严格定义——对任意ε>0存在δ>0使任何细度<δ的分划的黎曼和与积分值之差<ε——完全依赖ε-δ语言对极限的精确刻画。

→ 实分析：黎曼积分的两大缺陷——极限与积分不可随便交换、Dirichlet函数不可积——直接推动了实分析的严格化和Lebesgue积分的诞生。

→ 测度论：Lebesgue积分用"纵切"（按函数值分划）替代黎曼积分的"横切"（按定义域分划），以测度替代长度——由此克服了黎曼积分在收敛性上的所有不足。
