〇、直觉入门——把一堆沙子搬到另一堆，怎么搬最省钱

想象你要把客厅的一堆沙子搬去院子里，堆成另一个形状。你可以一铲一铲地搬，问题是：每一铲沙子该搬到哪儿，才能让所有人搬的路加起来最短？这就是"最优传输"想解决的问题。

它专门研究"怎么把一堆东西变成另一堆东西、花的路费最少"，搬家、送货、把一种图像变成另一种图像，都用得上它。

一句话：给定起点和终点两堆"沙子"，找到让总搬运距离最短的搬法。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 前沿 级别，正文较深。

建议先掌握：测度论、概率论基础。

高级章节（证明、前沿、工作题）需要相应背景，未掌握可先看「〇、直觉入门」了解核心思想，或回到前置课程补基础。

题目。 求一个搬运计划：每座沙场全部清空、每个工地刚好收满，使总运费最小。

第一步：找"便宜路"。 表里最便宜的两条路是 A₂→B₁（单价 1）和 A₁→B₂（单价 2）。直觉上应尽量多走这两条。

第二步：先喂最便宜的。 让 A₂ 全力供 B₁：A₂→B₁ = 50（A₂ 就这么多），剩 10 铲 B₁ 的需求。这 10 铲谁送最便宜？A₃→B₁ 单价 3、A₁→B₁ 单价 4，故选 A₃→B₁ = 10。此时 A₁ 还剩 30 铲，B₂ 还需要 40 铲。

第三步：补齐需求。 给 B₂ 供货：A₁→B₂ = 30（单价 2），A₃→B₂ = 10（单价 5）。四个工地全部满足。

第四步：算总账并核对最优性。 总运费 = 50·1 + 10·3 + 30·2 + 10·5 = 50 + 30 + 60 + 50 = 190 元。

为什么它是最优的？ 设 x = A₂→B₁ 的量、y = A₃→B₁ 的量，则 A₁→B₁ = 60−x−y，A₁→B₂ = x+y−30，A₂→B₂ = 50−x，A₃→B₂ = 20−y。总运费是关于 (x,y) 的线性函数，整理得

最小化 cost ⟺ 最大化 7x+4y。约束是 x≤50、y≤20、x+y≤60、x+y≥30。取 x=50（能取的最大值）、y=10（此时 x+y=60 顶格）得 7·50+4·10=390，故最小 cost = 580−390 = 190，与上面的计划吻合。∎

这一步的价值。 这个问题 1781 年就被 Monge 提出（"沙堆搬运"），但直到 1942 年 Kantorovich 才找到正确写法。它的本质是：只要允许"一座沙场可以同时供两个工地"（即允许劈分），问题就是一个线性规划，可以手算、可以上机解。全课的抽象框架就是从这个具体的表里提炼出来的。

二、Monge 与 Kantorovich——"整铲搬运"为何要改成"任意劈分"

把沙场与工地变成数学对象：沙场的分布是 μ（每个位置上有多少沙），工地的分布是 ν。一铲沙从 x 运到 y 的运费是 c(x,y)（如距离的 p 次方 |x−y|p）。

Monge（1781）原问题。 找"搬运映射" T：把 x 处的沙子整铲送到 T(x)，要求把所有沙送到目标分布：

T 是"函数"，每一处只有唯一去向。这是非线性约束（T#μ=ν），很难处理。

Kantorovich（1942）放松。 允许"劈分"：与其规定 x 去哪，不如规定"多少沙从 x 到 y"——即给出 X×Y 上的联合分布 π，它的两个边缘分布恰是 μ、ν。π 称为 耦合（coupling），所有耦合的集合记作 Π(μ,ν)。问题变成

这是一个线性问题（对 π 线性）——Kantorovich 因此把它变成线性规划，并获 1975 年诺贝尔经济学奖。

为什么必须允许劈分？看一个具体反例。 设 μ = δ₀（沙全在 0 点），ν = (δ₁ + δ₋₁)/2（目标是一半在 1、一半在 −1）。任何函数 T 只能把 0 送到一个点，无法同时变成 1 和 −1——Monge 问题无解。而耦合 π 可以写 π = (δ_{(0,1)} + δ_{(0,−1)})/2，把质量 1/2 分给 1、1/2 分给 −1——Kantorovich 问题有解。这就是"劈分"不可省的原因：映射太僵硬，耦合才足够灵活。

取成本 c(x,y) = |x−y|p（p ≥ 1），并限制在 p 阶矩有限的测度空间 P_p(ℝⁿ) = {μ : ∫|x|^p dμ < ∞} 上。定义

为什么它配叫"距离"？ 四条度量公理逐条可证：

  • 对称性与正定性：W_p ≥ 0，且 W_p(μ,ν) = 0 ⟺ μ = ν（因为 |x−y|^p = 0 仅当 x=y，此时最优耦合把质量全部"原地不动"）。
  • 三角不等式：W_p(μ,ν) ≤ W_p(μ,ρ) + W_p(ρ,ν)——把 μ→ρ 的最优耦合与 ρ→ν 的最优耦合用 gluing lemma 沿 ρ 拼起来，得到 μ→ν 的耦合，Minkowski 不等式给出距离估计。
  • 完备性：(P_p(ℝⁿ), W_p) 是 Polish 空间；紧性 ⟺ p 阶矩一致有界（Villani 定理 6.18）。
  • 与弱收敛的关系：μₖ → μ 在 W_p 意义下 ⟺ 弱收敛且 p 阶矩收敛。
  • 测地性：McCann 位移插值 μ_t = ((1−t)id + tT)#μ 是 W₂-测地线（见"Otto 几何"一节）。

为什么别的"距离"不行？ 全变差距离与弱收敛不相容：δ_{1/n} 到 δ₀ 的全变差距离恒为 2，但 δ_{1/n} 却弱收敛到 δ₀——它"看不见"支撑在缓慢漂移。KL 散度不对称、不满足三角不等式，且对支撑不交的分布取 ∞。Wasserstein 距离"连续度量支撑漂移"：把一个分布连续变形为另一个时，W_p 连续变化。这正是它在统计与生成建模中备受青睐的根本原因。

为什么最优映射必须是凸函数的梯度？ 直观上：一维最优映射"保序"（T 单调递增）；高维的推广是"单调映射"（⟨T(x)−T(y), x−y⟩ ≥ 0）。而单调映射与凸函数次梯度之间有一个经典一一对应（Rockafellar 的单调映照定理）——于是最优映射 = 凸梯度。这是重排思想从一维走向高维的桥梁。

证明思路。 ① 先解 Kantorovich：用对偶定理得最优对 (φ,ψ)。由成本二次，c-凹性精细化：最优 ψ 的 c-变换 φ 满足 φ(x)+ψ(y)=|x−y|² 在 supp π 上几乎处处成立。② 单调性：在 supp π 上取两对 (x,y)、(x′,y′)，由等式相减得 ⟨y−y′, x−x′⟩ ≥ 0——T 在 supp μ 上单调（一维重排不等式的高维推广）。③ 凸函数梯度：单调映射与凸函数次梯度有一一对应（Rockafellar 的单调映照定理）⟹ 存在凸 φ 使 T = ∇φ。④ 唯一性：两个最优映射的凸组合仍最优，用严格凸性的线性插值论证迫使二者 μ-a.e. 相等。∎

Monge-Ampère 方程。 当 ν 也绝对连续时，φ 满足（在 Alexandrov/粘性意义下）

其正则性理论（Caffarelli 等）是"最优映射为何光滑"的核心。物理直觉：最优位移 = 把沙堆铺成目标形状的势场梯度。这是继 Kantorovich 对偶之后，最优传输理论第二个里程碑——它给出 Monge 问题与 Kantorovich 问题等价的第一个实质性结果。

九、标准反例——Brenier 定理的假设一步都省不得

反例 1（μ 非绝对连续 ⟹ 最优映射不存在）。 μ = δ₀，ν = (δ_{−1}+δ₁)/2。二次成本下唯一最优耦合把质量 1/2 分给 −1、1/2 分给 1——这不是函数 T 诱导的（函数只能把 0 送到一个点）。Monge 问题无解，Kantorovich 问题有解——这就是必须放松的原因。

反例 2（ν 非绝对连续 ⟹ T 非光滑）。 μ = U([0,1])，ν = δ₀。最优映射 T(x) ≡ 0（整段坍缩）。Monge-Ampère 方程右边 ν(∇φ(x)) = δ₀(0) 未定义——密度之比为无穷大，φ 非光滑（梯度在每点"跳向 0"）。正则性定理必须假设 ν ≪ Leb。

反例 3（成本非严格凸 ⟹ 最优性退化）。 c(x,y)=|x−y| 在 ℝ 且 μ=δ₀、ν=δ₂ 时唯一耦合是 0→2；但若成本仅为凸而非严格凸（如 c(x,y)=|x−y|）且支撑合适，最优耦合可能不唯一（多个 T 均可最优）。一般地，严格凸且可微的成本是 Brenier 型结论（T = ∇φ 的凸梯度形式）的充分条件——非凸或非光滑成本会出现多解与非函数化。

十、Sinkhorn 算法——熵正则化让最优传输跑得起来

对偶化后的问题仍是大规模线性规划，动辄上亿变量，直接求解不可行。Cuturi（2013）的洞见：给目标函数加一个熵惩罚项，问题立刻变成可以迭代求解的矩阵缩放：

对离散情形，最优解有解析形式 π = diag(u)·K·diag(v)，其中 K_ij = e^{−c_{ij}/ε}。未知量 u、v 通过交替缩放行列和来求：先按行缩放匹配 μ，再按列缩放匹配 ν，反复迭代——这就是 Sinkhorn-Knopp 算法。每一步只是矩阵与对角阵相乘，计算速度比传统线性规划提升几个数量级。这是最优传输从纯理论走向大规模应用（图像、NLP、生成模型）的关键突破。

为什么熵正则化"合理"？ 熵惩罚量鼓励 π 尽量"均匀、光滑"；ε 很小时，熵几乎不影响结果，解逼近真正的 W_p 最优耦合；ε 越大越光滑、越容易算。参数 ε 是一个可调的"软化尺度"——这也呼应 W₁ 对偶中 Lipschitz 函数"越光滑越好算"的直觉。

十二、Wasserstein 几何——Otto 的形式 Riemann 结构

Otto（2001）发现在 W₂ 距离下，概率测度空间 (P₂(ℝⁿ), W₂) 具有形式的 Riemannian 结构（并非真正的无穷维 Riemann 流形，但实际效果如次）。在该结构下：切空间 = {∇f: f∈C_c^∞}，指数映射 = McCann 位移插值 μ_t = ((1−t)id + tT)#μ。W₂-测地线连接任意两个测度，而 McCann 证明了在 W₂ 中的位移凸性（displacement convexity）概念——凸函数的无穷维新泛函版本。这为研究概率分布的"凸分析"开辟了道路。

十三、梯度流——统一一大类非线性 PDE

在 Otto 的形式 Riemannian 结构中，自由能泛函 F(ρ)=∫ρlogρ+∫Vρ 的梯度流 = ∂_tρ = Δρ + ∇·(ρ∇V)——即为Fokker-Planck 方程。这是经典热力学第二定律的数学表现：自由能沿水流动力学减小。进一步：Tsallis 熵的梯度流 → 多孔介质方程（非线性扩散）。Jordan-Kinderlehrer-Otto（1998）的开创性论文确立这种 PDE 的"Wasserstein 梯度流"对应关系——自此之后，许多非线性发展方程有了统一的最优传输解释。

十四、GAN 与前沿——从 Wasserstein 到生成模型

生成对抗网络（GAN）中，Wasserstein GAN 用 W₁ 替代 Jensen-Shannon 散度作为损失函数 → 更稳定的训练，不再有模式坍塌。这是最优传输理论在深度学习中最著名的应用——其损失函数的数学根基正是 Kantorovich-Rubinstein 公式（W₁ = 1-Lipschitz 函数积分差的上确界）。

前沿：Score-based 生成模型与 Schrödinger 桥。 Score-based 模型（Song 2021）和扩散模型 = SDE 视角下的最优传输。Schrödinger 桥问题（1932）——在扩散过程中找到最接近给定端点分布的演化——正在成为生成模型的新范式。仍开放：离散空间上的 Schrödinger 桥。

十五、关键文献与诺贝尔奖级的影响

Monge（1781, "Mémoire sur la théorie des déblais et des remblais"——提出运输问题）。Kantorovich（1942, 用线性规划重新表述——1975年诺贝尔经济学奖）。Brenier（1991, 二次成本最优映射=凸函数梯度——突破性）。McCann（1997, 位移凸性——凸分析在概率测度空间上的移植）。Otto（2001, Otto 微积分——W₂ 的 Riemannian 结构）。Villani（2003,"Topics in Optimal Transportation"; 2009,"Optimal Transport: Old and New"——Fields 奖相关专著,完整记录领域发展）。开放: 一般成本函数的正则性理论、最优传输的量化稳定性。

十六、工作题

题 1：μ = δ_a，ν = δ_b 为 Dirac 质量。计算 W_p(μ,ν)。

题 2：μ = U([0,1])，ν = U([0,2])。用一维最优耦合公式 T = F_ν^{-1}∘F_μ（F 为分布函数）计算 W₂(μ,ν)。

题 3：μ = U([0,1])，ν = U([1,2])（平移一个单位）。证明 W₁(μ,ν) = 1 且最优 1-Lipschitz 势可取 f(x) = x（用 Kantorovich-Rubinstein 对偶）。

显示解答

题 1：唯一耦合是 δ_{(a,b)}，故 W_p(μ,ν) = (∫|x−y|^p dδ_{(a,b)})^{1/p} = |a−b|。结论：Dirac 质量之间的 W_p 距离就是两点间距（与 p 无关）。∎

题 2：F_μ(x) = x（x∈[0,1]），F_ν^{-1}(t) = 2t。故 T(x) = 2x，把 [0,1] 铺到 [0,2]。位移 |T(x)−x| = x。于是 W₂² = ∫₀¹ x² dx = 1/3，W₂ = 1/√3。（完整计算见例题 2。）∎

题 3：取 f(x) = x（1-Lipschitz）：∫f d(μ−ν) = 1/2 − 3/2 = −1；改取 f = −x 得 ∫(−x)dμ − ∫(−x)dν = −1/2 − (−3/2) = 1。故 W₁ ≥ 1。反过来平移耦合 π = (id+1)#μ ∈ Π(μ,ν) 给出 ∫|x−y| dπ = 1 ⟹ W₁ ≤ 1。合起来 W₁ = 1。（完整计算见例题 3。）一般结论：平移 t 的均匀分布，W₁ = W₂ = |t|。∎

十七、试试看（每题附提示）

试试看 1（排序的变体）。 μ = U([0,2])，ν = U([1,3])（仍是平移 1 个单位）。用例题 2 的公式算 W₂。提示：T(x) = x+1，位移恒为 1，故 W₂² = ∫₀² 1²·(1/2)dx = 1，即 W₂ = W₁ = 1。

试试看 2（Dirac 与均匀分布）。 计算 W₁(δ₁, U([0,1]))。提示：下界取 f(x)=x：∫x dδ₁ − ∫x dμ = 1 − 1/2 = 1/2；上界：把 δ₁ 送到 [0,1] 的任意耦合，期望成本 = ∫₀¹|1−y|dy = ∫₀¹(1−y)dy = 1/2。

试试看 3（两个二点分布）。 μ = (δ₀ + δ₂)/2，ν = (δ₁ + δ₃)/2。求 W₂。提示：单调重排按序配对：0→1、2→3，位移各为 1，故 W₂² = (1²+1²)/2 = 1，W₂ = 1。

试试看 4（熵的极限行为）。 在 Sinkhorn 的核 K_ij = e^{−c_{ij}/ε} 中，当 ε → 0 时 K 发生什么？提示：对 c₁₂ > c₁₁，e^{−c₁₂/ε} / e^{−c₁₁/ε} = e^{−(c₁₂−c₁₁)/ε} → 0——大成本项指数级消失，K 趋于"只允许最小成本"的 0-1 矩阵，正是未正则化最优传输的行为。
