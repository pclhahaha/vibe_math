〇、直觉入门——把西兰花掰下一小朵，看起来和整棵一模一样

自然界有很多形状"越放大越像自己"：西兰花的每一小朵都像整棵西兰花，树枝的分叉像大树，雪花的边缘怎么放大都毛茸茸的。这种"局部=整体"的形状，就叫分形。

数学家发现，只要用一行极简单的规则反复套用，就能画出比任何人工图形都复杂千百倍的图案——Mandelbrot集就是最著名的例子。它告诉你：粗糙和不规则，背后其实也有一套隐藏的秩序。

分形的第二课是"维数可以是分数"：一条线是 1 维、一个面是 2 维，但 Koch 雪花的边缘是 log4/log3≈1.26 维——比线粗、比面细。把"维度"从整数放宽到实数，是 20 世纪几何最深刻的观念之一。

洞察：世界上的"不规则"大多不是乱来的——很多粗糙的形状里藏着"无限放大都一样"的秘密。只想懂核心思想，看到这里就够了。

Koch 雪花的全部教训浓缩成一个数字对：周长 3·(4/3)ⁿ→∞，面积 →(8/5)A₀≈0.693。长度量不出来的东西，要用"1.26 维"来量。

二、先直觉后严格——"维度该是几"：为什么量长度和量面积都失败

想描述 Koch 曲线"有多大"，先试最朴素的两个工具。

用长度量：失败。 曲线无限长。理由（严格化）：第 n 步曲线由 4ⁿ 段组成、每段长 3⁻ⁿ，总长 (4/3)ⁿ→∞。无论拿多小的尺子，量出来的总长只会越来越大——长度发散。

用面积量：也失败。 Koch 曲线可以铺进面积任意小的带子里（它没有"厚度"），所以面积是 0。面积测不出它的"宽度"。

正确的问法。 长度测了 =∞，面积测了 =0。中间一定藏着一个临界指数 s，让"s 维测度"既不趋于 0 也不趋于 ∞。直觉：把整条曲线切成 N=4ⁿ 段，每段缩到 3⁻ⁿ 倍。如果"长度"随缩放的规律是"段数×(段长)^s"，那么

把它理顺：若 s<log4/log3，则 4/3^s>1，(4/3^s)ⁿ→∞——测度爆炸成 ∞；若 s>log4/log3，则 4/3^s<1，(4/3^s)ⁿ→0——测度塌缩成 0。测度有限且非零只可能发生在 4/3^s = 1，即 s = log4/log3。这个临界 s 就是 Koch 曲线的"维数"：比它小的 s 都量出 ∞（像长度），比它大的 s 都量出 0（像面积），恰好在它上面才量得出一个有限数。下面第五节和第六节把这个直觉写成严格定义并算完。

一句话直觉：分形维数就是"从 ∞ 掉到 0 的那个临界点"。长度在临界点之下（∞），面积在临界点之上（0），临界点本身 ≈1.26。

三、Hausdorff 维数的定义——为什么这样定义：从"测度"到"临界指数"

把上一节的直觉严格化。设 A 为度量空间中的集合。先定义 s 维 Hausdorff 测度：用直径不超过 δ 的可数覆盖 {U_i} 来"测"A，

作为 s 的函数，H^s(A) 在某一临界值从 ∞ 跳到 0，这个临界值就是 Hausdorff 维数：

为什么这样定义？（逐个动机讲清）

  • 为什么取 inf ？ 覆盖越细，U_i 越碎，"s 维测量"越接近真值；inf 保证我们用到最优覆盖。这是模仿 Lebesgue 测度的外测度构造。
  • 为什么用 diam(U_i)^s 求和？ s=1 时它测"长度"（直径之和），s=2 时测"面积"（直径平方之和），s=3 时测"体积"——把整数维的直觉插值成连续维。
  • 为什么会有"从 ∞ 跳 0"？ 对光滑曲线：s<1 时 H^s=∞（把 s 维盒子塞进 1 维物体），s>1 时 H^s=0。跳跃点就是维度。

例子：光滑曲线 D=1、光滑曲面 D=2、Koch 雪花 D=log4/log3≈1.26、Cantor 集 D=log2/log3≈0.63、Mandelbrot 集边界 D=2（Shishikura 1991 证明）。

七、Mandelbrot 集——一行代码的无限复杂

z_{n+1}=z_n²+c，c∈ℂ。从 z₀=0 开始迭代。如果不发散到无穷→c 属于 Mandelbrot 集（黑色区域）。点击任意位置放大——无限的自相似结构。

为什么从 z₀=0 出发？ 这是唯一既平凡又普适的起点：任何轨道在 0 处的行为完全由 c 决定，所以"Mandelbrot 集"是一个关于复参数 c 的几何对象，而不是关于初始点的。

怎么判断"不发散"？逃逸半径定理。 一旦某个 |zₙ|>2，轨道就永远逃逸（因为 |z_{n+1}|=|zₙ²+c|≥|zₙ|²−|c|≥|zₙ|²−2>|zₙ|，一步比一步大）。所以只要观测到 |zₙ|>2 就可以判 c∉M；观测到 |zₙ|≤2 一直保持，则 c∈M。这个简单的判据让"无限复杂"可以严格验证（见例题 3）。

边界 Hausdorff 维数 =2——二维中最粗糙的边界（Shishikura 1991）。不管放大多少倍，边界永远不会变光滑。一个简单到一行代码的迭代规则，产生了人类已知最复杂的数学对象。

八、例题 3——手算几次迭代，判断 c 是否在 Mandelbrot 集里

题目。 分别取 c=−1、c=i、c=2，手算 z_{n+1}=zₙ²+c 的前几步，用逃逸半径定理判断 c∈M 与否。

第一步：c=−1。 从 z₀=0 出发：

轨道在 0 ↔ −1 之间来回，永远满足 |zₙ|=0 或 1 ≤ 2。c=−1∈M（周期 2 轨道）。

第二步：c=i。

从 z₂ 起进入周期 2 循环 {−1+i, −i}，模长 |−1+i|=√2≈1.414、|−i|=1，都 ≤2。c=i∈M。注意轨道并不停在原点附近——它是"绕着原点附近转"。

第三步：c=2。

z₁=2 时已经 ≥ 逃逸半径（严格说 2 还不够，要看下一步）：z₂=6>2，立刻判据生效。c=2∉M。数值对比：|z₂|=6、|z₃|=38、|z₄|=1446——这正是"逃逸后以平方速率爆炸"的模样。

第四步：总结。 −1 和 i 留下（周期轨道，有界），2 逃走。Mandelbrot 集就是这样一"点"一"点"判出来的；边界的无限复杂来自周期与逃逸之间无穷细腻的分界线。∎

为什么是"无限复杂"？ 边界上的每个 c 对应一个"临界有界"的轨道：不逃逸、也不进入稳定周期。这些轨道在复平面上留下的"花状"图形千变万化，且自相似——放大边界任何一处，都会看到新的小 Mandelbrot 集挂在细须上。

Julia集——Mandelbrot集的"近亲"

固定c,Julia集J_c={z0:迭代z_{n+1}=z_n^2+c不发散}的边界。Mandelbrot集中的c->Julia集是连通的(一个整体)。Mandelbrot集外的c->Julia集是Cantor尘埃(完全不连通)。Mandelbrot集本质上是"Julia集的连通性地图"。

为什么两个对象要一起看？ Mandelbrot 集把"所有 c 的 Julia 集连通性"汇总成一张图：c 落在 M 内 ⟺ J_c 连通。于是 M 的复杂边界同时编码了无穷多个 J_c 的形态突变点——这就是"地图"的含义。

分形在自然界

海岸线、雪花、血管分支、肺部支气管树、山脉轮廓——都不是光滑的几何。Mandelbrot 1975年创造"fractal"一词，开启了"粗糙度作为可量化的几何量"的新视野。分形维数一般不是整数——这是分形最本质的特征。

为什么"粗糙度"能当几何量？ 海岸线的长度取决于你用什么尺子量：尺子越短，量出的长度越长（类似 Koch 曲线的 (4/3)ⁿ）。真正的"海岸线长度"因此没有定义，但"长度随尺子变短的速率"（维数）却有定义——分形把"模糊"变成了"精确"。

反例——可数集的 Hausdorff 维数为 0

设 A={a₁,a₂,…} 为任意可数集。对任意 s>0，用半径 δ2⁻ⁱ 的小球逐个盖住 a_i，则直径和 Σ(2δ2⁻ⁱ)^s=(2δ)^sΣ2⁻ⁱˢ→0（δ→0）。故 H^s(A)=0 对所有 s>0 成立，即 dim_H(A)=0。

由此得著名反例：有理数集 Q∩[0,1] 在 [0,1] 中稠密，但 Hausdorff 维数为 0——拓扑/直觉的"充满区间"在这里完全失效。这也说明 Hausdorff 维数与盒维数不同：Q∩[0,1] 的盒维数是 1。

为什么这个反例重要？ 它警告我们："到处稠密"与"占据体积/维度"是两回事。Q 在 [0,1] 里密密麻麻，却没有"体量"。任何靠直觉用"密度"代替"维数"的论证，在这里都会翻车——分形维数必须回到"覆盖测度"这个严格工具上来。

前沿：Mandelbrot集的局部连通性(MLC猜想)

MLC猜想:Mandelbrot集在所有参数处局部连通。这是复动力系统最重要的未解问题——Douady-Hubbard(1982)提出。它等价于"Mandelbrot集没有幽灵分支"。仍开放:仅对某些实参数和有限多个复数参数得证。

为什么 MLC 这么难？ 局部连通要求边界上"没有割断的细须"——每一处都像一束从一点发出的连续分支。但 Mandelbrot 集的边界上是否存在"断点"（幽灵分支的根），与深海般的复动力系统结构纠缠在一起。它一面连着 Koch 式的自相似，一面连着周期参数空间的分层——是分形几何与动力系统的交汇点。

工作题——计算 Cantor 集的维数

三分 Cantor 集：从 [0,1] 出发，每一步删去每个区间的中间三分之一。第 n 步剩 2ⁿ 个区间，每个长度 3⁻ⁿ。求其 Hausdorff 维数 D。

显示解答

与 Koch 同理：N_n=2ⁿ、ε_n=3⁻ⁿ，令 H^D~N_n ε_n^D=2ⁿ·3⁻ⁿᴰ=1 ⇒ 2ⁿ=3ⁿᴰ ⇒ D=log2/log3≈0.6309。推广公式：自相似分形把整体分成 N 个缩放因子为 r 的副本时，D=logN/log(1/r)。
