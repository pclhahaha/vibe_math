核心思想：任何周期波形都是正弦波的叠加。具体函数 f(x)=x 告诉我们系数怎么算（2(−1)^{n+1}/n），方波告诉我们谐波越多拼得越像。只想懂核心思想，看到〇到第四节就够。

〇·一、正弦波是什么？——频率/振幅/相位的直觉（声波、音叉）

先来认识本课唯一的主角：正弦波（sine wave）。它是一个像"连绵的波浪"那样的曲线，可以用三个数字完全描述——这三个数字就是本课最常用的三个术语，我们先用大白话把它们讲清楚。

频率（frequency）：波浪"有多快"，或者声音"有多高"。频率决定这个波每秒钟上下起伏多少次。频率高，就代表起伏得快，听起来是高音；频率低，起伏得慢，听起来是低音。比如音叉上写着 440，意思是它每秒振动 440 次，发出的就是我们常说的中央 A 音（钢琴上"标准音"）。中央 C 上面的 A 是 440 Hz，它的高八度是 880 Hz——频率加倍，音高刚好高一个八度。

振幅（amplitude）：波浪"有多高"，也就是声音"有多响"。振幅决定了波峰到波谷的"个头"。振幅大，声音响亮；振幅小，声音轻柔。你说话小声还是大声，改变的就是振幅。

相位（phase）：波浪"从哪里开始"。两个频率、振幅都一样的波，可以一个正好在波峰起步，另一个正好在波谷起步——这就是它们相位不同。相位不改变波"听起来"的频率和响度，但决定了它们在时间轴上的错位。就像两个步调一致的人，一个晚半拍出发。

为什么用音叉举例子？因为音叉发出的就是自然界里最"单纯"的声音——一个单一频率、单一振幅的正弦波，没有杂质。它是声音世界的"纯色"，其他复杂的声音都是靠它拼出来的。

正弦波 = 最简单的"纯音"。频率决定音高，振幅决定音量，相位决定起步位置。记住这三个词，本课就不难了。

〇·二、"拼波"的具体数字——用 sin x + ⅓sin 3x + ⅕sin 5x 拼出方波

现在请你做一个小实验：同时按下一个钢琴键和一个高一截的钢琴键，你会听到一个比单独按任何一个都"丰满"的声音。为什么？因为两个纯音（两个正弦波）在空中叠加（superposition）到了一起——同一时刻的"高度"相加，波浪的轮廓就变复杂了。

这个想法再往前推一步，就是本课最重要的思想：我们能不能反过来，用一堆简单的正弦波，拼出一个复杂的波形？

打个比方。一道菜的味道千变万化，但基本调料就那么几种；一种音色（timbre）听起来很有"质感"，其实也只是把几个纯音按不同比例混在一起。小提琴和长笛吹同一个音高，你为什么能分辨出来？就是因为它们混进去的"泛音"（比基频高的那些成分）比例不同。声音的"个性"（音色），本质上就是"每个频率加了多少"。

〇·三、傅里叶说的事——任何周期波形都能拼出来，谐波越多拼得越像

有了"拼波"的想法，傅里叶（Fourier，法国数学家）在 1807 年提出了一个大胆到让同行都怀疑的猜想，结果证明是对的：

任何一个周期的波形（就是每隔一段时间重复一遍的形状，不管多奇怪、多棱角），都可以用一堆不同频率的正弦波拼出来。

这里的"不同频率"不是随便挑的：它们必须是基频的整数倍。举个例子，如果基础频率是 1 次/秒，那能用的就是 1、2、3、4、5… 倍频率的正弦波。这些"整倍数频率"的成分，就叫谐波（harmonics）。

那拼得像不像呢？谐波越多，拼得越像。只取第一项（1 倍频），拼出来的是一个圆圆的光滑波，和目标的方形波差得很远；再加上第三、第五、第九、第十七……谐波，每加一个，拼出来的形状就在目标的尖角处"咬"得更紧一点。加得足够多（几百上千项），几乎就和原波形重合了——这就是"越多越像"。方波这种带尖角、带棱角的波形都能拼出来，那些圆润的波形就更不在话下了。

为什么这个发现如此重要？因为它把"一个复杂波形"这个看起来无从下手的东西，转化成了"一堆系数"（每个谐波各加多少）——存这些系数，就等于存下了整个波形。图像、音乐、信号的压缩与传输，全都建立在这个转换上。

傅里叶说的事：任何周期波形都能用基频整数倍的正弦波（谐波）拼出来；谐波加得越多，拼得越像。把波形换成"一串系数"，这就是傅里叶级数。

如果你想理解核心思想，看到这里就够了。后面的章节会把这些直觉变成严格的数学：正交基、傅里叶系数怎么算、为什么衰减速率对应光滑程度、以及从级数推广到傅里叶变换。

1807 年，傅里叶向法国科学院提交了一篇论文，声称任何周期函数都可以展开为正弦和余弦的级数。Lagrange 当场反对——"你怎么能用光滑的正弦叠加出有尖角的方波？"但傅里叶是对的（§十三 会解释：收敛到平均值、有 Gibbs 过冲，但确实收敛）。

傅里叶级数 = 在函数空间的"正交基"上展开。正弦和余弦是 L²[−π,π] 上的正交基——就像 (1,0,0)、(0,1,0)、(0,0,1) 是 ℝ³ 的标准正交基。傅里叶系数 = 函数在"基向量"上的投影；正交性把"解方程组"变成"做内积"。

五、为什么谐波系数按 1/n 衰减？——光滑性和衰减

函数越光滑→傅里叶系数衰减越快。方波（有跳变）:a_n~1/n。三角波（连续但导数有跳变）:a_n~1/n²。C^∞函数:a_n衰减快于任何多项式。解析函数:a_n指数衰减。傅里叶系数的衰减速率直接反映了原函数的光滑程度。

直觉：高阶谐波（频率高、振动密）只有靠近"尖角"才能产生明显影响。函数越光滑，"尖角"越少越钝，所以高频分量越不需要、系数越小。数学上，每做一次分部积分就会"吃掉"一个 n（因为 sin/cos 的积分或导数给出因子 1/n 或 n），系数衰减幂次 = 分部积分能安全进行的次数 = 光滑的阶数。

这也是为什么 JPEG 和 MP3 压缩有效——丢弃高频分量（小的系数）对感知质量影响最小。人眼和耳朵对高频不敏感→傅里叶变换→保留低频→丢弃高频→压缩。

六、傅里叶变换——从级数到积分

非周期函数→傅里叶积分：f̂(ξ) = ∫ f(x) e−2πi x·ξ dx。这是傅里叶级数的连续极限——将"离散求和"替换为"连续积分"。周期函数把频率"离散"成整数倍谐波；非周期函数把"周期推到无穷"，频率变成连续变量 ξ，求和就变成积分。Plancherel 定理：‖f̂‖₂ = ‖f‖₂——傅里叶变换是 L² 上的酉算子，能量在时域和频域守恒。

不确定性原理的傅里叶版本：函数越"集中"在时域→傅里叶变换越"分散"在频域，反之亦然。这和量子力学的 Δx·Δp≥ħ/2 是同一个数学现象——位置和动量互为傅里叶变换。

1. 20 个谐波时方波的 Gibbs 过冲还在——增加到 100 个会消失吗？提示：不会。过冲约 9% 且与项数 N 无关（见「反例」节的精确公式 lim s_N(x_N) − 1 ≈ 0.179）。增加谐波只会让过冲的位置更贴近跳变点，幅度不变。

2. 三角形波的傅里叶系数按 1/n² 衰减——为什么比方波"更光滑"？提示：方波本身有跳变（第 0 阶不连续）⇒ 系数 ~1/n；三角波连续、但导数在 x=0 处从 −1 跳到 +1（第 1 阶不连续）⇒ 系数 ~1/n²。规律：若第 k 阶导数首次出现跳变，系数按 1/n^{k+1} 衰减。连续 = 衰减至少快 1/n²。

3. 用傅里叶变换解释"时间-频率不确定性"：为什么短脉冲有宽频谱？提示：宽度为 Δt 的矩形脉冲的傅里叶变换是 sinc，主瓣宽度 ~1/Δt——脉冲越短，主瓣越宽。频谱越宽，说明需要越多的频率成分叠加才能"拼"出那个尖锐的脉冲，这就是 Δt·Δξ ≥ 常数。

4. 用 §二 的结果求 Leibniz 级数。在 f(x)=x 的级数中令 x=π/2，得到 1 − ⅓ + ⅕ − ⅐ + … = π/4。提示：sin(nπ/2) 只在 n 奇时非零，交替取 ±1。

5. 为什么级数里常数项写 a₀/2 而不是 a₀？提示：因为 ⟨1,1⟩ = (1/π)∫1² dx = 2，常数 1 这支"基向量"的长度平方是 2 而不是 1；投影公式给出 a₀ = ⟨f,1⟩，要还原 f 的常数分量需要除以 2。

6. 三角波 |x| 在 x=0 的级数值给出什么数？提示：0 = π/2 − (4/π)Σ_{odd}1/n² ⇒ Σ_{odd}1/n² = π²/8（见 §四 第五步）。这是 ζ(2) = π²/6 的"奇频版本"。

历史：从热传导到信号处理

Fourier（1807）在研究热传导时提出三角级数展开。Lagrange 当场反对——这个争议催生了分析学的严格化。Nyquist（1928）和 Shannon（1948）将傅里叶分析变成了信息论的基础——采样定理、带宽、压缩全部依赖傅里叶变换。

现代应用

JPEG 压缩 = 图像的离散余弦变换→保留低频→丢弃高频。MP3 = 音频的傅里叶变换→心理声学模型→丢弃听不到的频率。MRI = 梯度磁场 + 傅里叶变换重建体内图像。地震勘探 = 反射波的傅里叶分析确定地下结构。

前沿：压缩感知与稀疏傅里叶变换

Candes–Tao（2006）的压缩感知证明：如果信号是 k-稀疏的，可以用远少于 Nyquist 率的采样完美重建。稀疏傅里叶变换（SFT，Hassanieh 等 2012）对频谱稀疏的信号做 O(k log n) 而非 O(n log n)。仍开放：噪声鲁棒的稀疏变换和量子压缩感知。

九、工作题（带解答）

题 1（方波系数）。设 f(x)=1 (0<x<π)，−1 (−π<x<0)，周期 2π。求 aₙ、bₙ。

显示解答

f 是奇函数 ⇒ aₙ = 0（含 a₀）。bₙ = (1/π)∫_{−π}^π f(x)sin(nx)dx = (2/π)∫₀^π sin(nx)dx = (2/nπ)(1−(−1)ⁿ)。故 bₙ = 4/(nπ) 当 n 奇，bₙ = 0 当 n 偶。于是 f(x) = (4/π)Σ_{n odd}(sin nx)/n。

题 2（三角波系数）。设 g(x)=|x|，−π≤x≤π，周期延拓。求 a₀、aₙ、bₙ。

显示解答

g 是偶函数 ⇒ bₙ = 0。a₀ = (1/π)∫_{−π}^π|x|dx = (2/π)∫₀^π x dx = π。aₙ = (2/π)∫₀^π x cos(nx)dx = (2/π)[x sin(nx)/n + cos(nx)/n²]₀^π = (2/πn²)(cos(nπ)−1) = 2((−1)ⁿ−1)/(πn²)。故 aₙ = −4/(πn²) 当 n 奇，0 当 n 偶。即 |x| = π/2 − (4/π)Σ_{n odd} cos(nx)/n²。这与正文第四节完全一致。

题 3（Parseval 求和）。用 Parseval 等式求 (a) Σ_{n=1}^∞ 1/n²；(b) Σ_{n=1}^∞ 1/n⁴。

显示解答

(a) 对方波 f（题 1）：‖f‖²₂ = (1/2π)∫_{−π}^π|f|²dx = (1/2π)·2π = 1。Parseval：1 = a₀²/4 + ½Σ(aₙ²+bₙ²) = ½·Σ_{n odd}(4/nπ)² = ½·(16/π²)·Σ_{n odd}1/n²。故 Σ_{n odd}1/n² = π²/8。又 Σ_{n even}1/n² = ¼Σ1/n²，两式相加得 Σ1/n² = π²/6。

(b) 对三角波 g=|x|（题 2）：‖g‖²₂ = (1/2π)∫x²dx = π²/3。Parseval：π²/3 = a₀²/4 + ½Σaₙ² = π²/4 + (8/π²)·Σ_{n odd}1/n⁴。故 Σ_{n odd}1/n⁴ = (π²/3−π²/4)·(π²/8) = π⁴/96。又 Σ_{n even}1/n⁴ = (1/16)Σ1/n⁴，得 Σ1/n⁴ = π⁴/90。

题 4（收敛定理）。对题 2 的三角波，用 Dirichlet 定理说明傅里叶级数每点的取值，并解释为何无 Gibbs 现象。

显示解答

三角波 g(x)=|x| 在 [−π,π] 上连续，周期延拓后仍连续（|π|=|−π|=π 处衔接），但在 x=0 与 x=±π 处导数有跳变（g′ 于 0 处从 −1 跳到 +1）。Dirichlet 定理保证级数处处收敛到 g(x)（连续点收敛到 g(x)）；导数间断使系数按 1/n² 衰减（比跳变函数的 1/n 快），且函数本身无跳变，故无 Gibbs 过冲。代入 x=0 得 0 = π/2 − (4/π)Σ_{odd}1/n²，即 Σ_{odd}1/n² = π²/8，与题 3 互相印证。

题 5（锯齿波系数——左右端点不等的周期函数）。设 h(x)=x，0<x<2π，周期 2π（在 x=0 从 0 跳到 2π）。求 a₀、aₙ、bₙ。

显示解答

这不是奇函数也不是偶函数，所有系数都要算。a₀ = (1/π)∫₀^{2π}x dx = (1/π)·(4π²/2) = 2π。aₙ = (1/π)∫₀^{2π}x cos(nx)dx = (1/π)[x sin(nx)/n + cos(nx)/n²]₀^{2π} = (1/π)(1/n² − 1/n²) = 0。bₙ = (1/π)∫₀^{2π}x sin(nx)dx = (1/π)[−x cos(nx)/n + sin(nx)/n²]₀^{2π} = (1/π)(−2π cos(2πn)/n) = −2/n。故 h(x) = π − 2Σ(sin nx)/n。注意常数项是 π（端点跳变平均值 (0+2π)/2 = π 的体现）。

十、反例：Gibbs 现象与处处发散傅里叶级数

Gibbs 现象的数学解释。对方波 f（从 −1 跳到 +1，跳变 Δ=2），部分和在紧邻跳变点 x=0 处过冲。设 x_N = π/(2N) 为部分和 s_N 在跳变点右侧最近的极值点，则

过冲量 ≈ 0.179 ≈ 9% 的跳变幅度，与 N 无关——取再多谐波也不消失。原因：s_N 在跳变点附近的行为由 Dirichlet 核的振荡尾巴决定，s_N 在 [0,x_N] 上逼近固定的卷积极限函数；Riemann-Lebesgue 保证逐点收敛，但收敛在跳变点邻域非一致（sup 范数不收敛，因为过冲恒定）。几何本质：间断处级数收敛到左右极限的平均值，但"平均"在两侧各留约 9% 的永久凸包。对照：三角波（连续、导数间断）无 Gibbs 现象——过冲只出现在真正的跳变处。

处处发散的傅里叶级数（Kolmogorov）。du Bois-Reymond (1876) 构造了连续函数在某一点傅里叶级数发散。Kolmogorov (1923, 1926) 更强：存在 L¹[−π,π] 函数，其傅里叶级数几乎处处（甚至处处）发散。其构造依赖极强的振荡与频率叠加：用调和分析中"发散率"的精细估计逐级拼装，每一级都使新区间上的部分和无界（稠密性论证）。Carleson (1966) 证明 L² 函数的傅里叶级数几乎处处收敛——Kolmogorov 的例子因此必须恰在 L² 之外（L¹∖L²）：这精确刻画了 L² 与 L¹ 的差别。仍开放：是否存在连续函数，其傅里叶级数处处发散（目前只有 a.e. 发散与点态发散的例子）。

（右侧的"本节可动手探索"面板演示的是同一个核心现象：fₙ(x) = xⁿ 逐点收敛到极限、但非一致收敛——红刺永远在绿色 ε 管道之外。Gibbs 过冲正是"非一致收敛"在傅里叶级数里的翻版。）

十一、定理证明：Parseval 等式

陈述。对 f ∈ L²[−π,π]，设复系数 cₙ（或实系数 aₙ、bₙ）。则

证明。

① 正交性。函数系 {e^{inx}} 在 L²[−π,π] 中正交（差常数）：∫_{−π}^π e^{i(n−m)x}dx = 2πδ_{nm}。

② 投影公式（Bessel）。部分和 s_N = Σ_{|k|≤N}c_k e^{ikx} 是 f 在 span{e^{−iNx},…,e^{iNx}} 上的正交投影。由正交性，‖f−s_N‖² = ‖f‖² − Σ_{|k|≤N}|c_k|²（勾股定理），故 Σ|cₖ|² ≤ ‖f‖²（Bessel 不等式）。

③ 完备性。Weierstrass 第二逼近定理：三角多项式在 C[−π,π]（sup 范数）稠密，进而在 L² 稠密。故对任意 ε 存在三角多项式 p 使 ‖f−p‖₂ < ε；取 N 足够大使正交投影 s_N 不劣：‖f−s_N‖₂ ≤ ‖f−p‖₂ + ‖p−s_N‖₂ → 0。

④ 取极限。‖f−s_N‖²₂ = ‖f‖²₂ − Σ_{|k|≤N}|cₖ|² → 0 给出 Σ_{n=−∞}^∞|cₙ|² = ‖f‖²₂。实系数形式由 cₙ 与 aₙ、bₙ 的关系得到。∎

Parseval 是"勾股定理在函数空间"：傅里叶级数把 L² 中的能量 ‖f‖² 无损分解为各频率分量的能量和。它是 Plancherel 定理的周期版本，也是信号处理中"功率谱 + 能量守恒"的数学依据。用它还能反推 Σ1/n² = π²/6（见工作题 3）。
