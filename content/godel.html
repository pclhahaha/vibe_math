〇、直觉入门——先玩一局"自指"游戏

先玩一个游戏。在一张纸上写下这句话：

"这句话是假的。"

现在"运行"这句话，只有两条路可走：

→ 假设它为真：它说的是"这句话是假的"，于是它就应该是假的——矛盾。
→ 假设它为假：那么"这句话是假的"这句话本身是假的，也就是说它不是假的，于是它为真——还是矛盾。

两条路都通向矛盾。这就是两千年来困扰逻辑学家的说谎者悖论（liar paradox）：一句话谈论它自己（自指），就绕出了一个解不开的圈。逻辑学家当然想躲开它——所以给数学立下严格规则，想把"自己说自己"关在门外。

本课要问的问题：这个"自指"的圈，能不能在一个不矛盾（一致）的形式系统里"复活"？直觉上答案当然是"不能"。可 Gödel（1931）证明了令人不安的答案：能，而且根本挡不住。

但复活之后的它变了形态：不再爆炸成矛盾，而是变成一句"温和的真理"——系统里存在一个真句子，你既证明不了它，也证明不了它的否定。规则没有坏，只是永远漏着一个洞。这就是哥德尔不完备定理。

本课路线图（每步先直觉、后严格）：

→ 形式系统：规则、"证明"到底指什么（第一节）；
→ 算术编码：把"句子"变成"数字"，元数学走进算术（第二节）；
→ 替换函数：让一句话谈论"它自己"（第三节）；
→ 对角线构造：造出"我说我不可证"的句子 G（第四节）；
→ 两条定理：第一定理（存在不可证明的真理）与第二定理（系统不能自证一致）（第五、六节与"证明"章）。

一句话记住本课：规则足够强，就必然能"谈论自己"；而一旦能谈论自己，就必然存在它既证明不了、也否证不了的真理。不完备不是规则的缺陷，而是规则足够强大的代价。

一、形式系统：一场"符号操作"的证明游戏

要让数学证明能被机器检查，就得先立下"规矩"。一个形式系统（formal system）由三样东西组成：

① 符号（symbols）：允许出现的字符表，比如 0、s、+、=、括号。
② 公理（axioms）：一开始就无条件承认的句子，不需要证明。
③ 推演规则（rules of inference）：允许从已知句子合法地推出新句子的操作，每一步就像游戏里走一步。

证明（proof）就是一条从公理出发、每一步都按规则走、最终停在目标句子的脚印。一个句子只要存在这样一串脚印，就叫它在系统内可证明（provable）。关键点：这套规则只关心"符号怎么摆"，不关心符号"是什么意思"——正因为如此，证明才能被精确检查，甚至被机器验证。

用一个具体的小游戏来体会。著名的 MIU 系统：用大写字母 M、I、U 组成字符串，公理只有一条 MI，规则四条：

→ R1：以 I 结尾的串，可在末尾加 U（xI → xIU）。
→ R2：Mx 可改写成 Mxx（把 M 后面的内容复制一遍）。
→ R3：串中任意 III 可换成 U。
→ R4：串中任意 UU 可删去。

例题 0（热身的推演）：证明 MUIU 是定理。一步步来：

MI （公理）
→ MII （R2）
→ MIIII （R2）
→ MUI （R3：把中间的 III 换成 U）
→ MUIU （R1）

追问：MU 是定理吗？规则这么多、离得又近，但答案是否。理由是一个不变量：任何定理中 I 的个数都不能被 3 整除——公理有 1 个 I；R1、R4 不改 I 的个数；R2 把个数翻倍，翻倍不改变"能否被 3 整除"（2 在模 3 下可逆）；R3 减去 3，也不改变。而 MU 有 0 个 I，能被 3 整除，所以永远推不出来。

请注意这个现象的滋味："MU 不是定理"是我们站在系统外、用不变量证明的事实，可系统内部永远推不出 MU。这种"关于系统的真理"与"系统能推出的结论"之间的裂痕，正是哥德尔要挖到最深处的东西。

最后立下两个贯穿全课的定义：

一致性（consistency，无矛盾）：不存在句子 φ，使 T⊢φ 且 T⊢¬φ。等价地说，系统不会证明矛盾，从而不会"什么都能证"。
完备性（completeness）：对每个句子 φ，要么 T⊢φ，要么 T⊢¬φ——每个问题系统都给得出答案。

形式系统＝符号操作游戏：意义被关在门外，只留下可机械检查的推演。而"证明可检查"正是这一切的地基——正因为如此，"证明"本身才可能变成研究对象（第二节），也正因为如此，系统才可能"谈论自己"。

第三步：两条路，逐一堵死。

→ 若 T⊢G：那么存在一个真正证明 G 的数 n，由表示性，T 能证明 Prf(n, ⌈G⌉)，进而 T⊢Provable(⌈G⌉)。但 G ↔ ¬Provable(⌈G⌉) 又给出 T⊢¬Provable(⌈G⌉)——矛盾于一致性。所以 T 证不出 G。

→ 若 T⊢¬G：由 G ↔ ¬Provable(⌈G⌉) 推出 T⊢Provable(⌈G⌉)。但另一方面，T 证不出 G（上一步），于是对每个具体数字 n，n 都不是 G 的证明，由表示性 T⊢¬Prf(n, ⌈G⌉) 对每个 n 都成立；ω-一致性（比一致性稍强的假设，见"证明"章）就推出 T 证不出 ∃x Prf(x, ⌈G⌉)——与 T⊢Provable(⌈G⌉) 矛盾。所以 T 也证不出 ¬G。

第四步：G 是真的。G 的内容就是"我没有证明"。而我们刚刚在元层次证明了确实没有证明（T⊢G 不可能），所以 G 在标准模型中为真——只是这个"真"是站在系统外面说的事实，系统内部恰恰证明不了它。

说谎者悖论说"这句话是假的"——矛盾；Gödel 说"这句话不可证"——不矛盾，只是成了漏网之鱼。把"假"换成"不可证"，矛盾就成了不完备。这一句话，就是整门课。

五、完备性与一致性：分清两条不同的"轴"

先并排摆出两个定义，它们极易混淆：

一致性说的是"不矛盾"，完备性说的是"每个问题都有答案"。它们不是一回事：一个系统可以一致但不完备（PA），可以完备但不一致（矛盾系统平凡地完备），可以一致且完备但太弱（Presburger 算术）。哥德尔定理堵死的是"又强、又一致、又完备"这个组合。

例题 4（三个系统逐一对照）：

→ (a) 不一致的系统：公理同时含 φ 和 ¬φ，再用规则"从矛盾推出任何句子"（爆炸原则）。结果什么都能证，于是完备（平凡地）——但自相矛盾，毫无价值。结论：完备，但不一致。
→ (b) Presburger 算术（自然数 + 加法，无乘法）：一致且完备、可判定。注意它躲过不完备的原因：没有乘法，就做不了素因子分解，定义不了替换函数 sub，于是无法自指。结论：一致、完备，但太弱。
→ (c) Peano 算术 PA（加法 + 乘法）：一致（在更强的元理论中可证——Gentzen 用 ε₀ 归纳证明了它）、够强，于是不完备。结论：一致、够强、不完备。

还要分清真（truth）与可证（provable）：在 Presburger 里两者重合；在 PA 里分家了——G 在标准模型为真却不可证。别把"系统证明不了"误读成"数学不知道答案"。

不完备定理是"完备性 + 一致性 + 足够强"三者不可兼得的精确表述。想同时拥有三者？唯一出路是把系统做弱到不能自指（Presburger 路线）——这就是"强大的代价"。

六、不完备是特征，不是缺陷

不完备定理不是说"数学不可靠"。它们是关于形式系统表达能力的深刻定理：足够强的系统必然包含"自己无法证明的真理"。这不是系统的 bug——是系统足够强大的必然代价。

弱系统（Presburger 算术：自然数 + 加法，无乘法）是完备且可判定的。不完备来自算术的丰富性——特别是乘法。为什么恰恰是乘法？因为素因子分解依赖乘法，替换函数 sub 依赖素因子分解，自指依赖 sub——没有乘法，自指这台机器根本转不起来。所以"不完备"＝系统强大到能谈论自身。

还有一个更细的层次值得注意：不需要完整的 PA。Robinson 算术 Q（有限条公理，只含算术基本运算）就已经不完备。所以不完备不是"公理太多"的毛病，而是"语言足够表达自身"的必然。

七、和计算机科学的联系

Turing（1936）把不完备定理翻译为计算语言：停机问题不可判定（halting problem，通俗说：不存在一个程序，能检查出任意程序会不会永远跑下去）。证明结构几乎相同：假设存在 HALT 程序 → 构造"当且仅当自己不停机才停机"的程序 → 矛盾。Gödel 和 Turing 在同一个逻辑边界上工作——Gödel 从证明论端，Turing 从计算论端，两边摸到的是同一堵墙：可证明/可计算的界限。

Curry–Howard 同构：证明＝程序，命题＝类型。Gödel 不完备 ＝ 存在类型正确的表达式，但不是所有程序都能归约到范式（停机）。这是类型论和程序语言设计的核心约束：类型系统再强，也不能同时保证"每个类型正确的程序都终止"且"覆盖所有程序"。

这个家族还有第三个成员：Tarski 定理——算术的真不可定义（见"反例"）。证明力、可计算性、可定义性，共享同一道对角线。

反例——边界、假完备与自指的"安全区"

反例 1：Presburger 算术是"不完备定理"的边界反例。它一致、完备、可判定——说明不完备不是算术的普遍属性，而是"能编码乘法/能自指"的系统的属性。离开乘法，Gödel 论证的每一步都失灵：没有唯一分解、没有 sub、没有自指。

反例 2：不一致系统平凡地完备。若 T 不一致，则"从矛盾推出一切"让每个句子都可证，完备性平凡成立——但这恰恰说明完备性单独不足取。哥德尔定理的震撼在于"一致 + 完备 + 够强"三者不可兼得，缺一不可。

反例 3：一致但 ω-不一致的系统可以证 ¬G。Gödel 原始论证需要 ω-一致性；存在一致却 ω-不一致的理论——例如 PA + ¬Con(PA)：由第二定理它一致，但它证明 ¬Con(PA)（即"存在证明矛盾的编码"），同时对每个标准数字 n 都证明 ¬Prf(n, ⌈0=1⌉)——正是 ω-不一致。这解释了为什么 Rosser 必须把假设降为普通一致性，也打开了"标准模型之外还有别的模型"（非标准模型）的入口。

反例 4：Löb 定理——自指不一定产生悖论。"这个句子可证"是可以证明的：若 T⊢Provable(⌈S⌉)→S，则 T⊢S。自指不是敌人，关键在于句子断言什么："我是假的"→矛盾；"我不可证"→不完备；"我可证"→没问题（可证）。自指是一台中性的机器，装什么进去由你决定。

反例 5：Tarski 定理——"真"不可定义。若存在公式 True(x) 表示"编码为 x 的句子为真"，则由对角引理可得 S ↔ ¬True(⌈S⌉)，即"我是假的"——矛盾。所以"真"不能成为算术公式，而"可证"可以。这就是为什么 G 的"真"只能站在系统外面说，也是"真 ≠ 可证"最深层的证据。

工作题——试试看（带提示）

工作题 1（编码）。计算 gn("0 + 0 = 0") 和 gn("x₁ = x₁") 的素数幂展开。

提示：查符号表（0→1, +→5, =→9, x₁→31）；公式第 k 个符号对第 k 个素数取幂。7⁹ 很大，可以只写到素数幂展开，再给出第一个式子的完整数值。

显示解答

"0 + 0 = 0" 的符号编号为 [1, 5, 1, 9, 1]，故
gn = 2¹·3⁵·5¹·7⁹·11¹ = 2·243·5·40353607·11 = 1,078,651,915,110。
"x₁ = x₁" 的符号编号为 [31, 9, 31]，故 gn = 2³¹·3⁹·11³¹（数值约 8×10⁴⁵）。

工作题 2（替换函数）。计算 sub(gn(x₁ + 0 = x₁), 3)，写出结果公式的符号串及其编码的素数幂展开。

提示：数字 3 的数字名是 sss0（编号 [3, 3, 3, 1]）；把原公式里两个自由 x₁ 都替换掉。

显示解答

结果公式是 sss0 + 0 = sss0，符号编号为 [3,3,3,1,5,1,9,3,3,3,1]，故
gn = 2³·3³·5³·7¹·11⁵·13¹·17⁹·19³·23³·29³·31¹。

工作题 3（对角线固定点）。用对角化构造 φ(x₁) = "x₁ = 0" 的固定点 ψ，并判断 ψ 在标准模型中的真假。

提示：仿照"证明——对角引理"：先设 m = gn("x₁ = 0")；ψ 是把 m 代入 φ 得到的句子，即"sub(m, m) = 0"。再问：sub(m, m) 到底等于什么？

显示解答

m = gn("x₁ = 0") = 2³¹·3⁹·7¹。ψ = "sub(m, m) = 0"，由对角引理 T⊢ψ↔(⌈ψ⌉ = 0)。而 sub(m, m) = d(m) = ⌈ψ⌉ 是一个巨大的数，不等于 0，故"⌈ψ⌉ = 0"在标准模型中为假，ψ 也为假。关键教训：对角引理对任何 φ 都造得出固定点（哪怕 φ 恒假）——自指是机器，不是悖论；固定点的真假由 φ 本身决定。

工作题 4（区分完备性与一致性）。对下列四个系统逐一判断"一致？完备？"，并解释。(a) 语言 {0, s, =}，公理 "0 = 0"，无推演规则；(b) 同语言，公理 "0 = 0" 和 "¬(0 = 0)"，规则是从矛盾推出任何句子；(c) Presburger 算术（自然数 + 加法）；(d) Peano 算术 PA（加法 + 乘法）。

提示：回顾定义——一致＝推不出矛盾；完备＝每个句子或其否定可证。先问：(a) 能证出几个句子？(b) 能证出几个？(c)(d) 直接用第五节结论。

显示解答

(a) 一致，但不完备——无规则时只有公理 "0 = 0" 可证，像 "s0 = s0" 这样的句子及其否定都不可证。
(b) 不一致（公理直接给出矛盾），由爆炸规则什么都能证，故完备（平凡地）——完备性单靠"一致"远远不够。
(c) 一致且完备（Presburger），但太弱，无法自指。
(d) 一致（假定）且够强，故不完备。
结论：完备性与一致性互相独立，"强 + 一致"才是难对付的组合。

工作题 5（自指骨架）。用本课的思想解释：为什么"停机问题不可判定"与"不完备定理"共享同一个自指骨架？

提示：假设存在程序 HALT(p) 判定任意程序是否停机。构造程序 D："调用 HALT(D)，如果 D 会停机，D 就不停机"。看看 HALT(D) 该返回什么。

显示解答

反设 HALT 存在。程序 D 的做法：先调用 HALT(D)，若它回答"D 停机"，D 就进入死循环（不停机）；若回答"D 不停机"，D 就立即停机。于是 HALT(D) 回答哪个都自相矛盾。这正是算术里造 G 的同一台机器：把"自己"喂给自己，再用"不"翻转答案。可证性/停机这类元概念一旦能表达（编码成数/程序），就必然包含自己的对角线——所以证明论与计算理论摸到的是同一堵墙。

前沿：证明论序数与反推数学

第二不完备定理给出一个任务清单：要证明更强的系统一致，必须借助系统外的更强手段，而"更强"可以有序数来度量——这就是证明论序数纲领。Peano 算术的理论强度＝ε₀，Gentzen（1936）正是用 ε₀ 归纳证明了 PA 的一致性，绕过了不完备定理——"有限"不够，但"可接受的构造性方法"够。

反推数学（Reverse Mathematics）：从数学定理反向推出需要的公理。大多数本科微积分等价于 WKL₀（弱 König 引理）。仍开放：哪些数学定理严格需要超越 PA 的更强公理（Higman 定理 = Borel 确定性 = 超越 PA）。
