〇、直觉入门——一把任何人都能锁、只有你能开的锁

几千年来，密码学有个死穴：发信人与收信人必须先共享一个秘密（密钥）。凯撒密码、恩尼格玛机、AES 全都如此——可两个陌生人隔着互联网，怎么安全地共享秘密？1976 年 Diffie 与 Hellman 在论文 "New Directions in Cryptography" 中提出一个颠覆性想法：公钥密码。每个人公开一把"锁"（公钥），任何人都能用它把消息锁进箱子；但开锁的"钥匙"（私钥）只有你一个人有。不需要事先共享任何秘密，陌生人都能给你寄密信。

1977 年 Rivest、Shamir、Adleman 给出了第一个实用公钥方案——RSA，它建筑在一个教科书般的算术事实上：

把两个大素数乘起来，一秒钟；把乘积分解回素数，人类最好的算法（数域筛法）也要指数时间。这就是单向函数的候选：正着算容易、反着算极难。RSA 的妙处在于它还有一扇"后门"：如果你知道 p、q（私钥），解密就变得容易——这种"带陷门的单向函数"叫陷门置换。公钥 = 锁 + 广告；私钥 = 那对素数 p、q。

洞察：RSA 的正确性是一行欧拉定理（m^{ed}≡m mod n），安全性是一个未证假设（分解困难）。它是"数学能做密码"的第一次成功示范：把"难"建立在数论问题的平均情形困难上——与 P≠NP（最坏情形）相关但不等价（→ P vs NP 课）。而 1994 年 Shor 证明量子计算机能多项式时间分解——"数学锁"第一次在物理面前露出裂痕（→ 量子门 课）。
⚠️ 背景提示：本课属于 核心 级别。

建议先掌握：素数筛（素数与整除）、抽象代数（模 n 的环与单位群）、群作用（可选：欧拉定理的群论视角）。安全性讨论需要 P vs NP 与 量子门 的背景。

一、一个具体问题——1977 年 RSA 到底做了什么

密钥生成。 选两个大素数 p、q，令 n=pq，并计算 φ(n)=(p−1)(q−1)。选加密指数 e（与 φ(n) 互素），解 ed≡1 (mod φ(n)) 得私钥 d。公开 (e,n)，保密 d（以及 p、q、φ）。

加密与解密。 消息 m（看成小于 n 的数）：

为什么解密能还原？ ed=1+kφ(n)，故 c^d = m^{ed} = m^{1+kφ(n)}。由欧拉定理 m^{φ(n)}≡1 (mod n)（gcd(m,n)=1 时），于是 m^{ed}≡m。若 m 与 n 不互素（m 恰是 p 或 q 的倍数——实际概率 ~1/p 可忽略），用中国剩余定理补全同一结论（第五节）。

为什么这"安全"？ 攻击者知道 n、e、c，要恢复 m 或私钥 d。最直接路线是分解 n（得 φ 与 d）。至今没有多项式时间分解算法；公认最快的通用算法是数域筛法（GNFS），运行时间约

n 取 2048 位时这在工程上不可行。诚实声明：RSA 的"安全性"是一个假设（RSA 假设：求 e 次根模 n 困难），它没有被证明等价于分解困难——数学上仍可能有不需要分解就破解 RSA 的方法。密码学现代理论（Goldwasser–Micali 1984 起）把这类假设做成精确的"归约安全"体系。

二、先直觉后严格——"乘方取模"为何又慢又快到正好

计算 m^e mod n 其实很快。 用"平方-乘"（反复平方）法：把 e 写成二进制，从低位起反复平方底数、按位乘入结果——只需 O(log e) 次乘法，每次 O((log n)²) 位运算。e 有 2048 位，整个过程毫秒级。指数运算是"看着吓人、算着飞快"的典型。

而"求离散对数/分解"没有已知捷径。 关键在于模运算"搅乱"了结构：m^e mod n 的表观随机性来自乘法群 ℤ_n* 的循环行为。密码学赌的就是：正向（幂）在群结构里是便宜的，反向（根/对数）在群结构里没有统一捷径。

单向函数与 P vs NP 的精确关系。 单向函数存在 ⟹ P≠NP（若 P=NP，反演多项式可解，没有单向函数）；但反过来 P≠NP 是否给出单向函数未知——因为密码学需要的是平均情形困难与可采样分布，而 P≠NP 只承诺最坏情形。这就是为什么"分解难"目前只是一个假设而非定理（尽管它已被赌了几十年）。

正确性 = 数论定理（免费）；安全性 = 计算复杂性假设（付费）。RSA 把"数学之美"与"工程之赌"缝在一起：欧拉定理保证锁一定能开，GNFS/量子算法决定锁能撑多久。理解这个结构，才算理解现代密码学。

三、例题 1——手算一套完整的微型 RSA（一步步算完）

题目。 p=5、q=11。加密消息 m=7，再解密验证。

第一步：公开参数。 n=pq=55；φ(n)=(5−1)(11−1)=40；选 e=3（gcd(3,40)=1）。

第二步：私钥。 解 3d≡1 (mod 40)：3·27=81≡1 ⟹ d=27。

第三步：加密 m=7。 用平方-乘：7²=49≡49；7⁴=49²=2401≡2401−43·55=2401−2365=36？算：55·43=2365，2401−2365=36；c=7³=7²·7≡49·7=343≡343−6·55=13。

第四步：解密 c=13。 求 13²⁷ mod 55：13²=169≡4；13⁴=16；13⁸=16²=256≡36；13¹⁶=36²=1296≡1296−23·55=31。故

逐乘：31·36=1116≡16；16·4=64≡9；9·13=117≡7 = m ✓ 解密成功。∎

第五步：画布检查。 本课画布用这套参数（p=5,q=11,e=3,m=7）会自动得到 c=13、解密回 7；你可以换参数亲手"跑一遍密码"。真实 RSA 的差别只在位数：p、q 是 1024 位的素数（n 2048 位），上面的算术原样进行，只是数更大。

四、例题 2——Diffie–Hellman 密钥交换手算（一步步算完）

题目。 公开素数 p=23 与生成元 g=5。Alice 取 a=6，Bob 取 b=15。双方如何得到共享密钥？窃听者 Eve 看到什么？

第一步：Alice 发 A。 A=g^a=5⁶ mod 23：5²=25≡2、5⁴=4，故 A=5⁶=5⁴·5²≡4·2=8。Alice 公开 A=8。

第二步：Bob 发 B。 B=g^b=5¹⁵ mod 23：5⁸=5⁴·5⁴=16、16·5⁴=64≡18、18·5²=36≡13、13·5=65≡19，故 B=19。Bob 公开 B=19。

第三步：各算共享密钥。 Alice 算 B^a=19⁶ mod 23：19²=361≡16、19⁴=3，故 19⁶=19⁴·19²≡3·16=48≡2。Bob 算 A^b=8¹⁵：8²=64≡18、8⁴=2、8⁸=4，故 8¹⁵=8⁸·8⁴·8²·8≡4·2·18·8：4·2=8、18·8=144≡6、8·6=48≡2。两人都得到 s=2。∎

第四步：Eve 的困境。 Eve 看到 p=23、g=5、A=8、B=19，但不知道 a=6 或 b=15；要算 g^{ab} 需要解离散对数（从 8 反推 a）。模 23 太小她一试便知；但 p 取 2048 位素数时，离散对数（CDH/DDH 假设）被视为不可行——DH 的安全性就赌在这里。∎

第五步：实战结构。 实际互联网不用"教科书 DH 裸奔"：现代协议（TLS）用 ECDHE（椭圆曲线版，→ 椭圆曲线 课）协商密钥，再用 AES 等对称加密传输数据（混合加密）——公钥只用来"握手"，对称密码负责"干活"。

五、严格陈述——本课核心事实清单

  • 完美保密（Shannon 1949）： 一次性便签（OTP）——密钥与消息等长且真随机时，密文与消息统计独立，信息论意义不可破；代价是密钥分发（鸡生蛋问题）——这正是公钥要解决的。
  • RSA 正确性： ed≡1 (mod φ(n)) ⟹ m^{ed}≡m (mod n)（欧拉定理 + CRT 处理 m 与 n 不互素的情形）。
  • 素数判定 ∈ P（AKS 2002）： 判定 n 是否素数是多项式时间的——生成大素数容易；分解 n 却没有多项式算法已知——"验证难易不对称"是公钥的全部赌注。
  • 分解的最好算法： 数域筛法（GNFS，Lenstra 等），次指数时间 exp(O((ln n)^{1/3}(lnln n)^{2/3}))；量子：Shor 算法 O((log n)³) 多项式——量子计算机威胁 RSA/DH/ECC（公钥），对 AES 仅 Grover 二次加速。
  • 假设体系： 分解假设、RSA 假设、CDH/DDH——现代密码学把每个方案归约到明确的困难问题（Goldwasser–Micali 1984 语义安全；随机预言机模型）。
  • 实现注意（教科书 RSA 不安全）： 需 OAEP 填充（防低指数/广播攻击、Coppersmith）、签名需哈希+PSS；随机数质量差会导致共享素数（批量 GCD 攻击）。

七、延伸——从 RSA 到现代密码前线

  • 椭圆曲线密码（ECC）。 同样的公钥框架搬到椭圆曲线群的离散对数上（→ 椭圆曲线与 Wiles 课）：256 位 ECC ≈ 3072 位 RSA 的安全性——你手机里的 TLS 早已是 ECDHE 的天下。
  • 量子威胁与后量子密码。 Shor 算法宣告 RSA/DH/ECC 在量子计算机前失效；NIST 后量子竞赛 2022/2024 选定格基方案（Kyber/ML-KEM、Dilithium）——安全性建立在格上带错误学习（LWE）问题上，它与"最短向量问题"（SVP）一样没有已知量子捷径。→ 量子门 课。
  • 全同态加密（Gentry 2009）。 在加密的数据上直接计算：E(m₁)+E(m₂)=E(m₁+m₂)。隐私计算、联邦学习的数学引擎——"把计算搬进密文里"的二十年工程化。
  • 数字签名与区块链。 签名 = 私钥"签署"消息、公钥验证；哈希链把交易串成账本——比特币/以太坊的安全支柱是 ECDSA/哈希，全部站在本课的概念上。
  • 理论密码学。 混淆（iO）的候选构造、可验证延迟函数、安全多方计算（MPC）——"一群互不信任的人共同计算一个函数而不泄露输入"是理论计算机给密码学的最新玩具。

八、反例与陷阱——五个"密码想当然"

陷阱 1："RSA 安全已被证明 = 分解困难"？ 没有。RSA 假设（求 e 次根）与分解假设是两个不同假设；存在理论模型说明"分解难 ⟹ RSA 难"未必成立。工程上大家都赌它们都难，但数学上两者关系仍开放。

陷阱 2："教科书 RSA（直接 m^e）够用"？ 不够。e=3 且消息小时 m^e<n，开三次方即破（低指数攻击）；同消息发给 e 个接收者可广播攻击恢复 m；Coppersmith 定理对"已知部分消息"的攻击更致命。填充（OAEP）不是装饰，是安全性的组成部分。

陷阱 3："n 够大就绝对安全"？ 安全还依赖实现：随机数生成器坏了（两个用户共享一个素数 → 批量 GCD 秒破）、侧信道（计时/功耗泄露 d）、以及"先记录后解密"（量子崛起后历史流量可被回溯破解）。"密钥大小"只是安全链的一环。

陷阱 4："签名 = 私钥加密的朴素版"？ 教科书 RSA 签名（s=m^d）不安全（存在性伪造：s₁s₂ 是 m₁m₂ 的合法签名）。现代签名需要哈希 + 概率填充（PSS）。"公钥加密"与"数字签名"是两种原语，不能互相朴素替代。

陷阱 5："量子计算机来了，密码学全完"？ Shor 只摧毁公钥（RSA/DH/ECC 的代数结构）；对称 AES 只受 Grover 二次加速（密钥长度翻倍即可）；后量子格密码（Kyber/Dilithium）已经标准化。密码学在迁移，不是终结。

九、当前状态——密码学的地图边界

  1. 后量子迁移。 NIST 已定稿 ML-KEM/ML-DSA（Kyber/Dilithium，2024 标准）；全球基础设施（TLS 1.3 混合模式）正在迁移——这是未来十年最大的密码工程。
  2. 基础假设仍未解。 单向函数是否存在？它与 P≠NP 的确切关系？分解/离散对数是否有经典亚指数以下算法？——50 年来这些问题纹丝不动，是理论计算机最深的地基之一。
  3. 同态与隐私计算。 全同态加密从"存在性证明"走向"硬件加速的实用系统"；多方的安全计算在联邦学习、医疗数据共享落地。
  4. 密码学与量子纠缠。 量子密钥分发（QKD）用物理定律换安全（窃听必扰动）；与"计算假设"路线互补——"物理安全"与"数学安全"的争论是当代密码学的文化前沿。

工作题——小参数手算与概念辨析

题 1（RSA 全套）。 p=7、q=13：算 n、φ(n)；取 e=5，求 d。提示：n=91、φ=72；5d≡1 (mod 72) ⟹ d=29（5·29=145≡1）。

题 2（加密一步）。 用上题的 (e,n)=(5,91) 加密 m=10。提示：c=10⁵ mod 91：10²=100≡9、10⁴=81、10⁵=810≡82。c=82。

题 3（为什么 e 要互素）。 若 gcd(e,φ(n))≠1，为什么解密必然失败？提示：需要 ed≡1 (mod φ(n))；e 不互素时模 φ 无逆元，幂映射 m↦m^e 不再可逆（欧拉定理的指数运算要求 e 在模 φ 的单位群里）。

题 4（欧拉定理验证）。 验证 2^{φ(35)}≡1 (mod 35)（φ(35)=24）。提示：2⁴=16、2⁸=256≡11、2¹⁶=121≡16、2²⁴=2¹⁶·2⁸=16·11=176≡1。✓

试试看——练习与提示

试试看 1（画布跑 RSA）。 在画布选 (5,11) 预设并输入 m=7：验证 c=13、解密回 7。再试 e=3 与 m=1、2 等小消息——想"为什么小消息没被 e=3 攻破"？（提示：m^e<n 时开方即可；55 太小 m=7 时 343>55 已取模，实战里 OAEP 填充防的正是 m^e<n 那类。）

试试看 2（试除法动画）。 点"暴力分解"：对 (5,11) 立即试到 5；对 (61,53) 要试 53 步；n 每大一位试除成本翻倍——把步数换算成 2¹⁰²⁴ 就明白 2048 位 RSA 为何"试除不可行"。

试试看 3（与量子课联动）。 在 量子门 课回想 Shor 的三步（周期发现→连分数→分解）：本课 RSA 的 n 越大，量子优势越明显——2048 位 RSA 在量子计算机上"几分钟"。提示：这是 2024 年 NIST 后量子标准出台的直接原因。

试试看 4（共享素数攻击）。 想象两家机构各自随机选素数建 RSA，结果其中一家复用了一家用过的 p。窃听者只需对两个公钥 n₁=pq₁、n₂=pq₂ 求 gcd——一行 Euclid 算法即得 p，两家全破。提示：这正是 2012 年真实发生的"批量 GCD"大规模攻击（Lenstra 等扫描全网公钥）。
