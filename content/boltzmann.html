〇、直觉入门——为什么热水会变凉，而冷水从不自动变热

把一滴墨水滴进一杯水，墨水会慢慢散开、混匀，从来没人见过它自动聚回一滴。热水放在桌上只会变凉，从不自动变热。把这段录像倒过来放，你一眼就能看出"不对"。为什么？

Boltzmann 的整个理论（本课分两半）就是回答这个"为什么"的：前半给出"平衡时分子怎么分配"的精确公式——Boltzmann 分布：处于能量 E 的某个微观状态的相对概率是 e−E/kT。为什么是指数？因为这背后是"数排法"：能量越高，热库能"腾出来"安排它的方法越少。后半给出"系统怎么一步步走到平衡"的运动方程——Boltzmann 方程，它描述亿万个分子整体如何从有序走向乱糟糟的平衡，以及为什么这个过程不可逆。

这门课同时是两门学科的地基：统计力学（由配分函数算一切热学量）和气体动理学（由输运方程算输运系数）。先给一个带数字的预告，勾住你的好奇心——一个 0.1 eV 的激发能级，在室温（300 K，kT ≈ 0.0259 eV）下被占据的概率只有约 2%。为什么这么少？第四节你会亲手把这个 2% 从零算出来。

核心思想：平衡不是"均匀"，而是"按能量指数衰减的占据率"。越高的能量态越难被占据，因为热库能"配"给它的微观排法太少。只想懂核心思想，看到〇到第六节就够；想看微观不可逆性的动力学证明（H 定理、Loschmidt 悖论），从第八节开始。

一、具体问题：两个能级、4 个分子——把"乱"数出来

先忘掉温度，做一件人人都能动手的事：数排法。设想一个小盒子，里面有 4 个可区分的分子（真分子是天文数字，先用 4 个练手）。每个分子要么躺在能量 0 的基态，要么站在能量 ε 的激发态（ε 是一个数，比如 0.1 eV）。

"只看有几个分子在激发态"，这叫宏观状态：n=0、1、2、3、4（总能量是 nε）。"具体到哪几个分子在激发态"，这叫微观状态。关键差别：同一个宏观状态，往往有不止一种微观实现——有多少种，就叫它的"多重度" W。

八、微观可逆如何产生宏观不可逆？——H 定理与 Loschmidt 悖论

牛顿方程在 t → −t 下完全对称。如果每个分子都遵守时间可逆的力学定律——为什么热水会变凉而不会自动变热？宏观不可逆性从哪来？

Boltzmann 1872 年的回答：H 定理。定义 H(t) = ∫ f log f dv（f 是速度分布函数）。从 Boltzmann 输运方程可严格证明 dH/dt ≤ 0——H 永不增加。平衡态时 H 最小，f 恰为 Maxwell 分布。又因为 S = −kH，H 递减正对应熵增加（永不减少）。注意：这里 H 的单调性不是"经验"，而是从输运方程推出的数学结论。

Loschmidt（1876）当场反驳：如果所有分子速度瞬时反转，系统应沿原轨迹返回——H 应增加！Boltzmann 的回答是："继续走下去，不必回头。"（意思是：反转后的系统再次演化，H 照样往下跌。）这场辩论至今没有完全终结——它逼出了下一节的时间箭头之谜。

九、为什么 H 定理不违反时间反演？——分子混沌假设

Boltzmann 方程的推导隐含了一个至关重要的假设——分子混沌假设（Stosszahlansatz，德文原义"碰撞数假设"）：两个即将碰撞的粒子，其速度在碰撞前不相关。这个假设本身是时间不对称的——碰撞之后粒子速度确实相关了（它们刚交换过动量），但碰撞之前被假设为彼此独立。粗粒化（只跟踪单粒子分布 f，丢掉两体以上的关联）就把不可逆性引进了本来可逆的微观世界。

换句话说：H 定理成立的真正原因是方程只在"朝前"的方向上正确。速度反转后的系统，其演化史不满足同一个（作了分子混沌假设的）方程。这不是矛盾，而是"方程适用范围"的说明。

严格程度如何？Lanford（1975）在极短时间内、Grad 极限下，从 Liouville 方程（精确的 N 体方程）严格推导出了 Boltzmann 方程——这是统计力学中少数几条从微观到宏观的严格推导之一。但任意长时间、一般情形的严格推导至今仍然开放（见第十七节）。

不可逆性从哪来？不是从牛顿方程来，而是从"假设碰撞前不相关"这个时间不对称的截断来。Loschmidt 的反转论证失效，正是因为反转后的轨迹不满足同一个截断方程。

十、Boltzmann 方程的数学挑战——150 年未解的偏微分方程

Boltzmann 方程长这样（v 是速度，Q 是碰撞项）：

左边 = 自由输运（线性，好对付）；右边 = 碰撞积分，对 f 是二次非线性（两个粒子同时到场，概率 ∝ f·f），还带速度与散射角的五重积分。这个方程太难了：

全局光滑（强）解的适定性至今完全开放——物理学家努力了 150 年。已知进展：DiPerna–Lions（1989）证明了全局重整化弱解的存在性；Desvillettes–Villani（2005）在附加正则性假设下证明了弱解向平衡态（Maxwell 分布）的收敛——Villani 2010 年凭相关非线性稳定性工作获 Fields 奖。但"从任意初始数据出发、全局光滑强解的存在唯一性"仍然悬而未决。

为什么物理问题要抠数学细节？因为 f 的正则性直接关系到"宏观不可逆性能否严格成立"——光滑解存在，H 定理才是逐点成立的定理；弱解只能给到积分意义的结论。

Boltzmann 方程 = 二次非线性 + 高维积分 + 全局时间。物理直觉它必然可解，数学上光滑解适定性 150 年未解决。这是 Hilbert 第 6 问题（见第十七节）的核心案例。

提示：总能量 = 各分子能量之和，e−βE = Πe−βEᵢ 是乘积，求和可逐分子分解：Σ…Σ Πᵢ e−βEᵢ = Πᵢ(Σ e−βEᵢ)。注意这要求分子可区分且无相互作用；全同粒子会有 1/N! 修正（Gibbs 因子）。

5. Boltzmann 方程碰撞项 Q(f,f) 为什么是二次的？
提示：一次碰撞同时涉及两个粒子的分布函数；单位时间碰撞率 ∝ 两粒子同时出现在某处的概率 ∝ f·f。这就是分子混沌假设的用法：把两粒子概率近似成单粒子概率的乘积。

6. Loschmidt 悖论怎么化解？
提示：H 定理要求分子混沌假设（碰撞前速度不相关）。速度反转后的轨迹在碰撞瞬间会建立相关性，不再满足同一假设，所以 H 定理对它不适用。H 只在"朝前"演化中单调。

十三、工作题（带解答）

题 1（两能级数字题）。ε = 0.025 eV，T = 290 K（恰好 kT = 0.025 eV，x = 1）。求 Z₁、p₀、p₁、⟨E⟩₁。

显示解答

x = βε = 1。Z₁ = 1 + e−1 = 1.368。p₀ = 1/1.368 = 0.731，p₁ = e−1/1.368 = 0.269。⟨E⟩₁ = ε·p₁ = 0.025 × 0.269 = 0.0067 eV。核验（换一种形式）：⟨E⟩ = εe−x/(1+e−x) = 0.025 × 0.368/1.368 = 0.0067 ✓；⟨E⟩ = ε/(1+ex) = 0.025/(1+2.718) = 0.0067 ✓。三种形式一致。

题 2（谐振子数字题）。y = βħω = 2。求 Z₁ 与 ⟨E⟩₁（以 ħω 为单位）；若 ħω = 0.05 eV，⟨E⟩ 是多少？

显示解答

Z₁ = 1/(1−e−2) = 1/(1−0.1353) = 1.157。⟨E⟩₁ = ħω/(e2−1) = ħω/(7.389−1) = 0.1565 ħω。代入 ħω = 0.05 eV：⟨E⟩ = 0.00783 eV ≈ 0.30 kT（此处 T 满足 kT = ħω/2 = 0.025 eV）。量子冻结明显。

题 3（由 Z 求熵）。两能级系统一般公式：证明 S = k ln Z + ⟨E⟩/T，并求 x = 1 时每分子熵。

显示解答

S = −kΣp ln p。p₀ = 1/Z，p₁ = e−x/Z，ln p₀ = −ln Z，ln p₁ = −x − ln Z。故 S = k[(1/Z)ln Z + (e−x/Z)(x + ln Z)] = k ln Z + k x e−x/Z。又 ⟨E⟩/T = (εe−x/Z)/(kT) = x e−x/Z，故 S = k ln Z + ⟨E⟩/T ✓。x = 1：Z = 1.368，ln Z = 0.313，x e−x/Z = 0.269，S = 0.582 k。与第六节结果一致。

题 4（配分函数分解）。用两能级、N = 3 个无相互作用分子显式验证 Z₃ = Z₁³。

显示解答

Z₃ = Σₙ C(3,n) e−nx = 1 + 3e−x + 3e−2x + e−3x = (1+e−x)³ = Z₁³。（二项式定理。）物理：三个分子的能量取 0,ε,2ε,3ε，多重度 1,3,3,1——计数与指数权重相乘，正是第二、三节的机制。

题 5（热容量峰）。两能级系统 C/Nk = x²ex/(1+ex)²。证明它在 x = 2.4 附近取峰，并求 ε = 0.1 eV 时的峰温。

显示解答

把 C/Nk = x²ex/(1+ex)² 视为 x 的函数。代入数值：x=1 → e/(1+e)² = 2.718/13.82 = 0.197；x=2 → 4e²/(1+e²)² = 29.6/70.4 = 0.420；x=2.4 → x²e^x = 5.76×11.02 = 63.5，(1+e^2.4)² = 144.5，比值 0.439（峰）；x=4 → 16×54.6 = 874，55.6² = 3091，比值 0.283。峰在 x ≈ 2.4。精确峰条件：对 x 求导置零得 ex(x−2) = x+2，数值解 x ≈ 2.40。峰温 Tpeak = ε/(2.4k) = 0.1/(2.4×8.617×10⁻⁵) = 483 K。

十四、反例与注记：简并度、能均分失效、负温度、孤立 vs 热库

① Boltzmann 分布是对"状态"说的，不是对"能量"说的——简并度！pᵢ ∝ e−βE 的求和跑遍微观状态；若某能量 E 有 g(E) 个状态（简并度），则"能量 E 被占据的总概率"是

反例：两个能级，低能级 g=1（E=0），高能级 g=100（E=ε）。若 βε = 2，则 P(高)/P(低) = 100·e−2 = 13.5 > 1——高能级反而更可能被占据。教训：永远先数状态，再谈能量。若简并度随能量增长过快（如 g(E) 比 eβE 涨得还快），Z 会发散，这种能谱不物理——这提醒我们配分函数收敛性本身是物理的约束。

② 能均分定理会在低温失效（量子冻结）。经典统计预言每个二次型自由度贡献 kT；量子统计在 kT ≲ ħω 时给出 ⟨E⟩ ≈ ħω e−βħω ≪ kT。数字：ħω = 0.05 eV、T = 300 K 时 ⟨E⟩ ≈ 0.00845 eV = 0.33 kT（第五节）。这正是低温下固体的比热低于 Dulong–Petit 值的原因——"经典常数比热"只是高温极限。

③ 负温度（粒子数反转）。能谱有上界的系统（如两能级、核自旋系统）可以出现 β < 0：高能态反而多于低能态（"粒子数反转"，激光的工作机制）。此时"温度"是负的——但这只是定义 T = (∂S/∂E)⁻¹ 的必然结果，系统实际处于比任何正温都"更热"的状态。注意：无上界能谱（谐振子、自由粒子）永远不会有负温度。

④ 孤立（微正则）与热库（正则）的差别。第二节的两个推导视角：微正则固定总能量（W 计数），正则固定温度（e−βE）。两者只在 N → ∞ 时给出相同结果；有限 N 时，正则系综的能量有涨落 ΔE ~ ⟨E⟩/√N，且 P(E) 本身不是 δ 函数。这不是矛盾，而是"固定温度"与"固定能量"在有限系统上的真实区别。

⑤ Boltzmann 方程的适用范围。Q(f,f) 只描述两体瞬时碰撞，因此 H 定理严格成立限于稀薄气体。稠密液体、长程相互作用（等离子体、引力）需要 BBGKY 层级或 Fokker–Planck 等推广——"熵永不减少"在这些系统里的证明路径完全不同，甚至不再逐点成立。

十六、推导：从 Liouville 到 Boltzmann——BBGKY 层级

从 N 粒子 Liouville 方程（精确、可逆）出发，对 N−1 个粒子的坐标积分，得到BBGKY 层级——约化密度函数满足的一族不闭合方程组：每一层的方程都依赖更高一层的函数（f₁ 依赖 f₂，f₂ 依赖 f₃，……）。要把它截断成闭合的单粒子方程，需要分子混沌假设（Stosszahlansatz，见第九节）：f₂(x₁,v₁,x₂,v₂) ≈ f₁(x₁,v₁)f₁(x₂,v₂)——两个碰撞粒子的速度在碰撞前不相关。这一截断正是宏观不可逆性的微观来源：它把无穷层可逆方程"砍"成一层不可逆方程。

十七、前沿：Lanford 定理与 Hilbert 第 6 问题

Lanford（1975）在Grad 极限（N → ∞，σ → 0，Nσ² = 常数，即低密度极限）下，在极短时间内严格从 Liouville 方程推导出了 Boltzmann 方程——统计力学中为数不多的从微观到宏观的严格推导之一。

Hilbert（1900）第 6 问题（"物理学的公理化"）要求从微观动力学对任意长时间严格推导 Boltzmann 方程，至今仍然开放。最近进展：Gallagher–Saint-Raymond–Texier（2013）在 Grad 极限下对硬球与短程势模型严格推出了 Boltzmann 方程；相关方向仍是活跃研究前沿。
