〇、开场问题——一束光 3 秒后在哪里？谁能收到它的信号？

在你面前点燃一支激光笔，光束沿 x 轴射出。取时间单位为"秒"、长度单位为"光秒"（1 光秒 = 3×10⁸ m，即光 1 秒走的距离），于是光速就是 c = 1 光秒/秒。把每一个"事件"记作坐标 (ct, x)——注意横轴用 ct 而不是 t，这样坐标的"单位"一致，光线画出来永远是一条 45° 斜线。

光在 (ct, x) = (0, 0) 出发。3 秒后，向右的光到达 (3, 3)，向左的光到达 (3, −3)。这条 45° 线就是光锥的边界。现在比较三个事件：

  • 事件 A = (3, 1)（光锥内部）：要在 3 秒内到达 x = 1 光秒处，只需平均速度 v = 1/3 c < c——一束普通信号就能按时到达。
  • 事件 B = (3, 3)（光锥表面）：恰好只有光能以 c 到达。
  • 事件 C = (3, 5)（光锥外部）：要在 3 秒内到达 x = 5 光秒处，需要 v = 5/3 c > c——没有任何信号能赶到。

于是这张图第一次告诉你：并非"时间够久就能到达任何地方"——未来光锥之外的事件，无论等多久都够不到。本课的全部内容，就是把这句直觉变成一条严谨的几何判据（时空间隔），并解释为什么它不可能被绕开。

一句话：光锥 = 因果关系的边界。未来的光锥是你的信号能影响的范围，过去的光锥是能影响你的范围，光锥之外的东西无论等多久都不会波及你。只想懂核心思想，看到这里就够了。

一、时空间隔——闵可夫斯基的"勾股定理"，为什么时间要带负号

在欧氏空间中，两点距离是 Δs² = Δx² + Δy² + Δz²，永远非负。但在时空中，两事件"相隔多远"必须这样量：

为什么时间项带负号？因为光速不变。设想时间项若带正号（像欧氏那样 ds² = c²dt²+dx²+...），那么对一束沿 x 轴的光（dx = cdt），间隔算出来是 2c²dt² ≠ 0——"光信号"就与"零间隔"脱钩了。而事实上光速不变要求：任何惯性系里光的轨迹都满足 c²dt² = dx²+dy²+dz²，即 ds² = 0。要让"光速不变"成为一个几何事实，时间项必须带负号，且系数必须是 −c²。

间隔的符号因此把时空分成三类，这就是光锥的代数形式：

  • 类时（ds² < 0）：因果可达。你的世界线只能走这类方向。
  • 类光（ds² = 0）：光速。
  • 类空（ds² > 0）：因果不可达，两个事件不能互相影响。

例 1（一步步算：间隔的分类）。设光秒单位（c = 1）。事件 P = (0, 0)。现在要判断另外三个事件能否被 P 发出的信号触发：Q = (3, 2)、R = (3, 4)、S = (3, 3)。

① 算间隔 PQ：Δs² = −(Δt)² + (Δx)² = −(3)² + (2)² = −9 + 4 = −5 < 0，类时。Q 需要速度 v = Δx/Δt = 2/3 c < c，可被触发。

② 算间隔 PR：Δs² = −9 + 4² = −9 + 16 = +7 > 0，类空。R 需要 v = 4/3 c > c，不可能被触发——无论等多久。

③ 算间隔 PS：Δs² = −9 + 9 = 0，类光。S 恰好被光信号触及。

④ 核对：三个符号对应三种命运，与开场问题的 A、B、C 完全吻合（内部/表面/外部）。∎

光锥 = 因果律的几何表达。你此时此地发出一个信号——它只能在未来光锥内部传播。没有任何信号可以跑出光锥。超光速 = 类空间隔 = 因果律被破坏。

二、世界线——粒子在时空中的轨迹，以及"固有时"

一个粒子在时空中留下的全部轨迹叫世界线：静止粒子画出一条竖直直线（沿 t 轴）；匀速运动画出倾斜直线；加速运动画出弯曲曲线。所有质量粒子的世界线必须在光锥内部（类时），光子的世界线在光锥表面（类光）——这是"不可能超光速"的几何翻译。

三、同时性的相对性——为什么"现在"不是绝对的

在静止参考系 S 中，t = 常数的所有事件是"同时"的。在运动参考系 S' 中，t' = γ(t − vx/c²) = 常数定义的是另一组事件。因为公式里含 x，不同位置的"同时"时刻并不同——这就是同时性的相对性。

为什么"现在"必须是相对的？追根究底是光速不变逼出来的：如果 S 中"同时"的事件在 S' 中仍"同时"，那么对同一束光，S 说它同时到达车厢两端、S' 也必须说同时到达——但车厢在运动，光要追上运动中的车头必须走更远的路（见 Lorentz 变换课附 D 的标准反例）。物理定律只能有一个答案，于是"同时"只能随参考系而变。

例 3（一步步算：同地的两件"同时"事，换参考系就不同时）。在 S 中取两个同时事件：P = (t, x) = (0, 1)、Q = (0, 3)（光秒单位，c = 1）。设 S' 相对 S 以 v = 0.6c 运动。

① 取 γ：γ = 1/√(1−0.6²) = 1/0.8 = 1.25。

② 变换 P：t'_P = γ(t − vx) = 1.25×(0 − 0.6×1) = −0.75。

③ 变换 Q：t'_Q = 1.25×(0 − 0.6×3) = −2.25。

④ 结论：t'_P ≠ t'_Q，且 Q 在 P 之前发生。S 说"同时"，S' 说"先后"——两者都是对同一物理事实的合法描述。不存在绝对的"现在"。∎

1.（计算间隔） 事件 A：(t,x)=(0,0)；事件 B：(t,x)=(1,3)，单位取光年（c=1）。计算 Δs² 并判断 B 能否被 A 发出的信号触发。
