每一行都成立，而且往往不止一种写法。1742 年，德国数学家 Goldbach 在给 Euler 的信里问：是不是每一个大于 2 的偶数都能写成两个素数之和？Euler 回信说他"完全确信"这是对的，却给不出证明。

将近 285 年后的今天，这个小学生都能听懂的命题仍然悬而未决——它已经被验证到 4×1018 的每一个偶数，却没有任何人能证明"永远如此"。它问的不是"有没有反例"，而是"为什么必须如此"。本课就从这个具体的数字问题出发，一步步看清它为什么难、难在哪。

每个大于 2 的偶数 = 两个素数之和：人人看得懂，验证到 4×1018 全对，至今无人证明。只想懂核心思想，看到这里就够了。

一、两个素数之和——陈述（直觉 → 严格）

现代的标准陈述（去掉 Goldbach 原始版本里那个不成立的"1"）：

直觉先来。素数是"拆不动的数"：2,3,5,7,11,13,… 只能用 1 和自身整除。偶数 n 是"能被 2 整除的数"。问题问的是：给一个偶数 n，能否在 0 到 n 之间找到一对素数，恰好隔着 n 对称（p 在左，q=n−p 在右）？

严格化第一步：为什么排除 n=2？因为唯一的分解只能是 2=1+1 或 2=2+0，而 1 不是素数、0 也不是——所以猜想从 n≥4 开始（等价于原来的"大于 2"）。严格化第二步：允许 p=q（如 6=3+3），这不会让问题更容易，只是少数一种对称重复。

一个立刻可见的事实：一旦我们接受素数定理 π(x)~x/log x，平均来看 0 到 n 之间有约 n/log n 个素数，而"随机选两个数恰巧都是素数且和为 n"的概率按 Hardy–Littlewood 的启发式计算会给出正的比例——所以"随机模型"强烈暗示猜想为真。可那只是启发（heuristic），不是证明：随机模型不能排除某处藏着"反例结构"。这就是全课的张力所在。

哥德巴赫猜想是数论中"陈述最简单的未解问题"——小学三年级就能理解。但它的证明需要的数学深度可能超越了人类当前的工具。

二、为什么这么难——加法的表面与乘法的内核

要理解这问题为什么卡住 285 年，先看它把两类信息搅在了一起。

素数是用乘法定义的："p 只能被 1 和 p 整除"，这是一个关于分解 p=a×b 的陈述。算术基本定理说每个数都是素数的乘积。素数概念完全属于乘法世界。

哥德巴赫猜想却是一个加法陈述：n = p + q 用到的是"加"。它要求我们在乘法的原子之间找加法的关系——而数学里最深的鸿沟之一，就是加法与乘法之间没有直接的翻译规则。素数定理能精确告诉我们"大约有多少素数"，却一个字也说不出"哪两个素数相加等于 n"。

用记号"1+1"来感受尺度：

  • "1" 表示"1 个素数"本身；
  • "2" 表示"至多 2 个素数之积"（如 49=7×7、15=3×5）。

于是"每个大偶数 = 素数 + 素数"就是"1+1"；而下面要讲的陈景润定理"每个大偶数 = 素数 + 至多两个素数之积"是"1+2"。从 1+2 到 1+1 只差一个素数，但这"一步"已经走了 60 年。

  • 大弧（major arcs）：α 接近"分母很小的有理数" p/q 的部分——这里 S(α) 的行为可以用解析数论精确控制，给出主项；
  • 小弧（minor arcs）：其余部分——需要估计这里的积分贡献"小到可以忽略"。

这一套就是 Hardy–Littlewood 1923 年创立的圆法。1937 年 Vinogradov 用它证明了弱哥德巴赫：每个足够大的奇数都能写成三个素数之和。2013 年 Helfgott 用圆法 + 计算机辅助，把"足够大"降到了"大于 5 的奇数"——弱哥德巴赫彻底解决。

为什么强版（两个素数）比弱版（三个素数）难？两个加数比三个加数"少一个自由度"：三个数 p₁+p₂+p₃=n，中间那个 p₂ 可以自由变化来吸收误差；两个数 p+q=n 没有这样的缓冲，圆法的误差项直接落在主项的尺度上，把结果卡死了。这是本课反复出现的主题：项越少，误差越致命。

四、攻击路线之二：筛法——陈景润定理"1+2"（1966）

思路：不数"和等于 n 的素数对"，改从 2,3,4,…,n−2 这串数里筛：把与 n 相加仍是素数的候选留下。令 P₂ 表示"至多两个素数之积"的数。陈景润 1966 年用 Selberg 筛法 + 深刻的组合论证证明了：

直觉：筛法像一个"层层剥皮"的过程——先用小素数把明显不合格的数剥掉（比如 n−k 被 3 整除的 k 直接扔掉），再用加权函数让"恰好剩一个素因子"的数占优。陈景润的关键创新是在 Selberg 权上叠加"二重筛"：同时控制"k 是素数"和"n−k 的素因子个数 ≤2"，并用深刻的组合计数把误差压到可接受。

这篇文章发表于文革期间——陈景润在 6 平方米的小屋里用笔算完成了最繁重的部分。它给出了人类距离"1+1"最近的一步：60 年来，没有人能把"1+2"改进到"1+1"。目前普遍认为，从 1+2 到 1+1 需要全新的、超越圆法和筛法的技术——因为筛法有一个内在的"奇偶性问题"：它很难区分"一个数恰好是一个素数"与"一个数是两个素数的乘积"。

六、当前状态

• 强哥德巴赫（偶数 = 两素数，即 1+1）：未解决。圆法在"1+2"之后困了 60 年。

• 弱哥德巴赫（奇数 = 三素数）：Helfgott 2013 年完全解决（对所有大于 5 的奇数）。

• 相邻的孪生素数方向：Zhang（2013）证明差距 ≤ 7×10⁷ 的素数对无穷多，现已压缩到 246。

• 哥德巴赫与 GRH：若广义黎曼假设（GRH）成立，哥德巴赫对足够大的偶数成立——但 GRH 本身就是更深的未解问题。

七、前沿——困住我们的工具瓶颈

为什么 1966 年之后停滞？因为两条经典路线都撞上了墙。

圆法的墙：两个加数时，小弧上的误差项与主项同阶，积分被"噪声"淹没。弱哥德巴赫（三个加数）里 p₂ 的自由度让误差可被平均吸收；强版没有这个缓冲。

筛法的墙：筛法对"恰好一个素因子"极不敏感——它天然区分不了素数与"两个素数之积"。这个奇偶性问题（parity problem）是筛法的硬天花板，陈景润已经撞到了它的最边缘。

当前的共识：突破需要新的世界观——要么来自 Elliott–Halberstam 猜想式的解析推广（它若成立可直接压缩孪生素数间隙），要么来自某种尚未被发明的"加性-乘性混合"技术。Zhang、Maynard 的工作证明这类问题的答案藏在"权函数的选择"里，但把权选到恰好能看清"1+1"，还无人做到。

证明："1+2"的严格含义与筛法思路

陈景润定理的完整证明有几十页，这里给出它的逻辑骨架与每一步的含义。

定理（Chen, 1966）：存在绝对常数 N₀，使得对一切偶数 2N ≥ N₀，存在素数 p 与整数 a,b（a,b 可为 1）使 2N = p + ab，其中 a,b 为素数。

第一步：加权筛的框架。选一组非负权 w(d)（Selberg 型），对每个候选 k ≤ 2N 记"k 是素数"的指示函数为 1P(k)。陈景润的关键对象是

直觉：括号里第二项"惩罚"那些 n−p 有太多小素因子的情形。D 是筛的深度（取 D≈N^{1/8}）。

第二步：主项与误差的估计。用 Selberg 筛 + Bombieri–Vinogradov 定理（素数的算术级数均匀性）证明主项 ~ (某正常数)×N/log²N，误差 O(N/log³N) 可被主项吸收。

第三步：奇偶性技巧。把"ab 至多两个素因子"写成"Ω(ab)≤2"，其中 Ω 是带重数的素因子总数。陈景润用一个深刻的组合恒等式把"Ω 小"与"权函数和大"联系起来——这是全文最精妙处，它恰好越过奇偶性问题、但不至于到"Ω=1"（那正是 1+1，过不去）。

第四步：合并。主项严格为正，故存在 p 使 2N−p 的素因子个数 ≤2，即 2N = p + P₂。∎

这条证明的技术终点恰好是筛法的极限：奇偶性问题允许我们控制 Ω≤2，却禁止我们单独控制 Ω=1。这就是"1+2 到 1+1 的这一步"如此困难的严格原因。
