〇、直觉入门——橡皮膜被拉大了几倍

想象一块画着单位方格的橡皮膜上，有一个 1×1 的小方块。你用力拉伸、旋转这张膜，小方块变成了一块平行四边形。这块平行四边形比原来大了多少倍？这个"放大倍数"就叫行列式（determinant，记作 det）。

它还藏着两个隐藏信息：如果倍数算出来是负数，说明膜被"翻面"了（像照镜子）；如果倍数是 0，说明膜被整个压扁成一条线——所有信息糊在一起，再也变不回去。

下面先做一件最具体的事：拿一张写着数字的表格，把"放大倍数"真的算出来。算出来之后，再回头问它为什么恰好等于面积、为什么非零就代表可逆。

核心洞察：行列式就是一个数字，一句话告诉你变形"放大了几倍、有没有翻面、是不是被压扁了"。如果你只想理解核心思想，看到这里就够了。

四、为什么叫"行列式"？——它"决定"了什么

中文"行列式"来自英文 determinant，词根是"determine"——决定。它"决定"的正是变换的三件大事，一件都不少：

① 决定放大倍数。面积放大了 |det| 倍（第三节）。
② 决定有没有翻面。det 的符号告诉你变换是不是像照镜子一样把图形翻了过来（第五节）。
③ 决定还能不能撤销。det=0 表示变换把平面压成一条线，信息被毁，再也回不去（第六节）。

这三个信息打包在一个数字里，是线性代数里罕见的高密度信息。另外，历史上"determinant"这个名字还有一个更早、更朴素的来源：在研究线性方程组

时，这个数决定（determine）方程组是否有唯一解——ad−bc≠0 时有唯一解，ad−bc=0 时没有唯一解。后来它被抽象出来，成了描述一切线性变换"缩放、定向、可逆性"的量。

行列式只用一个数字告诉你变换：放大了几倍（|det|）、有没有翻面（符号）、能不能撤销（是否为 0）。这个数字还等于所有特征值的乘积（见第十一节）。

五、正负号——翻没翻面

第三节回答了"放大多少倍"，那回答的是绝对值。本节回答另一个问题：det 的正负号代表什么？

看一个最简单的翻面例子——交换两个坐标轴的矩阵（把整张纸沿 45° 线"对折"，像照镜子）：

M(x,y)=(y,x)，它把 (1,0) 送到 (0,1)、把 (0,1) 送到 (1,0)——面积一点没变（|det|=1），但左右手对调了，这就是"翻面"。于是规则很清楚：

det(A) > 0 → 保持定向（旋转 + 拉伸，不翻转）。
det(A) < 0 → 翻转定向（镜像操作）。
det(A) = 0 → 正方形被压扁成线段或点——降维，不可逆。

怎么理解"负数倍"这个说法？把变换连续地从 I 变到 M（比如 R(θ)=[[cosθ, sinθ],[sinθ, −cosθ]]，从 0 转到 90°），det 会从 +1 连续滑过 0 到 −1。翻面不是瞬间发生的——它必须"穿过"压扁状态。这个直觉在物理和几何里反复出现：定向的翻转 = 强制经过一次退化。

先看一个具体例子：

为什么偏偏是 0？注意 B 的第二个列向量 (2,4) 正好是第一个 (1,2) 的 2 倍——两条"边"朝同一个方向，根本张不成一块面，只能形成一条线段。用第三节的面积公式看，|det|=面积=0。单位正方形被 B 变换后，四个顶点全部落到同一条直线上，整块正方形被压扁成一条线段（数学上叫"退化"，singular），面积变成 0。

这样的矩阵叫退化矩阵（singular matrix，也叫奇异矩阵）。它压扁了平面，被压没的那个方向的信息永远丢了——数学上叫不可逆（no inverse）：你没法从一条线段复原整块正方形，因为"垂直方向去哪了"已经无从得知。反过来，只要 det≠0，正方形还保有面积，变换就能"撤销"回去。

证法一（用乘性）。若 A 可逆，则存在 A⁻¹ 使 AA⁻¹=I。两边取 det：

八、三条公理——为什么三条就够

到现在为止，我们靠几何直觉认识行列式（放大倍数、翻面、压扁）。更严格的做法，是把行列式从三条最基本的规则（公理）重新定义出来，其余一切性质都能从这三条纯代数地推出，不再需要看图形。这就是教材里常说的"公理化定义"。

公理 1：det(I)=1。恒等变换不改变体积。
公理 2：交换两行 → det 变号。反射改变定向。
公理 3：行列式对每一行是线性的——某行乘以 c → det 乘以 c；某行是两个向量之和 → det 等于两项之和。

对一般 n 阶矩阵，理由是同一条路的推广：任何矩阵都能用行变换化为单位阵（Gauss 消元），即写成初等矩阵的乘积；而三条公理把每个初等矩阵的 det 钉死（交换→−1、某行乘 c→c、某行加另一行 c 倍→1），并保证"乘初等矩阵时 det 跟着初等矩阵走"（det(EA)=det(E)det(A)，证明见文末附注）。每块拼图的 det 都被唯一决定，拼起来的 det 也就唯一了。这就是"公理化"的威力：不需要图形，三条规则就足够，还能在任意维数工作。

为什么偏偏是这三条？因为它们精确对应 Gauss 消元的三种行操作（交换、倍乘、倍加），而每一种行操作都有一个几何事实：交换 = 定向翻转、倍乘 = 体积成比例放大、倍加 = 错切不改变体积。公理是把几何事实提炼成了代数规则。

九、为什么 det(AB)=det(A)det(B)？

这是行列式最重要的乘法性质，先用直觉，再给严格版。

直觉论证（几何）。A 把正方形面积放大 det(A) 倍。B 再把 A 的像（平行四边形）放大 det(B) 倍。总放大倍数 = det(A)·det(B)。但复合变换 AB 就是把两者依次执行，它的总放大 = det(AB)。所以 det(AB)=det(A)det(B)。

这个论证漂亮，但要严谨还差一步：A 的像是"平行四边形"，B 对它的作用确实是放大 det(B) 倍吗？严格证明的做法是初等矩阵：任一可逆矩阵都是初等矩阵的乘积（Gauss 消元的记录），而 det(EA)=det(E)det(A) 可以沿着公理逐行直接验证（交换、倍乘、倍加三种情况各查一遍，见文末附注）。用初等矩阵的"积木"把 A 一块块搭起来，乘性就严格成立了。若 A 不可逆，两边都是 0（第六节），也成立。∎

三个马上到手的推论：

推论 1（逆）：det(A⁻¹)=1/det(A)。因为 1=det(I)=det(A)det(A⁻¹)。
推论 2（相似）：det(P⁻¹AP)=det(A)。用两次乘性，P 可逆时 det(P⁻¹AP)=det(P⁻¹)det(A)det(P)=det(A)。这告诉我们：换基底不改变行列式——行列式是变换的内在属性，不依赖你站在哪个坐标系里看它。
推论 3（幂）：det(A²)=det(A)²，一般地 det(Aᵏ)=det(A)ᵏ。

十二、历史：从线性方程组到现代代数

行列式比矩阵更早出现。Leibniz（1693）和 Cramer（1750，克莱姆法则）在研究线性方程组时独立发现了行列式——它最初就是"决定方程组是否有唯一解"的那个量。Vandermonde（1772）首次把行列式当作独立的数学对象来研究。Cauchy（1812）证明 det(AB)=det(A)det(B)，并首次给出系统的行列式理论。

有趣的是，符号 |a b; c d|、术语 "determinant" 的定型都发生在"矩阵"这个观念被清晰提出之前很久——行列式是爷爷辈，矩阵是后来为它设计的储物柜。到了数值计算时代，行列式的地位反而下降了：直接算它太慢（朴素算法 O(n!)），但它作为理论工具（可逆性、体积、特征值乘积）依然不可或缺。

十三、前沿：行列式的计算复杂性

现代数值线性代数不再靠展开来算行列式——而是用行变换化为三角阵，O(n³) 就够。理论上，行列式计算等价于矩阵乘法：O(n^ω)，其中 ω≈2.37 是矩阵乘法指数（2024 年还被改进到 2.371866）。

但事情在符号领域变得很微妙：元素是符号（含未知量的多项式）时，展开会指数爆炸。Valiant（1979）证明了惊人结果：计算 permanent（行列式的"无符号"亲戚）是 #P 完全的——几乎不可能高效计算；而 determinant 却在多项式时间 P 内。这个"永久式 vs 行列式"的复杂度鸿沟，是理论计算机科学最深的开放问题之一（与 Valiant 猜想相关）。

提示：第一列是 2,1,0，符号 +,−,+；det=2·det[[3,2],[1,1]]−1·det[[0,1],[1,1]]+0=2·(3−2)−1·(0−1)=2+1=3。

5. det(cA) 与 c·det(A) 是什么关系？
提示：公理 3 的线性是对"每一行"而言，n 阶矩阵有 n 行，每行都被乘 c，共 n 个因子：det(cA)=cⁿdet(A)（n 次齐次）。除 n=1 外都不是 c·det(A)——这是行列式对"整个矩阵"非线性的典型体现。

6. 若 det(A)=0，能不能从乘性直接推出 A 不可逆？
提示：反证。若 A 有逆，1=det(I)=det(A)det(A⁻¹)=0·det(A⁻¹)=0，矛盾。

前沿：行列式的计算复杂性（续）——从符号到量子

除 Valiant 的结果外，还有一个反直觉的结论：permanent 与 determinant 之间只有"一撇"之差（permanent 不变量变号、determinant 按置换符号变号），但计算复杂度天差地别。量子计算一侧，permanent 还与玻色子采样（Boson Sampling）的经典模拟难度直接相关——Aaronson & Arkhipov (2013) 证明"近似永久式困难"是量子霸权实验的基础。一个古老的行列式亲戚，至今仍卡在量子与经典计算的分界线上。

附：det(AB)=det(A)det(B) 的初等矩阵证明

引理 1（初等矩阵的 det）。三类初等矩阵 E：交换两行、某行乘 c、某行加另一行的 c 倍。由公理直接逐行验证：det(E) 分别为 −1、c、1。

引理 2（行操作与乘性）。对任意初等矩阵 E 与任意方阵 A，恒有 det(EA)=det(E)det(A)。

验证：左乘 E 就是给 A 做对应的行操作；公理 2 说交换行 det 变号，公理 3 说某行乘 c 则 det 乘 c、某行加另一行 c 倍不改变 det（把"加的那行"与"被加的行"一起看，两行成比例的部分贡献为 0）。三种情况都给出 det(EA)=det(E)det(A)。

证明 det(AB)=det(A)det(B)。固定 B，考察 F(A)=det(AB)。若 A 可逆，则 A 是初等矩阵之积：A=E₁⋯Eₖ（Gauss 消元把 A 化为 I 的过程反过来写），于是

逐次使用引理 2，最后一次用引理 1 把 det(E₁⋯Eₖ)=det(A) 拼出来。若 A 不可逆，则 rank(AB)≤rank(A)<n，故 AB 不可逆，det(AB)=0=det(A)det(B)。两种情形均成立。∎

推论：det(A⁻¹)=1/det(A)（取 B=A⁻¹）；det(P⁻¹AP)=det(A)（取 B=P⁻¹、P 可逆，两次乘性）。

附：行列式与体积的严格联系

定理。设 A 为 n 阶实矩阵，则 A 作用于单位立方体得到的平行多面体 A[0,1]ⁿ 满足 vol(A[0,1]ⁿ)=|det(A)|。

严格证明思路。令 V(A)=A[0,1]ⁿ 的带符号体积。验证 V 满足行列式唯一刻画的公理：

① V(I)=1——单位立方体体积为 1。② 交换两列 V 变号——交换两条边相当于反射（定向翻转），体积保持绝对值但符号取反。③ 对每列多重线性——把一列写成 u+w 时多面体沿该方向被"切开"成两片，体积相加；某列乘 c 时对应边拉长 |c| 倍，带符号体积乘 c。

由于满足这三条公理的函数唯一（行列式公理刻画定理，见第八节），必有 V=det，故 vol=|det|。∎

代数与微积分版本：楔积范数 |v₁∧⋯∧vₙ| 定义平行多面体体积；Jacobian 变量替换公式 dx₁⋯dxₙ=|det(J)|du₁⋯duₙ 正是这一联系的无穷小形态。

附：标准反例

反例 1（行列式不可加）：det(A+B)≠det(A)+det(B)。取 A=[[1,0],[0,0]]、B=[[0,0],[0,1]]：det A=0、det B=0，但 A+B=I₂，det(A+B)=1≠0。行列式对矩阵加法没有线性——公理 3 的线性只对"单行"，不对"整矩阵"。

反例 2（退化矩阵）：A=[[1,2],[2,4]]，第二列是第一列的 2 倍，det A=0。几何上两列张成的平行四边形面积为 0——两向量共线被压成线段。退化 ⟺ 不可逆 ⟺ det=0，这是 rank(A)<n 的直接判据。

补充警示：det 对"整个矩阵"非线性——det(cA)=cⁿdet(A)（n 次齐次），除 n=1 外都不是 c·det(A)。

附：工作题

题 1：用拉普拉斯展开（余子式展开）计算 A=[[1,2,3],[0,1,4],[5,6,0]]，选择最省事的展开行/列。

题 2：判断可逆性：B=[[2,0,0],[3,−1,0],[4,5,2]]（三角阵），C=[[1,2,3],[4,5,6],[7,8,9]]。

显示解答

题 1：沿第一列展开最省事（第二行 a₂₁=0 消去一项）：det A=1·det[[1,4],[6,0]]−0+5·det[[2,3],[1,4]]=1·(−24)+5·(8−3)=−24+25=1。直接展开校验：1·(1·0−4·6)−2·(0·0−4·5)+3·(0·6−1·5)=−24+40−15=1 ✓。

题 2：B 为上三角，det B=2·(−1)·2=−4≠0 ⟹ 可逆。C：第 3 行 −2×第 2 行=(−1,−2,−3)=−第 1 行 ⟹ 第 3 行−2×第 2 行+第 1 行=0，行线性相关 ⟹ det C=0，不可逆。也可这样看：C 的列向量线性相关（第三列=第二列+(1,1,1) 之类的组合），三列共面，平行六面体体积为 0。
