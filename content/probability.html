〇、直觉入门——概率论是"把不确定讲清楚"的数学

抛一枚硬币，正面朝上的机会是一半；掷一颗骰子，掷出 6 点的机会是六分之一；明天下雨"大概七成"。结果本身不确定，但你可以说出一个数——这个数就是概率。概率论把这句"大致有多可能"变成精确的数学，让"不确定"也有严谨的规则。

它为什么存在？因为在真实世界里几乎没有事情是百分之百确定的。保险要定价（今年有千分之一的人出险，保费怎么算？）、天气预报要量化（这个台风 48 小时内登陆的概率是 0.7）、AI 要推理（机器视觉判定"猫"的信心是 0.93）、连手机信号的误码率都要被精确控制。科学家和工程师需要一套工具来量化和处理不确定性——这套工具就是概率论。

人生充满不确定，但概率论能让"不确定"变得可算、可预测。

〇·一、概率是什么？——抛硬币的直觉，"可能性的大小"怎么量化（0 到 1）

先做个小实验：随手抛一枚硬币，它落下时是正面还是反面？在它落地前，你不知道结果——这叫"结果不确定"。但你心里其实有个数：正面和反面"大概各有一半机会"。这句"一半机会"就是概率（probability）的雏形：一个用来描述"某件事有多可能发生"的数。

为了把"多可能"变成精确的数，人们约定：概率用 0 到 1 之间的一个数来表示。0 表示"绝对不会发生"，1 表示"一定发生"，中间的数表示"有时候发生"——越接近 1，越容易发生。比如"明天下雨"的概率是 0.7，就是说 100 次类似的天气里，大约有 70 次会下雨。

来读几个具体的数：

  • 抛一枚公平硬币，正面和反面机会均等，所以正面的概率就是 0.5（也就是"一半"，写成百分数是 50%）。
  • 掷一颗公平骰子，六个面机会均等，所以"掷出 6 点"的概率是 1/6 ≈ 0.1667。
  • 从一副 52 张的扑克牌中抽一张，"抽到红桃 A"只有 1 张，概率是 1/52 ≈ 0.0192。
  • "明天太阳照常升起"几乎必然，概率约等于 1。

这个从 0 到 1 的"标尺"，就是整个概率论的起点。越接近 1 越可能，越接近 0 越不可能。

概率 = 用一个 0 到 1 之间的数，量化"事情有多可能发生"。0 是不可能，1 是必然，越接近 1 越可能。

〇·二、怎么算概率？——基本事件、样本空间、事件，用骰子/扑克例子

光知道概率是 0 到 1 之间的数还不够，我们还得知道怎么算它。这里先记住三个词，每个都先用大白话解释，后面整门课都会用到它们。

第一个词：样本空间（sample space），记作 Ω。它就是把一次实验"所有可能的结果"都装进一个大集合。比如抛一枚骰子，可能的结果只有 1、2、3、4、5、6 这六种，所以样本空间就是 {1,2,3,4,5,6}——六个元素，每个代表一个结果。抛两次硬币，样本空间是 {正正, 正反, 反正, 反反}，四个元素。

第二个词：基本事件（elementary event）。样本空间里的每一个单独结果，就是一个基本事件。抛骰子得到"5"，就是一个基本事件；抛硬币得到"正面"，也是一个基本事件。它是"最小的一块"，没法再拆了。

第三个词：事件（event）。事件就是"基本事件拼成的集合"——也就是样本空间的子集，表示"我关心的那种结果"。比如"掷出偶数"是一个事件，它其实是 {2,4,6} 这三个基本事件合在一起；"抽到红心"是一个事件；"抽到 J、Q、K"也是一个事件。

来用骰子试试：掷一次骰子，"掷出偶数"包含 2、4、6 共 3 个基本事件，总数是 6，所以概率 = 3/6 = 0.5。"掷出 5"只有 1 个基本事件，概率 = 1/6 ≈ 0.167。

再换扑克牌：一副牌 52 张，每种花色 13 张。抽一张，"抽到红心"有 13 种有利结果，概率 = 13/52 = 0.25。"抽到 A"有 4 张，概率 = 4/52 ≈ 0.077。

样本空间 = 所有结果的清单；基本事件 = 清单里单独的一项；事件 = 你想关心的若干项拼成的集合。机会均等时：概率 = 有利的基本事件数 ÷ 总数。

一个重要的特殊情形：独立。如果"知道 B 之后，对 A 的概率毫无影响"，即 P(A|B) = P(A)，那么由条件概率公式得 P(A∩B) = P(A)P(B)。此时称 A、B 相互独立。例如抛两次硬币，第二次正面的概率不因第一次结果而改变：P(正∩正) = 1/2 × 1/2 = 1/4，而独立定义要求 P(A)P(B) = 0.5 × 0.5 = 0.25，两者相等——所以两次抛掷独立。独立性是整个概率论的脊柱，后面 §四、§五、§六 全要仰仗它。

条件概率 P(A|B) = 在 B 已知的世界里 A 的比例。贝叶斯公式把"先验判断"和"证据强度"合成"后验判断"——这是统计推断与机器学习最核心的动作。

〇·四、期望——"平均能赢多少"的精确答案

一个随机实验的"平均结果"叫期望（expectation），记作 E[X]。直觉：如果这个实验重复做很多很多次，把每次的结果加起来除以次数，你会接近的那个数就是期望。大数定律（见 〇·五）会证明这句话。

第三步（解读）。平均每张"返还"0.6 元，而售价 1 元——长期看每卖一张票，发行方平均赚 0.4 元。这就是彩票的"期望收益为负"：买彩票的人多，中奖是少数。保险刚好相反：保险公司收的保费 = 赔付期望 + 运营成本，所以"保险公司稳赚、买保险者求的是转移风险"。

〇·五、两个重要直觉——大数定律和中心极限定理

这一节我们不推公式，只讲两个最重要的"直觉"，它们会贯穿整门课（后面的章节会给出严格证明）。

直觉一：大数定律（law of large numbers）——抛多了，比例就趋于理论值。抛一枚公平硬币，正面概率是 0.5。但如果你只抛 10 次，可能正面 8 次、反面 2 次，比例 0.8，离 0.5 差得远——这很正常，别慌。可是当你抛 100 次、1000 次、一万次，正面的比例就会越来越接近 0.5：抛 100 次可能 55 正（0.55），抛 10000 次可能 4992 正（0.4992）。这就是大数定律：实验次数越多，平均结果越稳定地靠近"理论上该有的值"（也就是上节的期望）。它是保险、统计、赌博模型全都依赖的根基——单个结果不可预测，但"大量"之后就变得规律。上节彩票的例子正是靠它兑现：发行一百万张，总收入几乎必然接近 60 万元。

直觉二：中心极限定理（central limit theorem）——很多独立的小随机加在一起，会"长得像"正态分布。什么叫"很多独立的小随机加在一起"？比如你一个人一天赚多少钱不确定，但成千上万人的总收入；你测一次体温有误差，但测很多次取平均；抛 100 次硬币，正面的总数。中心极限定理说：当把很多个"互相不影响"（独立）的随机量加起来，不管每个量本身长得多么奇怪，它们的总和（或者平均）都会趋向一个特定的、像钟形曲线的分布——正态分布（normal distribution，也叫高斯分布）。例如抛 100 次硬币，正面数 S 的分布就非常接近均值 50、标准差 5 的正态分布——P(40 ≤ S ≤ 60) ≈ 95.4%，这可以用正态曲线快速估算（后面 §六 和 工作题 2 会算给你看）。

这两个直觉合起来讲了一个故事：单个事件可以毫无规律，但"大量"会让世界显现出稳定的统计规律，而且规律都指向同一个"钟形"。

大数定律：抛得够多，结果比例就接近理论值。中心极限定理：很多独立随机量加在一起，总和趋近正态分布（钟形曲线）。这两个直觉是理解后面所有章节的地图。

如果你想理解核心思想，看到这里就够了。后面的章节会用更严格的语言把这些直觉变成数学，并展开它们背后的测度论、极限定理与不等式工具。

一、为什么概率要公理化？——从"抛硬币"到"所有子集都能算"的失败

前面所有计算都建立在"基本事件机会均等"或"事件个数有限"之上。但这个世界很快就不配合了：

  • 可数无穷：掷硬币直到出现正面为止，需要掷的次数可以是 1、2、3、… 任意大——样本空间 {1,2,3,…} 有无穷多个基本事件，"有利事件数 ÷ 总数"直接失效。
  • 连续无穷：在 [0,1] 区间随机取一个点，"取到有理数"的概率是 0 但"可能发生"——古典计数法给不了这样的数。
  • 不可测集合：测度论里我们见过 Vitali 集：用选择公理可以从每个等价类里挑代表元拼出一个集合 V，使得任何"合理的长度"都赋不上去。如果概率要定义在"所有子集"上，Vitali 集这样的集合就会制造矛盾（Banach–Tarski 悖论：单位球能拆成 5 块再拼成两个球）。

所以"概率应该对每个子集都有定义"的朴素愿望必须放弃。出路是：只对"足够规整"的一族集合（σ-代数）定义概率，并规定概率必须满足几条不能违背的规则。Kolmogorov 在 1933 年给出了这三条公理，把概率论"降维"成了测度论的特例——这让概率论获得了与微积分同等的严谨地位。

为什么是这三条？每条都有无可辩驳的动机：

  • 非负性 P(A) ≥ 0：概率是"份额"，份额不能是负数。
  • 规范性 P(Ω) = 1：全集代表"必然发生"，把总份额归一化成 100%。
  • σ-可加性：对两两不相交的事件 A₁, A₂, …, P(∪Aᵢ) = ΣP(Aᵢ)。"互不重叠的两块合起来，概率相加"——这是计数、测度的基本直觉，也是整个积分理论的地基。之所以要"可数"（σ）而不是只要求有限个，是为了让极限与期望（积分）能够顺畅地进行。
公理化的动机：古典定义在无穷与不可测集面前失效。Kolmogorov 把概率定义为满足 非负性、规范性、σ-可加性 三条公理的测度——"概率 = 总质量为 1 的测度"。

二、测度论基础：概率空间

现在把上一节的公理化落到记号上。概率空间是一个三元组 (Ω, F, P)：

  • Ω（样本空间）：一切可能结果的集合。抛两次硬币：Ω = {正正, 正反, 反正, 反反}；掷骰子：Ω = {1,2,3,4,5,6}；随机取 [0,1] 的点：Ω = [0,1]。
  • F（σ-代数，可测事件族）：我们允许谈概率的那些事件。它必须对可数并、可数交、补集封闭。为什么要 σ-代数而不直接要"所有子集"？——正是上一节说的：Vitali 集不可测，我们只能对"规整"的集合赋值。F 越大，代表我们"能分辨"的事件越多。
  • P（概率测度）：映射 F → [0,1]，满足 P(Ω)=1 且 σ-可加。它就是"给每个可测事件分配份额"的规则。

随机变量 X 是"把结果翻译成数字"。严格地说，随机变量是可测函数 X: (Ω,F) → (ℝ, B(ℝ))，即对一切 Borel 集 B，原像 X⁻¹(B) ∈ F。例子：X = "抛两次硬币的正面次数"，则 X(正正)=2、X(正反)=1、X(反正)=1、X(反反)=0。于是"P(X = 1)"就有意义：

可测性正是"随机变量"一词的全部数学内容——它让"概率"可以被回拉：P(X ∈ B) = P(X⁻¹(B))。分布是 ℝ 上的概率测度 P∘X⁻¹，由分布函数 F_X(x)=P(X≤x) 唯一决定。例如掷骰子的 F_X 在 x=3 处取值 P(X≤3)=3/6=1/2。

可测函数 = 信息通道：F 描述"知道多少"。σ-代数越大，可测函数越丰富。子 σ-代数 G ⊂ F 编码"更粗的信息"——这正是条件期望的舞台。

三大不等式是概率分析的引擎：Markov P(X≥a) ≤ E[X]/a；Chebyshev P(|X−μ|≥a) ≤ Var(X)/a²（= Markov 作用于 (X−μ)²）；Jensen 对凸函数 f：E[f(X)] ≥ f(E[X])——由"期望是积分的保序性 + 凸函数是切线的包络"给出。

四、独立性：Kolmogorov 0-1 律

事件族 {F_i} 独立 ⇔ 对任意有限选取的 A_i ∈ F_i，P(∩A_i) = ∏P(A_i)。独立 σ-代数的构造：给定独立随机变量族 {X_i}，取 F_i = σ(X_i)，则 {F_i} 独立。回到 〇·三 的直觉：独立 = "知道其中一个，对另一个的判断毫无影响"。抛两次硬币：P(正∩正) = 1/4 = P(正)P(正)，故独立。

独立性的核心定理是 Kolmogorov 0-1 律：设 {X_i} 独立，尾 σ-代数 T = ∩_n σ(X_n, X_{n+1}, …)，则 T 中每个事件的概率要么 0 要么 1。因此"ΣX_i 收敛"这类只依赖无穷尾巴的事件以概率 1 决定。

相互独立 ⟹ 两两独立，反之不成立。反例：X, Y 独立 Bernoulli，Z = X⊕Y (mod 2)。则 X,Y,Z 两两独立，但 σ(X,Y,Z) 不独立——因为 Z 完全由 X,Y 决定。这是初学者最重要的警示。

五、大数定律：Borel-Cantelli

设 {X_i} i.i.d.，E[X₁]=μ，则弱 LLN（Chebyshev 证明）：对任意 ε>0，P(|S_n/n − μ| ≥ ε) → 0，即 S_n/n 依概率收敛到 μ。强 LLN（Kolmogorov 证明）：S_n/n → μ a.s.。强版本要求更多（E|X₁|<∞ 的有限性 + 鞅收敛或 Egorov），但给出更本质的结论。

这就是 〇·五 直觉一 的严格化身：抛 n 次硬币，S_n/n = 正面比例，随着 n → ∞ 以概率 1 逼近 0.5。弱 LLN 说的是"比例偏离 0.5 的概率趋于 0"，强 LLN 说的是"比例本身几乎必然收敛到 0.5"——后者更强、更本质。

证明强 LLN 的关键引理是 Borel-Cantelli：(i) 若 ΣP(A_n) < ∞，则 P(limsup A_n)=0——事件只出现有限次；(ii) 若 {A_n} 独立且 ΣP(A_n)=∞，则 P(limsup A_n)=1——出现无穷次。用 Borel-Cantelli + 截断 + Kronecker 引理即可完成强 LLN 证明。

六、中心极限定理：特征函数方法

Lindeberg-Lévy CLT：{X_i} i.i.d.，E[X₁]=μ，Var(X₁)=σ²<∞，则标准化和 (S_n − nμ)/(σ√n) 依分布收敛到 N(0,1)。

证明用特征函数。特征函数是概率测度的 Fourier 变换：φ(t)=E[e^{itX}]=1+itμ−t²σ²/2+o(t²)。对标准化和，

由 Lévy 连续性定理 + Lévy 反转公式得分布收敛。为什么特征函数是"正确的工具"？因为"独立和的分布"在特征函数下变成"乘积"，而 e^{itx} 的指数结构把 1/n 缩放 + n 次相乘 变成 exp(−t²/2)——一切"形状"都被指数函数的极限吸收，只留下均值与方差。

Berry-Esseen 界把收敛速度量化：若 E|X₁|³<∞，则 |F_{Z_n}(x) − Φ(x)| ≤ C ρ/σ³√n，其中 ρ=E|X₁−μ|³，C≈0.47。这回答了"CLT 到底有多准"。

为什么正态分布无处不在？因为正态是无穷可分分布的稳定吸引子：特征函数 exp(−t²/2) 对一切 t 满足半群性质 φ(t/√n)ⁿ=φ(t)——它同时是最短熵、最大熵（固定一、二阶矩）、以及在矩替换下的固定点。中心极限 + 大偏差意味着大量小独立扰动的总和"忘掉"了每个分量的具体形状，只记住均值与方差。

1. 生日问题。房间里有 n 个人，至少有两人生日相同的概率，在 n=23 时就已超过 50%。请验证：先算"没有两人生日相同"的概率，n=23 时它约等于 e^{-253/730} ≈ 0.49。提示：第一个人生日任意（365/365），第二个人要避开它（364/365），第三个人避开前两个（363/365）……把这些乘起来：P(无重复) = ∏_{k=1}^{n-1}(1 − k/365)，再用近似 1−x ≈ e^{-x} 估算 n(n−1)/730。

九、关键论文

Kolmogorov (1933, "Grundbegriffe der Wahrscheinlichkeitsrechnung")——现代概率论的《几何原本》：把概率公理化（非负性、规范、σ-加性），定义随机变量、期望，证明强 LLN 与 CLT 的严格版本。

Doob (1953, "Stochastic Processes")——鞅论的奠基著作，证明可选停止定理与鞅收敛定理，把马尔可夫过程和鞅纳入统一框架。

Lévy (1937, "Théorie de l'addition des variables aléatoires")——特征函数、Lévy 过程、稳定分布；Lévy 连续性定理是 CLT 证明的基石。

十、前沿

随机矩阵理论：Wigner 半圆律、Marchenko-Pastur 律、Tracy-Widom 分布——大随机矩阵特征值谱的普适性定律，连接自由概率与数论。

自由概率论：Voiculescu (1985) 的非交换概率论，自由独立性取代经典独立，R-变换取代特征函数；被用于随机矩阵与算子代数的交叉研究。

鞅论与金融数学：Girsanov 变换、风险中性测度、Black-Scholes-Merton 定价——鞅表示定理是资产定价理论的核心工具。

工作题 5：条件概率——疾病检测（对应 〇·三 例题 1）。患病率 1%，检测对患病者阳性率 99%、对健康者阳性率 5%。某人检测为阳性，求他真正患病的概率；若他再复查一次仍阳性（两次检测独立），概率变成多少？

显示解答

第一次：P(患病|阳性) = 0.99×0.01 / (0.99×0.01 + 0.05×0.99) ≈ 0.167。第二次：把第一次的后验 0.167 当作新的"先验"，再用同样公式 P = (0.99×0.167)/(0.99×0.167 + 0.05×0.833) ≈ 0.1653/0.2069 ≈ 0.799。两次阳性几乎坐实了患病——贝叶斯公式可以"滚动更新"，这正是序贯推断的原理。

工作题 6：贝叶斯——两个盒子（对应 〇·三 例题 2）。盒子 A：2 红 3 蓝；盒子 B：4 红 2 蓝。随机选盒后抽一球为红，求来自 A 的概率；若抽出的球放回并再抽一次，第二次仍为红，求两次都来自 A 的概率（两次抽样独立）。

显示解答

P(A|红) = (1/2)(2/5)/(8/15) = 3/8 = 0.375。两次独立抽样同为红的条件概率 P(红红|A) = (2/5)² = 4/25，P(红红|B) = (2/3)² = 4/9。总概率 P(红红) = (1/2)(4/25) + (1/2)(4/9) = 2/25 + 2/9 = 68/225。于是 P(A|红红) = (1/2)(4/25)/(68/225) = (2/25)×(225/68) = 18/68 = 9/34 ≈ 0.265。证据更"支持"盒子 B（红球比例高），故后验进一步偏向 B。

工作题 7：期望——保险定价（对应 〇·四 例题 4）。某保单：出险概率 p=0.01，一旦出险赔付 10000 元。求"纯保费"（使保险公司期望利润为 0 的保费）；若还要覆盖 20% 的运营成本，保费应定多少？

显示解答

赔付额 X 满足 P(X=10000)=0.01、P(X=0)=0.99，故 E[X] = 10000×0.01 + 0 = 100 元——纯保费 100 元。设实收保费 c，则利润期望 E[c−X] = c − 100；要利润为 0 取 c=100；覆盖 20% 运营成本即 E[X] = 0.8c，得 c = 100/0.8 = 125 元。这展示了大数定律与期望在金融定价中的角色：个体出险不可预测，但大量保单让平均赔付稳定在 E[X]。
