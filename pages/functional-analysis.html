函数也一样。f(x)=x² 在 [0,1] 上，用"最高点"量：‖f‖_∞ = 1；用"能量"量：‖f‖₂ = √(∫₀¹ x⁴ dx) = 1/√5 ≈ 0.447。函数不是"一堆数"，而是一个"点"——这正是泛函分析的核心视角。

泛函分析 = 无穷维线性代数：把函数、序列当成"点"，用几何（长度、角度、距离）研究它们。只懂核心思想？看到这里就够了：无穷维里"长度"的定义是关键，而要用的"长度"必须满足三条规矩——正定、数乘、三角不等式，见第一节。

一、赋范空间：把"长度"公理化

先回答最根本的问题：凭什么给函数"量长度"？因为"长度"只要守三条规矩，就能像真长度一样用。设 X 是线性空间（向量能加、能乘数），函数 ‖·‖: X→[0,∞) 叫范数，若：

  • 正定性：‖x‖=0 ⟺ x=0（只有零向量长度为零）；
  • 齐次性：‖cx‖=|c|‖x‖（放大 c 倍，长度放大 |c| 倍）；
  • 三角不等式：‖x+y‖ ≤ ‖x‖+‖y‖（两边之和至少第三边）。

（X, ‖·‖）就叫赋范空间。第三条"为什么重要"？因为它保证由 d(x,y)=‖x−y‖ 定义的距离真的是距离——没有它，极限就失去意义。

例 1（一步步算：验证 ℓ² 范数 + 具体计算）。ℓ² = {x=(xₙ) : Σ|xₙ|²<∞}，范数 ‖x‖₂ = (Σ|xₙ|²)^{1/2}。验证 x=(1,1/2,1/3,…) 属于 ℓ² 并算范数：

① 有限性：‖x‖₂² = Σ_{n≥1}1/n² = π²/6 < ∞，故 x∈ℓ²。

② 正定/齐次：显然。① 三角不等式：由 Cauchy-Schwarz（见例 3 的推广），‖x+y‖₂² = ‖x‖₂²+‖y‖₂²+2Re⟨x,y⟩ ≤ (‖x‖₂+‖y‖₂)²。故 ℓ² 是真赋范空间，‖x‖₂ = π/√6。∎

例 2（函数空间的三个范数）。同一个空间 C[0,1]（连续函数）可以有不同范数：sup 范数 ‖f‖_∞=sup|f(x)|（"最高点"），L¹ 范数 ‖f‖₁=∫|f|（"面积"），L² 范数 ‖f‖₂=(∫f²)^{1/2}（"能量"）。f(x)=x² 的三种长度：‖f‖_∞=1、‖f‖₁=1/3、‖f‖₂=1/√5≈0.447。同一个函数三副面孔，选哪个范数，就是选哪种逼近标准——这正是"为什么泛函分析里收敛概念多"的根源：sup 收敛要求整条曲线同时贴近，L² 收敛只要求整体能量贴近。

二、完备性：Banach 与 Hilbert 空间——为什么分析要"没洞"

光有范数还不够。回顾实分析（实数完备性）：序列自己内部越来越挤（柯西），极限未必存在——有理数里有"洞"。赋范空间同样有洞：

无穷维里洞更多也更隐蔽，所以分析必须住在"没洞"的空间里。

定义（Banach / Hilbert 空间）。若 X 的每个柯西列都收敛（极限仍在 X 中），称 X 为 Banach 空间（完备赋范空间）。若范数还来自内积 ⟨·,·⟩（‖x‖²=⟨x,x⟩，能谈"角度""正交"），则叫 Hilbert 空间（完备内积空间）。

两者的关系是"梯形"：内积 ⊂ 范数；Hilbert ⊂ Banach。为什么需要 Hilbert？因为有正交——能"投影"、有最佳逼近、有正交基，这些是量子力学和逼近论的核心。

三、线性算子：无穷维的"矩阵"

矩阵是把有限维向量送到有限维向量的线性映射；算子（operator）把无穷维空间送到无穷维空间。算子的"大小"用算子范数衡量：

‖T‖<∞ 的线性算子叫有界算子。一个关键事实：在线性算子身上，"有界"与"连续"是同一回事（‖Tx−Ty‖=‖T(x−y)‖≤‖T‖‖x−y‖；反过来连续可推有界）。这回答了"为什么算子的连续性问题不多讲"——有界就连续。

例 4（一步步算：对角算子范数 = 1）。T:ℓ¹→ℓ¹，(Tx)ₙ = xₙ/n。

① 上界：‖Tx‖₁ = Σ|xₙ|/n ≤ Σ|xₙ| = ‖x‖₁，故 ‖T‖ ≤ 1。

② 下界（找一个省不掉的点）：取 x=e₁=(1,0,0,…)，‖e₁‖₁=1，而 Te₁=(1,0,…)，‖Te₁‖₁=1。故 ‖T‖ ≥ 1。

③ 合起来 ‖T‖ = 1。∎ 套路：先三角不等式给上界，再用一个"测试向量"（往往是基向量）顶出下界。

例 5（一步步算：积分算子的范数 = 1）。V:C[0,1]→C[0,1]，(Vf)(x)=∫₀^x f(t)dt。

① 上界：|(Vf)(x)| ≤ ∫₀^x |f(t)|dt ≤ ‖f‖_∞·x ≤ ‖f‖_∞，故 ‖V‖ ≤ 1。

② 下界：取 f≡1，则 (V1)(x)=x，‖V1‖_∞ = sup_{x∈[0,1]} x = 1 = ‖1‖_∞。故 ‖V‖ ≥ 1。

③ 合起来 ‖V‖ = 1。∎ 这个 V 是经典 Volterra 积分算子，它的谱会在紧算子一节再登场。

为什么有界性在无穷维里值得大书特书？因为无穷维线性映射可以无界——这是与"矩阵总有界"的致命区别。例：D:C¹[0,1]→C[0,1]，Df=f′。取 fₙ(x)=sin(2πnx)，‖fₙ‖_∞=1 但 ‖Dfₙ‖_∞=2πn→∞。无界算子照样出现（微分是量子力学动量算符的核心），但它们不能当"连续对象"直接用——这正是分布论与自伴算子理论的用武之地。

四、三大支柱定理：泛函分析的"宪法"

整个学科有三大支柱，它们回答三件看似平凡、实则决定一切的事：能不能造泛函？有没有自动连续？逆是否自动连续？

① Hahn-Banach（延拓定理）。在子空间 Y 上有界线性泛函 f:Y→ℝ（‖f‖<∞），总能保范延拓到全空间 X。直觉：一个小范围的"尺子"能无损地扩大成全空间的"尺子"。它由 Zorn 引理证明（见附），直接后果是 X*（对偶空间）极其丰富——对任意 x₀≠0 都存在 x*∈X* 使 x*(x₀)=‖x₀‖ 且 ‖x*‖=1（支撑泛函，见工作题 3）。这是凸分析分离定理的起点。

② 一致有界原理（Banach-Steinhaus）。一族算子 {T_α} 若在每个点 x 上都逐点有界（sup_α‖T_αx‖<∞），则整体一致有界（sup_α‖T_α‖<∞）。"逐点有界 ⟹ 一致有界"——由 Baire 类别定理一把证出。大白话：连续就是输入微调、输出也跟着微调、不突然跳变；该定理说，无穷多个连续映射"在每个点都不爆"，就"处处都不爆"。它的价值：很多结论（傅里叶部分和发散、插值算子的无界性）都靠"若不一致有界，则某点爆掉"的反证。

③ 开映射定理（含闭图像定理）。Banach 空间之间的连续线性满射 T:X→Y 是开映射（开集映到开集）；于是连续线性双射的逆自动连续。"逆自动连续"——在无穷维里这不是免费的，完备性换来的。闭图像定理说：闭图 ⊂ 连续（若 T 的图是闭集，T 自动连续），这是"检查连续"最省事的工具。

三大支柱定理支撑整个泛函分析：①Hahn-Banach(线性泛函可延拓→凸分析基石)②Banach-Steinhaus(逐点有界⇒一致有界→"自动连续性")③开映射定理(连续线性双射⇒逆自动连续)。三条都依赖完备性——这是"为什么必须住进 Banach/Hilbert 空间"最实在的回答。

五、对偶空间与弱收敛——"测"向量的另一种方式

把全空间 X 上的有界线性泛函收集起来，得到对偶空间 X* = 𝔅(X,ℂ)。对偶是"探针"：x 和 y 是否不同？用所有探针去测 x*(x)≠x*(y)（Hahn-Banach 保证探针足够多，能分离任意两点）。于是有了新的收敛观念：

弱收敛：xₙ ⇀ x ⟺ 对所有 x*∈X*，x*(xₙ)→x*(x)。它比强收敛（‖xₙ−x‖→0）宽松，因为只要求"每个方向上的投影"都收敛，不要求整体距离收敛。为什么需要这么多种收敛？因为无穷维里强收敛太苛刻——很多自然出现的序列（如正交基在 0 处"摊开"）只有弱收敛。测度论中 e^{inx} 弱收敛于 0 而不强收敛，正是同一个故事的傅里叶版。

例 6（一步步算：ℓ² 中强、弱收敛的对照）。在 ℓ² 中取 eₙ（第 n 个坐标 1，其余 0）。① 弱收敛到 0：对任意 y=(yₙ)∈ℓ² ≅ (ℓ²)*，⟨eₙ,y⟩=yₙ→0（yₙ 是收敛级数 Σ|yₙ|² 的通项，必趋于 0）。② 不强收敛：‖eₙ−0‖₂=1 不趋于 0。∎ 于是 (eₙ) 是"弱收敛不强收敛"的活标本——这种序列在紧算子理论里恰恰是特征向量的典型行为。

常见对偶（都算得出来）：(c₀)* ≅ ℓ¹，⟨x*,x⟩=Σaₙxₙ；(ℓ¹)* ≅ ℓ^∞；Riesz 表示定理给出 (ℓ²)* ≅ ℓ²（每个泛函由一个序列用内积表示）。注意 (c₀)*=ℓ¹ 但 ℓ^∞ 自身的对偶 ⊋ ℓ¹——需要推广的有限可加积分（大白话：积分就是把无穷多小份贡献加总起来，是求和的连续版）。

六、紧算子与谱：无穷维线性代数的核心

无穷维空间上的算子太多、太野，值得盯住一类"最像矩阵"的算子——紧算子。定义：T 把有界集映成相对紧集（其闭包紧）。直觉：T 在某种程度上"忘记"了无穷维——把"无限个自由度"压缩成"几乎有限"的输出。

Fredholm 择一性。对紧 T、λ≠0：要么 (T−λI) 可逆，要么有非零核——没有第三种可能。这和有限维中 det(A−λI)≠0 ⟺ A−λI 可逆完全类似。Fredholm 指标 ind(T)=dim ker−dim coker 在同伦下不变——这是 Atiyah-Singer 指标定理的雏形。

紧致自伴算子的谱定理。T 紧 + T 自伴（⟨Tx,y⟩=⟨x,Ty⟩）⟹ 存在 H 的正交基 {eₙ} 和实数 λₙ→0 使得

非零谱全是特征值，特征空间有限维。这和对称矩阵的 QΛQᵀ 完全一致——只是维数变成无穷。量子力学中束缚态能谱就是这个定理的直接应用。

例 7（一步步算：紧算子的谱长什么样）。取对角算子 T:ℓ²→ℓ²，Teₙ = (1/n)eₙ。它紧（对角项 →0 的对角算子总是紧的）。求谱 σ(T)：

① 非零特征值：对每个 n，Teₙ=(1/n)eₙ，故 1/n 是特征值，特征向量 eₙ。

② 0 不是特征值：若 Tx=0 则 xₙ/n=0 对一切 n，故 x=0，ker T={0}，T 单射。

③ 0 却在谱里：T 的逆若是算子，应满足 T⁻¹eₙ = n eₙ，但 sup‖T⁻¹eₙ‖/‖eₙ‖=n→∞，逆无界，T 不可逆。故 0∈σ(T) 但 0∉σ_p(T)。

④ 于是 σ(T) = {0} ∪ {1/n : n≥1}。∎

这个例子浓缩了紧算子的全部谱特征：可数个谱点、唯一聚点 0、0 是谱点却不是特征值。对照有限维：对称矩阵的谱是有限特征值集、无聚点。

为什么谱理论对物理那么重要？能量算符（Hamiltonian）的谱 = 可观测能量值；束缚态 = 特征值（例 7 里 1/n），散射态 = 连续谱（0）。紧自伴算子给出"离散的、可数的一套能量"——这就是原子光谱离散化的数学源头，详见 谱定理课 与 氢原子课。

5. 紧算子的特征值。说明 T:ℓ²→ℓ²，Teₙ=eₙ/n 的每个特征值 1/n 是"孤立"的（有开邻域不含其他谱点），而 0 不是孤立的。

提示：{1/n} 中任意一点 1/n 到其他谱点的距离 > 0（除有限个近邻外），故孤立；但 0 是 {1/n} 的聚点，任何含 0 的开邻域都含无限多个 1/n。

6. 闭图像定理的应用。为什么"线性映射的图是闭的"比"连续"更容易验证？给一个直觉解释。

提示：连续要求"对每个输入 x 的所有逼近列"都保持极限，工作量大；闭图只要求"恰好极限存在的列"极限也落在图里。很多算子（如微分算子在恰当定义域上）图天然闭，闭图像定理立刻送给你连续性。

证明。

① Baire 类别定理。记 B = B_X(0,1) 为单位开球。T 满射 ⇒ X = ∪ₙ nB ⇒ Y = ∪ₙ n·T(B)。每个 n·T(B) 的闭包都是闭集；Baire 定理（完备度量空间不能是稠密无处集的可数并）给出某个 n 使 \overline{T(B)} 含内点：存在 δ>0 与 y₀ 使 B_Y(y₀,δ) ⊂ \overline{T(B)}。

② 从闭包到包含。由 ① 得 B_Y(0,δ) ⊂ \overline{T(B)}。用完备性强化为真包含：取 y∈B_Y(0,δ)，因 y∈\overline{T(B)} 可取 x₁∈B 使 ‖y−Tx₁‖<δ/2；令 y₁=y−Tx₁∈B_Y(0,δ/2)⊂T(B/2)，取 x₂∈B/2 使 ‖y₁−Tx₂‖<δ/4；归纳得 xₙ∈B/2ⁿ⁻¹ 且 Σ‖xₙ‖<2。由 X 完备，x=Σxₙ 收敛且 y=Tx。故 B_Y(0,δ) ⊂ T(B(0,2))，即 B_Y(0,δ/2) ⊂ T(B_X(0,1))。

③ 开性。对任意 x₀、r>0：T(B(x₀,r)) = Tx₀ + T(B(0,r)) ⊇ B(Tx₀, rδ/2)。故 T 把开球映为含内点之集，T 是开映射；双射情形下 T⁻¹ 连续。∎

附：定理证明——Hahn-Banach 延拓定理（Zorn 引理）

陈述（实范数版本）。设 X 是实赋范空间，Y⊂X 是子空间，f:Y→ℝ 是有界线性泛函。则存在有界线性泛函 F:X→ℝ 使 F|_Y = f 且 ‖F‖ = ‖f‖。更一般地，对任意次线性泛函 p（p(x+y)≤p(x)+p(y)，p(tx)=tp(x) 对 t≥0），只要 f(y) ≤ p(y) 于 Y，就存在 F 延拓 f 且 F(x)≤p(x) 于 X。

证明。

① 单步延拓。设 y₀ ∉ Y，Z = Y + ℝy₀。要延拓 f 到 Z，只需选实数 c 定义 F(y+ty₀) = f(y) + tc。条件 F ≤ p 要求：t>0 时 c ≤ (p(y+ty₀)−f(y))/t，t<0 时 c ≥ (f(y)−p(y+ty₀))/(−t)。由次可加性与正齐性可验证 sup ≤ inf（上确界不超过下确界）：

故这样的 c 存在，单步延拓完成。

② Zorn 化。令 𝒫 = {(E,g) : Y⊂E⊂X 子空间，g 是 f 的延拓且 g≤p 于 E}，按 (E₁,g₁) ⪯ (E₂,g₂) ⟺ E₁⊂E₂ 且 g₂ 延拓 g₁ 定义偏序。任何全序子链——大白话：链就是偏序里一串"一个能比过下一个"、首尾相接排下去的元素列（像珠串），这里是不断变大、互相包含的延拓串——{(E_α,g_α)} 有上界 (∪_αE_α, ∪_αg_α)，因为并集仍是子空间。由 Zorn 引理，𝒫 有极大元 (Ē, ḡ)。

③ 极大 ⇒ 全空间。若 Ē ≠ X，取 x₀ ∈ X∖Ē，由①可把 ḡ 真延拓到 Ē + ℝx₀，与极大性矛盾。故 Ē = X，F = ḡ。

④ 保范。取 p(x) = ‖f‖·‖x‖，则 |F(x)| ≤ p(x) = ‖f‖‖x‖，故 ‖F‖ ≤ ‖f‖；反向由延拓性自动成立。复情形以实部 Re F 化归实泛函再还原。∎

Hahn-Banach 是 Zorn 引理（选择公理）的第一个重大分析后果：X* 极其丰富——对任意 x₀≠0 存在 x*∈X* 使 x*(x₀) = ‖x₀‖，这是分离定理与凸分析支撑面定理的起点。

附：反例——非闭子空间与紧算子的谱

非闭子空间。令 c₀₀ = {有限支撑序列} ⊂ ℓ²。c₀₀ 是线性子空间、稠密（有限支撑逼近 ℓ² 元素）但不闭：极限点——大白话：极限是一串元素不断逼近、最终趋向的对象；极限点就是"可以被一串点无限逼近"的位置——(1, 1/2, 1/3, …) ∉ c₀₀。更一般地，无穷维 Banach 空间的真稠密子空间必非闭。在 C[0,1] 中多项式全体 𝒫 同理稠密而非闭（Weierstrass 逼近定理）。意义：闭性是"线性代数"与"分析"的分界——开映射定理、闭图像定理都要求完备闭子空间。

附：工作题（带解答）

题 1（对偶空间）。确定下列空间的对偶并给出配对公式：(a) (c₀)*；(b) (ℓ¹)*；(c) (ℓ²)*（用 Riesz 表示定理）。

显示解答

(a) (c₀)* ≅ ℓ¹：任意 x*∈(c₀)* 对应 a=(aₙ)∈ℓ¹，⟨x*,x⟩ = Σaₙxₙ，且 ‖x*‖=‖a‖₁。要点：取测试元 x = (sign(aₙ) 前 N 项) ∈ c₀ 得 ‖x*‖ ≤ ‖a‖₁。(b) (ℓ¹)* ≅ ℓ^∞：⟨x*,x⟩ = Σaₙxₙ，a∈ℓ^∞，‖x*‖=‖a‖_∞（取基向量 x=eₙ）。注意 (c₀)* = ℓ¹ 但 ℓ^∞ 自身的对偶 ⊋ ℓ¹（需推广的有限可加积分——大白话：积分就是把无穷多小份贡献加总起来，是求和的连续版）。(c) Riesz 表示定理——大白话：表示就是把抽象的泛函具体翻译成能算的配对公式，这里就是把每个泛函对应成一个序列用内积配对：(ℓ²)* ≅ ℓ²，对每个 x* 存在唯一 a∈ℓ² 使 ⟨x*,x⟩ = Σaₙxₙ（内积），映射 x*↦a 是共轭线性等距同构。

题 2（算子有界性）。判断下列线性算子的有界性并求范数（若存在）：(a) T:ℓ¹→ℓ¹, (Tx)ₙ = xₙ/n；(b) S:ℓ²→ℓ², (Sx)ₙ = Σ_{k=1}^n x_k；(c) D:C¹[0,1]→C[0,1], Df = f′（C¹ 取 sup 范数）。

显示解答

(a) 有界：‖Tx‖₁ = Σ|xₙ|/n ≤ Σ|xₙ| = ‖x‖₁，且 ‖T‖ = 1（取 x=e₁）。(b) 无界：取 xₙ = (−1)ⁿ⁺¹/n ∈ ℓ²，则 (Sx)ₙ = 交替调和部分和 Hₙ = O(1)（收敛于 ln 2），但 ‖Sx‖₂² = Σ|Hₙ|² = ∞，故 sup{‖Sx‖/‖x‖} = ∞。(c) 无界：fₙ(x) = sin(2πnx)，‖fₙ‖_∞ = 1 但 ‖Dfₙ‖_∞ = 2πn → ∞。与有限维矩阵"总有界"的本质区别：无穷维线性映射不一定连续。

题 3（Hahn-Banach 应用）。设 X 是赋范空间，x₀≠0。证明存在 x*∈X* 使 x*(x₀) = ‖x₀‖ 且 ‖x*‖ = 1（支撑泛函）。

显示解答

取 Y = ℝx₀，定义 f(tx₀) = t‖x₀‖，则 f 有界、‖f‖ = 1（|f(tx₀)| = |t|‖x₀‖，等号取 t=1）。由 Hahn-Banach 保范延拓得 F:X→ℝ 满足 F|_Y = f、‖F‖ = 1。故 F(x₀) = ‖x₀‖。推论：X* 分离点，由此可证"X 等距嵌入 X**"等自反性结果。

前沿：非交换L^p空间与量子信息

Pisier-Xu(2003)发展了非交换L^p空间——将向量值L^p推广到算子代数。这在量子信息(信道容量)和非交换概率(自由概率论)中有重要应用。仍开放:非交换Riesz-Thorin定理的完全推广。
