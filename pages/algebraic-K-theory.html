为什么强调"稳定"？ 直觉：分类要干净，得把"平凡丛"当零处理——因为平凡丛是"虚的洞"，不携带拓扑信息。把"同构类"升级为"稳定等价类"（允许加一个平凡直和项抵消），分类才又小又美又可计算。这就是 Grothendieck 群的动机。

一、热身：射影模与 Grothendieck 群——K₀ 的定义

为什么射影模 = "向量丛"？ 向量丛的截面层是局部自由的：局部看是平凡丛，全局由转移函数拼起来。射影模是"局部自由的模"：P 射影 ⟺ P ⊕ Q = R^{free}（某自由模的直和项）。直觉：自由模 = 平凡丛，直和项 = 局部平凡但整体缠绕的丛。

定义（Grothendieck 群）。 K₀(R) 由有限生成射影 R-模的同构类生成：

对每个短正合列 0 → P′ → P → P″ → 0 施加关系 [P] = [P′] + [P″]。直接推论（直和正合）：[P ⊕ Q] = [P] + [Q]，故 K₀ 是 Abel 群，元素是"稳定等价类"。

泛性质（universal property）。 任何从投射 R-模范畴到 Abel 群的加性函数（把短正合列映到和）唯一地通过 K₀(R) 分解——K₀ 是射影模的"万有加法不变量"。为什么这是核心？ 因为几乎所有"不变量"（维数、行列式、Chern 类、特征标）都是加性函数，泛性质说：算它们只需算 K₀ 上的同态。

拓扑版本。 拓扑 K 理论中 K⁰(X) 是 X 上复向量丛的 Grothendieck 群，由 Atiyah–Hirzebruch（1959）引入——这是代数 K 理论与拓扑 K 理论的"Rosetta 石碑"：两个理论共享同一种构造哲学。

二、完整例题 1：K₀(PID) = ℤ——维数是唯一不变量

对 PID（主理想整环，如 ℤ、ℂ[t]）从头算到底。

第 1 步：射影模的结构。 在 PID 上，有限生成射影模 = 无挠有限生成模（射影性 ⟺ 自由直和项，而 PID 上无挠 ⟹ 自由）。故每个射影模同构于 R^n（秩 n）。

第 2 步：维数映射。 定义 dim: K₀(R) → ℤ，[R^n] ↦ n。它是良定义的：短正合列 0 → R^a → R^{a+b} → R^b → 0 给出 dim 加性，故诱导出同态。

第 3 步：满射。 [R] ↦ 1，故 dim 满。

第 4 步：单射。 若 Σ nᵢ[R^{aᵢ}] = 0 ∈ K₀，两边取 dim 得 Σ nᵢaᵢ = 0 ∈ ℤ。所以"K₀ 中相等的类维数必相同"，且维数唯一确定类（每类 = 某个 [R^n]）。故

第 5 步：解释"为什么"。 PID 上"向量丛全是平凡的"——没有缠绕。K₀ = ℤ 说明拓扑信息为零，只剩"维数"（秩）。真正的"洞"要靠非 PID 才出现（例题 2）。∎

四、K₁——GL 与初等矩阵，Whitehead 引理

定义。 K₁(R) = GL(R)/[GL(R), GL(R)]，其中 GL(R) = lim→ GLₙ(R)（稳定一般线性群）。K₁ 测量一般线性群离完美群有多远。

Whitehead 引理（Whitehead 1940s，Bass 1964 完善）。 对任何环 R，换位子群 [GL(R), GL(R)] = E(R)，其中 E(R) 是由初等矩阵 e_{ij}(r)（i ≠ j，r ∈ R，单位矩阵在 (i,j) 位置加 r）生成的子群。因此

对域 F： 行列式同态 det: K₁(F) → F^× 是同构（Dieudonné 行列式）——因为域上初等矩阵恰是行列式 1 的矩阵（高斯消元）。

对整数环： K₁(ℤ) = {±1} ≅ ℤ/2——只有 ±1 两个元素（例题 3 算给你看）。

为什么 K₁ 有用？ K₁(R) = 0 当且仅当对充分大的 n，任何幺模行（行向量能补成可逆矩阵）都可扩充为 GLₙ(R) 中的可逆矩阵——这是稳定秩理论和矩阵消去律的基石。

九、关键计算结果——从整数环到有限域到数环

ℤ 的 K 群——已知部分与巨大未知。 K₀(ℤ) = ℤ；K₁(ℤ) = ℤ/2；K₂(ℤ) = ℤ/2（Milnor 1971，由符号映射给出）；K₃(ℤ) = ℤ/48（Lee–Szczarba 1976，48 来自 Bernoulli 数分母）；K₄(ℤ) = 0（Rognes 1993，用拓扑循环同调证明）；K₅(ℤ) = ℤ ⊕ 有限群（Elbaz-Vincent–Gangl–Soulé 2013，结合了模形式和多重 zeta 值）。n ≥ 8 时 K_n(ℤ) 的结构完全未知！

Quillen 的有限域定理（Quillen 1972, Ann. Math. 96）：K_{2n}(F_q) = 0（n ≥ 1）；K_{2n−1}(F_q) ≅ ℤ/(qⁿ−1)。证明用到 Tits building 的 Lefschetz 不动点定理——是群上同调、代数拓扑和 K 理论交叉的里程碑。

十、证明——K₀ 的泛性质与 K₀(域) = ℤ

把第一、二节的断言写成完整证明。

定理（泛性质）。 设 F 为从有限生成射影 R-模范畴 ℰ 到 Abel 群 G 的加性函数（对每个短正合列 0 → P′ → P → P″ → 0 有 F(P) = F(P′) + F(P″)，且 F(0) = 0）。则存在唯一同态 F̄ : K₀(R) → G 使 F̄([P]) = F(P)。

证明。 定义 F̄ 于生成元 [P] ↦ F(P)。良定义：K₀(R) 的定义关系恰好是 F 所保持的 [P] = [P′] + [P″]。故 F̄ 在生成元与关系上兼容，唯一性由生成元决定。∎

定理（K₀(域) = ℤ）。 设 k 为域。则 K₀(k) ≅ ℤ，由 [k] 生成。

证明。 k 的射影模 = 向量空间，同构类由维数决定，[kⁿ] 是生成元全体。定义 dim : K₀(k) → ℤ 为 [kⁿ] ↦ n：良定义（维数在短正合列上加性），满射（[k] ↦ 1）。单射：若 Σ mᵢ[k^{aᵢ}] = 0 ∈ K₀(k)，因每个生成元都等于 a·[k]（[k^a] = a[k] 由直和关系迭代），故该元形如 n·[k]；应用 dim 得 n = 0。故核为零。∎

这两个证明展示了 K 理论的标准套路：先定生成元与关系，再用"加性不变量"（维数、行列式、Chern 类）作坐标检验。

十一、反例——射影模不自由、K₀ 有挠

反例 1：ℤ[√−5] 上的射影但非自由模。 理想 I = (2, 1+√−5)。先证非主：若 I = (α)，则 α | 2 且 α | 1+√−5。用范数 N(a + b√−5) = a² + 5b²：N(2) = 4、N(1+√−5) = 6，故 N(α) | gcd(4,6) = 2，即 N(α) ∈ {1, 2}。但 a² + 5b² = 2 无整数解（b = 0 ⟹ a² = 2；b ≠ 0 ⟹ ≥ 5），故 N(α) = 1，α 为单位，I = (1) = 整环。但商 R/I ≅ ℤ/2 ≠ 0（因 (2, 1+√−5) 是极大理想，商为域 ℤ/2），矛盾。故 I 非主理想。而 Dedekind 整环上非零理想是有限生成无挠模，因而射影——所以 I 是射影但非自由的模。这是"非平凡向量丛"的代数化身（对应 S¹ 上缠绕数 ≠ 0 的线丛）。

反例 2：K₀ 的挠元。 由上，[I] ≠ [𝒪_K] ∈ K₀(ℤ[√−5])，但 2([I] − [𝒪_K]) = 0（例题 2 已算）。所以 K₀ 含有二阶挠——"非平凡丛的两倍是平凡丛"。这对应拓扑中"非平凡线丛的 Whitney 和两倍变平凡"。

反例 3：稳定秩不等于 1。 在稳定秩 sr(R) = 1 的环（如 PID、局部环）上，幺模行可自由扩充，K₁ 等计算简单；但对 sr(R) > 1 的环（某些坐标环），消去律失败——[P ⊕ R] = [Q ⊕ R] 推不出 [P] = [Q]。这提醒：K 理论必须"稳定化"到足够高维才可靠，正是 BGL(R) 取直极限的原因。

十二、经典文献与历史发展

Grothendieck（1958, Bourbaki 讨论班第 157 号报告）——在 Riemann–Roch 定理的推广中首次引入 K₀，作为代数向量丛的 Grothendieck 群；完整理论见 SGA 6 (1971)。Atiyah–Hirzebruch（1959–1961）——在拓扑中独立发展了 K 理论，Bott 周期性 K(X×S²) ≅ K(X) 是其基石，Atiyah–Singer 指标定理（1963）用 K 理论统一了分析和拓扑。拓扑 K 理论提供了一条与代数 K 理论平行的、相互启发的路径。Bass（1964, "K-theory and Stable Algebra"）——独立于 Grothendieck 发展了环论的 K₁，发现了稳定秩和 Whitehead 群的深刻联系，是第一本代数 K 理论专著。Milnor（1971, "Introduction to Algebraic K-Theory", Princeton）——定义了 K₂ 和 Milnor K 群，Milnor 猜想（1970）首次提出 K^M_n(F)/2 ≅ Hⁿ(F, ℤ/2)，成为 Bloch–Kato 猜想的原型。Quillen（1973–1974）——"Higher Algebraic K-Theory I"（LNM 341）和 II，建立 +-构造和 Q-构造，奠定了现代 K 理论的拓扑基础。获 1978 年 Fields 奖。Suslin（1982–1984）——证明了仿射空间上的向量丛是平凡的（Serre 猜想的 K 理论版），建立了 K 理论局部化定理。Voevodsky（1996–2011）——构建 motivic 同伦论（A¹ 同伦论），证明 Milnor 猜想和 Bloch–Kato 猜想。Motivic 稳定同伦范畴 SH(k) 中，代数 K 理论谱 KGL 是实现 motivic 球谱的关键对象。获 2002 年 Fields 奖。

十三、开放问题与前沿方向

1. ℤ 的 K 群。 计算 K_n(ℤ) 是所有代数 K 理论的圣杯之一。n ≤ 7 已知，n ≥ 8 几乎空白。Lichtenbaum–Quillen 猜想将模 ℓ K 群关联于 étale 上同调和 L 函数特殊值，但 ℓ = 2 情形仍有大量精细问题。Vandiver 猜想（p 不整除分圆域的类数）若成立则可约束 K_n(ℤ) 的部分挠结构。本质上，K_*(ℤ) 的完全计算等价于理解球谱稳定同伦群与代数数论之间的全貌——这是同伦论和数论最深度的交叉。
2. Baum–Connes 猜想（1982，发表为 Baum–Connes–Higson 1994）：对局部紧群 G，装配映射 μ: K_*^{top}(G) → K_*(C_r^*(G)) 是群 C*-代数 K 理论的同构。对 a-T-menable 群成立（Higson–Kasparov 2001），对双曲群成立（Lafforgue 2002, Clay 研究奖），对 SL(3,ℤ) 成立——但一般情形广泛开放。与 Novikov 猜想（高维特征类同伦不变性）和正标量曲率存在性问题（Gromov–Lawson–Rosenberg 猜想）构成几何拓扑中的"铁三角"。
3. Motivic 红移（Red-Shift）猜想。 在 motivic 稳定同伦范畴 SH(k) 中，色展局部化函子 L_{K(n)} 作用于代数 K 理论时存在"红移"现象——色展层次"移动一位"。若成立，将揭示代数 K 理论和色展同伦论（chromatic homotopy theory）之间的深层同源性。Beilinson–Soulé 猜想（motivic 上同调在负权消失）与此密切相关。
4. K 理论在物理中的应用。 拓扑绝缘体和量子 Hall 效应中 K⁻ⁿ(pt) 对拓扑超导体分类（Kitaev 周期表）。非交换 Brillouin 区方法（Bellissard 1990s）用 C*-代数 K 理论分类非周期固体的拓扑相。弦论中 D-brane 的 Ramond–Ramond 荷由 K 理论分类（Witten 1998）——K 理论已取代通常上同调成为量子场论中反常分类的正确不变量语言。这些应用正在启发纯数学中 K 理论的新结构（扭曲 K 理论、微分 K 理论等）。

十五、试试看（每题附提示）

1. 为什么 K₀(k) 对域 k 等于 ℤ 而 K₀(ℂ[t]) 也等于 ℤ？两者有什么共同结构？

提示：两者都是 PID；PID 上射影模都自由，唯一的加性不变量是维数（例题 1）。

2. 验证 ℤ[√−5] 中 (2, 1+√−5) 的商环 ≅ ℤ/2，从而它是真理想。

提示：商 = ℤ[√−5]/(2, 1+√−5) ≅ ℤ/(2)（模掉 1+√−5 后 √−5 ≡ −1，剩 ℤ/2）；故理想真且极大。

3. 证明 2([I] − [𝒪_K]) = 0 ∈ K₀(ℤ[√−5]) 需要 I² 是主理想。为什么 Cl = ℤ/2 保证了这一点？

提示：类群阶 2 ⟹ I ⊗ I = I² 属于平凡类，即 I² ≅ 𝒪_K 作为射影模（主理想 ≅ 自由模）。

4. 用 Whitehead 恒等式验证 e₁₂(1) 与 e₂₁(1) 的换位子属于 E(ℤ)，且其行列式为 1。

提示：交换 i,j 顺序后 [e₁₂(1), e₂₁(1)] 需用 e₁₂(1)、e₂₁(1) 的同阶形式；初等矩阵行列式皆 1，故 det = 1。直接算 e₁₂(1)e₂₁(1)e₁₂(−1)e₂₁(−1) = diag(2, 1/2)（在 ℤ 上不属于 GL₂(ℤ)！）——所以要在 GL₃(ℤ) 里做，用 e₁₂、e₂₃ 的形式才是正确的 Whitehead 恒等式方向。

5. 说明为什么 K₁(F) = F^×（F 为域）"测量 GL(F) 离 E(F) 有多远"。

提示：域上高斯消元把任何可逆阵变成对角阵，对角阵只差行列式；E(F) 恰是行列式 1 的群，故 GL/E ≅ F^×（Dieudonné 行列式）。

6. 为什么 Borel 的定理（K_n(𝒪_F) ⊗ ℚ 的维数由嵌入数 r₁、r₂ 决定）暗示 K 群是"算术对象"而非纯代数的？

提示：维数由 ℚ 的嵌入数决定——r₁、r₂ 是数域 F 的算术数据（实的/复的嵌入个数），与 zeta 函数特殊值 ζ_F(1−2k) 相连（Lichtenbaum 猜想的雏形）。

十六、附：工作题——K₀ 与 K₁ 的显式计算

工作题 1（K₀(ℤ/6ℤ)）。 用中国剩余定理算 K₀(ℤ/6ℤ)。

显示解答

ℤ/6ℤ ≅ ℤ/2 × ℤ/3（CRT）。射影模：ℤ/6 上射影模 = (ℤ/2)^a ⊕ (ℤ/3)^b（每个分量上自由）。正合列加性给出 K₀(ℤ/6) = ℤ²，由 [ℤ/2] 与 [ℤ/3] 生成。一般：K₀(R₁×R₂) = K₀(R₁) ⊕ K₀(R₂)。

工作题 2（K₁(ℂ)）。 说明 K₁(ℂ) = ℂ^×，并指出它作为 Abel 群的结构。

显示解答

域上 K₁ = 乘群（Dieudonné 行列式）。ℂ^× ≅ ℝ_{>0} × U(1) ≅ ℝ ⊕ (ℚ/ℤ 的 ℚ-向量空间版本，即其可除包）——更精确地 ℂ^× ≅ ℝ_{>0} × S¹，作为 Abel 群 ℂ^× 可除。K₁(ℂ) 携带了"复数乘群"的全部信息。

工作题 3（射影但非自由）。 证明 ℤ[√−5] 的理想 (2, 1+√−5) 是射影的（直接理由），并写出它的一个补模。

显示解答

Dedekind 整环上一切非零理想可逆（I·I⁻¹ = 𝒪_K），可逆理想是射影的（视为模，分式理想 ⊗ … 给出分裂）。补模 Q 满足 I ⊕ Q = 自由模：取 Q = I⁻¹（分数理想），则 I ⊕ I⁻¹ ≅ … 可逆性给出 I ⊕ I^{-1} ≅ 𝒪_K ⊕ 𝒪_K（标准恒等式 I ⊗ I^{-1} = 𝒪_K 配直和恒等式 I ⊕ I^{-1} = 𝒪_K ⊕ I·I^{-1}）。
