〇、直觉入门——拿一个具体的纠缠态，算一次具体测量

先写下一个带数字的具体纠缠态：

这是两个量子比特的态：第一个位置放 Alice 的比特，第二个位置放 Bob 的比特。|00⟩ 表示"Alice 的比特是 0、Bob 的比特也是 0"；|11⟩ 表示"两个都是 1"。现在 Alice 测量自己的比特，会发生什么？

按量子力学的规则，这个态以 1/2 的概率投影到 |00⟩、以 1/2 的概率投影到 |11⟩——也就是说：Alice 得到 0 的概率是 50%，而且一旦她得到 0，Bob 的比特就必然是 0；她得到 1 的概率也是 50%，一旦她得到 1，Bob 的比特就必然是 1。测量关联的数字写全：P(00)=1/2、P(11)=1/2、P(01)=0、P(10)=0——两个比特的结果永远一致，从不一错。

这就像你左手和右手各戴一只手套，分开八千里路，打开左手的盒子发现是左手套，立刻知道右手拿的是右手套——但手套的配对是发货时就安排好的，这不神奇。量子纠缠比这更奇妙：|00⟩ 和 |11⟩ 这两个"选项"同时叠加在一起，在测量之前，两个比特连"各自是什么"都谈不上，而测量一个，另一个的状态瞬间确定。

这东西在干什么：纠缠是量子计算机和"隐形传态"的原料，让信息可以不走寻常路地传递；下面你会看到，纠缠甚至能用具体数字打败任何"早就安排好的配对"。

两个粒子一旦纠缠，就成为一个不可分割的整体，测量其中一半就能确定另一半，但你不能用它超光速通信。只想懂核心思想，看到这里就够了。

一、什么是纠缠？——为什么 |Φ⁺⟩ 不能写成张量积

量子力学的世界像一个乐高积木盒。两个独立系统各有一个状态，把它们放在一起时，合法的组合方式是它们的张量积：

也就是说：如果 Alice 的态是"a 分像 0、b 分像 1"，Bob 的态是"c 分像 0、d 分像 1"，那么组合后的四个成分 |00⟩、|01⟩、|10⟩、|11⟩ 的系数分别是 ac、ad、bc、bd——四个系数由 a、b、c、d 四个数相乘得到，不是随便四个数都行。

现在问：|Φ⁺⟩ = (|00⟩+|11⟩)/√2 能写成这种乘积吗？试着匹配系数。如果 |Φ⁺⟩ = (a|0⟩+b|1⟩)⊗(c|0⟩+d|1⟩)，则必须同时满足

ad=0 要求 a=0 或 d=0。但 ac=1/√2≠0 告诉我们 a≠0，所以必须有 d=0；而 bd=1/√2≠0 又要求 b≠0 且 d≠0。矛盾。因此 |Φ⁺⟩ 不可能写成两个单比特态的乘积——它属于"整体"而非"两个部分的拼合"。这种不可分解的两体态就叫纠缠态。

为什么这一点重要？因为不可分解意味着：你不能单独描述 Alice 的比特"是什么"——除非你把它和 Bob 的比特放在一起作为一个整体。它的两个比特之间没有"各自的独立身份"，只有"联合的身份"。这正是 EPR（Einstein–Podolsky–Rosen, 1935）当年觉得不能接受的地方：爱因斯坦认为每个粒子总该有自己确定的状态，量子力学却坚持这两个粒子只有联合状态，所以他称纠缠为"鬼魅般的超距作用"。

还有一句话要钉在墙上：叠加是纠缠的必要原料。|00⟩ 或 |11⟩ 单独拿出来都是平凡的可分解态；是"|00⟩ 和 |11⟩ 叠在一起"这件事，制造了不可分解性。

John Bell 1964年终结了这个争论：他导出了一个任何局域隐变量理论必须满足的不等式。量子力学预测违反CHSH不等式（|S| ≤ 2 vs 量子预测 |S| = 2√2 ≈ 2.828）。2015年三个独立实验同时关闭所有漏洞。2022年Nobel物理学奖——Aspect, Clauser, Zeilinger。局域实在论不是宇宙的正确描述。

二、测量关联——纠缠在实验里怎么"看"出来（完整例题 1）

上一节我们"算"出了纠缠，但实验中怎么观察它？答案：测量关联——比较两个比特结果的吻合程度。先把直觉讲透，再用数字严格算。

直觉。一对"心灵感应"的硬币：抛一次，两个结果要么都正面、要么都反面，从不一正一反。你可以统计"两个结果一致的频率"来验证它们的关联。量子纠缠的关联更奇特：你在两个互相垂直的测量方向上，都能看到这种完美关联——而任何"预先配好的对"只能在一个方向上做到。

严格计算。完整例题 1：对 |Φ⁺⟩ 做两组不同的测量，算关联数字。

四、量子隐形传态——用量子纠缠传输量子态（完整例题 3）

Alice 手里有一个量子态 |ψ⟩ 要传给 Bob，但她不能直接送过去，也不能测量它（一测就破坏）。怎么传？答案是：先共享一对纠缠比特，再补两条经典信息。

协议。(1) Alice 把她要传的 |ψ⟩ 与她的半个 Bell 对放到一起，做一个Bell 测量（把两个比特整体投影到 Bell 基上）→ 得到 2 个经典比特。(2) Alice 通过经典信道把这 2 比特发给 Bob。(3) Bob 按收到的比特施加 X 和/或 Z 门 → 他的比特恢复成 |ψ⟩。

七、纠缠判据——约化密度矩阵的纯度

设 AB 处于纯态 |ψ⟩ ∈ HA ⊗ HB。A 的约化密度矩阵通过对 B 求迹得到 ρA = TrB|ψ⟩⟨ψ|。作 Schmidt 分解（把两体态展开成"正交基之积"的规范形式）|ψ⟩ = Σᵢ √pᵢ |eᵢ⟩ ⊗ |fᵢ⟩(pᵢ>0, Σpᵢ=1)，则 ρA = Σ pᵢ |eᵢ⟩⟨eᵢ|，故

推导。Tr(ρA²)=Σpᵢ²=1 当且仅当只有一项 p₁=1(其余为 0)，即 |ψ⟩=|e₁⟩⊗|f₁⟩ 是纯可分离态；此时 ρA=|e₁⟩⟨e₁| 为秩 1 投影，S=0。反之只要有两个 pᵢ>0 就有 Σpᵢ²<1 且 S>0，态不可分离，即纠缠。故对纯态，纠缠 ⟺ 约化密度矩阵非纯。

八、标准反例：可分离态也有关联——相关 ≠ 纠缠

考虑混合态 ρ = ½|00⟩⟨00| + ½|11⟩⟨11|。它可显式写成量子比特态的凸组合（按概率加权混合）ρ = ½(|0⟩⟨0|⊗|0⟩⟨0|) + ½(|1⟩⟨1|⊗|1⟩⟨1|)，因而是可分离态，不含纠缠。但测量两个比特仍 100% 相关：要么同为 0，要么同为 1。这证明经典关联 ≠ 量子纠缠——纠缠需要量子叠加。

另一反例：纯可分离态 |ψ⟩ = |0⟩ ⊗ (|0⟩+|1⟩)/√2 的约化密度矩阵 ρA=|0⟩⟨0| 是纯态，S(ρA)=0，无纠缠。严格判据：ρ 可分离 ⟺ ρ=Σₖ pₖ ρₖᴬ ⊗ ρₖᴮ(本反例的混合态满足此式)。

十、试试看（带提示）

1. 证明 |Ψ⁻⟩=(|01⟩−|10⟩)/√2 也是纠缠态。
提示：设它等于 (a|0⟩+b|1⟩)⊗(c|0⟩+d|1⟩)，展开得 ac=bd=0、ad=1/√2、bc=−1/√2。ad≠0 与 bc≠0 推出 a,b,c,d 全非零，与 ac=0 矛盾。捷径：算 ρA=½I₂，Tr(ρA²)=½<1。

2. 计算 |Ψ⁺⟩=(|01⟩+|10⟩)/√2 的约化密度矩阵与纠缠熵。
提示：ρAB 的交叉项 |01⟩⟨10| 求迹时乘 ⟨0|1⟩=0 消失，剩下 ½(|0⟩⟨0|+|1⟩⟨1|)=½I₂；S=ln 2=1 bit。四个 Bell 态全是最大纠缠。

3. 验证四个 Bell 态两两正交。
提示：例如 ⟨Φ⁺|Φ⁻⟩=½(⟨00|00⟩−⟨00|11⟩+⟨11|00⟩−⟨11|11⟩)=½(1−0+0−1)=0；⟨Φ⁺|Ψ⁺⟩ 则每个内积都是 ⟨00|01⟩=0 之类。

4. 对直积态 |0⟩|+⟩ 计算 E(ZAZB) 和 E(XAXB)，与 Bell 态对比。
提示：直积态关联可分解 E(ZAZB)=⟨ZA⟩⟨ZB⟩=1·0=0；⟨XA⟩=0、⟨XB⟩=1 给出 E(XAXB)=0。直积态完全没有关联——关联要么来自纠缠（第二节），要么来自经典混合（第八节反例）。

5. 隐形传态：若 Alice 的 Bell 测量结果是 |Ψ⁺⟩（编码 10），Bob 应施加什么门恢复 |ψ⟩=(√3/2)|0⟩+(1/2)|1⟩？
提示：查第四节表格，|Ψ⁺⟩→X 门。此时 Bob 的态是 X|ψ⟩=(1/2)|0⟩+(√3/2)|1⟩，再施加 X 得 (√3/2)|0⟩+(1/2)|1⟩=|ψ⟩ ✓。

6. 为什么 Alice 测完 Bell 对、Bob 的态"瞬间确定"，却不能用它超光速通信？
提示：Bob 单独测量自己的比特，得到 0 或 1 各占 50%——和从没有纠缠的无关量子比特测量结果完全一样，Bob 无法分辨 Alice 是否已经测量；要真正得到 |ψ⟩，必须等经典比特送到。关联是真实存在的，但因果性的信息传递仍受光速限制。

十一、工作题：Bell 态 |Φ⁺⟩ 的纠缠熵

题目。给定 Bell 态 |Φ⁺⟩ = (|00⟩ + |11⟩)/√2 ∈ ℂ²⊗ℂ²。(1) 求约化密度矩阵 ρA = TrB|Φ⁺⟩⟨Φ⁺|；(2) 验证 Tr(ρA²) = ½ < 1(纠缠判据)；(3) 计算 von Neumann 纠缠熵 S(ρA)，分别用自然对数 ln 与 log₂ 给出。

显示解答

(1) ρAB = |Φ⁺⟩⟨Φ⁺| = ½(|00⟩⟨00| + |00⟩⟨11| + |11⟩⟨00| + |11⟩⟨11|)。对 B 求迹：TrB(|00⟩⟨00|)=|0⟩⟨0|，TrB(|00⟩⟨11|)=|0⟩⟨1|·⟨0|1⟩=0(交叉项消失)，对称地 TrB(|11⟩⟨00|)=0，TrB(|11⟩⟨11|)=|1⟩⟨1|。故 ρA = ½(|0⟩⟨0|+|1⟩⟨1|) = ½I₂，最大混合态。(2) ρA²=¼I₂，故 Tr(ρA²)=½<1——判据确认 |Φ⁺⟩ 为最大纠缠态。(3) S(ρA) = −Tr(½I₂·ln(½I₂)) = −(½ln½+½ln½) = ln 2 ≈ 0.693(nats)。用 log₂：S = −(½log₂½+½log₂½) = 1 bit。两单位相差因子 ln 2：1 bit = ln 2 nats。∎

题目 2。对 singlet |Ψ⁻⟩=(|01⟩−|10⟩)/√2 重做 (1)–(3)。

显示解答

ρAB=|Ψ⁻⟩⟨Ψ⁻|=½(|01⟩⟨01|−|01⟩⟨10|−|10⟩⟨01|+|10⟩⟨10|)。交叉项 |01⟩⟨10| 求迹时给出 |0⟩⟨1|·⟨0|1⟩=0，同样消失，故 ρA=½(|0⟩⟨0|+|1⟩⟨1|)=½I₂。Tr(ρA²)=½，S=ln 2=1 bit。所有 Bell 态都是最大纠缠态。∎

十二、Bell 实验的历程——从 Aspect 到 Nobel

Aspect(1982)首次在实验室中严格违反Bell不等式。但三个"漏洞"需要逐一关闭：(1)定域性漏洞——测量设备之间的信号可能超光速？→ 2015年Delft实验室用1.3km光纤间距关闭。(2)探测漏洞——只检测到部分光子可能不是随机的？→ 2015年NIST和维也纳同时关闭。(3)自由选择漏洞——粒子源和测量设置之间可能有"阴谋"？→ 2018年用来自遥远类星体的随机光设置了测量。全关。

十三、前沿：量子互联网与纠缠蒸馏

长途传输中噪声会降低纠缠质量。Bennett等(1996)提出的纠缠蒸馏：从多份低质量纠缠对中提取少量高质量纠缠对——纯化。量子中继器 = 纠缠交换 + 纠缠蒸馏。2024年中国"墨子号"量子科学实验卫星已实现4600公里量子密钥分发。仍开放：纠缠蒸馏的最优速率公式。

关键论文

  • Einstein–Podolsky–Rosen (1935)：EPR 悖论——纠缠的物理发问。
  • Bell (1964)：Bell 不等式——纠缠的局域隐变量不可能性。
  • Clauser–Horne–Shimony–Holt (1969)：CHSH 不等式——可实验检验的形式。
  • Aspect 等 (1982)：Bell 不等式的实验违背——量子纠缠的实验确立（2022 诺奖）。
  • 教材：Nielsen–Chuang, Quantum Computation and Quantum Information。
