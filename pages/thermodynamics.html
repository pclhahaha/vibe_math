〇、直觉入门——热力学是"能量往哪跑"的记账本

热水放久了会凉，冰会化，这是热在"到处跑"。热力学就是研究能量和热怎么转移的学问，像一本严格的记账本：能量不会凭空消失（第一定律），而热量总爱从热的流向冷的、不会自动回头（第二定律）。

它为什么存在？因为从发动机、冰箱到天气和宇宙演化，都要靠这几点简单规则来解释，它不问细节，只用几条大原则就把整个"能量世界"管住。

能量不会凭空消失，热量总爱往冷处跑——热力学就是这两句话的完整记账本。只想懂核心思想，看到这里就够了。

一、数字驱动的问题——一罐气体能掏出多少功？

把 1 mol 理想气体（例如氦气）封在带活塞的气缸里，温度 T = 300 K。让它做等温可逆膨胀：活塞缓缓后移，气体始终保持 300 K，体积从 V₁ = 1 L 胀到 V₂ = 2 L。这一步能算出多少功？

对 pV = nRT 求积分：W = nRT ln(V₂/V₁)。代入 n = 1、R = 8.314 J·mol⁻¹·K⁻¹、T = 300 K：

气体对外做了 1729 J 的功。能量不会凭空产生——这笔功从哪来？只能来自它从外界吸的热。等温时理想气体内能不变（ΔU = 0），所以 Q = W ≈ 1729 J。最朴素的一本账：吸热 1729 J，做功 1729 J，内能没变。

换个问法：把同一罐气体夹在 600 K 的热源与 300 K 的冷源之间当热机，哪怕是最理想的情形，效率天花板也只有 1 − 300/600 = 0.5——吸进 1000 J 最多只吐出 500 J 功（详见 Carnot 循环）。这背后，正是"热不肯自动回流"的第二定律。

这门课的目标：把上面几笔账，用四条定律算清楚、算严格。

二、第零定律——为什么"温度"这个概念存在

要记账，先要有"币种"——温度。但温度并不是先验存在的：它由热平衡定义。把两块铁放到一起，等它们不再变化，就称它们热平衡；一个"温度计"就是能与被测物达成热平衡、并随温度单调变化的小装置。

第零定律：若 A 与 B 各自与 C 处于热平衡，则 A 与 B 也热平衡——热平衡是等价关系，从而可定义温度 T 这一状态函数。

为什么需要第零定律？ 因为我们测量温度靠的是"温度计先与物体平衡，读数再代表物体"——这一步只有在热平衡是等价关系时才有意义。没有它，温度只是心理概念；有了它，温度才是定义在"平衡态集合"上的函数。

第零定律给出"温度的存在"，第一定律给出"能量是状态量"，第二定律给出"熵的方向"，第三定律给出"熵的标尺"。四者合在一起才定义了完整的热力学。

三、第一定律——能量记账本，以及为什么 Q、W 不是状态函数

第一定律：内能是状态函数，dU = δQ − δW。循环过程中 ∮δQ = ∮δW，能量守恒（焦耳当量实验确立热功等价：4.186 J 的机械功等价于 1 cal 的热）。

内能 U 只依赖热力学态，与路径无关；而热 δQ 与功 δW 依赖路径——它们不是全微分，故用 δ 而非 d。判据：若 ω = A dx + B dy 满足 ∂A/∂y = ∂B/∂x，则 ω 是全微分。δQ 不满足这一条件，所以"热量"不能写成某个状态函数的微分；功同理。

为什么 Q、W 依赖路径而 U 不依赖？ 因为热和功是能量穿越系统边界的两种方式。同样的始末态，你可以先多给热再补做功，也可以反过来——边界上"流量"由你选的路决定，而终点油箱里的"存量"由终点决定。这就是 δ 与 d 的本质区别。

热力学势 = Legendre 变换。F(T,V,N) 是 U(S,V,N) 对 S 做 Legendre 变换的结果：F = U − TS = inf_S (U − TS)。它把"自然变量从 S 换到 T"——极小化 F 对应在给定温度下系统自发到达的状态。G(T,P,N) 同理对 (S,V) 做变换，是化学势的生成函数。

四、完整例题1——同一起终点，三条路，三份不同的功

仍取 1 mol 理想气体，起点 A：(V = 1 L, T = 300 K)，终点 C：(V = 2 L, T = 300 K)。走三条不同的路径，验证 Q 与 W 依赖路径、而 ΔU 不依赖。

路径 ①：等温可逆膨胀（上一节已算）：

路径 ②：先等压加热，再等容冷却。A→B 在恒定压强 P = nRT_A/V_A ≈ 2.49×10⁶ Pa 下加热到 600 K（体积随之胀到 2 L）；B→C 在恒定体积下冷却回 300 K。

等压段：W = P(V_B − V_A) = 2.49×10⁶ × 10⁻³ ≈ 2494 J；单原子气体 C_v = (3/2)R ≈ 12.47 J/(mol·K)，故 ΔU = nC_v(T_B − T_A) = 12.47×300 ≈ 3742 J；第一定律给出 Q = ΔU + W = 6236 J。等容段：W = 0，ΔU = −3742 J，Q = −3742 J。

路径 ③：先等容冷却，再等压膨胀。A→D 等容冷却到 150 K（压强减半为 1.25×10⁶ Pa）；D→C 在恒定压强下膨胀回 (2 L, 300 K)。

等容段：W = 0，ΔU = 12.47×(−150) ≈ −1871 J，Q = −1871 J。等压段：W = PΔV = 1.25×10⁶ × 10⁻³ ≈ 1247 J，ΔU = +1871 J，Q = 1871 + 1247 = 3118 J。

总结：三条路终态相同，ΔU = 0 三者皆同；而功分别是 1729 J、2494 J、1247 J，热对应相等。W 与 Q 没有唯一数值——它们不是状态函数；ΔU 有唯一数值——它是状态函数。这就是"为什么用 δ 而不是 d"。

同一始末态，功可以是 1247 J、1729 J 或 2494 J——路径决定功与热；但内能的变化永远是 0。状态量守恒，过程量随路。

五、第二定律——热为什么只肯往一个方向流

第一定律说能量守恒，却不禁止热量从冷水流向热水；经验告诉我们这种事从不发生。第二定律把这条经验变成一条独立于第一定律的法则：

第二定律（Kelvin–Planck）：不存在只从单一热源吸热并全部做功的循环过程；等价地（Clausius），热量不能自发从低温流向高温。

为什么需要第二定律？ 第一定律管"账目平衡"，第二定律管"交易方向"。若没有它，一台永动机就能把大海当热源、吸热全部变成功——第一定律并不禁止（能量仍守恒），第二定律却把它判为死刑。方向性来自微观统计：分子速度分布的细节让"逆过程"在宏观上需要天文数字的时间。这一点最直接的定量后果，正是 Carnot 定理：任何热机效率 η ≤ 1 − T_c/T_h。第二定律还规定 T dS ≥ δQ：可逆时取等号（δQ = T dS），不可逆时 δQ < T dS。

六、第三定律——绝对零度是地平线

第三定律（Nernst）：当 T → 0，任何纯物质的熵 S → S₀，S₀ 与压强、相无关（有序基态唯一时 S₀ = 0）；因此绝对零度不可通过有限步骤到达——等温与绝热路径的交点无法在有限时间内收敛到 T = 0。

为什么不可达？ 若 T_c = 0，则 Carnot 效率 = 1，即热完全变成功；更麻烦的是，要冷却一个物体到更低温，你需要更冷的冷源，而制造它又需要更冷的冷源……无限递推（详见 Carnot 循环）。第三定律给出熵的标尺：S₀ 是基准，温度越高熵越大——这是熵能当"时间箭头"的最后一块拼图。

七、熵与熵产生——为什么熵会增加

把熵的变化拆成"外流项"与"产生项"：dS = dS_ex + dS_int，其中 dS_ex = δQ/T（与外界交换），dS_int ≥ 0（内部产生），等式当且仅当过程可逆。第二定律 = dS_int ≥ 0。孤立系统（dS_ex = 0）中熵单调不减。

为什么熵会增加？ 统计地说，宏观态对应的微观态数 W 越多，占据概率越大；熵 S = k ln W 度量"这个宏观态有多少种微观实现"。平衡态是 W 最大的状态——从任何偏离平衡的态出发，系统"滑向"微观态数更多的态，这就是 dS_int ≥ 0 的统计来源，也是"热不回头的"深度原因。

自由膨胀：理想气体从体积 V₁ 绝热自由膨胀到 V₂ > V₁。因绝热且对外不做功，U 不变 → T 不变。但熵变化 ΔS = nR ln(V₂/V₁) > 0——完全由内部产生，无任何外流。微观解释：气体在更大体积中有更多微观态，W₂/W₁ = (V₂/V₁)^N，S = k ln W 严格增加。可逆性 = 每一时刻处于"局部平衡"，不可逆 = 内部耗散（摩擦、粘滞、扩散、有限温差传导）。

八、完整例题2——自由膨胀的熵账本

1 mol 理想气体，300 K，绝热自由膨胀，体积从 V 胀到 2V。

第 1 步：自由膨胀 Q = 0、W = 0，故 ΔU = 0；理想气体 ΔU 只由 T 决定，T 不变。

第 2 步：求熵变。熵是状态函数，可以挑一条可逆的路径从初态走到末态来算——选等温可逆膨胀：

第 3 步：这笔熵从哪来？可逆路径上它来自吸热 δQ = T dS；但自由膨胀是绝热的（δQ = 0）。所以 ΔS 完全是内部产生的：dS_int = 5.76 J/K > 0，孤立系统熵增。

对比：换成"等温可逆膨胀"到同一末态，系统同样 ΔS_sys = 5.76 J/K，但这次它从外界吸热 1729 J，环境损失熵 ΔS_surr = −1729/300 = −5.76 J/K，两者相抵，ΔS_total = 0（可逆）。

同一始末态的熵变是固定的 5.76 J/K；可逆过程把"熵账"记在环境头上（总账持平），不可逆过程只能记在自己头上（总账盈余）。

恒定体积：W = 0，热量全变成内能：

这笔差额去哪了？ 变成气体推开大气做的功。为什么恒定压强要多花钱？因为多买了一份"膨胀的功"。这个对比立刻给出一个普遍结论：理想气体总有 C_p − C_v = nR——而 Maxwell 关系（下一节）正是用来把它修正到真实气体的工具。

十、Maxwell 关系——把测不到的换成测得到的

由状态函数二阶混合偏导的交换性（Schwarz 定理）导出的四组关系。以 F(T,V)：dF = −S dT − P dV，交叉导数相等 ⟹ (∂S/∂V)_T = (∂P/∂T)_V。同理从 U, H, G 得到另外三个。

为什么它们有用？ 熵 S 和它对体积的偏导几乎不可直接测量——世上没有"熵计"。但这些关系把 (∂S/∂V)_T 换成 (∂P/∂T)_V：压力对温度在恒容下的偏导，只要把样品放进恒容容器、测不同温度的压强即可。Maxwell 关系 = 把热力学量翻译成实验室里摸得着的量。

十一、统计力学桥——熵从计数中来

配分函数 Z = Σ e^{−E_i/kT} 编码了系统全部平衡信息。自由能 F = −kT ln Z：对 F 求导得到 U = −∂ln Z/∂β，S = k(ln Z + βU)，P = −∂F/∂V。微观层面，Boltzmann 关系 S = k ln W 把熵定义为微观态数 W 的对数——熵"涌现"自统计：宏观平衡态对应微观态数最多的分布，而概率集中让这个最概然分布几乎确定。

为什么热力学"涌现"？因为 N ~ 10²³ 个粒子的微观态分布极度集中在少数宏观态上。自由能最小化 = 配分函数求和的对数——它同时是最大熵原理（固定能量约束下的最大不确定性分布）的体现。

十三、关键论文

Clausius (1865)——在论文中首次命名"熵"(entropy, 源自希腊语"转变")并给出第二定律的熵表述 dS ≥ δQ/T，确立热力学第二定律的现代形式。

Gibbs (1876-78, "On the Equilibrium of Heterogeneous Substances")——相平衡与化学势的里程碑，创立吉布斯自由能、相律 F=C−P+2，被 Gibbs 本人称为"一生最重要的贡献"。

Boltzmann (1877)——用组合计数给出 S = k ln W，把熵的统计解释奠定为概率论；1896-98 的《Lectures on Gas Theory》系统化。

Carathéodory (1909)——热力学的公理化：以"绝热不可达性"（在任意态近旁存在绝热不可达的态）作为第二定律的几何基础，回避了循环过程的语言。

十四、前沿

非平衡热力学：Onsager 倒易关系（线性响应矩阵对称性）、Prigogine 最小熵产生原理与耗散结构——远离平衡的自组织。Crooks 涨落定理与 Jarzynski 等式把平衡与非平衡联系起来。

信息热力学：Landauer (1961) 原理——擦除 1 bit 信息至少消耗 kT ln 2 的热量；信息熵与热力学熵通过 Szilard 引擎与 Maxwell 妖在 21 世纪的实验（量子热机、光镊单分子）中被定量验证。

黑洞热力学：Bekenstein-Hawking 熵 S_BH = kc³A/(4Għ)，黑洞面积永不减少（类比熵增）；AdS/CFT 对偶把体态引力映射到边界量子场论的热力学——广义第二定律的黑洞形式。

  1. 逆向等温压缩：1 mol 理想气体在 300 K 等温可逆压缩，从 2 L 压回 1 L。求气体做的功 W、吸的热 Q 与熵变 ΔS。
    提示

    与例题1的路径①恰好相反，ln(1/2) = −ln 2 ≈ −0.693。压缩时外界对气体做功：W ≈ −1729 J；Q ≈ −1729 J（放热）；ΔS = −5.76 J/K——熵是状态函数，正反路径熵变反号。

  2. 两倍的气体：2 mol 单原子理想气体从 300 K 加热到 350 K，恒容与恒压各需多少热？哪个多？为什么？
    提示

    C_v = (3/2)R、C_p = (5/2)R，n = 2、ΔT = 50。恒容 Q = 2×12.47×50 ≈ 1247 J；恒压 Q = 2×20.79×50 ≈ 2079 J。多出的 832 J ≈ nRΔT，正是膨胀对外做的功。

  3. 自由膨胀到三倍：0.5 mol 理想气体绝热自由膨胀，体积从 V 到 3V。求 ΔS。
    提示

    ΔU = 0，T 不变；ΔS = nR ln 3 ≈ 0.5×8.314×1.0986 ≈ 4.57 J/K。这是纯粹的 dS_int > 0。

  4. 融冰的熵：1 mol 冰在 0 °C（273.15 K）完全融化成水，熔化热 6.01 kJ/mol。求 ΔS，并解释为什么相变熵为正。
    提示

    相变温度不变、可逆吸热：ΔS = Q_rev/T = 6010/273.15 ≈ 22.0 J/K。冰的晶格比水更有序（W 更小），融化把"晶格排列"换成水的"流动无序"，微观态数激增。
