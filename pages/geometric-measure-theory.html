〇、直觉入门——给"面积为零却无处不在"的集合称重

康托尔三分集 C：从 [0,1] 挖去中段、再挖……长度（Lebesgue 测度）最后是 0，但它显然比一个点"更厚"——它有多少"维度"？Hausdorff（1918）给出的答案：用 s-维 Hausdorff 测度 H^s 给集合"称重"，再找那个临界指数：

H^0 数点、H^1 量长度、H^2 量面积（到常数）——整数维的 Lebesgue 测度只是这个家族的特例。康托尔集的维度落在非整数：

这门"几何测度论（GM theory）"由 Hausdorff、Besicovitch、Federer 等建立，研究非光滑集合的"几何可测"结构：任意集合的维数（Hausdorff/密度/Frostman）、Lipschitz 映射下的面积与余面积公式、可求长/可求积集合（几乎处处有切平面）、以及变分问题（极小曲面、周长、currents）。它是分形几何（→ 分形）、Kakeya/限制性猜想（→ Kakeya 课，Besicovitch 集合正是"面积 0 却满维"的教材例）、PDE 自由边界与最优传输（Monge）的共同地基。

洞察：几何测度论的座右铭——维度与测度是两把尺：面积可以是 0、维数照样满（Besicovitch 集）；测度为零 ≠ 维数低。它的三件工具支撑着现代分析几何：Hausdorff 测度（维数的秤）、Frostman 引理（维数下界的"质量分布"证明法）、面积/余面积公式（Lipschitz 世界的微积分）。画布上把康托尔集递归到第 k 层，看 H^s 估计如何在 s=dim 处从 ∞ 跳到 0——维数就是那条"相变线"。
⚠️ 背景提示：本课属于 前沿 级别。

建议先掌握：测度论（Lebesgue 测度与可测函数）、分形（维数的直观）、Kakeya 猜想（集合维数与调和分析的接口）。

一、一个具体问题——三个递进的问题把"病态集合"变成数学对象

问题 1：任何集合的"维数"是多少？ Hausdorff 用覆盖给出 H^s 与 dim_H：满足单调、可数半加、Lipschitz 下不增（dim_H f(A)≤dim_H A），对 ℝ^d 的 d-维子集给出 dim=d。例子：Cantor 三分集 ln2/ln3、Cantor×Cantor（维数相加 2ln2/ln3）、Koch 曲线 ln4/ln3≈1.2619、Sierpiński 地毯 ln8/ln3。

问题 2：病态函数/集合怎么"微积分"？ Rademacher：ℝⁿ→ℝ^m 的 Lipschitz 映射几乎处处可微——Lipschitz 世界里有微积分；面积公式把"曲面的积分"化成"映射雅可比"的积分，余面积公式把"分层计数"化成纤维上的积分。可求积集合 = Lipschitz 像的可数并（a.e. 有切平面）——"光滑"的弱版本。

问题 3：变分问题（极小曲面）有解吗？ Plateau 问题（给定边界找面积最小曲面）在任意边界下需要"允许有奇异点的广义曲面"：周长/currents/varifolds 框架（Federer–Fleming）给出存在性——几何测度论因此是现代变分法与自由边界理论的语法。

二、先直觉后严格——维数的两把尺与 Frostman 引理

覆盖数与缩放。 若 A 的每个 ε-覆盖至少需 N(ε) 段、每段 ~ε，则"体积"估计 ~N(ε)ε^s。s 太小：N(ε)ε^s→∞（覆盖太细数太多）；s 太大：→0。临界 s=dim_A 处既不爆也不灭——维数是"测量成本"的临界指数。

Frostman 引理（质量分布法）。 紧集 A 满足 dim_A>s ⟺ 存在概率测度 μ 支在 A 上，使 μ(B(x,r)) ≤ C·r^s 对所有 x、r——"A 上能放一个把质量摊得足够薄的测度"。用途：证明维数下界时，先造这样的 μ，再估计能量的积分（如 ∬|x−y|^{−s}dμdμ<∞）。这是 Kakeya、限制性、丢番图（数的几何）里反复出现的"称重技巧"。

维数不是 Lebesgue 的投影。 Besicovitch 集：面积 0（H²=0）却 dim=2——维数与测度独立（→ Kakeya 课反例 1）。几何测度论的第一课就是别把"测度为 0"当成"维数低"。

三、例题 1——康托尔三分集的维数（一步步算完）

题目。 计算 C 的 dim_H = ln2/ln3，并解释上/下界。

第一步：上界（覆盖）。 第 k 层 C_k 是 2^k 段、每段长 3^{−k} 的并：对 s>ln2/ln3，H^s 用这些段覆盖，得 H^s(C) ≤ lim 2^k·3^{−sk} = lim (2/3^s)^k。s>ln2/ln3 ⟹ 2/3^s<1 ⟹ 趋于 0 ⟹ H^s=0 ⟹ dim ≤ ln2/ln3。

第二步：下界（Frostman）。 在 C 上取均匀测度 μ（每层每个拷贝质量 2^{−k}）：对长度 r≈3^{−k} 的区间，μ(B)≤2·2^{−k}≤C·r^s（s=ln2/ln3 时 2^{−k}=(3^{−k})^{ln2/ln3}）。Frostman ⟹ dim ≥ s。

第三步：合并。 dim_H C=ln2/ln3≈0.6309。∎ 画布会画出"第 k 层估计 f(s)=2^k·3^{−sk}"在 s 处的行为：s<dim 时随 k→∞ 爆炸、s>dim 时塌缩到 0、恰在 dim 处持平——维数就是那条相变线。

第四步：同类例。 Koch 曲线 ln4/ln3；Cantor×Cantor ln4/ln3? 2ln2/ln3=ln4/ln3 ✓ 相同——注意 C×C 维数是两倍 C 的维数（乘积公式），与 Koch 数值巧合相同是常见的混淆点。∎

Jf 是雅可比（m 维体元放大率）。它把"m 维曲面上的积分"与"定义域上的积分"互换——曲面测度的"换元公式"。∎

第二步：m=n=1 核对。 f(t)=(t, g(t))（图曲线，g 光滑）：Jf=√(1+g′²)；A=[a,b]：左边 ∫√(1+g′²)dt = 弧长；右边 H¹(f([a,b])) 也是弧长 ✓——面积公式就是"曲线的长度 = ∫速度"。∎

第三步：余面积公式（分层计数）。 对 f:ℝ^n→ℝ^m（m≤n）：∫_ℝⁿ Jf dx = ∫_ℝ^m H^{n−m}(f^{−1}(y)) dy——把 n 维积分分成 (n−m) 维纤维的积分。例：f(x)=x₁ 时 Jf=1，公式给 ∫dx = ∫_ℝ H^{n−1}(切片)dy——正是 Fubini！∎

第四步：读意义。 两个公式把"曲面的测度理论"还原成"映射的微积分"——这是 rectifiable 集合（可求积、a.e. 切平面）上做分析的通行证。∎

五、严格陈述——核心定理清单

  • Hausdorff 测度与维数： H^s 定义（δ-覆盖的下确界）、单调/可数半加、Lipschitz 收缩、ℝ^d 中 H^d=常·Lebesgue；dim_H 临界点。
  • Frostman： dim_A>s ⟺ 存在概率测度 μ⊂A 使 μ(B(x,r))≤Cr^s；推论：紧集维数可由"可放质量分布"刻画。
  • 密度与微分： Lebesgue 密度定理；Besicovitch 覆盖与微分定理（L¹_loc 的 a.e. 微积分基本定理）——测度论分析的地基。
  • Rademacher： Lipschitz ℝ^m→ℝ^n 几乎处处可微。
  • 面积/余面积公式： 如上（m≤n 与 n≥m 两个方向）。
  • 可求积集： H^m-rectifiable = Lipschitz 像的可数并（去掉零测集后）；a.e. 有 m 维切平面；结构定理（Besicovitch–Federer）。
  • 变分框架： BV 函数与周长（De Giorgi）、integral currents 的紧性（Federer–Fleming 1960）⟹ Plateau/极小曲面存在性；isoperimetric 不等式的测度论证明。

七、延伸——几何测度论的现代足迹

  • 分形与复动力学。 Julia 集、康托尔集的维数计算（→ 分形、复动力系统）用 Frostman/Hausdorff 工具；Kakeya 与限制性猜想是"集合维数 × 调和分析"的战场（→ Kakeya）。
  • PDE 自由边界。 Alt–Caffarelli、障碍问题、燃烧面：几何测度论给"解的正则性与自由边界的维数"提供语言。
  • 极小曲面与几何流。 Plateau 问题、调和映射、以及曲率流中的奇异集（→ 曲率 课）——测度论性方法统治奇异分析。
  • 度量测度空间与合成曲率。 Ricci 下界的"测度论化"（Lott–Villani–Sturm：测度空间上的合成曲率）把 GM 工具推进到最优传输（→ 最优传输）与度量几何。
  • 调和测度与节点集。 调和测度维数（Bourgain 等）、拉普拉斯本征函数节点集测度（Logunov–Malinnikova，→ 鼓的谱 课的 2020 大进展）——GM 是这些现代结果的工具箱。

八、反例与陷阱——五个"测度想当然"

陷阱 1："面积 0 ⟹ 维数低"？ 反例：Besicovitch/Kakeya 集 H²=0 却 dim=2（→ Kakeya 课）。测度与维数是两把独立的尺——"测度小"不承诺"维数低"。

陷阱 2："box 维数 = Hausdorff 维数"？ 盒维数（覆盖计数 lim log N(ε)/log(1/ε)）≥ Hausdorff，可严格更大：ℚ∩[0,1] 盒维 1、Hausdorff 维 0（可数点集 H^s=0 对 s>0）。Hausdorff 维对可数并稳健，盒维不是——别混用。

陷阱 3："H^s 在维数处自动有限正"？ 临界处 H^{dim}(A) 可以是 0 或 ∞（dim 只是"变号的点"）。说"维数 d 的集合有有限正 H^d"需要额外条件（如 Ahlfors 正则），不是默认。

陷阱 4："Lipschitz 映射保持维数"？ 只给 ≤（dim f(A)≤dim A）；投影可把维数压下去——Kakeya 猜想反过来说"投影不压维"是深刻内容。把"≤"当"="是几何测度论常见事故。

陷阱 5："可求积 = 光滑曲面（到处有切平面）"？ 可求积只要求几乎处处有切平面（去掉零测集后可数 Lipschitz 像）。康托尔函数图像、尖角并集可以可求积却处处不光滑。把"光滑"当"可求积"会低估它的宽容度。

九、当前状态——几何测度论的前沿

  1. 奇异集与正则性。 极小曲面/曲率流奇异集的维数分析（Almgren、White、最近的高维进展）——GM 正则性理论仍是活跃前线。
  2. 度量空间分析。 Lipschitz/切锥/维数的度量推广（Cheeger–Kleiner 微分结构）与合成曲率（Lott–Villani–Sturm）把 GM 方法带到非欧氏空间（→ 最优传输）。
  3. 调和分析交叉。 Kakeya/限制性、Frostman 与测度能量在"分形测度上的傅里叶变换"问题里反复登场——GM 与调和分析已难分彼此。
  4. 数据与计算。 数值 varifold/currents（几何数据的离散化）、最优传输的数值 GM——几何测度论进入现代计算几何与机器学习。

关键论文

  • Hausdorff (1918)：分数维测度——维数的现代定义。
  • Besicovitch (1920s–30s)：集合的结构理论、Besicovitch 集与覆盖定理。
  • Frostman (1935)：质量分布引理（维数的测度刻画）。
  • Federer–Fleming (1960)：integral currents 与紧性——Plateau 问题的测度论解法。
  • De Giorgi (1960s)：BV 与周长、等周不等式的测度论证明。
  • Federer (1969)：Geometric Measure Theory——学科的百科全书式奠基。
  • Almgren (1980s)：多重值函数与面积极小化奇异集（约化正则性）。
  • Lott–Villani / Sturm (2005–06)：合成 Ricci 曲率——GM 的度量测度时代。
