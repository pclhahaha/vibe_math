一、热身：旋转矩阵与"在单位元处求导"

先从最具体的对象出发。三维空间里所有旋转构成的集合记作 SO(3)（special orthogonal group，特殊正交群）。它由两条规则刻画：① 正交性 RᵀR = I（旋转不改变长度和夹角）；② 特殊条件 det R = 1（只转、不镜像）。

SO(3) 不是"一粒一粒"的离散集合，而是"一整片"的连续体——任意小的角度都能转，还能在它上面光滑地移动。这样的集合叫光滑流形（manifold，大白话：像地球表面，每一小块都能摊平成一张普通坐标纸）。所以

李群 = 群 + 光滑流形：既能做乘法、又有"连续可微"的结构。所有连续对称性（旋转、平移、Lorentz 变换、规范变换〔规范＝能随便换、却不改变物理结果的"标尺"〕）都是李群。

关键的一步：任取一个从单位旋转出发的单参数旋转族 g(θ)（例如 g(θ) = R_z(θ)，满足 g(0) = I 且 g(θ₁+θ₂) = g(θ₁)g(θ₂)），在 θ = 0 处求导：

X 是"单位元处的一个切线方向"。所有这样的方向拼成一个线性空间，叫单位元处的切空间 T_e G（tangent space，大白话：曲面在某点处所有"切线方向"铺成的小平面）。切空间是向量空间——能加减、能数乘，线性代数全部可用的工具都在里面。

为什么先"求导"再"还原"？因为李群是弯曲的（SO(3) 是个三维球面型的流形），矩阵乘法在它上面算起来很笨重；可切空间是平直的向量空间，只有加减法和数乘。指数映射 exp 负责把切空间里的方向"滚"回群上去（见第十四节证明一），在"无穷小"与"有限"之间来回翻译。整套策略可以概括为一句：把弯曲的群局部掰平，在平直处把结构算清楚，再滚回去。

它把"无穷小的方向 X"放大成"沿 X 走 t 步的有限元素"。两条基本性质立刻可以看到：

  • 群的乘法在切空间里"一阶"变成加法：exp(sX)exp(tX) = exp((s+t)X)——同一方向的小步可以合并。

七、表示论入门：为什么抽象李代数要"翻译"成矩阵

李代数本身的乘法 [·,·] 很抽象。把抽象元素"翻译"成具体的线性算子，让它们作用在某个向量空间上，得到的就叫表示（representation）：

定义（表示）。李代数 𝔤 在向量空间 V 上的表示是一个线性映射 ρ: 𝔤 → End(V)，满足 ρ([X,Y]) = ρ(X)ρ(Y) − ρ(Y)ρ(X)。也就是说，ρ 保持李括号（"翻译不破坏结构"）。

为什么研究表示？① 抽象李代数没法直接"作用"在物理态上，可具体矩阵能——量子力学里所有可观测量的取值，都由表示决定。② 任何抽象李代数自身都能作用在自身上（伴随表示 ad_X(Y) = [X,Y]），所以表示论同时是理解李代数内部结构的工具。③ 表示论把"李代数的全部信息"浓缩成一张不可约表示的清单——就像元素周期表把化学信息按原子序数排好。

两个表示若不能拆成更小的、被保持不变的子空间的直和，就称为不可约表示。不可约表示是"原子"，任何表示都是它们的直和。𝔰𝔲(2)（也即 𝔰𝔬(3)）的不可约表示正是第五节说的：对每个 ℓ ∈ {0, ½, 1, …} 恰有一个 2ℓ+1 维不可约表示。下一节把这个结论在 𝔰𝔩(2,ℂ) 上完整算出来。

李代数的乘法 [·,·] 不满足结合律，用起来不顺手。有没有办法把"李括号"变成"普通乘法"？这就是泛包络代数：

其中 T(𝔤) 是张量代数（张量＝多维"数组"，用一串下标排列的一堆数）。商掉"交换性差一个李括号"的关系，得到的 U(𝔤) 是结合代数，李代数的一切表示自动变成 U(𝔤) 的模（模＝module，一个供代数元素"作用"的空间；这里不是"模形式"的那个模）。

Poincaré–Birkhoff–Witt（PBW）定理：取有序基 {x₁,…,x_n} ⊂ 𝔤，则单项式 x₁^{k₁}…x_n^{kₙ} 构成 U(𝔤) 的基。推论：伴随分次代数 gr(U(𝔤)) ≅ S(𝔤)（对称代数）——U(𝔤) 的"一阶骨架"就是把 𝔤 变成普通多项式环。

Harish–Chandra 同构：Z(U(𝔤)) ≅ S(h)^W——泛包络代数的中心同构于 Cartan 子代数对称代数的 Weyl 群不变部分。Casimir 算子就是中心里对应于二次对称不变量的元素：在物理中它给出角动量平方 J² 和粒子的质量平方算符。对 𝔰𝔩(2,ℂ)，Casimir 是 C = H² + 2(EF + FE)：作用在最高权向量上得 H²v₀ + 2EFv₀ = n²v₀，作用在 v₁ 上可得 n(n+2)——一个很好的小练习。

十二、物理学中的李代数光谱

前面学到的同一套机制，在物理里反复以不同名字出现：

  • 𝔰𝔲(2)：自旋代数（Pauli 矩阵）→ 角动量量子化（第五节）。
  • 𝔰𝔲(3)：夸克模型（Gell-Mann 矩阵）→ 强相互作用的味对称性。
  • Lorentz 代数 𝔰𝔬(3,1)：狭义相对论 → Dirac 方程与自旋。
  • 超对称：Lie 超代数 → 玻色子/费米子配对，超 Poincaré 代数。
  • 仿射 Lie 代数：中心扩张后的无穷维李代数 → 2D 共形场论中的 Virasoro 代数、WZW 模型的 Kac–Moody 代数。

观察共性：每一步都是"找出对称性 → 求其李代数 → 分类不可约表示 → 表示即物理态"。这正是本课第三节定义和第八、九、十节分类方法的直接应用。

十三、几何表示论：Springer 对应与 Beilinson–Bernstein 局部化

表示论最深的分支之一，是把代数对象换成几何对象来研究。

  • Springer 对应（1976–78）：幂零轨道与 Weyl 群表示之间的双射关系——每个幂零轨道赋予 Weyl 群的一个不可约表示。
  • Beilinson–Bernstein 局部化（1981）：𝔤-模 ↔ 旗簇上的 D-模，把表示论转化为几何对象的层上同调——这是几何 Langlands 纲领的核心工具。
  • Kazhdan–Lusztig 猜想（1979）：用奇异层交叉上同调解 Schubert 簇 → Kazhdan–Lusztig 多项式给出 Verma 模所有不可约特征标的重数公式（Lusztig，1990 年证明）。

十四、证明一：指数映射与李群-李代数对应

现在把第一节"线性化群"的断言严格化。

定理。李群 G 的李代数 𝔤 = T_eG。指数映射 exp: 𝔤 → G 定义为 exp(X) = γ_X(1)，其中 γ_X 是左不变向量场 X 的积分曲线（积分＝把无穷小的变化一步步累加出整条路线；这里指单参数子群），满足 γ'(0)=X 且 γ(s+t)=γ(s)γ(t)。

关键定理。若 𝔤 是 G 的李代数，则存在唯一的连通李群 G 以 𝔤 为李代数（局部）。而 exp 在 0 附近是局部微分同胚——这是"李群局部由李代数决定"的精确含义。

深刻点。尽管一般李群可能有很多连通分量，其单位连通分支由李代数唯一确定。所以连续对称性完全被"无穷小生成元"的对易关系编码——这正是物理中用对易关系而非群元素做量子化的原因。

十六、反例：可解、幂零与半单李代数的区分

半单：无非零阿贝尔理想（如 𝔰𝔩(n)，特征标 Killing 形式非退化）。

可解：导出列终止于 0（如上三角矩阵代数 𝔟ₙ）。

幂零：下中心列终止于 0（如严格上三角矩阵 𝔫ₙ，所有对角元为 0）。

三者严格递推：幂零 ⊂ 可解，但可解未必幂零（𝔟ₙ 可解不幂零）。Lie 定理：域（＝能加减乘除的一整套数，如有理数、实数、复数）上复可解李代数的表示必有公共特征向量——但实域上不成立，这是经典反例。

十九、试试看（每题附提示）

1. 写出绕 y 轴转 θ 的矩阵 R_y(θ)，并在 θ=0 处求导，验证你得到的正是第四节里的 L_y。

提示：仿照第四节的 R_z：对 R_y(θ) 逐项求导，注意 (d/dθ)cosθ = −sinθ、(d/dθ)sinθ = cosθ，再代入 θ=0。

2. 验证 [L_y, L_z] = L_x（对第四节给出的矩阵，硬算 L_yL_z − L_zL_y）。

提示：先算 L_yL_z，再算 L_zL_y，相减。中间有两项（第二行第三列 / 第三行第二列）要特别小心符号。

3. 用厄米基 Jᵢ = σᵢ/2 验证 [J₁, J₂] = iJ₃。

提示：由第六节 [σ₁,σ₂] = 2iσ₃ 出发，(1/4)·[σ₁,σ₂] = iσ₃/2。这就是物理约定 [J_x,J_y] = iJ_z 的来源。

4. 证明 e^{iθσ₂}（绕 y 轴的 SU(2) 元）＝ cosθ·I + i sinθ·σ₂，并写出它的矩阵。

提示：σ₂² = I，与第六节第 4 步完全相同的幂次展开；把 σ₂ 的矩阵代入即可。

5. 对 𝔰𝔩(2,ℂ) 的最高权表示 V₂（权重 {2,0,−2}），算出 Casimir C = H² + 2(EF+FE) 在每个权重向量上的取值，验证它都等于同一个常数。

提示：C = H² + 2EF + 2FE。用第八节的公式 Hvₘ=(2−2m)vₘ、Evₘ=(3−m)vₘ₋₁、Fvₘ=(m+1)vₘ₊₁ 逐项代入。

6. 验证结构常数 c_{ij}^k = ε_{ijk} 满足 Jacobi 恒等式：对任意的 i,j,k 求和 ε_{iℓm}ε_{jkℓ} = ε_{kℓm}ε_{ijℓ} 的两边组合。

提示：用对易子 [A,B] = AB−BA 自动满足 Jacobi（因为它来自结合律），或用 ε 恒等式 ε_{ijk}ε_{lmk} = δ_{il}δ_{jm} − δ_{im}δ_{jl} 直接展开。

二十、附：工作题

题 1：计算 𝔰𝔲(2) 的结构常数并验证 Jacobi 恒等式。

显示解答

取基 X=iσ₁/2, Y=iσ₂/2, Z=iσ₃/2，由第六节有 [X,Y]=−Z, [Y,Z]=−X, [Z,X]=−Y（注意整体负号，这是反厄米约定的正确形式）。验证 Jacobi：[X,[Y,Z]]+[Y,[Z,X]]+[Z,[X,Y]] = [X,−X]+[Y,−Y]+[Z,−Z]=0。✓

题 2：求 e^{iθσₓ}（沿 x 轴旋转的指数映射）。

显示解答

σₓ²=I，所以 e^{iθσₓ}=cosθ·I + i sinθ·σₓ = [[cosθ, i sinθ],[i sinθ, cosθ]]。这是绕 x 轴转 2θ 的 SU(2) 元。

题 3：证明 SU(2) 的中心是 {±I}，从而 SU(2)→SO(3) 是 2 对 1。

显示解答

若 g∈Z(SU(2))，则 g 与所有 e^{iθσᵢ} 交换，故 g 与 σ₁,σ₂,σ₃ 交换。与三个 Pauli 都交换的 2×2 矩阵只能是标量 λI，又 det(λI)=λ²=1 ⟹ λ=±1。故 Z(SU(2))={±I}，覆盖映射的核的大小为 2。
