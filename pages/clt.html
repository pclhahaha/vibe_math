〇、直觉入门——掷硬币一百万次：平均会稳定，但误差永远"在"

掷一枚公平硬币 n 次，正面比例 p̂_n 会怎样？直觉告诉你两件事，而它们惊人地都对：

  • 大数定律（LLN）： p̂_n 越来越接近 1/2——n→∞ 时"收敛"到真实概率。误差 趋于消失（在概率的意义上）。
  • 但它"消失"得很慢： 误差的典型尺度是 1/√n。掷 100 次，比例误差 ~1/10；掷 10000 次，误差 ~1/100——想多一位精度，要掷 100 倍的硬币。误差从来不"均匀地"消失。

大数定律说"平均去哪了"，却没说"平均怎么晃"。中心极限定理（CLT）补上后半句：

标准化后的样本均值（减去期望、除以 σ/√n）的分布，随着 n 增大逼近标准正态钟形曲线——无论你掷的是硬币、骰子、指数还是任何"方差有限"的分布。正态分布因此是"所有独立同分布随机和的公共极限形状"：测量误差是正态的（许多小误差相加）、身高是正态的（基因×环境相乘取对数）、热噪声是正态的（分子碰撞无数）——高斯无处不在，不是因为世界偏爱它，而是因为 CLT 强制它出现。

洞察：大数定律与中心极限定理是一对互补的兄弟：LLN 说"样本均值 ≈ 期望"（一阶信息，收敛于一个点）；CLT 说"围绕期望的涨落服从钟形，宽度 ∝ 1/√n"（二阶信息，收敛于一条曲线）。统计推断（置信区间、民意调查的 ±3%）、物理中的扩散、数论里的 Erdős–Kac 定理，全是这对兄弟的后代。
⚠️ 背景提示：本课属于 核心 级别。

建议先掌握：概率论基础（期望/方差）、测度论（严格收敛概念）。特征函数用到复指数，傅里叶变换 课是它的近亲（特征函数 = 概率的傅里叶变换）。

一、一个具体问题——从赌桌到整个统计学：正态分布为什么"正常"

1733 年，de Moivre 在研究赌博问题（掷硬币的"长串"偏离）时发现：二项分布的中间形状可以用一条解析曲线逼近——他得到的正是正态曲线，但当时没人觉得它重要。此后两百年的故事是一连串"把条件放宽"的接力：

  • Laplace（1810）： 把 de Moivre 的结果推广到一般伯努利试验（"de Moivre–Laplace 定理"）。
  • Gauss（1809）： 在最小二乘误差论里独立"发现"正态分布——"正态"（normal）之名由此而来（它被当作误差的"正常"分布）。
  • Chebyshev（1867）与 Markov： 用矩方法证明更广情形的极限定理，并留下Chebyshev 不等式（"任何分布，偏离期望 k 个标准差以上的概率 ≤ 1/k²"）——大数定律最便宜的证明工具。
  • Lyapunov（1901）： 允许不同分布、用特征函数证明（特征函数方法从此成为概率论主武器）。
  • Lindeberg（1922）： 给出最优的（几乎必要的）条件——Lindeberg 条件。至此，CLT 的"独立（弱依赖）、同分布、方差有限"版本尘埃落定。

为什么这值得两百年？因为 CLT 不只是赌徒的算术：它解释了为什么统计学可以工作。民意调查的 ±3%、药物试验的 p 值、质量控制的控制图，全部建筑在"样本均值的分布 ≈ 正态、宽度 ∝ σ/√n"之上。普林斯顿数学指南把概率论列为现代数学分支（Part IV.21），CLT 正是概率论回赠给全人类的那件礼物。

指数上的原因是：把 φ 在 0 附近泰勒展开 φ(u)=1+iμu−σ²u²/2+o(u²)，代入 u=t/(σ√n) 并取 n 次幂，指数里第一项（均值项）与 e^{−itμ/σ√n} 抵消，剩下 −t²/2。而 e^{−t²/2} 恰是标准正态的特征函数；由 Lévy 连续性定理（特征函数收敛 ⟹ 分布收敛），得 CLT。∎

直觉：为什么是 e^{−t²/2}？ 和的特征函数是 φ 的 n 次幂——"取对数、乘 n、再取指数"。任何"方差有限"的 φ 在零点附近都长得像 1−σ²t²/2（二阶信息统一了所有分布），n 次幂后只剩下这个二阶项。正态是"无穷卷积"下的唯一公共吸引子——与 傅里叶变换 课里"盒函数反复卷积趋近高斯"是同一个现象（频域里就是反复乘 sinc 的主瓣）。

三、例题 1——硬币的算术：Chebyshev 上界 vs CLT 真值（一步步算完）

五、严格陈述——定理清单

  • 弱大数定律： X_i iid、E|X|<∞ ⟹ X̄_n → μ 依概率。
  • 强大数定律（Kolmogorov）： 同条件下 X̄_n → μ 几乎处处。
  • Lindeberg–Lévy CLT： X_i iid、E X=μ、Var=σ²∈(0,∞) ⟹ (S_n−nμ)/(σ√n) ⇝ N(0,1)。
  • 推广： Lyapunov/非 iid 版（三阶矩条件）、Lindeberg–Feller 版（最优）；三角阵列的统一框架。
  • 收敛速度（Berry–Esseen 1941/42）： 若 E|X|³<∞，则 sup_x |F_n(x)−Φ(x)| ≤ C·ρ/(σ³√n)（ρ=E|X−μ|³）。常数 C 的最佳值至今只知在 (0.4097, 0.4748] 之间——一个"已解决 80 年"的问题仍有敞开的常数。
  • 大偏差（Cramér 1938）： 均值偏离期望"很远"（非 √n 尺度）的概率以指数速率衰减：P(X̄_n ≥ μ+a) ≈ e^{−nI(a)}，I 是速率函数（Cramér 定理）——CLT 管钟形中心，大偏差管尾巴。
  • 稳定分布与吸引域（Lévy 1920s）： 正态只是"稳定分布"家族的一员（α=2）；柯西（α=1）等重尾分布的标准化和收敛到别的稳定律——CLT 的完整版图是"无穷可分分布"理论。

七、延伸——钟形曲线的子子孙孙

  • 扩散与布朗运动。 随机游走的位置 = 独立增量之和；把 CLT 的"时间标度"一起做极限（n 与 √n 同步放大），得到布朗运动（Donsker 不变原理 1951）——CLT 从"分布收敛"升级为"过程收敛"。→ 布朗运动 课。
  • 数论里的 CLT：Erdős–Kac（1940）。 取随机整数 n ≤ N，设 ω(n)=素因子个数（带重数）。Erdős–Kac 定理：ω(n) 标准化后收敛到正态！——素数的"随机性"用 CLT 表达。→ 素数筛 课。
  • 随机矩阵。 大随机矩阵特征值的分布收敛到半圆律——"矩阵的 CLT"（Wigner 1958）；自由概率论（Voiculescu）把它做成"非交换 CLT"，连接算子代数与量子信息。→ 算子代数 课。
  • 统计推断。 t 检验、置信区间、卡方分布全从"样本均值的正态性"派生；中心极限定理是频率学派统计学的第一块地基（民意调查例子的严格化）。
  • 金融与重尾。 资产收益的"肥尾"提醒我们：真实世界的"和的极限"未必是正态——大偏差、稳定分布、极值理论是金融数学的日常工具。CLT 的边界本身就是现代概率论最活跃的地带。

八、反例与陷阱——五个"看起来当然"的错误

陷阱 1："大数定律说误差最终会消失"？ 误差以 1/√n 缩小，永远不会等于 0；"收敛"是概率意义上的：对任意固定 ε，偏离超 ε 的概率趋于 0——但每一次具体实验的误差仍是随机量。想消除误差需要无穷样本，现实只能"控制误差"（用 √n 换精度）。

陷阱 2："CLT 说 n 大时样本本身服从正态"？ 错。CLT 说的是标准化和的分布逼近正态——单个样本 X_i 的分布永远是原来的（硬币永远是 0/1 两点）。正态性属于"和"或"均值"的统计量，不属于原始数据。

陷阱 3："任何分布都能用 CLT"？ 需要方差有限！标准柯西分布（密度 1/(π(1+x²))）没有期望与方差：样本均值 X̄_n 的特征函数是 e^{−n|t|} 的相应标准化……实际上柯西均值仍是柯西——标准化永远不会变成正态。重尾（α<2 稳定）分布是 CLT 的禁区（画布上选柯西预设即可亲见）。

陷阱 4："独立性只是技术细节"？ 完全依赖的反例：取 X₁=X₂=…=X（同一个随机变量重复 n 次），则 X̄_n=X 根本不收敛到常数、标准化后也非正态。弱依赖（如马尔可夫链、混合序列）需要额外条件；强依赖是 CLT 的另一个禁区。

陷阱 5："收敛速度与分布无关"？ Berry–Esseen 保证 O(1/√n) 的一致速度，但常数依赖三阶矩 ρ：分布越偏、尾巴越重，逼近越慢。对强偏斜分布，n=30 远不够"正态"——教科书里的"n≥30 就正态"只是粗糙经验，不是定理。

九、当前状态——CLT 家族的前沿

  1. Berry–Esseen 常数。 最优常数 C 仍未确定（已知 0.4097 < C ≤ 0.4748）——证明界的改进仍是活跃研究（近年有大量"第二代"工作）。
  2. 依赖数据的 CLT。 马尔可夫链、图上的函数、平稳序列的中心极限——遍历论与概率论的交叉（如 Stein 方法近年的系统化推广）。
  3. 高维与函数空间。 高维 CLT（Bhattacharya–Holzmann 等）、Banach 空间值随机元的 CLT、随机过程的 CLT（Donsker 及其在现代统计中的版本）——"维度"是 CLT 的下一个战场。
  4. 自由概率。 非交换概率中的"自由 CLT"收敛到半圆律，是 Voiculescu 自由概率论的核心，与随机矩阵、量子信息深度绑定。

关键论文

  • de Moivre (1733)：二项分布的正态逼近——CLT 的第一块砖（硬币问题）。
  • Laplace (1810)：de Moivre–Laplace 定理，一般伯努利情形的 CLT。
  • Chebyshev (1867)：矩方法与 Chebyshev 不等式——大数定律的通用证明工具。
  • Lyapunov (1901)：特征函数方法的 CLT（允许不同分布）。
  • Lindeberg (1922)：Lindeberg 条件——CLT 的最优充分（且近乎必要）条件。
  • Kolmogorov (1933)：强大数定律与概率测度论公理——概率论"现代化"的宣言。
  • Berry (1941) / Esseen (1942)：Berry–Esseen 定理——收敛速度的 O(1/√n) 一致界。
  • Erdős–Kac (1940)：素数因子个数的正态性——数论与概率的历史性握手。
  • Donsker (1951)：不变原理——从"分布收敛"到"过程收敛"（布朗运动）。
  • Voiculescu (1991)：自由概率论——非交换的 CLT（半圆律）。

工作题——不等式、特征函数与反例

题 1（特征函数一步）。 计算均匀分布 U[−1/2,1/2] 的特征函数，并写出其泰勒展开的前两项，验证"二阶项含 −σ²t²/2"。提示：φ(t)=∫_{−1/2}^{1/2}e^{itx}dx = sin(t/2)/(t/2)；展开 sin u/u = 1−u²/6+…，u=t/2 ⟹ 1−t²/24 = 1−σ²t²/2（σ²=1/12 ✓）。

题 2（Berry–Esseen 的工程用法）。 一个偏斜分布 σ=1、ρ=2。要 sup 误差 ≤0.01，n 大约要多大（取 C=0.5）？提示：Cρ/(σ³√n)≤0.01 ⟹ √n ≥ 0.5·2/0.01=100 ⟹ n ≥ 10⁴。

题 3（柯西反例验证）。 证明标准柯西（特征函数 e^{−|t|}）的样本均值 X̄_n 的特征函数仍是 e^{−|t|}，从而分布不随 n 变窄。提示：X̄_n 的特征函数 = [φ(t/n)]ⁿ = [e^{−|t|/n}]ⁿ = e^{−|t|}——稳定分布 α=1 的自相似性。

题 4（Erdős–Kac 直觉）。 说明为什么"取随机数、数它的素因子个数"能牵涉到 CLT。提示：用随机变量指示"p 整除 n"近似独立（Mertens 型估计），素因子个数 ≈ 独立伯努利之和 ⟹ 正态（ln ln N 尺度）；标准化的 ω(n) 收敛 N(0,1)。

显示解答

题 1：见提示：φ(t)=sin(t/2)/(t/2)，展开验证二阶项 −t²/24。∎

题 2：n ≥ 10⁴（若 C=0.5）。收敛速度 O(1/√n) 意味着"高精度要天文样本"。∎

题 3：见提示：均值仍是柯西（尺度不变），标准化后也非正态。∎

题 4：ω(n) 的方差 ~ ln ln N 发散但慢；Erdős–Kac：(ω(n)−ln ln N)/√(ln ln N) ⇝ N(0,1)。∎

试试看——练习与提示

试试看 1（画布逼近）。 选"均匀"分布，把 n 从 1 滑到 256：直方图从"平顶"变成钟形，同时右上角经验方差 → 1（标准化正确）。注意 n=1 时直方图就是原分布本身——CLT 的"n 越大越正态"是渐进，不是瞬间。

试试看 2（1/√n 律）。 观察"经验均值 ± 区间"：n=100 时均值分布的宽度 ~σ/10，n=10000 时 ~σ/100。在画布上用"多次试验的平均"做几次，亲手体会误差按 1/√n 而非 1/n 收缩——想省一半误差，样本要 ×4。

试试看 3（柯西反例）。 切到"柯西"预设：无论 n 多大，直方图始终是同一个尖峰胖尾形状，标准化的"均值"根本不收敛——右上角会提示"CLT 前提失效（方差无穷）"。再切回指数（偏斜）：小 n 时明显不对称，n 大了才像钟形——体会收敛速度依赖偏度。

试试看 4（硬币 vs 正态）。 选"伯努利（硬币）"预设，把 n 滑到很大：直方图的柱子仍落在 0/1 的两点——但均值的直方图是钟形。这就是陷阱 2 的直观版：正态属于均值，不属于硬币。
