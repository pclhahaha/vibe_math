〇、直觉入门——方程和形状是一枚硬币的两面

一个方程 x²+y²=1 画出来是个圆，一条圆的曲线反过来也能用方程写出来。代数几何就是研究这件事的学科：把"解方程"和"看形状"当成同一件事来琢磨。

它让数论里的数字（比如素数）也能被当成"形状"来看，于是很多难题变成了看图就能想的事。

一句话：方程的解组成形状，形状的规律写成方程——两者是一回事。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 前沿 级别，正文较深。

建议先掌握：交换代数、抽象代数、同调代数。

高级章节（证明、前沿、工作题）需要相应背景，未掌握可先看「〇、直觉入门」了解核心思想，或回到前置课程补基础。

一、具体问题先行——"一个方程就是一片形状"

先把"方程与形状的双向翻译"用一个可完整计算的例子立住。取方程 f = x² + y² − 1，基域取 ℂ。

方向一（解方程 → 形状）：零点集 V(f) ⊂ ℂ² 是复圆。对坐标环做除法：A = k[x,y]/(f)。A 里的元素就是"f 限制下的多项式"——它们是定义在 V(f) 上的函数。

方向二（形状 → 方程）：反过来，给任何交换环 R，都能造出一个"空间" Spec(R)（素理想的空间），使得环的代数信息（理想、局部化、维数）全部变成几何信息（闭集、茎、维数）。例如 k[x,y]/(x²+y²−1) 的素理想恰好"铺"成一个一维空间——圆。

为什么要走这么绕？ 经典代数几何只能处理"代数闭域上、由多项式零点定义的簇"。一旦想把素数的算术信息也当几何看（Spec(ℤ) 就是一个"空间"），或想研究"带重数"的退化对象，就必须拥抱"环 → 空间"的概形框架。本课从头到尾都在把这个翻译做得既严格又可算。

试试看 A. 取 R = k[x]（k 代数闭）。列出 Spec(R) 的全部点、指出哪些是闭点（Hint：极大理想 (x−a)）、哪个不是闭点（Hint：零理想 (0)），并说明 (0) 的闭包为什么是整个 Spec(R)。
提示：闭点对应极大理想；零理想只在 (0) ⊂ (x−a) 之下，故含 (0) 的闭集只有全体——这就是 Zariski 拓扑里"一般点"为何无处不在。

二、代数几何——Grothendieck 的革命

仿射簇 = 多项式方程零点集 ⇔ 坐标环 A(V)。概形（Scheme）：Grothendieck 将环的素谱 Spec(R) 定义为"几何对象"——任何交换环都是一个"空间"。Spec(ℤ) = "素数的空间"——数论问题变成几何问题。

étale 上同调 → Deligne（1974）证明 Weil 猜想（RH 的函数域类比）。模空间分类代数-几何对象。Calabi-Yau 流形 = 弦论紧致化的 6 维内空间。代数几何是 20 世纪数学最深刻的综合。

四、概形论——Grothendieck 的核心发明

经典代数几何的对象是代数簇——多项式方程零点集，基域必须是代数闭域。Grothendieck 的关键洞察：把任何交换环 R 的素谱 Spec(R) 定义为几何对象——带有 Zariski 拓扑和结构层。一个概形（scheme）是局部同构于某个 Spec(R) 的局部环化空间。这一步统一了：任意域上的代数几何、算术几何（Spec(ℤ) 本身就是一个概形！）、代数数论。例如仿射直线 A¹_k = Spec(k[x])——闭点对应极大理想（= 代数闭包中的点），加上一个稠密的一般点（generic point）对应零理想。Zariski 拓扑不是 Hausdorff 的——一般点在每个非空开集中，这体现了概形的"函数论"本质。相对概形的概念使得模空间理论、形变理论得以严格建立。

关键文献：Grothendieck-Dieudonné, Éléments de géométrie algébrique（EGA）, Chapitre I, §1.1–1.4 (1960). Eisenbud-Harris, The Geometry of Schemes, Springer GTM 197 (2000).

完整例题 1 —— 完整计算"带重数的一根线" Spec(k[x]/(x²))。
任务：算出这个仿射概形的所有点、每个点的茎、以及它与经典"线" Spec(k[x]) 的差别。
第 1 步（找素理想）：R = k[x]/(x²) 是局部环，元素形如 a + bx（b ≠ 0 时非零）。素理想只有 (x)（因为 R/(x) = k 是整环，而 (x) 之外的元素都可逆）。所以 Spec(R) 只含一个点（闭点 x = 0）。
第 2 步（算茎）：该点 (x) 处的茎 O_{Spec R, (x)} = R = k[x]/(x²)，是局部环，唯一极大理想 (x)，且 x² = 0。
第 3 步（对比经典线）：经典线 Spec(k[x]) 有无限多个点（每个 a ∈ k 一个闭点）；而 Spec(k[x]/(x²)) 只有一个点，却在环里藏了一个非零零元 x——这个"无穷小信息"在经典簇里完全看不见。
第 4 步（几何直觉）：Spec(k[x]/(x²)) 是"带重数 2 的线"：点集看只有原点，但形变理论、相交重数都靠这层"双重结构"。这正是概形比簇多出的信息量。∎
试试看 B. 仿照例题 1，计算 Spec(k[x]/(x²−1)) 的所有素理想并指出它为何"分裂成两个点"。
提示：x²−1 = (x−1)(x+1) 是互素因式的乘积，故环 ≅ k×(k 的直积)；直积环 Spec 是两片 Spec(k) 的并（每个极大理想 (x−1)、(x+1) 一个点）。对比 (x²) 与 ((x−1)(x+1))：同样一个"二次方程"，一个是重数 2 的单点，一个是两个分离的点。

五、上同调理论的演进——从 Serre 到 Grothendieck

Serre（1955, FAC）对代数簇定义了凝聚层上同调（coherent cohomology），用 Čech 上同调计算，将 Riemann-Roch 定理推广到任意维数。但 Zariski 拓扑太粗糙——"开集太少"导致上同调群不足以成为 Weil 上同调理论（不满足 Lefschetz 不动点公式所需的性质）。Grothendieck（1957, Tôhoku 论文）引入导出函子与 Abel 范畴；随后 Grothendieck 与 Artin 在 SGA 4（1963–1966）中发展出étale 上同调：用平展拓扑（étale topology）替代 Zariski 拓扑——"开集"是平展态射而非 Zariski 开子集。任意有限域上 étale 上同调给出 ℓ-adic 上同调（Grothendieck 学派, SGA 4–5, 1963–1966）。Deligne（1974, "La conjecture de Weil I"）用 étale 上同调完整证明了 Weil 猜想——这是 20 世纪数学的最高成就之一。后续发展：晶体上同调（crystalline cohomology, Berthelot 1974）给出 p-adic 上同调；刚性上同调（rigid cohomology）；动机理论（motives, Grothendieck 1964）作为"万有上同调理论"——每个 Weil 上同调理论是动机范畴的纤维函子。Voevodsky 发展了同伦不变的动机上同调，获 Fields 奖（2002）。

核心工具：六函子形式（six-functor formalism）——f*, f_*, f^!, f_!, Hom, ⊗——构成了 Grothendieck 对偶理论。Lurie 发展出 ∞-范畴版本的六函子。

关键文献：Serre, "Faisceaux algébriques cohérents", Ann. of Math. 61 (1955). Grothendieck, "Sur quelques points d'algèbre homologique", Tôhoku Math. J. 9 (1957). Deligne, "La conjecture de Weil I", Pub. Math. IHÉS 43 (1974).

试试看 C. 为什么 Zariski 拓扑"开集太少"？给出 A¹ 上一个具体计算：说明两个非空开集 U = A¹ − {a}、V = A¹ − {b}（a ≠ b）的交仍是开的、且仍是 Zariski 开集，但 A¹ 上不存在"一点处的小邻域"（任何非空开集都含无穷多个点）。
提示：开集 = 若干闭集之补 = 删去有限个点。故非空开集必为"补有限"，无法做到"只包含一个点"。这一现象导致常层/有限阶层在 Zariski 下丢失信息——étale 拓扑就是来补救它的。

六、模空间与几何不变量理论（GIT）

分类问题是数学的核心。在代数几何中，我们对代数簇、向量丛、曲线等对象构造参数空间——模空间（moduli space）。经典根源：Hilbert 不变理论——给定群 G 作用在多项式环上，不变多项式构成有限生成代数（Hilbert 基定理推论）。Mumford（1965）将 Hilbert 的想法推广到任意代数群作用：几何不变量理论（GIT）。核心步骤：标记群作用的"稳定"点和"半稳定"点（Hilbert-Mumford 数值判据），在半稳定点集上构造商概形 X//G——这是一个良定义的分类空间。模空间构造三阶段：（1）有界性（boundedness）——被分类对象构成有限型簇；（2）分离性（separatedness）——模空间是 Hausdorff 的，等价于存在唯一的极限对象（与估值判据相关）；（3）完备性（properness）——模空间的紧致化（Deligne-Mumford 稳定约化定理）。

经典例子：ℳg——亏格 g 的全体光滑曲线的模空间（Mumford-Deligne-Mumford, 1969），维数 3g−3 (g≥2)；ℳ(r,d)——曲线上秩 r、度 d 的半稳向量丛的模空间（Narasimhan-Seshadri, 1965）；Hilbert 概形（Hilbert scheme）——固定射影空间中全体具有固定 Hilbert 多项式的子概形的参数空间（Grothendieck, 1961），Hilbert 概形是可数多个有限型概形的并。

关键文献：Mumford-Fogarty-Kirwan, Geometric Invariant Theory, 3rd ed., Springer (1994). Newstead, Introduction to Moduli Problems and Orbit Spaces, TIFR (1978).

试试看 D. 用最简单的例子体会"商"为何困难：令 ℂ* 以 t·(x,y) = (tx, ty) 作用在 ℂ² 上，轨道除原点外都是过原点的直线。说明"轨道空间"为何在拓扑意义下不是 Hausdorff 的（原点的轨道闭包含其他轨道）。
提示：两条不同斜率的直线轨道都没有闭轨道包裹，但任意两个轨道都任意接近原点轨道；GIT 的答案是丢掉"坏轨道"、只保留半稳定轨道，再做商。

八、Nullstellensatz——几何和代数的桥梁

Hilbert 零点定理（1893）：I(Z(J)) = sqrt(J)。如果多项式 f 在代数集 Z(J) 上恒等于零 → f 的某次幂属于理想 J。弱形式：Z(J) 为空 ⟺ 1 属于 J。这是代数几何最基础的定理——将几何（零点集）和代数（理想）精确对应。证明核心：Rabinowitsch 技巧 + Zariski 引理（弱零点定理）。

九、Grothendieck 的 EGA/SGA——重写代数几何

Grothendieck 在 1960-1967 年间和 Dieudonné 合作发表了 Éléments de Géométrie Algébrique（EGA, 8 卷）和 Séminaire de Géométrie Algébrique（SGA, 7 卷）。总篇幅超过 8000 页。他将代数几何的基础从经典簇推广到概形——使数论和几何在同一个语言中得到统一。这是 20 世纪数学最宏大的写作计划之一。

十、Hilbert Nullstellensatz：完整证明

弱零点定理（Weak Nullstellensatz）：k 代数闭，理想 I ⊂ k[x₁,…,xₙ]，若 V(I) = ∅（无公共零点），则 I = k[x₁,…,xₙ]（即 1 ∈ I）。等价地：k 的每个极大理想形如 (x₁−a₁,…,xₙ−aₙ)。

证明（用 Zariski 引理）。设 m ⊂ R = k[x₁,…,xₙ] 为极大理想，L = R/m 为域。Zariski 引理：若 R 是域 k 上有限生成代数且本身是域，则 R 是 k 的有限代数扩张。证明：设 R = k[a₁,…,aₙ]，取非代数的元素逐步规范化，或更直接：R 整于某个 k[a₁]（由 Noether 正规化/传递性），而 k[a₁] 被压成域 ⟹ a₁ 在 k 上代数，归纳得每个 aᵢ 在 k 上代数 ⟹ R 是 k 的有限扩张。∎ 因 k 代数闭，有限扩张即 k 自身，故 R/m ≅ k。把 xᵢ 映到它在 L 中的余像 aᵢ，得 m ⊇ (x₁−a₁,…,xₙ−aₙ)；两者均为极大理想故相等。弱定理即得（若 V(I)=∅ 而 I≠(1)，则 I 含于某极大理想 m，V(I) 含 V(m) = {(a₁,…,aₙ)} 非空，矛盾）。∎

强零点定理（Rabinowitsch 技巧）：I(V(J)) = √J。⊇ 方向显然；证 ⊆：设 f ∈ I(V(J))（f 在 V(J) 上恒为 0），证明 f^N ∈ J 对某 N。引入新变量 xₙ₊₁，考虑 J′ = J + (xₙ₊₁ f − 1) ⊂ k[x₁,…,xₙ₊₁]。J′ 无公共零点（若 (a, b) 为零点则 a ∈ V(J) 且 b·f(a) = 1，与 f≡0 于 V(J) 矛盾）⟹ 由弱定理 1 ∈ J′。故存在多项式 g 与 hᵢ ∈ J 使

代入 xₙ₊₁ = 1/f（在分式域中看）得 1 = Σ gᵢ(x, 1/f)·hᵢ(x)。乘足够高的 f^N 消去分母：f^N ∈ J。∎ 这就是 Rabinowitsch 技巧——用弱定理 + "引入倒数变量"证强定理，是代数几何中"代数化几何"的最纯粹示范。

概形 X 在点 x 处的茎（stalk）O_{X,x} 是"x 邻域上的函数芽"，由结构层在 x 处的直接极限定义：

对仿射 X = Spec(R)，点 p 处的茎是局部化 R_p：

它是局部环（唯一极大理想 p·R_p）。动机：允许所有不在 p 中的元素取逆，但保持 p 的邻域信息——R_p 只看得到 p 附近。

性质与实例。① 局部-全局原理：R 是整环 ⟺ 所有 R_p 整；R 正则 ⟺ 所有 R_p 正则。② 向量丛在茎处分裂（射影模局部化后自由）。③ 数值例子：R = ℤ，p = (p)，ℤ_{(p)} = {a/b: p∤b} 是局部环，唯一极大理想 (p)——"在素数 p 处割一刀"的算术意义。④ 一般点：不可约仿射簇 X = Spec(R) 的一般点 η 对应零理想，茎 O_{X,η} = Frac(R) 是分式域——"在一般点，函数芽就是有理函数"。这解释了为何 Zariski 拓扑中一般点出现在每个非空开集。

十二、奇点与光滑性：Jacobian 判据与正则环

设 X = V(f₁,…,f_r) ⊂ 𝔸ₖⁿ，点 p ∈ X。光滑点（非奇异点）由 Jacobian 满秩刻画：

等价地：局部环 O_{X,p} 是正则局部环——唯一极大理想 m 可由 dim O_{X,p} 个元素生成（dim m/m² = dim O_{X,p}）。奇点 = Jacobian 秩下降（或局部环非正则）。

标准奇点分类。节点（node）：y² = x² 在原点——局部同构于两直线相交，m/m² 维数 2 > dim 1，非正则。尖点（cusp）：y² = x³——切空间维数 2 而簇维数 1。超曲面判据：对 V(f) ⊂ 𝔸ₖⁿ，p 光滑 ⟺ ∇f(p) ≠ 0。奇点不是"病态"：正规化（blow-up）允许消解——Hironaka 奇点消解定理（1964）：特征 0 的代数簇可经有限次 blow-up 消解为光滑簇。奇点理论（du Val 奇异、log canonical、极小模型纲领）把"奇点的好坏"与双有理几何的终止性联系起来。

完整例题 2 —— 具体算两条曲线的奇异点集。
任务：k 代数闭、特征 ≠ 2,3。分别求 V(y²−x³) 与 V(y²−x³+x) 在 𝔸ₖ² 中的奇异点。
曲线一（尖点 y² = x³）：f = y²−x³。第 1 步：∇f = (−3x², 2y)。第 2 步：∇f = 0 ⟺ x = 0 且 y = 0（用特征条件 2,3 可逆）。第 3 步：原点 (0,0) ∈ V(f)，故奇异点 = {(0,0)}。第 4 步（用正则环复核）：局部环 k[x,y]/(y²−x³) 在原点处 m/m² 由 x, y 生成、维数 2 > dim X = 1，非正则 ✓。
曲线二（椭圆曲线 y² = x³−x）：g = y²−x³+x。第 1 步：∇g = (−3x²+1, 2y)。第 2 步：∇g = 0 ⟹ y = 0 且 3x² = 1。第 3 步：代入 g：x³−x = x(x²−1)。当 x² = 1/3 时 x³−x = x(x²−1) = x(1/3−1) = −(2/3)x ≠ 0（特征 ≠ 2,3），故 ∇g = 0 的点不在曲线上。第 4 步：奇异点集为空——曲线二处处光滑。∎
对比：一个奇异（尖点）、一个光滑，区别只在单项式 x 的有无——这正是奇点理论要精确测量的"偏差"。
试试看 G. 求曲线 y² = x²(x+1) 的奇异点集（Hint：∇f = (−(3x²+2x), 2y)；先解 ∇f = 0 再代入原方程）。
提示：y = 0 且 x(3x+2) = 0，得 x = 0 或 x = −2/3；代入 y² = x²(x+1)：x = 0 时成立（奇异点），x = −2/3 时 x²(x+1) = (4/9)(1/3) ≠ 0 不成立。所以唯一奇异点是原点——它像"尖点 + 光滑分支"的复合。

十三、标准反例：不可约 ≠ 约化

反例 1（约化但可约——坐标轴之并）。I = (xy) ⊂ k[x,y]。簇 V(xy) = X 轴 ∪ Y 轴是可约的（两分支），但环 k[x,y]/(xy) 是约化的（无平方零元：a + bxy 型元平方零须 a=0，且 x、y 非零零）。结论：约化 = 无非零零元；不可约 = 单一分支——两个概念相互独立。

反例 2（不可约但非约化——重数 2 的直线）。I = (x²) ⊂ k[x]。簇 V(x²) = V(x) = 直线是不可约的（几何零点集只有一个分支），但环 k[x]/(x²) 有非零零元 x（x²=0）。坐标环非约化——"带重数的直线"承载双重原点的无穷小信息。这说明概形比簇"记住"了重数，这正是 Grothendieck 概形论优于经典簇概念的关键。

反例 3（整 = 不可约 + 约化）。R 是整环 ⟺ Spec R 不可约且约化。经典（约化）簇对应整环坐标环；现代概形允许研究 (x²)、(x²,xy) 这类退化的"物理对象"——形变理论与模空间紧化（稳定曲线）都依赖这种宽容。

数值检验。k[x,y]/(x²,xy)：x² = 0 非零 ⟹ 非约化；而 Spec 只有两个点（(x,y) 与 (x)）——坐标环维数不等于点的个数，体现"代数信息多于几何点"。

十四、工作题：Spec(ℤ) 与 Nullstellensatz 应用

题 1：列出 Spec(ℤ) 的所有点（素理想），指出哪些是闭点、哪个是一般点；解释 12 = 2²·3 的分解如何在 Spec(ℤ) 上体现为"纤维的重数"。

题 2：k 代数闭。求理想 I = (x²+y²−1, x−y) ⊂ k[x,y] 的零点集 V(I)，并用强 Nullstellensatz 求出 I(V(I))。

题 3：设 f ∈ k[x₁,…,xₙ] 在 V(Π(xᵢ−aᵢ))（n 个超平面的并）上恒为零。用 Nullstellensatz 证明 f 被 Π(xᵢ−aᵢ) 整除，并说明为何这里"整除"（而非"某次幂"）——精确刻画 √(Π(xᵢ−aᵢ))。

显示解答

题 1：ℤ 是 PID，素理想只有 (0) 与 (p)（p 素数）。Spec(ℤ) = {(0)} ∪ {(p): p 素数}。闭点 = 极大理想 = (p)；一般点 = (0)（其闭包是整个 Spec(ℤ)，因 (0) ⊂ (p)）。分解 12 = 2²·3 对应纤维 Spec(ℤ/12ℤ)：在 (2) 处重数 2、在 (3) 处重数 1——"分歧"概念的几何雏形。∎

题 2：V(I)：y = x 且 x²+y²=1 ⟹ 2x²=1 ⟹ x = ±1/√2，两个点 a = (1/√2, 1/√2)、b = (−1/√2, −1/√2)。强 Nullstellensatz：I(V(I)) = √I = I(a) ∩ I(b) = (x−1/√2, y−1/√2) ∩ (x+1/√2, y+1/√2)。∎

题 3：J = (Π(xᵢ−aᵢ)) 是主理想且因子互素 ⟹ 平方自由 ⟹ √J = J。若 f 在 V(J) 上恒为零，f ∈ I(V(J)) = √J = J = (Π(xᵢ−aᵢ)) ⟹ 整除成立，无需"某次幂"。这正是"平方自由理想下 √I = I"带来的精确化。∎

试试看 H. 在题 2 的答案中，为什么 √I = I(a) ∩ I(b) 而不是别的？请把 I(a) ∩ I(b) 重新写成单个理想（Hint：消去 y，用 (x−1/√2, x+1/√2) 与"两个点差别的平方"——答案里含 x²−1/2）。
提示：利用 (x−1/√2)(x+1/√2) = x²−1/2 ∈ I(a)∩I(b)，且 y−x 也属于它；反过来可证包含。这给出 I(V(I)) = (y−x, x²−1/2)。
