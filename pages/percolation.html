〇、直觉入门——一块石头里，水何时能穿过去？

把一块多孔材料切成薄片，想象成一张格子：每个"孔"独立地以概率 p 是通的、1−p 是堵的。问：水能否从左边流到右边？把 p 从 0 慢慢调到 1，你会看到一个毫不含糊的转折——存在一个临界值 p_c：

  • p < p_c：几乎不可能贯通（只有零星小水洼）；
  • p > p_c：几乎必然贯通（出现贯穿左右的"大团簇"）；
  • p = p_c：临界——恰好卡在"碎"与"通"之间，团簇呈分形。

这个模型叫渗流（percolation），由 Broadbent 与 Hammersley 在 1957 年提出（研究煤矿瓦斯过滤）。它是"相变"最干净的数学样本：没有温度、没有能量，只有一个参数 p 和一个连通性概念，却完整复现了物理相变的全部特征——尖锐阈值、普适临界指数、分形团簇、有限尺寸标度。最令人吃惊的事实之一：在平面正方形键渗流中，临界值恰好是 p_c = 1/2（Kesten 1980），一半开一半关就是相变点。

洞察：渗流把"相变"蒸馏成纯概率：无穷连通团簇的存在性 θ(p)=P(0↔∞) 充当"序参量"，它从 0（亚临界）跳到正值（超临界）的临界点 p_c 依赖格子细节，而临界指数（θ~(p−p_c)^β，β=5/36；关联长度 ξ~(p−p_c)^{−ν}，ν=4/3）却不依赖格子——普适性。画布上滑动 p，你会亲眼看到这个转折，以及临界点附近团簇的"处处相似"。
⚠️ 背景提示：本课属于 核心 级别。

建议先掌握：概率论基础（独立与极限）、图论与网络（连通性与团簇）、Ising 模型（可选的相变对照）。与 大数定律 的"大偏差"思想也相关。

一、一个具体问题——Broadbent–Hammersley 1957 与 Kesten 的 1/2

模型。 键渗流：取无限图（如平面方格 ℤ²），每条边独立地"开"（概率 p）或"关"。开边的连通分量叫团簇。核心量：

θ(p) 是"原点处有无限大水洼"的概率。单调性给出临界值 p_c=sup{p：θ(p)=0}：

历史上的里程碑。

  • Broadbent–Hammersley（1957）： 提出模型并证明 p_c 存在、0<p_c<1（平面格）；一维情形平凡（p_c=1）。
  • Harris（1960）： 用平面对偶证明方形键渗流在 p=1/2 无贯通（θ(1/2)=0）。
  • Russo–Seymour–Welsh（1978，RSW）： 关键估计：临界附近的"穿越概率"被夹在正上下界之间——为尖锐相变提供几何工具。
  • Kesten（1980）： 证明方形键渗流 p_c=1/2——最著名的精确临界值。三角形格键渗流 p_c=2sin(π/18)≈0.3473、蜂窝格 ≈0.6527 也是精确的（Sykes–Essam 猜测、Wierman 证明）；但点渗流方形格 p_c≈0.5927 至今没有闭式。
  • Aizenman–Kesten–Newman（1987）： 无穷团簇至多一个（几乎必然唯一）。

二、先直觉后严格——为什么平面键渗流的临界值会是 1/2

平面对偶。 方形格的"对偶格"还是方形格：把每个小方格中心连成网，原始边与对偶边一一对应、且恰好相交于一点。原始图的"无限开团簇"与对偶图的"无限闭团簇"不能共存——若两边都贯通，拓扑上必然相交于一条原始开边与一条对偶闭边的交叉处，矛盾。而开/闭互换恰好把 p 换成 1−p：

由于方形格自对偶，若 p=1/2 时存在无限开团簇，则对偶同样存在无限闭团簇，矛盾——于是 θ(1/2)=0（Harris）。RSW 估计再保证 p>1/2 时穿越概率 >0（Kesten 完成另一半），合起来 p_c=1/2。∎

锐化（sharp threshold）。 在边长 L 的方盒里，"左-右穿越"概率作为 p 的函数在 p_c 附近从 ε 跳到 1−ε，过渡窗口宽度 ~L^{−1/ν}（ν=4/3 ⟹ 宽度 ~L^{−3/4}）：盒子越大，相变越"陡"。画布的扫参曲线正是这条阶梯曲线随 L 变陡的实况。

普适性从哪来？ 临界现象只"看见"大尺度几何：三角格、方形格、蜂窝格在 p_c 处的长程行为由同一个共形不变极限描述（Smirnov 2001 在三角格点渗流证明共形不变性，通向 SLE₆）。阈值 p_c 是"微观"细节（不普适）；临界指数是"宏观"行为（普适）。

三、例题 1——小盒子手算穿越概率与对偶（一步步算完）

题目。 (a) 一维链 p_c=1（平凡）：说明为何无相变。(b) 方形 n×n 盒键渗流：用对偶论证它在 p=1/2 的左→右穿越概率恰为 1/2。

第一步：(a) 一维。 原点属于长 L 团簇需要连续的 L 条边全开，概率 p^L→0（p<1）。只有 p=1 才有无穷团簇：p_c(ℤ)=1——维度不够，没有非平凡相变（树的 p_c=1 同理）。相变需要"绕过障碍的多种路径"，即维度 ≥2 的拓扑。∎

第二步：(b) 旋转对称。 把 n×n 盒旋转 90°：左→右的穿越变成下→上的穿越，故 P(LR)=P(BT)。

第三步：平面对偶收尾。 “无 LR 穿越” ⟺ 对偶图存在一条下→上的闭穿越（屏障）。方形格自对偶，p=1/2 时开/闭过程同分布，故 P(无LR)=P(对偶有BT闭)=P(BT开)=P(LR)，于是 P(LR)=1/2。∎

第四步：为什么这是 Kesten 定理的种子？ 有限盒临界穿越概率 = 1/2 是对偶性的直接后果；RSW 估计保证临界处该概率被夹在正数之间（盒子增大不塌到 0），Kesten 再用单调性与对偶把它钉成全局 p_c=1/2。画布的扫参曲线在 p=1/2 附近最陡，正是这一定理的数值回声。∎

四、例题 2——临界团簇的分形与普适指数（一步步算完）

题目。 把 p_c 处与 p>p_c 处的团簇几何"称重"：引入并核对 2D 关键指数。

第一步：临界关联长度。 定义 ξ(p)（两点关联衰减的相关长度）：ξ ~ |p−p_c|^{−ν}。2D：ν=4/3。

第二步：序参量。 θ(p) ~ (p−p_c)^β。2D：β=5/36（≈0.1389）。θ 增长"极缓"：p−p_c=10⁻⁶ 时 (10⁻⁶)^{5/36}=10^{−30/36}=10^{−0.833}≈0.147·C——临界点附近的序参量从零"翘起"得非常慢，这是连续（二级）相变的标志。

第三步：临界团簇是分形。 在 p=p_c，无穷大团簇尚不存在，但有限团簇的尺寸分布与"质量—半径"满足幂律：

d_f≈1.9 介于线(1)与面(2)之间——临界团簇是分形（→ 分形 课）。∎

第四步：普适与不普适。 上述 ν、β、τ、d_f 对方形/三角/蜂窝键或点渗流都一样（同一普适类）；而 p_c 不同（0.5、0.347、0.653、0.593…）。"阈值是格子的事、指数是维度的事"——这是相变理论最深的经验律之一，也是画布扫参曲线的注脚。∎

五、严格陈述——核心定理清单

  • 定义： 键/点渗流、团簇、θ(p)=P(0↔∞)、p_c=sup{p：θ(p)=0}。
  • Kesten（1980）： 方形格键渗流 p_c=1/2。三角键 p_c=2sin(π/18)、蜂窝键 p_c=1−2sin(π/18)（Wierman）；方形格点渗流 p_c≈0.592746…（无闭式）。
  • 单调与对偶： θ(p) 单调；p>p_c 时几乎必然存在唯一无穷团簇（AKN 1987）；临界处 θ(p_c)=0（Kesten：连续性）。
  • RSW 估计（1978）： 临界附近方形盒穿越概率有正的均匀下界——"临界窗口不塌缩"的几何支柱。
  • Smirnov（2001）： 三角格点渗流在 p_c 的穿越概率共形不变（趋向 SLE₆ 驱动）；由此 Schramm–Smirnov 严格算出若干临界指数（如单臂指数 5/48）。方形键渗流的临界指数仍无严格证明（数值与 CFT 支持普适猜想）。
  • 临界维度： 高维（d>6，渗流的上临界维度）进入平均场行为（团簇像分支过程；Hara–Slade 用圈展开在"展宽模型"上严格化）。

七、延伸——渗流的亲戚与用途

  • Ising 与随机团簇。 Fortuin–Kasteleyn 把 Ising 模型（→ Ising 课）改写成带权渗流（随机团簇模型）：Ising 的相变 = 渗流意义的连通相变。两个模型的临界指数通过同一普适类连接（2D Ising β=1/8 ⟷ 渗流指数满足标度关系）。
  • 传染病与网络。 疾病传播 = 接触图上的渗流（超临界爆发 ⟺ 出现巨型连通分支）；互联网故障级联、社交"六度"、电网鲁棒性都用渗流分析真实网络（无标度网络的渗流阈值甚至为 0！）。→ 图论与网络 课。
  • 多孔介质与油藏。 石油开采、混凝土渗透、燃料电池多孔层——"能不能通"直接是 p 与 p_c 之比较量。渗流是工程里被引用最多的概率模型之一。
  • 共形不变量与 SLE。 Smirnov 证明三角格点渗流的穿越概率共形不变并满足 Cardy 公式，驱动曲线收敛到 SLE₆——二维临界现象的严格窗口。→ 分形、复动力系统 课的自相似世界观。
  • 有限尺寸标度。 数值研究靠"盒子越大曲线越陡、在 p_c 处交于一点"标度数据外推 p_c——画布扫参曲线的现代用法。→ 数值计算方法。

八、反例与陷阱——五个"渗流想当然"

陷阱 1："p>p_c 后整张格子都通"？ 不是。唯一无穷团簇的密度 θ(p) 是正的但远小于 1（p 略超 p_c 时 θ 只比 0 大一点）；到处仍有无限多个有限团簇。θ 是"序参量"，不是"全通概率"。

陷阱 2："p_c 是格子的几何常数（都一样）"？ p_c 依赖格子细节（方形键 0.5、方形点 0.59、三角键 0.347……）；普适的是临界指数不是阈值。看到"渗流临界"先问是哪个格子、键还是点。

陷阱 3："临界点 p_c 本身有巨团簇"？ 2D 的 θ(p_c)=0（Kesten 连续性）：临界处没有无穷团簇，只有幂律分布的有限分形团簇。相变的"临界"在于关联长度发散，不在于"已经通了"。

陷阱 4："数值图里的'黑团簇'= 无穷团簇"？ 有限盒里永远只有有限团簇；"无穷"是 L→∞ 的极限概念。画布大盒 p=0.55 看到的"大团簇"是有限盒近似——它在 p_c 处不会变成真正的无穷团簇（θ(p_c)=0）。

陷阱 5："渗流指数对一切 2D 格子都已被证明"？ 只有三角格点渗流的部分指数经 SLE 严格化；方形键渗流的临界指数仍缺严格证明（普适性在物理与数值上极强，数学上仍是核心开放问题）。"普适"是深刻的经验+部分定理，不是随处可用的黑箱。

九、当前状态——前沿与开放

  1. 临界指数严格化。 Smirnov–SLE 路线覆盖三角格点渗流；方形键（最经典模型）的 ν=4/3、β=5/36 严格证明仍是重大开放问题。
  2. 高维与平均场。 d>6 的均值场行为（与树/分支过程一致）——上临界维数以上已被圈展开处理，但"恰在 d=6"的临界行为仍有精细工作。
  3. 依赖性与一般图。 依赖渗流（边概率相关）、随机几何图、无标度网络（p_c 可为零）——网络科学的渗流前线。
  4. 量子与多体推广。 纠缠渗流、量子团簇相——渗流思想进入量子信息（→ 纠缠）与拓扑相变（玻色子/费米子随机团簇）。

关键论文

  • Broadbent–Hammersley (1957)：渗流模型与 p_c 存在性——"Percolation processes"（剑桥）。
  • Harris (1960)：θ(1/2)=0（方形键，对偶 + 连通性论证）。
  • Seymour–Welsh (1978) / Russo (1981)：RSW 估计与锐相变工具。
  • Kesten (1980)："The critical probability of bond percolation on the square lattice equals 1/2", Comm. Math. Phys.——最著名的精确临界值。
  • Aizenman–Kesten–Newman (1987)：无穷团簇唯一性。
  • Smirnov (2001)："Critical percolation in the plane"——三角格点渗流共形不变性（Cardy 公式），通向 SLE₆。
  • Schramm–Smirnov (2011)：三角格点渗流临界指数（单臂 5/48 等）严格计算。
  • Hara–Slade (1990)：圈展开与高维渗流均值场行为。

工作题——小计算与概念

题 1（一维平凡）。 证明 ℤ 上键渗流 p_c=1。提示：原点团簇长 L 需连续 L 条开边，概率 p^L→0（p<1）。

题 2（对偶+旋转）。 用旋转对称与平面对偶说明：方形 n×n 盒键渗流在 p=1/2 的左右穿越概率 = 1/2。提示：P(LR)=P(BT)（旋转 90°）；无 LR ⟺ 对偶存在 BT 闭穿越；p=1/2 时对偶与原始同分布 ⟹ P(LR)=1/2。

题 3（指数感觉）。 p−p_c=10⁻⁴ 时，(p−p_c)^{5/36} 约多大？提示：10^{−4·5/36}=10^{−0.556}≈0.28（乘上前因子即 θ 的量级——序参量爬升极慢）。

题 4（为什么 1D 没相变而 2D 有）。 用"绕过障碍的路径条数"语言解释维度的作用。提示：1D 里 0 到 +L 只有唯一路径，任何断点都切断；2D 有指数多条路径，关闭一条可绕行——"多条路"让连通变成集团现象（θ 从 0 跃升）。
