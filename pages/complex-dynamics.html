〇、直觉入门——反复按下一个键：z 变成 z²，再变成 (z²)²，再……

取一个复数 c，从 z₀=0 出发反复迭代 z_{n+1}=z_n²+c。这个"按平方再加 c"的简单操作，把平面上的点分成两类：轨道逃逸到无穷（z_n 的模越来越大），或永远待在有限范围内。分界线就是神秘的 Julia 集——一个可以光滑如线段、也可以毛糙如尘埃的集合。

而当我们把 c 本身当作变量、问"这个 c 的 Julia 集是否连通"，就在 c 平面上得到另一个集合：Mandelbrot 集（MB 集）。它在 1980 年因计算机图形学而举世闻名——那个"雪花/海马/灯泡层层嵌套"的黑色图形。但对数学家而言，MB 集的意义不是好看：它编码了二次多项式族 z²+c 的全部动力学，是 20 世纪复动力系统（Fatou–Julia 理论 + Douady–Hubbard 纲领）的心脏。

更惊人的是，这门"迭代平方"的学问连着数学的许多角落：牛顿法求根、连分数与小除数（Siegel 圆盘）、重整化与统计物理的相变、双曲几何的模群、以及尚未解决的重大猜想。它把"混沌"从口号变成了黎曼球面上的严格几何。

洞察：一个函数的所有"长期行为"浓缩成一个集合：J_c 是混沌的边界（排斥周期点稠密、对初值敏感），Fatou 集是秩序的地盘（吸引盆、Siegel 圆盘）。参数空间（MB 集）则反过来按 Julia 集的拓扑分类函数——"迭代一个函数"与"遍历所有函数"两个问题，由 Fatou–Julia–Douady–Hubbard 焊接成一套理论。
⚠️ 背景提示：本课属于 前沿 级别。

建议先掌握：复平面与全纯函数（迭代的舞台）、分形（自相似与维数的语言）、黎曼面（可选：黎曼球面视角）。本课画布直接实现逃逸时间算法。

一、一个具体问题——Fatou 与 Julia 在 1918 年的对垒

第一次世界大战前后，Fatou（1906、1919）与 Julia（1918，为此获法国科学院大奖）独立研究有理函数 f 的迭代：fⁿ=f∘…∘f。核心观察：黎曼球面 ℂ̂ 被迭代分成两个互补的开/闭集——

  • Fatou 集 F(f)： 轨道行为"正常"的开集（在它上面迭代族局部等度连续；Fatou 集由吸引盆、抛物盆、Siegel 圆盘与 Herman 环组成）。
  • Julia 集 J(f)： F 的补集——混沌集：排斥周期点稠密、J 在 f 下完全不变（f(J)=J）、对初值高度敏感。J 通常是有理函数动力学的"骨架"。

对二次多项式 f_c(z)=z²+c，理论变得惊人地丰富而干净：填充 Julia 集 K_c={z：轨道有界}，J_c=∂K_c。Fatou–Julia 时代就确立了：J_c 连通 ⟺ c 属于 MB 集 M（c 在 M 外时 J_c 是完全不连通的 Cantor 尘埃）。但"MB 集长什么样、是否连通"这类问题悬了近六十年——直到 Douady–Hubbard（1982，Orsay 讲义）用外部射线与位势理论证明：M 本身连通，并给出其精密的参数化理论。

为什么要问这些？ 三个至今未解的大问题把它推上前线：(1) M 的局部连通性（MLC）——若真则 M 的拓扑完全理解；(2) M 的面积是否有限（数值 ~1.506，严格未定）；(3) 参数空间中的双曲稠密猜想（吸引周期动力学的参数是否稠密）。复动力系统是少数"打开电脑就能看到、打开论文却推不动"的领域——像素与证明之间的鸿沟本身就是它的魅力。

二、先直觉后严格——"平方再加 c"的三个观察

观察 1：拉伸与折叠。 z↦z² 把角加倍（z=re^{iθ} → r²e^{2iθ}），模从 r 变 r²：|z|>1 被推向更远、|z|<1 被吸向 0。加 c 再把图形平移。迭代 = 反复"拉伸—折叠—平移"，混沌的几何来源就在这个动作里。

观察 2：逃逸判据。 若某个 |z_n|>2 且 |c|≤2，则轨道必逃逸（|z_{n+1}|≥|z_n|²−|c|>2|z_n|−2，一旦超过 2 就回不来）。所以填充 Julia 集被包含在闭圆盘 |z|≤2 内；"超过 2 就再见"是画布逃逸时间算法的判据。

观察 3：三类临界点行为。 二次多项式有唯一临界点 0（f_c′(0)=0）。它的轨道决定一切：

直观：若 0 逃逸，Julia 集被"撕碎"成 Cantor 尘埃（完全不连通）；若 0 有界，J_c 连成一个整体。Mandelbrot 集因此可以定义得很朴素：M = {c：0 的轨道不逃逸}——画布的小 MB 窗口就是把每个 c 的临界轨道画一遍。

三、例题 1——手算几条临界轨道（一步步算完）

题目。 分别取 c=0、−1、1、−2、i，从 z₀=0 迭代并判断归属。

第一步：c=0。 0→0→0…：不动点 0（超吸引，f′(0)=0）。K_0=单位圆盘，J_0=单位圆。0∈M ✓（Julia 是圆周——光滑！）。

第二步：c=−1。 0→−1→0→−1…：周期 2 环 {0,−1}；导数 f′(0)·f′(−1)=0·(−2)=0 ⟹ 超吸引周期环。−1∈M，Julia 连通（著名的"兔形"开端）。

第三步：c=1。 0→1→2→5→26→…：超过 2 后逃逸（z₂=2 已触发判据）。1∉M，Julia 是 Cantor 尘埃。∎

第四步：c=−2。 0→−2→2→2→…：进入不动点 2（f_c(2)=2）。−2∈M（MB 集最左端，实数轴端点）。

第五步：c=i。 0→i→−1+i→−i→−1+i→…：从 i 之后进入周期 2 环 {−1+i, −i}。i∈M ✓（Julia 连通但形状复杂）。∎

总结。 判别只靠"临界轨道逃不逃"：c∈M ⟺ 0 的轨道有界。画布上点 MB 窗口即可复现这五条轨道与对应的 Julia 集。

第二步：翻译轨道。 令 w=e^{iθ}（|w|=1）：w^{2ⁿ}+w^{−2ⁿ}=2cos(2ⁿθ)——轨道 = 2cos(2ⁿθ)，永远落在 [−2,2]，且有界。

第三步：反之。 若 z∉[−2,2]，则 w 满足 |w|≠1（w+w⁻¹=z 有两个解，一在单位圆内一在外，模 ≠1）。|w|>1 时 w^{2ⁿ}→∞，轨道逃逸；|w|<1 同理（倒数）。故填充集恰为 [−2,2]，Julia 集 = [−2,2]。∎

第四步：这一例的三重教训。 (1) Julia 集不必是分形；(2) 轨道 z_n=2cos(2ⁿθ) 对 θ 高度敏感——倍角映射 2cos 就是遍历理论课（→ 遍历理论）的共轭亲兄弟：混沌的根源同一个；(3) c=−2 位于 MB 集"主天线"端点，动力学退化到实直线——参数空间的边界点往往藏着退化与临界（抛物线化）行为。∎

五、严格陈述——核心定理清单

  • 定义。 f_c(z)=z²+c；填充集 K_c={z：f_cⁿ(z) 有界}；Julia 集 J_c=∂K_c；MB 集 M={c：0 的轨道有界}。
  • Fatou–Julia 基本事实（1918–19）： J_c 是完全不变的紧集、排斥周期点稠密于 J_c、J_c 对 f_c 敏感依赖；Fatou 集是正常族区域。
  • 逃逸判据： |c|≤2 时，若某 |f_cⁿ(z₀)|>2 则轨道逃逸；K_c⊆{|z|≤2}。
  • 连通性定理： c∈M ⟺ J_c 连通；c∉M ⟹ J_c 是完全不连通 Cantor 集（对二次多项式族）。
  • Douady–Hubbard（1982）： M 连通；外部射线参数化、势函数 G(c)=lim 2⁻ⁿ log⁺|f_cⁿ(0)| 存在且调和——M 的补集与单位圆外区域共形等价（对连通的 M 外部），是现代参数化与计算（外部射线画图）的根基。
  • Sullivan 无游荡域（1985）： Fatou 集的分量都是周期的（无"游荡"分量）——用拟共形形变证明，复动力系统迎来现代纪元。
  • Shishikura（1998）： MB 集边界的 Hausdorff 维数 = 2。
  • 开放问题： MLC（M 局部连通）、M 面积有限性、双曲稠密猜想——均未解决（Lyubich 1990s 证明双曲参数在 M 内部稠密、且 M 在双曲参数处局部连通）。

七、延伸——平方迭代的亲戚们

  • 牛顿法。 求多项式根的牛顿迭代 z↦z−p(z)/p′(z) 的 Julia 集把复平面分成各根的吸引盆，边界常是分形；"哪个初始值收敛到哪个根"就是动力系统的地图题。→ 数值计算方法 课。
  • Siegel 圆盘与小除数。 当 c 使临界点附近有不动的中性点且旋转数满足丢番图条件时，出现 Siegel 圆盘（线性化的旋转区域）——与连分数/丢番图逼近（后续课程）直接相连。
  • 重整化与统计物理。 周期加倍瀑布的自相似结构可用重整化算子解释（Feigenbaum 常数、Sullivan/Lyubich 的严格理论）——复动力系统成为相变理论的数学外壳。→ Ising、分岔（后续课程）。
  • 模群与双曲几何。 二次多项式的参数空间（MB 集）与模空间、外部射线的"分母有理数"标记连接泰希米勒理论；双曲分量上的动力学由拟共形映射刚性化。→ 双曲几何、模形式 课。
  • 计算与算法。 逃逸时间算法（画布所用）、外部射线追踪、高精度参数空间计算——"看得见的数学"的最成功案例；也催生了"Julia 集的可计算性"研究（Braverman–Yampolsky 2006 起）。

八、反例与陷阱——五个"像素想当然"

陷阱 1："Julia 集一定分形"？ 反例：c=0 时 J=单位圆（光滑）；c=−2 时 J=[−2,2]（例题 2 线段）。分形只出现在"动力学复杂"的参数上——把"看到分形"当"所有情况"，会漏掉理论里最精妙的部分（光滑 Julia 与 Cantor 尘埃同样重要）。

陷阱 2："MB 集 = 参数 c 对应的图形"？ 概念要分清：填充 Julia 集 K_c（动态平面里的一个点集）、Julia 集 J_c（其边界）、MB 集 M（参数平面上 c 的集合）。画布左图是 K_c 的近似（黑色），右栏小窗是 M——两者活在不同的平面上。

陷阱 3："|z|>2 判据可以一次定论"？ 判据只在 |c|≤2 且从某一步起成立；像素图里"黑色"只是"迭代 N 次仍未超过 2"的近似——真正的 K_c 边界需要无穷迭代。增加最大迭代数会让图"长毛"，但永远不会变成证明。计算机画的是近似，定理才管精确。

陷阱 4："周期点都是稳定的"？ 周期点按乘子 |(fⁿ)′(z₀)| 分类：<1 吸引（稳定）、>1 排斥（Julia 集里的稠密点）、=1 中性（Siegel/抛物线/Cremer 的精微情形）。"混沌"恰恰由排斥周期点构成——稳定性与混沌并存于同一函数的不同周期点上。

陷阱 5："MB 集边界就是 Julia 集"？ 两者无关地"相像"是审美巧合。M 是参数空间的连通紧集（它的每个点是一个二次多项式）；J_c 是动态平面上的集合。M 的边界在参数上对应临界轨道"临界"的行为——但这是参数空间自己的故事，与某个 J_c 的形状无直接包含关系。

九、当前状态——未解问题与活跃方向

  1. MLC（Mandelbrot 局部连通性）。 M 的每个点是否都有任意小连通邻域？Douady–Hubbard 纲领的头号目标；已知在双曲参数处成立，一般情形仍开放——"M 的拓扑是否完全理解"就卡在这。
  2. M 的面积。 数值 ≈1.50659177…；严格证明"面积有限"或"为正"（后者显然？面积可测为正易证？实际"面积 >0"部分易？M 有内点故面积>0 trivially；"有限"难）——"M 的面积有限吗"仍是开放（Buff–Chéritat 2012 证明了存在面积正的二次 Julia 集，但那是动态平面不是参数平面）。
  3. 双曲稠密猜想。 具有吸引周期轨道的参数（双曲参数）是否在 M 中稠密？Lyubich 证明了双曲参数在 M 内部稠密（1990s），但边界附近情形（与 MLC、面积问题纠缠）仍开放——这是"参数空间动力学"的最大猜想。
  4. 更高次与超越。 三次多项式连通轨迹集、指数族 e^{λz}、超越整函数的 Julia 集（无穷远成为本质奇点）——结构远比二次族复杂，是当前最活跃的扩张方向。

关键论文

  • Julia (1918)：迭代有理函数的大奖论文——Julia 集理论与排斥周期点的稠密性。
  • Fatou (1906, 1919)：Fatou 集与正规族方法（与 Julia 独立、互补）。
  • Douady–Hubbard (1982)："Itération des polynômes quadratiques complexes"（Orsay 讲义）——MB 集连通性、外部射线、势函数；现代复动力系统奠基。
  • Sullivan (1985)："Quasiconformal homeomorphisms and dynamics I: solution of the Fatou–Julia problem on wandering domains"——无游荡域定理。
  • Shishikura (1998)：MB 集边界 Hausdorff 维数为 2。
  • Lyubich (1990s)：双曲参数稠密性（M 内部）与重整化收敛（Feigenbaum 的严格化）。
  • Buff–Chéritat (2012)："Quadratic Julia sets with positive area"——存在面积正的二次 Julia 集（动态平面）。
  • Braverman–Yampolsky (2006 起)：Julia 集的可计算性——像素与精确拓扑计算的分野。

题 1（超吸引环）。 c=−1：写出 0 的轨道并验证它是周期 2 的超吸引环。提示：0→−1→0；乘子 = f′(−1)·f′(0)=(−2)·0=0。

题 2（进入环）。 c=i：验证轨道 0→i→−1+i→−i→−1+i…（从 −1+i 起周期 2）。提示：(−1+i)²+i=−i；(−i)²+i=−1+i。
