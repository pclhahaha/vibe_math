〇、直觉入门——研究"位置加速度"这个整体空间的几何学

想象台球桌上的一颗球：光说"球在哪儿"还不够，还要知道它往哪个方向滚、滚多快，才算完整描述它的状态。辛几何就是研究这种"位置+速度"组合起来的空间的数学。

它专门管一件事：这个空间里的东西是怎么"流动"的。物理学家早就发现，物体怎么动都逃不出这个空间的规矩——辛几何把这些规矩用数学严格地写了出来。

辛几何是经典力学的数学舞台——它研究"位置和动量"这个整体空间，并保证了其中的流动像水一样不可压缩。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 前沿 级别，正文较深。

建议先掌握：平行移动、变分法、测地线。

高级章节（证明、前沿、工作题）需要相应背景，未掌握可先看「〇、直觉入门」了解核心思想，或回到前置课程补基础。

二、辛流形——相空间的抽象化

把上面"会算的平面"推广成任意流形。

定义（辛流形）。 (M, ω) 其中 M 是 2n 维光滑流形，ω 是 2-形式，满足：

  • 闭性：dω = 0；
  • 非退化性：ω^n = ω∧…∧ω ≠ 0（处处成立，它定义一个体积形式）。

为什么要求"闭"？ 闭性保证哈密顿动力学与微分形式理论相容：它让"哈密顿向量场存在且唯一"（因为 ω(v,·) 的映射是线丛同构）、让守恒量的泊松括号闭合、让 ω 的积分在同调下不变。非退化性则保证每个方向都有配对——相空间没有"死角"。

泊松括号。 对函数 f,g，定义 {f,g} = −ω(X_f, X_g)，其中 X_f 由 ω(X_f,·) = df 决定。符号约定说明：这个 − 号保证正则坐标满足 {q,p} = 1（与物理学家一致）；换用 {f,g} = ω(X_f,X_g) 只把每个括号整体变号，"是否为零"完全不受影响。它是反对称、满足 Leibniz 律与 Jacobi 恒等式的运算，把"函数"变成李代数。物理意义：沿哈密顿流的时间演化写为 ḟ = {H,f}，故 {H,f} = 0 恰表示 f 是守恒量。谐振子里能量守恒写为 {H,H}=0。

Liouville 定理。 对任何哈密顿函数 H，其流保 ω（进而保体积形式 ωⁿ/n!）。证明只需 Lie 导数：L_{X_H}ω = d(ι_{X_H}ω) = d(dH) = 0。这就是"相空间里的流不可压缩"的严格陈述——统计力学的数学基础。

三、Darboux 定理——局部全同 vs. 整体刚性

Darboux 定理（1882）：设 (M^(2n), ω) 为辛流形。对任意 p ∈ M，存在局部坐标 (q₁,…,q_n, p₁,…,p_n) 使得 ω = Σ dp_i ∧ dq_i。这意味着所有同维辛流形局部不可区分——辛几何没有类似于 Riemann 几何中黎曼曲率的"局部不变量"。这与 Riemann 几何形成鲜明对比：Riemann 流形的截面曲率在每点变化，而辛流形在局部完全刚性。

为什么"局部全同"反而让辛几何难？ 因为没有局部不变量，辛流形的差别只能出现在整体层面（如同调、嵌入、辛刚现象）。Riemann 几何靠"每一点的曲率"就能区分空间；辛几何必须发明整套整体工具（拟全纯曲线、Floer 同调）来"看见"差别。这就是为什么辛拓扑需要如此深刻的技术。

四、Darboux 定理的证明思路（Moser 技巧）

定理。设 (M^{2n}, ω) 为辛流形。对任意 p ∈ M，存在以 p 为心的坐标卡 (q₁,…,qₙ, p₁,…,pₙ) 使 ω = Σᵢ dpᵢ ∧ dqᵢ。

证明思路。① 线性化：ω_p 是 T_pM 上的非退化反对称双线性形式，线性代数（标准辛形式定理）保证存在线性坐标使 ω_p = Σ dpᵢ∧dqᵢ。于是问题化为：给定"常数形" ω₀ 与在 0 处与之重合的一般闭 2-形式 ω₁，求微分同胚 φ 使 φ*ω₁ = ω₀。② 凸形变：设 ω_t = (1−t)ω₀ + tω₁（在 0 的某邻域上仍为辛形式）。若存在时间相关向量场 X_t 生成流 φ_t 满足 φ_t*ω_t = ω₀，则对 t 求导得 L_{X_t}ω_t + dω_t/dt = 0。③ Moser 方程：因 ω₁ − ω₀ 闭，由 Poincaré 引理局部 ω₁ − ω₀ = dα，故 dω_t/dt = dα_t，解

非退化性保证 X_t 良定义且唯一；解 ODE 得流 φ_t，取 t=1 得 φ₁*ω₁ = ω₀。④ 结论：(q,p) = φ₁⁻¹(线性坐标) 满足要求。∎

为什么 Moser 技巧是通用的？ 它把"找坐标"化为"找微分同胚流"，把几何问题变成解 ODE，证明是构造性的。注意"ω₀ 与 ω₁ 在 0 点相重合"这个条件保证整个区间上 ω_t 都非退化——Moser 的同伦论证正是在这条"非退化走廊"里滑行。由此辛流形无局部不变量——没有曲率张量，与 Riemann 几何形成根本对照。

六、例题 2——ℝ⁴ 上的辛形式：验证 Darboux 化与哈密顿向量场（一步步算完）

题目。 在 ℝ⁴（坐标 (x₁,y₁,x₂,y₂)）上取 ω = dx₁∧dy₁ + dx₂∧dy₂。①验证它是辛形式；②求 H = x₁²+y₁² 的哈密顿向量场 X_H，并描述其流。

第四步：读流。 这是 (x₁,y₁) 平面内以角速度 2 的旋转，(x₂,y₂) 保持不变，能量 x₁²+y₁² 守恒。

为什么这个例子有代表性？ 它演示了辛形式的"体检流程"（闭 + 非退化）、哈密顿向量场的系统求法，以及 Darboux 坐标为什么平凡（这里本身就是标准形）。求 X_H 的"匹配系数"法，是后面所有辛计算的模板。

七、辛流形、近复结构与 Kähler 情形

设 (M, ω) 为辛流形。一个近复结构 J 是端射 J: TM → TM 满足 J² = −id。相容性条件：g_J(v,w) = ω(v, Jw) 是正定 Riemann 度量，且 ω(Jv, Jw) = ω(v,w)。满足这些的 J 称为与 ω 相容的近复结构。

存在性。相容近复结构总存在（分两步：任取 Riemann 度量 g，用偏振与正交分解在每点构造 ω-相容 J——纯线性代数；整体性来自张量丛的连续性）。且相容 J 的全体构成可缩空间——故辛流形与"带 ω 相容的几乎 Kähler 结构"等价。相容性给出关键的面积控制：ω(v, Jv) = g_J(v,v) ≥ 0，于是 ω 限制在 J-全纯曲线的切方向上恰为面积形式——这是 Gromov 紧致性的几何来源。

可积性（Kähler 情形）。 J 来自复结构（可积）当且仅当 Nijenhuis 张量 N_J = 0。此时 (M, ω, J, g_J) 是 Kähler 流形——辛几何与复几何的交汇点：Hodge 分解、Lefschetz 定理带来丰富拓扑结构。非 Kähler 的辛流形反例：Heisenberg nilmanifold × S¹（三维 Heisenberg 流形乘以圆）有辛形式但无 Kähler 结构——其第一 Betti 数 b₁ = 3 为奇数，违反 Kähler 流形的 Hodge 对称性 b₁ 必为偶数。

八、Gromov 非压缩定理——辛刚度的惊人体现

辛球 B^{2n}(r) 不能被辛嵌入到圆柱 B²(R) × ℝ^{2n−2} 中当 r > R。你不能把辛球"挤"进更细的圆柱——即使在体积足够大的情况下！这和微分拓扑（任何嵌入都可能）完全相反。非压缩定理是辛拓扑作为独立学科诞生的标志（Gromov 1985）。

为什么"体积足够大"还是不行？ ω 是 2-形式，它约束的是二维面积而非 2n 维体积。辛嵌入必须保持每一片二维子流形的 ω-面积，于是"球内部那片半径 r 的截面圆"的面积被辛刚性地锁定，没法被圆柱的"窄口径"塞下——这就是辛刚度的来源。

证明框架。① 相容结构：取与 ω₀ 相容的近复结构 J，把圆柱视为 (ℂ × ℂ^{n−1}, J)，问题化为 J-全纯曲线存在性/面积矛盾。② J-全纯圆盘：考虑映射 u: D² → ℂ × ℂ^{n−1}，满足 CR 型方程 du∘j = J∘du，边界条件 u(∂D²) ⊂ ℂ × {0}（圆盘被"钉"在零阶切片）。Gromov 紧致性与无能量爆炸性保证：给定该边界条件，存在非平凡的 J-全纯圆盘。③ 面积估计：J-全纯圆盘的 ω-面积 = ∫_D u*ω = ∫_D u*ω₀，而由 Stokes 与边界条件，此面积受限于边界在 B²(R) 内的半径：≤ πR²。④ 矛盾：若 r > R，则源球 B^{2n}(r) 内含一个截面圆，其 J-全纯像的 ω-面积恰为 πr² > πR²，与第③步的界矛盾。∎

历史意义。证明的核心工具是拟全纯曲线——满足 Cauchy-Riemann 型偏微分方程的映射 u: (S², j) → (M, J)，其存在性和能量单调性给出了几何障碍。这一方法最终发展为整个辛拓扑和 Floer 理论的基石。

为什么辛约化是"消除对称性"？ 相空间的对称性意味着"多余的变量"（如旋转对称下的整体角度）。矩映射的零水平集选出的正好是"取定守恒量的截面"，再模掉 G 轨道把对称方向本身也约掉——留下的空间只承载真正的动力学自由度。

几何意义：辛约化是以下构造的数学根源：

  • 规范理论：Yang-Mills 理论中的约束曲面（高斯定律）正是矩映射的零纤维，物理状态空间 = μ^{-1}(0)/G（规范轨道空间）。
  • BRST 形式：在几何量子化框架中，矩映射的零纤维上同调（Cartan 等变上同调模型）给出 BRST 上同调——规范固定（gauge fixing）的几何起源。
  • GIT 商：代数几何中 Mumford 的几何不变量理论 (GIT) 商 X//G 是辛约化的代数类比——两者在 Kähler 情形下精确对应（Kempf-Ness 定理）。

十一、几何量子化——从经典到量子的数学桥梁

经典力学：辛流形 + 哈密顿函数 H → 哈密顿方程。量子力学：Hilbert 空间 + 自伴算子。几何量子化尝试在两者之间建立严格的数学对应：泊松括号 {f,g} → 对易子 (1/iℏ)[F,G]。

为什么这不只是"换记号"？ 经典的量（函数）要变成量子算符，首先要选一个"极化的 Hilbert 空间"（如 L²-截面），还要处理预量子化线丛的曲率必须等于 ω——这些约束正是量子化"不能任意做"的数学体现。它把"从经典到量子"的物理跃迁，翻译成一个几何上可定义、可判定的问题。

十二、Floer 同调——无穷维 Morse 理论与辛拓扑的融合

Andreas Floer (1988–89) 将 Morse 同调推广到辛流形的无穷维环路空间 L(M) = {光滑映射 S¹ → M}。关键创新：用辛作用量泛函 A_H 代替 Morse 函数（其梯度流方程正好是 J-全纯曲线的 Floer 方程），从而在无穷维辛几何中定义同调不变量。

Hamiltonian Floer 同调 HF_*(M, ω)

对象：非退化哈密顿路径 φ_H 的不动点（即周期轨道）。链复形由不动点生成；边缘算子计数连接两条轨道的 J-全纯柱面（Floer 方程的解）。

Lagrangian Floer 同调 HF(L₀, L₁)

对象：辛流形中两个拉格朗日子流形 L₀, L₁（满足 transversality 和单调性条件）。链复形由 L₀ ∩ L₁ 的交点生成；边缘算子计数连接两交点的 J-全纯条带（strip）。

Arnold 猜想与 Floer 的证明

Arnold 猜想（1960年代）：非退化哈密顿微分同胚的不动点数 ≥ 闭辛流形 (M, ω) 的 Betti 数之和。

Floer 证明：HF_*(M) ≅ H_*(M; Z₂)（Floer 同调与奇异同调同构）→ 复形的生成元个数 = 不动点数 ≥ 同调群的维数 = Betti 数之和。这就是 Arnold 猜想的证明——Floer 同调的存在意义。

此后，Floer 同调系列（Heegaard Floer, Instanton Floer, Seiberg-Witten Floer, Symplectic Field Theory）成为低维拓扑和辛拓扑的核心工具。

十三、镜对称——Fukaya 范畴与凝聚层范畴的等价（含前沿）

镜对称起源于弦论（Greene-Plesser 1990）：Calabi-Yau 三流形对 (M, M^∨) 满足 h^{1,1}(M) = h^{2,1}(M^∨) 且其 Hodge 菱形互换。物理上，M 对应 Type IIA 弦论，M^∨ 对应 Type IIB 弦论——两者给出相同的物理。

Kontsevich 同调镜对称猜想 (1994 ICM 报告)：对 Calabi-Yau 流形 M 和镜对 M^∨，存在导出范畴的等价：

A 模型（Fukaya 范畴 Fuk(M, ω)）：对象为 M 中满足某条件（如被分次 Lagrangians）的拉格朗日子流形；态射空间为 Lagrangian Floer 复形；乘法由 A_∞ 代数的 m₃ 运算给出（计数全纯三角形）。

B 模型（凝聚层范畴 Coh(M^∨)）：对象为复流形 M^∨ 上的凝聚层（Coherent sheaves）；态射为 Ext-群（层上同调）；乘法为层的乘法。

为什么"范畴等价"比"数值对称"强得多？ 物理最初只是说两个理论的数（如 Gromov-Witten 不变量与 Hodge 数）相等；Kontsevich 断言两个范畴（连同全部态射、全部高次运算）三角等价——这是一整个结构的同构，远远超越了原始物理中的数值对称。

证明现状：

  • 四次曲面（quartic K3 曲面）的部分情形：Seidel (2000s) 构建了 Fukaya 范畴和镜的凝聚层范畴的对应。
  • 环面簇（toric varieties）：A 模型 → SYZ 纤维化（Strominger-Yau-Zaslow 1996）→ 镜构造在组合几何层面已完整。
  • 一般 Calabi-Yau 三流形：完整 HMS 证明仍开放——这是 21 世纪代数几何、辛几何和高能物理交汇的核心未解问题之一。

A_∞ 结构的意义：Fukaya 范畴携带 A_∞ 代数结构（高次乘法的组合）——其 mₖ 运算计数 k 边形的全纯多边形。Kontsevich-HMS 断言这个无穷范畴与镜上凝聚层范畴的导出范畴三角等价。

十四、标准反例——辛 vs 泊松

反例 1（泊松但不辛——退化性）。泊松流形 (M, {·,·}) 要求 {·,·} 是 Lie 括号（反对称、双导子、满足 Jacobi），但不要求非退化。辛流形是"处处非退化"的泊松流形（其泊松括号由 ω 诱导：{f,g} = ±ω(X_f,X_g)，整体符号是约定，见第二节）。反例：ℝ³ 带 {f,g} = ∂f/∂x·∂g/∂y − ∂f/∂y·∂g/∂x 只依赖 x,y——第三维是 Casimir 方向，括号退化。泊松流形 = 辛叶状化（symplectic foliation）+ 横向结构；辛流形 = 只有一个叶子。

反例 2（体积嵌入 ≠ 辛嵌入）。Gromov 非压缩针对辛嵌入；若只要求保体积（保 ωⁿ 或任意体积形式），大球总能嵌入细圆柱（Whitney + 体积讨论）——辛刚性只对辛映射成立，这是"辛 vs 体积"最尖锐的对照。

反例 3（同一流形上的多种泊松结构）。辛流形 (M, ω) 上的泊松括号由 ω 唯一诱导；但存在与 ω 无关的泊松结构——零泊松结构 {f,g} ≡ 0 合法（退化但不矛盾）。关系图：辛 ⊂ 泊松 ⊂ 泊松代数流形；辛流形 ⊂ 几乎复流形 ⊄ Kähler（见 nilmanifold 反例）。

十六、工作题

题 1：设 G = S¹ 通过 ψ_t(z) = (e^{it}z₁, e^{−it}z₂) 作用在 (ℂ², ω₀ = (i/2)Σ dzⱼ∧dz̄ⱼ = Σ dxⱼ∧dyⱼ) 上。求矩映射 μ: ℂ² → ℝ，并确定 μ^{-1}(0) 与商 μ^{-1}(0)/S¹。（完整计算见例题 3。）

题 2：G = S¹ 通过 ψ_t(z) = e^{it}z 作用在 (ℂⁿ, ω₀) 上。求矩映射；对 n=1 做辛约化 μ^{-1}(0)/S¹，验证维数公式 dim(M//G) = dim M − 2 dim G。

题 3：证明在自由辛约化中，M//G = μ^{-1}(0)/G 携带唯一辛形式 ω_red 满足 π*ω_red = ι*ω（ι: μ^{-1}(0) → M 含入，π 商投影）。

显示解答

题 1：ξ = 1 ∈ ℝ 的基本向量场 X_ξ(z) = dz/dt|₀ = (iz₁, −iz₂)。矩映射满足 ⟨dμ, v⟩ = ω(X_ξ, v)。取 μ(z) = −(|z₁|² − |z₂|²)/2 验证：dμ = −(z̄₁dz₁ + z₁dz̄₁)/2 + (z̄₂dz₂ + z₂dz̄₂)/2 = ι_{X_ξ}ω。故 μ(z) = −(|z₁|²−|z₂|²)/2。μ^{-1}(0) = {|z₁| = |z₂|}；商 e^{it}·(z₁,z₂) = (e^{it}z₁, e^{−it}z₂) 把轨道识别——商 μ^{-1}(0)/S¹ ≅ ℂ（光滑，复一维），与 GIT 商 ℂ²//ℂ*_{(1,−1)} = Spec ℂ[z₁z₂] ≅ 𝔸¹ 一致（Kempf-Ness）。∎

题 2：X_ξ(z) = iz，μ(z) = −|z|²/2。n=1：μ^{-1}(0) = {0}，商为单点，dim(M//G) = 0 = 2·1 − 2·1 ✓。几何含义：旋转对称性被约化后只剩不动点。∎

题 3：三步。① 轨道方向退化：对 p ∈ μ^{-1}(0)，ι*ω 在 G 轨道方向为零（ι_{X_ξ}ω = d⟨μ,ξ⟩ = 0 于 μ=0 层）。② 下降：定义 ω_red([v],[w]) = ω_p(v,w)，其中 v,w 为垂直于轨道的代表元；良定义由①保证。③ 闭与非退化：闭性来自 ω 闭（拉回与商保持），非退化来自"垂直方向限制是辛形式"，维数 dim μ^{-1}(0) − dim G = dim M − 2 dim G。唯一性：π*ω_red = ι*ω 且 π 满射、核恰为轨道方向 ⟹ 唯一。∎

十七、试试看（每题附提示）

试试看 1（面积守恒的直接验证）。 对例题 1 的谐振子流 Φ_t，直接算其 Jacobi 行列式。提示：Φ_t 由矩阵 [[cos t, sin t],[−sin t, cos t]] 给出，det = cos²t + sin²t = 1——保面积，即保 ω。

试试看 2（正则坐标的泊松括号）。 在 (ℝ², ω=dp∧dq) 上验证 {q,p} = 1。提示：由 ω(X_q,·)=dq、ω(X_p,·)=dp 解出 X_q = ∂/∂p、X_p = −∂/∂q；于是 {q,p} = −ω(X_q, X_p) = −ω(∂/∂p, −∂/∂q) = −(−1) = 1。

试试看 3（S¹ 作用在 ℂⁿ 的矩映射）。 对 ψ_t(z) = e^{it}z 作用在 (ℂⁿ, ω₀) 上，验证 μ(z) = −|z|²/2。提示：X_ξ(z) = iz，逐项算 ι_{X_ξ}ω₀ = −x·dx − y·dy = −d(|z|²/2)。

试试看 4（辛形式非退化的矩阵判据）。 在 ℝ² 上把 ω=dp∧dq 写成矩阵（相对基 ∂/∂q, ∂/∂p），验证其可逆。提示：矩阵是 [[0,1],[−1,0]]（或 [[0,−1],[1,0]]，取决于约定），行列式为 1 ≠ 0。
