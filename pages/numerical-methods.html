再看求方程 f(x) = x² − 2 = 0（即 √2）的牛顿迭代，从 x₀ = 1 出发：x₁ = 1.5，x₂ = 1.41667，x₃ = 1.41422，x₄ = 1.4142136——每走一步，正确的位数大约翻一倍。这就是"二次收敛"。

这门课研究的就是：计算机的算术会"悄悄出错"，好的算法让错小到看不见；以及为什么有的算法误差 ∝ h（一阶）、有的误差 ∝ h⁴（四阶）、有的每步翻倍（二次收敛）。

计算机的答案没有"精确"，只有"够准"——数值计算就是研究这个"准"有多大、能否控制、为何如此。只想懂核心思想，看到这里就够了。

一、浮点算术与误差

电脑用有限的"格子"存数字：IEEE 754 双精度 = 1 符号位 + 11 阶码 + 52 尾数，表示 x = ±1.m·2^(e−1023)。机器精度

直观感受：双精度能精确到约 16 位十进制数字。任何一次浮点运算都带一个相对误差 ≤ ε_mach：

为什么浮点加法不满足结合律？因为中间结果要被"四舍五入"到有限位。例如 a = 10¹⁶，b = 1，c = −10¹⁶：a+(b+c) = 10¹⁶ + (1−10¹⁶) = 10¹⁶ + (−10¹⁶) = 0，而 (a+b)+c = (10¹⁶+1)+(−10¹⁶) = 10¹⁶ + (−10¹⁶) = 0……本例恰好都为 0。换一组数就能看出差别：取 a = 1，b = 2⁻⁵³，c = −1。a+(b+c) = 1 + (2⁻⁵³ − 1) = 1 + (−1) = 0（b+c 精确等于 −1）；而 (a+b)+c = (1 + 2⁻⁵³) + (−1)：1 + 2⁻⁵³ 在双精度里恰好舍入成 1（2⁻⁵³ 比 ε_mach/2 还小），所以结果是 0 + (−1)……等等，是 1 + (−1) = 0。两个都是 0？让我换 a = 1，b = 2⁻⁵²，c = −1：a+(b+c) = 1 + (2⁻⁵² − 1) = 1 + (≈−1) = 2⁻⁵²（精确），而 (a+b)+c = (1 + 2⁻⁵²) + (−1)：1 + 2⁻⁵² 在双精度里恰好能表示（ulp），等于 1 + 2⁻⁵²，再加 −1 得 2⁻⁵²。还是相等？哦，这个例子不够直观。更直观的经典例子是"求和顺序"：0.1 + 0.2 − 0.3 在二进制浮点里不等于 0，因为 0.1 和 0.2 在二进制下都是无限循环小数，舍入后 (0.1+0.2) ≈ 0.30000000000000004。

所以正确的说法是：浮点加法不满足结合律——a+(b+c) ≠ (a+b)+c 一般而言，这是所有数值陷阱的根源。误差会在求和、迭代、解方程的过程中被逐级放大或幸运抵消，于是我们需要两把尺子来度量"难算"和"算得糙"：

条件数 vs 数值稳定性：病态问题（条件数大，输入扰动被放大）是问题本身的性质；不稳定算法（舍入误差被逐级放大）是算法的性质。良态问题 + 稳定算法 = 可靠计算。向后误差分析（Wilkinson）：一个稳定算法计算出的解是"精确求解了一个略微扰动的原问题"——把舍入误差解释为数据扰动，从而把"算法好坏"与"问题好坏"干净地分开。

解 x' = −x，x(0) = 1，h = 0.1，手算前三步并与真值比较。

第 1 步：x₁ = x₀ + h·f(x₀) = 1 + 0.1·(−1) = 0.9。（精确 e^{−0.1} ≈ 0.9048，误差 ≈ 0.0048。）

第 2 步：x₂ = 0.9 + 0.1·(−0.9) = 0.81。（精确 e^{−0.2} ≈ 0.8187，误差 ≈ 0.0087。）

第 3 步：x₃ = 0.81 + 0.1·(−0.81) = 0.729。（精确 e^{−0.3} ≈ 0.7408，误差 ≈ 0.0118。）

第 4 步：观察。误差逐次增大：0.0048 → 0.0087 → 0.0118，每个误差都大约等于"该时刻的真值 × 累计 h 步数 × ½h"的量级——单步误差被"滚雪球"成全局误差 O(h)。若继续算到 t = 1（第 10 步），得到 0.3487，与真值 e⁻¹ 的误差正是〇节表的 0.0192。若改用 h = 0.01，误差降到 0.00185——步长减半，误差减半。∎

六、RK4 与更高阶方法：用多次求值换更高阶

欧拉"一阶太糙"，人们用"一个步长内多次采样斜率"来换取高阶：中点法（改进欧拉）二阶、对称；经典四阶 Runge–Kutta（RK4）每次步进做四次函数求值：

为什么四步求值换到 O(h⁴)？四条斜率按 1:2:2:1 加权组合，恰好把 Taylor 展开里直到 h⁴ 的所有项都精确匹配，剩下第一个未匹配项是 O(h⁵)。单步误差 O(h⁵)，步数 1/h，全局误差 O(h⁴)——比欧拉高一截：h 缩 10 倍，RK4 误差缩 10⁴ 倍。这是"计算量换精度"的经典权衡：RK4 每步做 4 次求值，但允许用大得多的步长。

七、刚性系统与稳定域

有些系统让显式方法"寸步难行"：特征值 λ 满足 |λ|h ≫ 1 却仍要求精度——步长被稳定性（而非精度）限制。这叫刚性（stiff）。例如化学反应里既有慢反应又有极快反应，快特征值要求 h 极小，否则数值解爆炸，哪怕你快特征值对应的分量早该衰减完了。

A-稳定：若数值格式的稳定域包含整个左半复平面 ℂ⁻，则对任何步长都稳定（无稳定性限制）。隐式欧拉、梯形法、BDF 方法都是 A-稳定。判断法：把格式写成 x_{n+1} = R(λh)xₙ，要求 |R(λh)| ≤ 1 对所有 λh ∈ 谱集成立。

为什么"显式"的稳定域总是有限？因为显式格式的 R(z) 是多项式，|R(z)| 在左半平面深处必然 > 1；而隐式格式的 R(z) 是分式（如隐式欧拉 R(z) = 1/(1−z)，在 ℂ⁻ 上恒有 |R(z)| ≤ 1），所以能吸收整个左半平面。这是"隐式换稳定性"的本质。

八、线性代数数值：为什么不用 Cramer 法则

求解 Ax = b 的教科书方法（Cramer 法则）计算行列式需要 n! 次运算——n = 30 时远超宇宙年龄。实用算法全部基于矩阵分解，一次分解、多次使用：

LU 分解（带部分选主元）：Ax = b 一次分解 O(n³/3)，之后每次求解 O(n²)——同一矩阵多右端问题的首选。对称正定时用 Cholesky：A = LLᵀ，O(n³/6)，稳定且省一半存储。QR 分解（Householder）用于最小二乘与特征值 QR 算法。共轭梯度（CG）：SPD 矩阵的 Krylov 子空间法，n 步内精确，实用中远快于 n 步。

为什么"病态"决定精度？解的相对误差被条件数放大：

κ(A) = σ_max/σ_min ≈ 1 良态；κ 大则解对噪声病态敏感。直觉：条件数衡量矩阵"拉伸"各方向的程度——某个方向被压扁（σ_min 小），则该方向上的解对 b 的扰动特别敏感。它刻画的不是算法，而是问题本身（见第一节的条件数/稳定性区分）。

九、迭代法：Jacobi 与共轭梯度

直接分解对稀疏大矩阵（每行 O(1) 个非零元）太贵，迭代法是正道。分裂 A = M − N，迭代 x_{k+1} = M⁻¹N x_k + M⁻¹b：

Jacobi：M = D（对角）；Gauss–Seidel：M = D − L（下三角，立即用新分量）；逐次超松弛 SOR：M = (1/ω)D − L 加松弛参数 ω。收敛当且仅当谱半径 ρ(M⁻¹N) < 1，误差 ∝ ρ^k。对 SPD 矩阵，Gauss–Seidel 谱半径是 Jacobi 谱半径的平方。为什么谱半径决定速度？误差传播 e_{k+1} = M⁻¹N e_k，第 k 步误差 ≈ ρ^k e₀——ρ 越小收敛越快，这和小数连乘一个道理。

共轭梯度是全局最优 Krylov 方法：

收敛率由 √κ 决定，配合预条件（M⁻¹A 条件数剧降）成为大规模稀疏线性系统的标准工具。为什么是 √κ 而不是 κ？CG 沿"共轭方向"行走，每步同时优化整个 A-内积空间，等价于在越来越低维的子空间里精确解——这使收敛依赖谱的"形状"而非单纯的最大比值。

十一、PDE 数值：有限差分与 CFL

有限差分：用网格差分近似导数，配合显式/隐式时间推进。有限元：变分形式 + 分片多项式基函数，处理复杂几何与自然边界条件。谱方法：全局基函数（Fourier/Chebyshev），指数收敛，适用于光滑解。

对双曲方程（波动、对流），CFL 条件给出显式格式的生死线：数值信息传播速度必须 ≥ 物理传播速度。

为什么信息传播速度是关键？双曲方程的解沿特征线传播：一个时间步 Δt 内，扰动最多移动 a·Δt。若网格间距 Δx 比这还大（CFL 数 > 1），数值解"够不着"它应该接收的信息，必炸。von Neumann 稳定性分析把误差展开为傅里叶模式 e^{ikx}，要求放大因子 |G(θ)| ≤ 1：对流方程的 FTCS 格式不稳定（无阻尼），Lax–Wendroff 有阻尼。

抛物方程（热传导）显式格式要求 r = αΔt/Δx² ≤ 1/2：为什么是 Δx²？因为热扩散是二阶算子的效应，信息在一个时间步内扩散距离 ∝ √(αΔt)，对应网格要求 Δx² 尺度。刚性时间尺度上隐式格式（Crank–Nicolson）无条件稳定。

十二、插值与逼近：Runge 现象与最小二乘

n 次多项式插值过 n+1 个点唯一，但高次多项式在等距节点上剧烈振荡——Runge 现象：对 f(x) = 1/(1+25x²) 在 [−1,1] 等距插值，|误差| 随 n 增大发散。为什么多项式插值会"越插越糟"？高次插值多项式必须在每个等距节点精确穿过，而等距节点在端点附近的 Lebesgue 常数指数增长，把端点处的振荡放大到失控。样条（分段三次、C² 光滑）用低次多项式避免振荡；切比雪夫节点把 Runge 现象指数级抑制——把节点按 cos 分布堆到端点附近，Lebesgue 常数降到对数级。

最小二乘：min ‖Ax − b‖₂ 的正规方程 AᵀAx = Aᵀb，但 AᵀA 会把条件数平方（κ(AᵀA) = κ(A)²）。数值稳健做法是 QR 或 SVD：解由 x = VΣ⁻¹Uᵀb 给出。SVD 还能做截断奇异值正则化（Tikhonov）：把病态问题"裁掉"小奇异值方向。为什么 AᵀA 会恶化条件数？奇异值被平方：σ_min² 比 σ_min 更接近 0，病态被"二次方"放大——所以用 QR/SVD 直接处理 A 而非 AᵀA。过拟合与模型选择：在残差与复杂度间做权衡。

十三、反例——数值计算里的陷阱

反例 1（灾难性消去）。计算 f(x) = 1 − cos(x) 在 x = 0.0001 处。精确值 ≈ 5×10⁻⁹。但 1 和 cos(0.0001) ≈ 0.999999995 在双精度里相减：两个接近的数"相减消去"了大量有效数字，结果只剩约 5 位可靠数字——相对误差高达 10⁻⁴，远大于 ε_mach。对策：用等价公式 1 − cos x = 2 sin²(x/2)，重新把消去的精度"算"回来。

反例 2（求和顺序）。a + (b + c) ≠ (a + b) + c：浮点加法不结合，把大量小量累加到大量上会"被吞掉"。求和小量先加（Kahan 求和），精度可以高几个量级。

反例 3（欧拉失稳）。对 x' = −25x 取 h = 0.1（λh = −2.5），欧拉放大因子 1 + λh = −1.5，|−1.5| > 1——误差每步放大 1.5 倍，数值解振荡发散，尽管精确解平缓衰减（完整数值见工作题 4）。

提示：f(x) = x² − 3。x₁ = 2 − (4−3)/(2·2) = 2 − 0.25 = 1.75；x₂ = 1.75 − (3.0625−3)/3.5 ≈ 1.7321。与 √3 ≈ 1.73205 对比。

2. 用欧拉法（h = 0.5）解 x' = x，x(0) = 1，算到 t = 1，并与 e 比较。

提示：x₁ = 1 + 0.5·1 = 1.5；x₂ = 1.5 + 0.5·1.5 = 2.25，真值 e ≈ 2.718，误差 ≈ 0.47——h 大，一阶误差就大。

3. 求 A = diag(1, 10⁻⁶) 的 2-范数条件数，并与 diag(1, 10⁻³)（κ = 10³）比较。

提示：对角阵奇异值即对角元，κ = 10⁶——比 10⁻³ 的例子病态 1000 倍，解对 b 的扰动更敏感。

4. 对 x' = −20x（λ = −20）取 h = 0.1：Euler 稳定吗？RK4 稳定吗？若 h = 0.2 呢？

提示：λh = −2 时 |1−2| = 1，Euler 在稳定域边界；R(−2) = 1−2+2−1.333+0.667 = 0.333，RK4 稳定。h = 0.2 时 λh = −4：Euler 的 |1−4| = 3 > 1 失稳；R(−4) = 1−4+8−10.667+10.667 = 5 > 1，RK4 也失稳——这就是刚性系统要换隐式格式的原因。

5. 热方程显式格式 r = αΔt/Δx² ≤ 1/2：α = 1，Δx = 0.1 时，Δt 最大可取多少？

提示：r = 1·Δt/0.01 ≤ 1/2 ⟹ Δt ≤ 0.005。注意 Δt 与 Δx² 同量级——抛物线问题时间步长收缩得比空间步长快。

6. 为什么 f(x) = 1/(1+25x²) 在 [−1,1] 上做等距高次插值会发散，而换样条就没事？

提示：等距节点高次插值的 Lebesgue 常数指数增长（Runge 现象）；样条用低次分段多项式，局部扰动不扩散。要指数收敛用切比雪夫节点。

工作题 2：Euler 法误差分析。对初值问题 x' = −x，x(0)=1（精确解 x(t)=e⁻ᵗ），用显式 Euler 法 x_{n+1} = x_n + h·f(x_n) 在 t=n h 处估计全局误差，并解释为何它是 O(h)。

显示解答

Euler 法的局部截断误差（单步）为 O(h²)：由 Taylor 展开 x(t+h) = x(t) + h x'(t) + ½h²x″(ξ)，格式丢弃了 ½h²x″ 项。对 x'=−x：x_{n+1} = (1−h)x_n，故 x_N = (1−h)ᴺ x₀ = (1−h)^{t_N/h}。

全局误差 ≤ (步数 N=t/h) × (局部误差 O(h²)) = O(h)。数值例：h=0.1 时 (1−0.1)¹⁰ ≈ 0.3487 vs e⁻¹ ≈ 0.3679，误差 ≈ 0.019；h=0.01 时误差降到 ≈ 0.0018——步长减半则全局误差减半，正是一阶格式的特征（〇节误差表）。结论：Euler 法全局一阶，稳定条件 |1+λh|≤1（此处 λ=−1，h<2）。
