〇、具体动机——北京飞纽约，为什么"直线"地图航线不是最短路？

先不看抽象定义，先看一个带数字的具体问题。北京约在北纬 39.9°、东经 116.4°，纽约约在北纬 40.7°、西经 74.0°。两地的直线距离（穿越地球内部）约 1.1 万公里——但飞机不能穿地心。飞机能飞的最短路径是多少？

一个"想当然"的答案：两地纬度几乎相同，那就沿北纬 40° 的纬线飞吧。北纬 40° 的纬线半径是 R·cos40° ≈ 6371 km × 0.766 ≈ 4880 km，它的周长 ≈ 2π×4880 ≈ 30660 km。北京的经度到纽约的经度相差约 169.6°，沿纬线飞要飞 (169.6/360)×30660 ≈ 14450 km。

但航空公司不这么飞。北京—纽约的实际航线从北京起飞先向东北越过北冰洋再南下，总航程约 11000 km——比沿纬线少了约 3500 公里。为什么？因为在地球（球面）上，"两点最短的路径"不是"看起来直的纬线"，而是大圆——过球心的平面与球面相交的那个圆（北京—纽约的大圆恰好穿过北极附近）。

再看一个可以手算的模型。取半径 R = 1 的球面，赤道上取两点，经度差 90°。沿赤道（大圆）走：弧长 = 90° = π/2 ≈ 1.571。改走"经线绕北极"：从一点沿经线上到北极（π/2），再沿另一条经线下到另一点（π/2），总长 π ≈ 3.142。大圆弧长 1.571 < 3.142，差了整整一倍。

核心洞察：在弯曲的面上，"最直的路线"并不由地图上的直尺决定，而由面本身的几何决定。这种"最直的弯线"就叫测地线。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 核心 级别，正文较深。

建议先掌握：线性变换（变换——大白话：把整个空间统一地拉伸、旋转或平移，像整张纸一起动，直线仍保持直线）、导数与切线。

高级章节（证明、前沿、工作题）需要相应背景，未掌握可先看「〇、具体动机」了解核心思想，或回到前置课程补基础。

一、什么是"最直的线"——从平面直线到球面大圆

先回顾平面：平面上两点间最短路径是直线。为什么？因为平面上的"方向"是全局的——把直线平移一小段，它仍然是直线，仍然最短。这个"平移不变"的直觉，正是后面测地线定义的种子。

再上球面：球面上两点间最短路径是大圆。要相信这一点，有三个理由，由浅入深：

  • 对称性：把球面绕连接两点的那个大圆所在的平面旋转，整条大圆都被固定。任何"最短路径"在这种对称下只能是它自己——就像圆的直径是唯一的对称轴一样。
  • 数字检验（〇节）：赤道上经度差 90° 的两点，沿赤道 1.571，绕北极 3.142——大圆确实更短。
  • 严格化：为什么"最短"恰恰会选中大圆？这是第二节的核心——"最短/最直"在数学上会被翻译成一条微分方程（测地线方程），而球面上满足这条方程的正是大圆。

定义（测地线的两种说法）：在弯曲空间里，"直线"不再有现成定义，但有两种等价的说法可以接管它：

  • 局部最短：连接两点的所有曲线里，把长度取到"临界值"的那条（足够短的一段里任何扰动都只会变长）；
  • 自平行：它的"方向"沿自身平移不变——直线上每个点的切方向"都是平行的"。（这条定义在《平行移动》课里讲。）

这两种说法都不需要"外部空间"来定义——你只需要在面本身内部量距离和角度。这一点极其重要：广义相对论说"引力不是力，是几何"，自由落体就是沿弯曲时空的测地线运动；而"弯曲"本身完全由时空内部的度量决定（见《曲率》课的绝妙定理）。

一句话：自由落体 = 在弯曲时空中沿测地线运动。你感觉不到"引力"——你只是在弯曲时空中自由下落。引力不是力，是几何。

二、为什么"最短"会给出测地线方程——从变分原理完整推导

五、为什么测地线"局部最短"——证明概要

第四节末尾的例子暴露了一个必须回答的问题：测地线到底是"最短"还是"临界点"？答案藏在"局部"两个字里。下面是严格定理。

定理（局部最短性）：设 γ 是黎曼流形 (M, g) 中的测地线（弧长参数化）。对 γ 上任一点 p，存在邻域 U ∋ p 使 γ ∩ U 中任意两点在 U 内的最短路径唯一，且就是 γ 本身。

为什么是"局部"？ 这跟"山谷的谷底是局部最低"是同一个道理：站在谷底，附近怎么走都上坡，但远处的山坡可能更矮。测地线同理——足够短的一段一定最短，长了就未必（见反例）。

证明思路（四步）：

  • 1. 指数映射与 Gauss 引理：exp_p: T_pM → M 在原点附近是微分同胚（d(exp_p)₀ = id 逆函数定理）。Gauss 引理：对 v ∈ T_pM 与 w ⊥ v，有 ⟨d(exp_p)(v), d(exp_p)(w)⟩ = 0——即 exp_p 的径向线正交于"exp_p 球面"。直观上这是说：径向变分对首阶长度无贡献。
  • 2. 指数球内的径向测地线：存在 ε > 0 使 exp_p 在开球 B(0, ε) ⊂ T_pM 上为嵌入。对 q ∈ exp_p(B(0,ε))，记 v = exp_p⁻¹(q)，则 t ↦ exp_p(tv) 是连接 p、q 的测地线，长度 = |v|。
  • 3. 任意曲线不短于径向测地线：设 α 为连接 p、q 的任意曲线，在 exp_p(B(0,ε)) 内写极坐标 α(t) = exp_p(r(t)u(t))（r ≥ 0，u 单位）。由 Gauss 引理，|α̇|² = ṙ² + r²|ū̇|² ≥ ṙ²，故长度 L(α) = ∫|α̇| ≥ ∫|ṙ| ≥ |r(b) − r(a)| = |v| = L(径向测地线)。等号仅在"角向不变且 r 单调"时取到，即 α 与径向测地线重合。□
  • 4. 唯一性：下界在等号条件（r 单调 + u 不变）下唯一实现，故最短路径唯一且为测地线。

为什么"局部"在这里会失效：指数映射在 T_pM 整体上未必是微分同胚；测地线一旦跨越共轭点或焦散线就不再最短。局部性由 Gauss 引理仅在 exp_p 的嵌入半径内成立。共轭点的存在性由曲率的正值强制（球面、测地线超半圈即失效）。

全局反例（球面）：球面 S²(R) 上南极到北极，每条大圆半圆（长度 πR）都是测地线也都是最短路径——最短路径不唯一。对非对径点 p, q：劣弧（大圆较短段）是唯一最短的，但同一大圆上的优弧是另一条测地线，却不是最短路径——长度 2πR − d > d，甚至可视为局部极大。结论："测地线"（长度临界点）严格弱于"最短路径"。

六、反例辨析——劣弧/优弧、欧氏空间、圆柱环面与圆锥顶点

把"测地线 ≠ 最短"的边界用四个反例钉死。

反例 1（球面上的劣弧与优弧）：设 p, q ∈ S²(R) 非对径，大圆被 p, q 分成两段：劣弧与优弧，均为同一条大圆的测地线段。

  • 劣弧：长度 d(p, q) = R·θ（θ = 大圆圆心角 = arccos(p·q/R²)），是连接 p、q 的唯一最短路径；
  • 优弧：长度 R(2π − θ)，是一条测地线但不是最短路径——它把大圆"绕了一圈"；
  • 对径情形（θ = π）：两段等长，最短路径不唯一（每一条大圆都最短，甚至沿任意方向的"任意半圆"）。

带数字检验：R = 1、θ = 1（两点角距 1 弧度）：劣弧长 1，优弧长 2π − 1 ≈ 5.28。都是测地线，只有劣弧最短。

反例 2（欧氏空间：测地线是直线）：Rⁿ 中度规 g = δ（常系数）。Christoffel 符号

（δ 的所有导数均为 0）。测地线方程退化为 ẍ^σ = 0 ⟹ x(t) = a + tv，即直线。这正是"平坦 ⟹ 无曲率 ⟹ 最直路径是直线"的自洽检验。

反例 3（圆柱与环面：测地线可"绕圈"）：圆柱 C = S¹ × R 可展成平面，测地线是螺旋线（含竖直线、水平圆两个退化情形）。连接同对端点的两条螺旋线（正绕 k 圈、负绕 l 圈）都是测地线，但只有缠绕最少的一条才最短。这再次区分"测地线"与"最短"。环面更极端：缠上去的螺旋线可以在环面上无限绕圈，绝大多数都不是最短。

反例 4（圆锥顶点）：去掉顶点后圆锥面平坦（可展），测地线是展开后平面中的直线；但一旦测地线需要"经过顶点"（顶点集中曲率 2π(1−sin半角)），顶点处最短性失效——平面展开法在该处不适用。这是在提醒：可展的技巧只在曲率为零的区域有效。

七、物理中的测地线——自由落体就是沿测地线（GR）

把测地线的语言搬进广义相对论，弯曲的"面"换成弯曲的"四维时空"。时空度规 gμν 中，粒子/光线的世界线满足测地线方程——"无外力"就是沿测地线。

类时测地线（ds² < 0）：质量粒子的世界线。地球绕太阳走的不是"受引力弯曲的轨道"，而是太阳质量弯曲时空后，地球沿类时测地线的惯性运动。

类光测地线（ds² = 0）：光子的世界线。光线经过太阳附近偏折 1.75 角秒——Eddington 1919 年日食观测验证，是广义相对论的第一场胜利。

Schwarzschild 测地线：近日点进动（水星轨道每世纪 43 角秒的异常 → GR 精确给出）、引力红移、光线偏折——GR 三大经典检验都是测地线运动的结果。

测地线偏离与潮汐力：邻近测地线的分离加速度 = −Rμαβγvαvγξβ。曲率越大，邻近测地线分离越快。这就是潮汐力的数学表达——在黑洞附近，头和脚的测地线方向如此不同以至于人被拉长（"意大利面化"）。

同一句话的三种说法：自由落体 / 测地线 / "最直的弯线"——在 GR 里它们是同一个东西。引力不是力，是时空的弯曲；自由落体只是"弯曲时空里的直线运动"。

九、试试看（带提示）

1. 球面上除了大圆，还有什么曲线是"局部最短"的？
提示：关键在"局部"二字。任何大圆的一小段都是局部最短的（只要不跨越对径点/共轭点）。思考：从北极出发沿任意方向走，走多少距离之后才不再是"局部最短"？——答案是走了整圈 πR 到达对径点之后才出问题。

2. 如果空间是圆柱面，测地线是什么形状？
提示：把圆柱沿母线剪开摊平成一张纸（这不动任何长度）。圆柱上的测地线 = 纸上哪条线？摊回去是什么形状？

3. ISS 上的宇航员处于自由落体状态——他们沿什么测地线运动？为什么他们感觉不到重力？
提示：整座空间站 + 宇航员在同一个（类时）测地线上一起下落，彼此没有相对加速度，所以"称不出"重量。想想第一节末的 key-insight。

历史：从 Gauss 到 Einstein

Gauss(1827)提出 Theorema Egregium:曲面的曲率是内禀的——不需要外部空间来定义。Riemann（Riemann——大白话：数学家黎曼，他把"弯曲"的概念从二维曲面推广到任意维空间，后面的几何都建立在他的框架上）(1854)推广到n维。Christoffel(1869)引入联络符号（联络——大白话：弯曲空间里"平移方向"的规则，告诉你在山路上搬一把尺子该怎么搬才能保持方向不变）。Einstein(1915)将所有拼图汇聚为广义相对论:引力=时空的曲率,自由落体=测地线。

前沿：Lorentzian测地线与奇点定理

Penrose(1965)和Hawking(1967)用测地线证明了黑洞奇点（奇点——大白话：时空被压到极致的"死胡同"，密度无限大、现有物理规律在这里统统失效的点）必然存在——"奇点定理"。2020年Nobel奖。仍开放:"宇宙监督假设"——所有奇点必然隐藏在事件视界后(裸奇点不存在)。这是GR最深层未解问题之一。

工作题——球面测地线与极值长度

题 1（球面测地线方程与显式解）：球面度规 ds² = R²(dθ² + sin²θ dφ²)，非零 Christoffel：Γ^θ_{φφ} = −sinθcosθ、Γ^φ_{θφ} = cotθ。写出测地线方程组；证明赤道 θ = π/2 是测地线；求起点 (θ₀, 0) 且初速沿经线（φ̇ = 0）的测地线显式解。

题 2（两点的最短路径）：球面上 p = (R, 0, 0)、q = (R cosφ₀, R sinφ₀, 0)（同处赤道，经度差 φ₀ < π）。验证赤道劣弧最短（长度 Rφ₀）；并算出"先沿经线到北极再沿另一经线南下"的折线长度 = πR，与 Rφ₀ 比较。

题 3（圆柱上的测地线）：圆柱 x² + y² = R² 参数化为 (θ, z)，线元 ds² = R²dθ² + dz²。求测地线方程，证明 (a) 竖直线是测地线；(b) 螺旋线 (θ, z) = (ωt, vt) 是测地线；(c) 对端点差 (Δθ, Δz)，最短螺旋线满足什么缠绕数条件？

题 4（长度泛函的直接变分）：对长度泛函 L(γ) = ∫√(g_{μν}ẋ^μẋ^ν)dt 直接变分，证明其 Euler-Lagrange 方程在等速参数化下与能量泛函相同，并说明参数化自由度的作用。

显示解答

题 1：测地线方程分量形式：θ̈ − sinθcosθ·φ̇² = 0；φ̈ + 2cotθ·θ̇φ̇ = 0。沿赤道 θ = π/2：θ̇ = θ̈ = 0，第一式左端 −sin(π/2)cos(π/2)φ̇² = 0 ✓；第二式 φ̈ = 0（匀速）满足。故赤道是测地线。若 φ̇ = 0（初速沿经线）：第二式恒成立，第一式化为 θ̈ = 0 ⟹ θ(t) = θ₀ + ωt，φ ≡ 0——经线的等速参数化，即大圆（经线）测地线。

题 2：赤道劣弧长度 = Rφ₀。折线：先沿经线从赤道到北极（弧长 πR/2），再沿另一条经线南下到赤道 q（πR/2），总长 πR。因 φ₀ < π，Rφ₀ < πR，赤道劣弧更短 ✓。一般结论：球面测地距离 = 大圆劣弧弧长 = 球心角 × R。这也说明"看起来直"的经线绕行并不最短——最短的是大圆本身。

题 3：线元 ds² = R²dθ² + dz² 与 (θ, z) 无关，故 Γ = 0，测地线方程 θ̈ = 0、z̈ = 0。(a) θ ≡ θ₀ ⟹ θ̈ = 0 ✓ 竖直线是测地线。(b) (ωt, vt)：θ̈ = z̈ = 0 ✓ 螺旋线是测地线（圆柱平坦，螺旋是"展开后的直线"）。(c) 满足端点的螺旋参数 θ(b) − θ(a) = Δθ + 2πk（k ∈ Z 为缠绕数），长度 L_k = √(R²(Δθ+2πk)² + Δz²)。最小者对应 k 最接近 −Δθ/(2π)；当 Δθ ∈ (−π, π] 时 k = 0 最短。其余 k 对应测地线但非最短。

题 4：F = √(g_{μν}ẋ^μẋ^ν)。Euler-Lagrange：d/dt(∂F/∂ẋ^σ) = ∂F/∂x^σ。计算得 d/dt(g_{σν}ẋ^ν/F) = ½∂_σ g_{αβ}ẋ^αẋ^β/F。作等速参数化（g_{μν}ẋ^μẋ^ν = c² 常数 ⟹ F = c 常数），F 提出积分号，方程化为 g_{σν}ẍ^ν + ∂_α g_{σν}ẋ^αẋ^ν = ½∂_σ g_{αβ}ẋ^αẋ^β，即 ẍ^σ + Γ^σ_{αβ}ẋ^αẋ^β = 0——与能量泛函结果相同。参数化自由度：长度泛函关于重参数化不变（测地线是"几何轨迹"），能量泛函则挑选出等速参数化这一"规范"；推导中必须利用等速条件消去 F 因子。
