〇、动机：在 ℂ¹ 的洞里能藏奇点，在 ℂ² 的洞里为什么藏不住？

先看一个一维的常识：函数 1/z 在去掉原点 0 的复平面上是全纯的，但在 0 处有一个真正的奇点——不管你怎么努力，都无法把它光滑地延拓到 0。更一般地，在环带 {z ∈ ℂ : 1 < |z| < 2} 上的全纯函数，用洛朗级数展开，会出现 z⁻¹、z⁻²、… 这些负幂项——正是这些项"记录"着洞里的奇点。

现在把问题搬到 ℂ²。想象一个"实心球壳"：

这是"大球套小球"之间的区域（球壳）。在一维，环形洞能装下奇点；在二维，这个洞里能装下奇点吗？直觉上应该可以——毕竟洞是立体的。但答案是：不能。Hartogs 延拓定理（1906）说：球壳上的任何全纯函数都自动延拓到整个大球内部。洞是空的，什么都没有。

更惊人的是这个小例子：设 f ∈ 𝒪(ℂ²∖{0})（在全空间挖掉原点后全纯）。直觉上"原点附近 f 该有个奇点吧"，但实际上 f 一定延拓到整个 ℂ²。哪怕你试图构造 f = 1/z₁，它也只在整条平面 {z₁ = 0} 上奇——这奇点集是非紧的，绕不过去的问题变成了"二维平面把空间切成两块"的问题，而不是"一个点孤立地奇"。真正"孤立地奇"在 ℂⁿ (n≥2) 里根本造不出来。

一句话：在 ℂⁿ (n ≥ 2) 中，全纯函数不能有紧致奇点——奇点的"余维数 ≥ 2"让函数总能绕过去。这是多复变与单复变最本质的分水岭。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 前沿 级别，正文较深。

建议先掌握：复平面与全纯函数。

一、热身：单复变里"洞装奇点"的机制——洛朗级数

在 ℂ 中，环带 A = {z : r < |z| < R} 上的全纯函数 f 有洛朗展开

（绕内圆 |ζ| = ρ、r < ρ < |z| 积分。）关键在于：负幂项的存在 ⟺ 洞里真的有奇点。若所有 cₙ = 0，级数变成泰勒级数，自动延拓进整个圆盘 {|z| < R}。

为什么一维的洞能装奇点？因为内边界 |z| = r 是一维的"墙"，一个函数要在环带上全纯，又要在洞里有奇点，只需让负幂项在 0 处发散即可——而 0 是单个点，挖掉它不会把圆盘"断开"（ℂ∖{0} 仍然是连通的，但函数值可以在 0 附近无界）。一维的"墙"很薄，函数可以隔着墙朝洞里爆炸。

二维的情况完全不同：ℂ²∖{0} 里，"墙"变成了三维球面 S³ = {|z| = 1}，函数要"隔着墙爆炸"，就得在球内某点无界——但那点四周全是"墙内部"的三维区域，函数根本绕不到它"背后"。这就是下一节 Hartogs 定理的直觉。

  • 为什么 n ≥ 2？ 紧致集 K 在 ℂⁿ 中的余维数 ≥ 2（K 是实紧致集，而"能隔开空间"的墙需要实余维数 1）。余维数 ≥ 2 ⟹ K 不把空间"切成两块"，函数可以绕着 K 从任何一边走到另一边。
  • 为什么要求 Ω∖K 连通？ 这是排除 n = 1 的退化情形（例如 ℂ∖{闭圆盘} 其实连通，但 K 挖掉的是闭球，一维里 Ω∖K = 环带，若取 K = {|z|≤1} ⊂ Ω = {|z|<2}，Ω∖K = 环带 1<|z|<2 连通，此时定理对 n=1 也"意外"成立——因为它只在挖掉一个有界圆盘的圆盘边界之外有定义，且边界上无奇点。真正的一维反例是 K 把区域切成两块，例如 Ω = 圆盘，K = 内部的小圆盘挖到边界？标准反例取 Ω∖K 不连通，比如环带被 K 分成两片）。条件 Ω∖K 连通正是用来保证"绕行"可行。
  • 为什么单射？ 若两个延拓 f、g 在连通开集 Ω∖K 上相等，恒等定理给出 f = g 于全 Ω。

与单复变的对照。 ℂ 中 1/z ∈ 𝒪(ℂ∖{0}) 但不能延拓：K = {0} 紧致，但 n = 1 余维数为 1，"墙"真的隔开了环带内部的洞，奇点 0 可以独立存在。Hartogs 定理在 n = 1 时显然为假。

四、刚性谱系——多复变处于单复变与实分析之间

用"函数被全局结构束缚得多紧"来衡量，三种分析形成一条谱系：

  • 单复变：刚性极强。 恒等定理（非空开集上为零 ⟹ 全局为零）、内部值由边界决定（调和/全纯延拓的唯一性）、Liouville、最大模原理。函数"一点定全局"。
  • 实分析：几乎没有刚性。 实光滑函数有"鼓包"（bump function）：在任意小块上非零、其余全零。局部信息对全局没有任何约束。
  • 多复变：刚性部分保留、但不那么极端。 恒等定理仍成立（这正是上节延拓唯一的根据）。但"边界决定内部"被削弱为"紧致洞藏不住奇点"这种结构性的刚性：函数不能有紧致奇点，却不能像一维那样由少量边界数据强制所有内部值。
刚性谱系：单复变（极刚）→ 多复变（部分刚：无紧致奇点，但延拓的"形状"自由）→ 实分析（几乎无刚）。Hartogs 延拓就是"局部决定整体"在多维的精确表述。

为什么"为什么"很重要： 一维全纯函数刚，是因为柯西积分公式把内部值写成了边界值的积分；多维里柯西公式变成 Bochner–Martinelli 公式，积分链（球面 S³）包围的是"实三维洞"，而奇点若只在"点"上就够不到了——刚性从"积分几何"来，这是多复变反复出现的主题。

  • 延拓问题变成方程问题。 想把 f ∈ 𝒪(Ω∖K) 延拓到 Ω：先用光滑函数 φ（φ ≡ 1 靠近 K，φ ≡ 0 远离 K）把 fφ 搭成一个光滑函数 F（在 K 处会出问题，但"问题"全部落在 ∂̄F 里），然后解 ∂̄u = ∂̄F（在 K 附近），则 F − u 就是全纯延拓。延拓定理的证明 = 解一个 ∂̄ 方程。
  • 障碍是可计算的。 ∂̄² = 0，所以 ∂̄u = g 有解的必要条件是 ∂̄g = 0（相容性条件）。在好的区域上这个条件也是充分的——"可解性"就刻画了区域的几何。
  • Hörmander 的 L² 估计（1965）。 在拟凸域（= 全纯函数的自然定义域 = 域 of holomorphy 的内蕴刻画）上，∂̄ 不但可解，还能保证解的 L² 范数受控：‖u‖ ≤ C‖g‖。这把 Hilbert 空间方法（投影、正交分解）引入复几何，成为多复变最重要的技术工具。
∂̄-问题：把"全纯延拓"变成"解带增长的偏微分方程"。Hörmander L² 估计（1965）在拟凸域上给出可控解，是连接分析与复几何的枢纽。

什么是拟凸域？ 一个区域若"永远不是其它区域的一部分"（域 of holomorphy：存在其上全纯函数不能延拓到更大的区域），则称它拟凸。圆盘、多圆盘、球壳内的大球都是拟凸的；而 ℂ²∖{0} 不是（Hartogs！）。拟凸域 ℂ ⊂ ℂⁿ 上一切 ∂̄-闭形式都可解——这是 Hörmander 定理的内容。

定理（Andreotti–Frankel，1959）。 n 维 Stein 流形同伦等价于一个维数 ≤ n 的 CW 复形——即它们"没有高维洞"（约化同调 Hⱼ 在 j > n 时为零）。

例子。 ℂⁿ 本身是 Stein 的（ρ = |z|²），同伦等价于点（维数 0）；仿射代数簇（多项式的零点集，如 ℂ²∖{0} 之外）是 Stein 的；任何开 Riemann 面（n=1）是 Stein 的。Stein 流形正是"可以嵌入 ℂᴺ 的全纯闭子流形"——它们的拓扑被复结构强烈约束。

十、反例——刚性边界在哪里？

反例 1：n = 1 时 Hartogs 显然为假。 f(z) = 1/z ∈ 𝒪(ℂ∖{0}) 不能延拓到 0。奇点余维数 = 1，是"真墙"。

反例 2：ℂ² 中 1/z₁ 仍不延拓——但原因变了。 f(z₁, z₂) = 1/z₁ 在 ℂ²∖{z₁ = 0} 上全纯，不能延拓到整个 ℂ²。注意奇点集 {z₁ = 0} 是非紧的（一条复直线），不满足 Hartogs 的条件（K 须紧致）。它把区域切成两块——从一侧走到另一侧必然撞墙。所以：Hartogs 的关键是"紧致 + 余维数 ≥ 2"，两者缺一不可。

反例 3：紧致复流形 ≠ 自动 Kähler——Hopf 曲面。 取 Γ = {z ↦ 2ᵏz : k ∈ ℤ} 作用在 ℂ²∖{0} 上，商 H = (ℂ²∖{0})/Γ 是紧复曲面（Hopf 曲面）。其基本群 π₁(H) ≅ ℤ，故 b₁(H) = 1。但 H 上没有任何全纯 1-形式：全纯 1-形式在 ℂ²∖{0} 上全纯（Hartogs！），延拓为 ℂ² 上的全纯 1-形式，且须是常数倍 dz₁、dz₂ 的组合（ℂ² 上的全纯 1-形式 df 中 f 全纯，f = 线性函数……且要 Γ 不变），最终只能为零。故 h^{1,0} = h^{0,1} = 0，而 b₁ = 1 ≠ 0——Hodge 分解 H¹ = H^{1,0} ⊕ H^{0,1} 失败。结论：H 不是 Kähler 流形。紧性不能替代 Kähler 性，Hodge 分解是 Kähler 专属的刚性。

十一、前沿：Hörmander L² 估计与 Ohsawa–Takegoshi 延拓

本课反复出现的 L² 方法在 1980 年代结出最重要的果实——Ohsawa–Takegoshi 定理（1987）：

它给出"从超平面到整个区域"的、带精确范数控制的延拓——多复变中最强大的工具之一：由它可推出乘性不等式、Berndtsson 的正定性定理、以及整个代数几何中大量"延拓 + 估计"的命题。

近年突破。 关启安–周向宇（Guan–Zhou，2014）用代数几何方法（解析难度很大的优化技巧）大幅简化了 Ohsawa–Takegoshi 的证明并给出最优常数。

仍开放。 L² 延拓的最优常数（一般域的精确 C 尚不清楚）；Bergman 核的渐近展开（Fefferman 猜测的高阶项）在多维的完整刻画。

十三、试试看（每题附提示）

1. 说明为什么 f(z₁, z₂) = 1/(z₁² + z₂²) 在 ℂ²∖{0} 上不定义全纯函数，从而不构成"孤立奇点"的例子。

提示：奇点集 {z₁² + z₂² = 0} 是两条复直线 {z₂ = ±iz₁} 的并，通过原点但不紧致；在 (0, 1) 处 f 无定义。Hartogs 只排除"紧致"奇点。

2. 用第 3 步的"固定 z₁ 的 Liouville 论证"检查：ℂ³∖{0} 上的全纯函数是否也全部延拓到 ℂ³？

提示：可以，且论证完全一样——固定 z₁ ≠ 0、z₂ ≠ 0，w ↦ F(z₁, z₂, w) 是整函数且 |w|→∞ 时 |w|ᵏ → 0。事实上 n ≥ 2 都成立。

3. 验证 g = z̄₁ dz̄₂ 不满足 ∂̄g = 0，并说明它为什么没有解。

提示：∂̄g = (∂z̄₁/∂z̄₁ − 0) dz̄₁∧dz̄₂ = dz̄₁∧dz̄₂ ≠ 0。若 ∂̄u = z̄₁ dz̄₂ 有解，则 ∂u/∂z̄₁ = 0，u 与 z₁ 无关，其 ∂u/∂z̄₂ 不含 z̄₁，矛盾。

4. 计算 CP² 的 Hodge 数 h^{0,0}、h^{4,0}，说明它们为什么分别是 1 和 0。

提示：h^{0,0} = 1：常函数生成全纯函数环；h^{4,0} = h^{0,0}（Hodge 对偶 h^{p,q} = h^{n−p,n−q}，n=2）……小心：h^{4,0} 对应 p+q=4，而 CP² 的实维是 4，复维是 2，故 p,q ≤ 2，h^{4,0} 不在菱形里——正确表述为 h^{p,q} 要求 p,q ≤ n = 2。

5. 设 M 为紧 Kähler 曲面，b₁(M) 为奇数。说明 M 不可能有 Hodge 分解意义上的"纯"结构。

提示：Hodge 分解 + 对称给出 b₁ = h^{1,0} + h^{0,1} = 2h^{1,0} 为偶数；b₁ 奇 ⟹ 矛盾，M 非 Kähler（这正是 Hopf 曲面反例的本质）。

十四、附：工作题——Hartogs 条件、∂̄ 解与 Hodge 数

工作题 1（Hartogs 条件检查）。 对下列 (Ω, K) 判断 Hartogs 定理是否适用：(a) Ω = ℂ²，K = 闭球 {|z| ≤ 1}；(b) Ω = ℂ²，K = 直线 {z₁ = 0}∩{|z|≤1} 的并；(c) Ω = ℂ，K = {0}。

显示解答

(a) 适用：n=2≥2，K 紧，Ω∖K = {|z|>1} 连通，故 𝒪(Ω∖K) → 𝒪(ℂ²) 满射。
(b) 不适用：K = {z₁=0}∩{|z|≤1} 不是闭球的一部分而是"帽片"——它紧致，但要注意 Ω∖K 是否连通：{z₁=0}∩{|z|≤1} 挖掉后 Ω∖K 仍连通（绕行可行），所以其实适用！真正的障碍是紧致性，这里 K 紧致，故仍适用。
(c) 不适用：n=1，1/z 是反例。

工作题 2（显式解 ∂̄）。 在 Δ² 上解 ∂̄u = 3 z̄₁² dz̄₁ − 2 z̄₂ dz̄₂（先检查相容性）。

显示解答

相容性：∂g₂/∂z̄₁ − ∂g₁/∂z̄₂ = 0 − 0 = 0 ✓。猜测 u = z̄₁³ + (−z̄₂²·…)：需 ∂u/∂z̄₁ = 3z̄₁²、∂u/∂z̄₂ = −2z̄₂。取 u = z̄₁³ − z̄₂²。检验：∂u/∂z̄₁ = 3z̄₁² ✓，∂u/∂z̄₂ = −2z̄₂ ✓。全部解：u = z̄₁³ − z̄₂² + h，h 全纯。

工作题 3（Hodge 数计算）。 求 CP¹ = S² 的 Hodge 数（这是 n = 1 的情形，先写出菱形）。

显示解答

b₀ = b₂ = 1，b₁ = 0。Hodge 分解 H¹ = H^{1,0} ⊕ H^{0,1} = 0，故 h^{1,0} = h^{0,1} = 0。H² = H^{1,1}（复维 1 时 p,q ≤ 1），故 h^{1,1} = 1。菱形：h^{0,0} = 1、h^{1,0} = h^{0,1} = 0、h^{1,1} = 1。CP¹ 是唯一的紧致紧 Riemann 面（黎曼球），其 Hodge 菱形正是 1；0 0；1。

  • Hartogs (1906)：Hartogs 现象——分离全纯 ⇒ 全纯，且可在紧集外延拓；多复变与单复变的第一次分野。
  • Poincaré (1907)：球与多圆盘不双全纯等价——多复变域分类问题的起点。
  • Levi (1911)：Levi 问题与伪凸性——可微域何时为全纯域。
  • Cartan–Thullen (1932)：全纯域与全纯凸性——域的共形不变刻画。
  • Oka (1936–53)：Oka 原理与凝聚层定理——多复变"整体问题"的可解性纲领。
  • Grauert (1958)：Levi 问题的解决与 Oka 原理的光滑版本——多复变现代时期的标志。
  • 教材：Hörmander, An Introduction to Complex Analysis in Several Variables（L² 方法）；Range, Holomorphic Functions and Integral Representations in Several Complex Variables。
