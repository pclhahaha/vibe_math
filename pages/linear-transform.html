一、向量：平面上的箭头

要读矩阵这张说明书，先得把"被搬的东西"说清楚。平面上的一个向量（vector）就是一根箭头：有长度、有方向。我们把箭头起点放在原点，于是箭头完全由末端位置决定，写成 v=(x,y)——比如 v=(2,3) 表示"从原点出发向右 2 格、再向上 3 格"。

箭头之间有两种基本运算，后面处处要用：

加法：一箭接一箭，终点是两箭之和，分量分别相加：(1,0)+(0,1)=(1,1)。

数乘：把箭头拉长或缩短若干倍，分量同乘一个数：2·(1,2)=(2,4)。

注意这两条运算的共同点：它们都"一格一格"地作用在分量上。下一节会看到，矩阵×向量做的也正是"乘一乘、加一加"——只是组合得更复杂。

三、变换：矩阵把整张平面搬去哪

既然每个向量 Av 都能算，那我们把平面上无穷多个向量都算一遍，就看到了整张平面的变形。这种"给每个向量一个去向"的规则，叫变换（transformation），记作 T(v)=Av：输入一个点，输出一个点。

怎么"看"整张平面在动？最好的观察对象是一个完整的图形，而不是单个点。把单位正方形交给 A=[[2,0],[0,1]]，四个顶点 (0,0),(1,0),(0,1),(1,1) 变成 (0,0),(2,0),(0,1),(2,1)——整块正方形被均匀拉宽。把单位圆（所有满足 x²+y²=1 的点）交给它呢？每个点 (x,y) 变成 (2x,y)，圆被拉成一块长轴在 x 方向的椭圆（第九、十节会详细讲）。

现在问题来了：点有无数个，难道要一个一个算它们搬到哪吗？——不用。下一节是整门课的钥匙：只要知道两个基向量去哪，所有点的去向就全定了。

六、什么是"线性"？——从三个条件到正式定义

第四节能推出"矩阵列 = 基向量去向"，第五节能反推矩阵，都依赖一个隐含前提：变换对"拼"和"拉"是配合的——这正是"线性"的含义。用肉眼可检验的三条标准来说：

① 原点不动：原点 (0,0) 被搬去的地方还是 (0,0)。

② 先拼再搬 = 先搬再拼：T(u+v)=T(u)+T(v)。

③ 先拉再搬 = 先搬再拉：T(cv)=c·T(v)。

用一个具体矩阵核对。A=[[2,0],[0,1]]：原点 (0,0) ↦ (0,0) ✓；取 u=(1,2)、v=(3,1)，T(u)=(2,4)、T(v)=(6,1)、T(u+v)=T(4,3)=(8,3)=T(u)+T(v) ✓；T(2u)=T(2,4)=(4,8)=2T(u) ✓。三条全过。

而平移 T(x,y)=(x+1,y) 呢？T(0,0)=(1,0)≠(0,0)——第一条就破了，所以平移不是线性变换。

这三条精确地写下来，就是线性变换的正式定义：

定义。 设 T 把平面上的向量送到平面上的向量。若对任意向量 u,v 和任意数 c，都有 T(u+v)=T(u)+T(v) 且 T(cv)=c·T(v)，则称 T 是线性变换。矩阵 A 与变换 T(v)=Av 一一对应——每个矩阵给出一个线性变换，每个线性变换对应一个矩阵。

七、怎么判断一个变换是不是线性——完整例题

有了定义，就能动手检验。三个例题，一个过、两个不过，看看区别在哪。

例 1：T(x,y)=(2x,3y) 是线性的。

验证 ① T(0)=T(0,0)=(0,0) ✓。验证 ②：取 u=(x₁,y₁)、v=(x₂,y₂)，

验证 ③：T(cv)=(2cx,3cy)=c(2x,3y)=cT(v) ✓。三条全过，线性。它的矩阵？e₁=(1,0) ↦ (2,0)、e₂=(0,1) ↦ (0,3)，排成列得 A=[[2,0],[0,3]]。

例 2：平移 T(x,y)=(x+1,y) 不是线性的。

T(0,0)=(1,0)≠(0,0)，违反 ①。也可以直接看出 ② 失败：T((1,0)+(1,0))=T(2,0)=(3,0)，而 T(1,0)+T(1,0)=(2,0)+(2,0)=(4,0)，不相等。平移是仿射变换——它保持直线和平行性，但原点跑了。

例 3：T(x,y)=(x²,y) 不是线性的。

T(0,0)=(0,0)，① 过了！但 ③ 失败：取 v=(1,0)、c=2，T(2v)=T(2,0)=(4,0)，而 2T(v)=2(1,0)=(2,0)，不等。教训：只满足 T(0)=0 远远不够，三条必须同时成立。

八、为什么 T(0)=0 是必要条件

定义里有 T(u+v)=T(u)+T(v)，为什么一定推出 T(0)=0？甚至不用"线性"这个名词，纯代数就看出来：

因为 0 可以写成自己加自己，加性把"T(0) = T(0)+T(0)"逼出来，两边同时减去 T(0) 就得到 T(0)=0。所以这是必要条件：任何线性变换都必须满足它。

九、直觉：矩阵在变形空间——单位圆变成椭圆

单个点看不出全貌，用完整的图形最好。把蓝色单位圆（所有满足 x²+y²=1 的点）输入矩阵 A，A 把每个点 (x,y) 送到 (ax+by, cx+dy)。所有这些像点组成红色椭圆。

矩阵 A 的第 1 列 = 基向量 (1,0) 被送到哪里；第 2 列 = (0,1) 被送到哪里。矩阵的列就是新坐标系的基向量。整个空间以这两个新基向量为"骨架"被均匀拉伸和旋转。

试一个小实验：把 a 拖到 0、b 拖到 1、c 拖到 1、d 拖到 0，A=[[0,1],[1,0]]。这是反射——(1,0) 和 (0,1) 互换了。det=−1（det 就是行列式，一个代表"面积放大倍数"的数，负号表示把图形翻了个面；行列式另有专门一课，这里先混个眼熟）。

十、几何：圆为什么一定变成椭圆

单位圆上的点满足 x²+y²=1。经过 A 变换后，像点 (u,v)=(ax+by, cx+dy)。如果 A 可逆，我们可以反解出 (x,y) 用 (u,v) 表示，代入 x²+y²=1，得到关于 u,v 的二次型方程——它定义一条圆锥曲线。

因为 A 可逆时原点映到原点、有界闭曲线映到有界闭曲线，所以这条圆锥曲线一定是椭圆，不可能是双曲线或抛物线。

为什么是椭圆而非圆？因为 A 一般不是正交矩阵——它不会同等拉伸所有方向。某些方向被拉伸得更多（长轴），某些更少（短轴）。

椭圆半轴方向 = A 的左奇异向量；半轴长度 = A 的奇异值 σ₁,σ₂，来自 AᵀA 的特征值：σᵢ=√λᵢ(AᵀA)。（奇异值、特征值分属《SVD》和《特征值与特征向量》两课，这里先预告椭圆长在哪个方向。）

十一、秩亏损：当椭圆被压扁

慢慢把 a 从 3 拖到 0，观察 det = ad−bc 的变化。当 det → 0，椭圆越来越扁——最终变成一条线段。

这意味着什么？A 把整个二维平面压缩到了一维子空间（一条过原点的直线）上。无穷多个不同的输入映射到同一个输出——信息丢失，A 不再可逆。这就是为什么 det=0 等价于"矩阵不可逆"：你无法从一条线段恢复出原来的二维圆。

det=0 的矩阵叫奇异矩阵；det≠0 叫非奇异。|det| 恰好等于椭圆的面积除以单位圆的面积（π）——正是面积放大倍数。

十三、完整推导：圆→椭圆的代数证明

单位圆：x²+y²=1。线性变换：(u,v)=(ax+by, cx+dy)。若 det≠0，反解：x=(du−bv)/det，y=(−cu+av)/det。代入 x²+y²=1：

(d²+c²)u² − 2(bd+ac)uv + (b²+a²)v² = (det)²

这是关于 u,v 的二次型。判别式 Δ=(bd+ac)²−(d²+c²)(b²+a²)=−(ad−bc)²=−(det)²<0（当 det≠0）。Δ<0 → 椭圆。半轴长度 = AᵀA 的特征值的平方根 = 奇异值 σ₁,σ₂。

十四、历史注记

线性代数的现代形式诞生于19世纪末到20世纪初。Cayley(1858)引入矩阵乘法；Sylvester(1850)命名"矩阵"；Peano(1888)第一个给出抽象向量空间的公理化定义。但线性变换的几何直觉——"空间在变形"——直到计算机图形学时代才真正可交互地展示出来。

3Blue1Brown的"线性代数的本质"系列(2016)用动画将线性变换的几何直觉带给了千万人。你现在看到的这个交互式可视化正是沿着这个传统。

十五、常见误解澄清

❌ "矩阵就是数字的表格"——矩阵是线性变换的坐标表示。同一变换在不同基下有不同矩阵。

❌ "行列式就是ad−bc的计算公式"——行列式是体积放大倍数。2×2中ad−bc恰好等于面积比。

❌ "线性变换一定是旋转+拉伸"——不一定。剪切(如A=[[1,1],[0,1]])是线性变换但不能分解为纯旋转+纯拉伸(需要SVD才能分解为旋转→拉伸→旋转)。

❌ "椭圆一定以坐标轴为对称轴"——只有对角矩阵产生的椭圆才如此。一般矩阵产生的椭圆可以倾斜。

十七、关联科目

→ 行列式：det(A)=椭圆的面积÷单位圆的面积。下一课用正方形展示这个关系。

→ 特征值与特征向量：椭圆长轴方向 = 最大特征值的特征向量。特征向量是"在变换下不改变方向"的特殊方向。

→ SVD：A = UΣVᵀ 将这个变换拆成三步：旋转(Vᵀ) → 沿轴拉伸(Σ) → 旋转(U)。

→ 量子力学：量子态空间中的线性变换 = 量子门。Bloch 球上的旋转都是酉矩阵。

→ 微分几何：流形在每点的切空间是向量空间。切映射是线性变换。

→ 数据科学：PCA=找到数据方差最大方向的特征向量。SVD=把数据矩阵分解为最重要的模式。推荐系统=矩阵分解。

→ 计算机图形学：所有3D变换(旋转、缩放、投影、透视)都是4×4矩阵。GPU每秒做数十亿次矩阵乘法。

前沿：矩阵乘法复杂度的突破

Strassen(1969)用分块法将矩阵乘法降到O(n^2.81)。当前最优:O(n^2.371552)(Williams-Xu-Xu-Zhou 2024,Duan-Wu-Zhou 2023用AI辅助搜索)。AlphaTensor(DeepMind 2022)用强化学习发现新的低秩分解——AI首次改进了几十年前的矩阵乘法算法。仍开放:omega=2(the "ultimate" bound)是否可达？

证明一：秩-零化度定理（维数定理）

设 V 是有限维向量空间，T: V → W 是线性映射。定理断言：

证明。 记 k = dim ker T，n = dim V。取 ker T 的一组基 {v₁,…,vₖ}，将其扩充为 V 的一组基 {v₁,…,vₖ, vₖ₊₁,…,vₙ}。我们证明 {T(vₖ₊₁),…,T(vₙ)} 是 im T 的一组基。

① 张成性。 对任意 w ∈ im T，存在 v ∈ V 使 w = T(v)。将 v 按基展开：v = Σᵢ₌₁ⁿ aᵢvᵢ。由线性性，w = T(v) = Σᵢ₌₁ⁿ aᵢT(vᵢ) = Σᵢ₌ₖ₊₁ⁿ aᵢT(vᵢ)，因为 v₁,…,vₖ ∈ ker T，T(vᵢ) = 0。故 w 由 {T(vₖ₊₁),…,T(vₙ)} 张成。

② 线性无关。 设 Σᵢ₌ₖ₊₁ⁿ cᵢT(vᵢ) = 0。由线性性 T(Σᵢ₌ₖ₊₁ⁿ cᵢvᵢ) = 0，即 Σᵢ₌ₖ₊₁ⁿ cᵢvᵢ ∈ ker T。于是该向量可被 ker T 的基 {v₁,…,vₖ} 表示：Σᵢ₌ₖ₊₁ⁿ cᵢvᵢ = Σⱼ₌₁ᵏ bⱼvⱼ。整理得 Σⱼ₌₁ᵏ bⱼvⱼ − Σᵢ₌ₖ₊₁ⁿ cᵢvᵢ = 0。由于 {v₁,…,vₙ} 是 V 的基（线性无关），所有系数为 0，特别 cₖ₊₁ = … = cₙ = 0。∎

故 dim im T = n − k，于是 dim V = k + (n−k) = dim ker T + dim im T。

推论。 ① T 单射 ⟺ ker T = {0} ⟺ dim im T = dim V。② 当 V = W 时，T 可逆 ⟺ rank T = dim V（满秩）。③ 从 V 到更小维数空间的线性映射必不是单射。

证明二：矩阵表示的唯一性

设 β = {v₁,…,vₙ} 是 V 的有序基，γ = {w₁,…,wₘ} 是 W 的有序基。定理：映射 Φ: L(V,W) → Mm×n(F)，T ↦ [T]βγ 是一一对应（线性同构）。

证明。 由于 γ 是基，每个 T(vⱼ) 有唯一的展开 T(vⱼ) = Σᵢ₌₁ᵐ aᵢⱼwᵢ，系数 aᵢⱼ 由向量在基下坐标的唯一性确定。定义矩阵 [T]βγ = (aᵢⱼ)。

单射。 若 [T]βγ = [S]βγ，则对所有 j，T(vⱼ) 与 S(vⱼ) 在基 γ 下坐标相同，故 T(vⱼ) = S(vⱼ) 对每个基向量成立；由线性性 T 与 S 在任意向量上一致，故 T = S。

满射。 任给 m×n 矩阵 A = (aᵢⱼ)，定义映射 T: V → W 为：先令 T(vⱼ) = Σᵢ aᵢⱼwᵢ，再线性延拓——对任意 v = Σⱼ cⱼvⱼ，令 T(v) = Σⱼ cⱼT(vⱼ)。易验证 T 是线性映射（加法与数乘都通过坐标线性地传递），且 [T]βγ = A。

故 Φ 是双射。由此 L(V,W) ≅ Mm×n(F)，维数均为 mn——线性变换的全体与矩阵的全体"同构"，这就是我们总用矩阵研究线性变换的合法性基础。

反例：线性与非线性之别

平移 T(x) = x + b（b ≠ 0）不是线性的。 验证：T(0) = b ≠ 0，违反线性条件 ① T(0) = 0。也可直接验证加性失败：T(u+v) = u+v+b ≠ T(u)+T(v) = u+v+2b。平移是仿射变换——它把直线映成直线、保持平行性与比例，但原点移动了，故不是线性变换。

T(x) = x² 不是线性的。 尽管 T(0) = 0，但 T(2v) = 4v² ≠ 2T(v) = 2v²，违反齐次性 ③。满足 T(0)=0 和加性仍可能不线性。

T(x) = |x| 不是线性的。 T(−1) = 1 ≠ −T(1) = −1。加性也失败：|1+(−1)| = 0 ≠ |1|+|−1| = 2。

T(x) = ‖x‖ 不是线性的。 对 v ≠ 0，T(2v) = 2‖v‖ = 2T(v) 看似通过，但 T(−v) = ‖v‖ ≠ −‖v‖。齐次性必须对所有标量成立，一个负号就足以证伪。

教训："保持直线的变换" ≠ "线性变换"。线性要求三条同时成立：T(0)=0、T(u+v)=T(u)+T(v)、T(cv)=cT(v)。三者缺一不可——总可构造满足任意两条而不满足第三条的反例。

工作题：核、像与秩-零化度定理

题1。 设 A = [[1, 2], [2, 4]]。求 ker A、im A 及它们的维数，并用秩-零化度定理验证。

显示解答

解方程组 A(x,y)ᵀ = 0：x + 2y = 0 且 2x + 4y = 0——两方程等价，故 y 自由。ker A = {(x,y) : x = −2y} = span{(−2, 1)}，dim ker A = 1。列空间 im A = span{(1,2), (2,4)} = span{(1,2)}（第二列是第一列的 2 倍），dim im A = 1。验证：dim ker + dim im = 1 + 1 = 2 = dim ℝ²。✓

题2。 设 A = [[1,1,1],[1,1,1]] : ℝ³ → ℝ²。求 rank、nullity，判断 A 是否单射、是否满射。

显示解答

im A = span{(1,1)}，rank = 1。由秩-零化度定理：nullity = dim ker A = 3 − 1 = 2。因 nullity = 2 ≠ 0，A 不单射——例如 v = (1,−1,0) 非零但 Av = 0。因 rank = 1 < 2 = dim ℝ²，A 不满射。直观：A 把 ℝ³ 压缩到一条直线，丢失了信息。

题3。 设 T: ℝ² → ℝ²，T(x, y) = (2x + y, x − y)。写出矩阵，求核与像，判断 T 是否可逆。

显示解答

矩阵 A = [[2,1],[1,−1]]。det A = 2·(−1) − 1·1 = −3 ≠ 0，故 A 可逆，T 是双射。于是 ker T = {0}（仅零向量），im T = ℝ²（全空间）。秩-零化度验证：dim ker + dim im = 0 + 2 = 2 = dim ℝ²。✓ 逆矩阵 A⁻¹ = (1/(−3))[[−1,−1],[−1,2]] = (1/3)[[1,1],[1,−2]]。

题4。 用秩-零化度定理回答：是否存在从 ℝ⁵ 到 ℝ³ 的单射线性映射？是否存在从 ℝ³ 到 ℝ⁵ 的满射线性映射？

显示解答

对 T: ℝ⁵ → ℝ³，dim im T ≤ 3，故 nullity = 5 − rank ≥ 5 − 3 = 2 > 0。单射要求 ker = {0}（nullity = 0），矛盾，故不存在单射。对 T: ℝ³ → ℝ⁵，满射要求 rank = 5，但 rank ≤ dim ℝ³ = 3 < 5，故不存在满射。一般结论：线性映射不能把信息压缩后无损失地恢复——单射需要目标空间足够"大"，满射需要目标空间足够"小"，这正是维数这一不变量在起作用。

关联课程

→ 行列式：det(A)=椭圆的面积÷单位圆的面积——行列式是线性变换的体积放大倍数，下一课用正方形展示这个几何关系。

→ 谱定理：对称矩阵可以被特征向量正交对角化——此时椭圆半轴和坐标轴重合，线性变换退化为沿正交方向的独立缩放。
