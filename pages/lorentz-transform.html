γ = 1.25 这个数字会反复出现：时间膨胀——飞船上过 1 秒，地面看到 1.25 秒；长度收缩——一艘地面测得长 100 m 的飞船，在地面看来只有 100/1.25 = 80 m。再举一个更惊人的：如果地面看到飞船飞了 10 年，飞船自己的钟只走了 10/1.25 = 8 年。

一句话：光速不变逼出来的规矩——换个参考系看时空，时间会变慢、长度会缩短。只想懂核心思想，看到这里就够了。

一、从两条公理到 Lorentz 变换——为什么光速不变需要一种新的变换

先问一个"为什么"：牛顿时代的伽利略变换 x' = x − vt、t' = t 有什么毛病？它假设时间绝对、空间绝对。但光速不变原理（公理 1：光速在所有惯性系中相同）直接跟它打架：在伽利略变换下，一束光相对运动参考系的速度会被"加"上参考系速度 v，光速就变了。所以伽利略变换必须被废弃。

Lorentz 变换是从两条公理逼出来的唯一自洽答案：

  • 公理 1（光速不变）：光速在所有惯性系中相同。
  • 公理 2（相对性原理）：物理定律在所有惯性系中形式相同。

从这两条出发 → 时空变换必须是线性的且保持光速 → 唯一解：

y' = y、z' = z。当 v ≪ c 时 γ ≈ 1，t' ≈ t − vx/c²，x' ≈ x − vt——退化成伽利略变换（vx/c² 一项小到可忽略）。Lorentz 变换不是被"发明"的——是被逼出来的：它是仅有的、同时满足两条公理的自洽选择（完整推导见附 A）。

拖动速度滑块看坐标轴如何倾斜。蓝色=静止参考系。红色=运动参考系——x'轴和ct'轴向中间"挤压"。这不是"空间收缩"——是不同参考系中"同时"的定义不同。

二、手算一个完整例子——两个参考系之间到底怎么换算

例 1（一步步算：对一个事件的 Lorentz 变换）。设 S' 相对 S 以 v = 0.6c 沿 x 轴运动。事件 E 在 S 中坐标为 (t, x) = (4 s, 2.4×10⁸ m)。它落在什么位置？

① 取 γ：γ = 1/√(1−0.6²) = 1.25（开场问题算过）。

② 先算 vx/c² 的量纲核对：vx/c² = 0.6c × 2.4×10⁸ / c² = 0.6 × 2.4×10⁸ / c = 1.44×10⁸/3×10⁸ = 0.48 s。这是"时间校正项"，单位是秒，说明它在 t 上是不可忽略的。

③ 变换时间：t' = γ(t − vx/c²) = 1.25 × (4 − 0.48) = 1.25 × 3.52 = 4.40 s。

④ 变换位置：x' = γ(x − vt) = 1.25 × (2.4×10⁸ − 0.6×3×10⁸×4) = 1.25 × (2.4×10⁸ − 7.2×10⁸) = 1.25 × (−4.8×10⁸) = −6.0×10⁸ m。

⑤ 核对固有时：在 S 中两参考系原点重合的事件沿此事件的间隔：Δs² = −c²t² + x² = −(3×10⁸×4)² + (2.4×10⁸)² = −1.44×10¹⁸ + 0.058×10¹⁸ ≈ −1.38×10¹⁸。在 S' 中 Δs'² = −(3×10⁸×4.40)² + (−6.0×10⁸)² = −1.74×10¹⁸ + 0.36×10¹⁸ = −1.38×10¹⁸。间隔不变 ✓。∎

这个例子演示了全课的核心：变换不是"移动坐标"，而是两个参考系对同一个事件给出不同的 (t, x)，但两者通过 γ 和 v 严格换算，且间隔 ds² 保持不变。

三、三个相对论效应——从公式到具体数字

时间膨胀：ΔT = γ τ₀，动钟变慢。τ₀ 是静止于参考系内的钟读数（固有时）。例：μ 子静止寿命 2.2 μs，若以 0.99c 运动，γ ≈ 7，地面测得寿命 ≈ 7 × 2.2 = 15.4 μs。

长度收缩：L = L₀/γ，动尺缩短。这不是"物质被压扁"——而是在运动参考系中同时测量两端的结果（附 C 证明）。例：0.99c 的 μ 子，经典算只能走 0.99c×2.2μs ≈ 0.66 km；考虑膨胀后走 0.99c×15.4μs ≈ 4.6 km——能穿透约 10 km 的大气层（这正是 μ 子能被地面观测到的原因）。

六、试试看（每题附提示）

1.（计算 γ） 粒子以 v = 0.6c 运动。求 γ，以及固有寿命 2 μs 的粒子在地面系中存活多久。

提示：γ = 1/√(1−0.36) = 1.25。存活时间 ΔT = γτ₀ = 1.25 × 2 = 2.5 μs。这一步练的是"先算 γ，再代入膨胀公式"。

2.（速度加法） 火箭以 v = 0.75c 相对地面飞行，相对火箭以 u' = 0.75c 向前发射导弹。导弹相对地面的速度？若 u' = c 呢？

提示：u = (0.75c+0.75c)/(1+0.75×0.75) = 1.5c/1.5625 = 0.96c。若 u' = c：u = (c+0.75c)/(1+0.75) = c——光速在一切参考系中不变，公式自动保证。

3.（时间膨胀/长度收缩验证） μ 子在 10 km 高空以 v = 0.999c 产生，固有寿命 τ₀ = 2.2 μs。经典计算它飞多远？相对论呢？能到地面吗？

提示：经典 0.999c×2.2μs ≈ 0.66 km ≪ 10 km。相对论：γ = 1/√(1−0.999²) ≈ 22.4，地面寿命 Δt = γτ₀ ≈ 49 μs，飞行 ≈ 14.7 km > 10 km。也可换到 μ 子系：大气收缩为 10/22.4 ≈ 0.45 km，2.2 μs 内追上。

4.（直觉） 为什么"长度收缩"不是把尺子压扁？如果你在运动的尺子旁边放一列静止的尺子，测量时最容易犯什么错？

提示：L = L₀/γ 的推导要求"同时读取两端"（附 C 第 2 部分）。若不同时读，读到的两点不是同一物理杆——所以收缩是"同时性定义的几何后果"，不是材料应力。

Thomas进动——Lorentz boost的非交换性

两个不同方向的Lorentz boost（沿某一方向的速度变换）复合=一个boost+一个纯旋转。这个旋转叫Thomas进动——电子自旋在原子中的精细结构修正。Lorentz群的非交换性是它最微妙(也最容易忽略)的几何特征。

前沿：Lorentz对称性的可能破缺

某些量子引力候选理论(如Horava-Lifshitz引力)在高能破坏Lorentz对称性。Fermi-LAT和IceCube在极高能光子/中微子中搜索Lorentz破缺——至今没有发现。仍开放:Lorentz对称性是绝对的还是仅仅是低能近似？
