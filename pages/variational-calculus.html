〇、直觉入门——从千万条路里挑出最省的那一条

两点之间直线最短，但如果是滑滑梯呢？最快的路不是直线，而是一条先陡后平的曲线（摆线）。变分法就是专门回答这种问题的方法：在无数种可能的曲线里，找到让时间、路程或能量最小的那一条。

物理里的"东西自然会选最省力的走法"、地图导航的最优路线，背后都是同一套思想。

一句话：把"找最好的一条路"变成算账，看哪条路"最划算"。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 前沿 级别，正文较深。

建议先掌握：导数与切线、黎曼积分。

高级章节（证明、前沿、工作题）需要相应背景，未掌握可先看「〇、直觉入门」了解核心思想，或回到前置课程补基础。

一、一个具体问题——最速降线：直线不是最快的（先算一笔账）

问题（Bernoulli, 1696）：质点只在重力下从 A=(0,0) 沿曲线滑到 B=(x₁,y₁)，哪条曲线用时最短？大多数人会猜直线——毕竟"两点之间直线最短"。但把时间算出来，直线就输了。

具体的账。 取 B=(1,1)，重力常数 g=1。速度由能量守恒给出：v = √(2gy)。沿曲线 y(x) 滑行的时间是

直线 y=x： v = √(2gx)，ds/dx = √2，故

摆线（旋轮线）： 参数方程 x = R(θ−sinθ)、y = R(1−cosθ)，调整 R 让它恰好穿过 (1,1)。在 y=x 上取点需 1−cosθ = θ−sinθ，解得 θ* ≈ 2.41 rad，于是 R ≈ 0.575，

结论： 1.83 < 2.00——摆线比直线快了约 8.5%。这个反直觉的数值结果，是整门变分法的入口：我们不是在一堆"候选值"里找最小，而是在一个"无穷维的曲线空间"里找最小。单变量微积分管不了这种问题，需要新的工具。

二、泛函与变分——从"函数"到"函数的函数"（直觉→严格）

微积分研究函数 y(x)；变分法研究泛函——输入是整条函数 y、输出是数：

（例如最速降线的 T[y] 就是 L = √(1+y'²)/√(2gy) 的泛函。）

极值条件怎么写？ 一元函数在极值点导数为零；泛函的对应物是：若 y₀ 是极小元，则往任意方向"微扰"一点，J 值不该下降。把扰动用单参数写成 y = y₀ + εη，其中 η 是端点为零的光滑函数（η(a)=η(b)=0，保证曲线仍从 A 到 B）。定义一元函数

极小条件就是 φ'(0) = 0 对一切 η 成立。这样"在函数空间中取极值"就被翻译成"一族一元函数的导数条件"——可算了。

为什么端点要求 η(a)=η(b)=0？ 因为问题是"固定端点的最短曲线"，扰动不能把起点终点挪走；若允许端点移动，会出现额外的边界项（自然边界条件），那是另一套（更复杂）的理论。

为什么这个方程配当"一切的起点"？ 它把"整条曲线的极值"压成了"每一点都必须满足的一条二阶常微分方程"——无穷维问题塌缩成有限维约束。变分法基本引理"若 ∫f·η dx=0 对所有光滑 η 成立则 f≡0"是核心跳板：它保证被积函数逐点为 0，而不是"只在一个可测集合上非零"。ε→0 时，若 L 有界可积，φ(ε) 与 J 在同一点取极值。

物理意义。 经典力学（最小作用量原理）、几何光学（Fermat 原理）、弹性力学都归结为这一个方程。Hamilton 力学、Noether 定理、最优控制，全部从这里生长。

七、Noether 定理——对称性与守恒律的变分证明

Lagrangian 在变换 q → q + εδq 下不变（允许改变一个全导数）→ 守恒量：

其中 K 是 L 改变量的"全导数项"（若 L 完全不变则 K=0）。为什么对称性会"产出"守恒量？ 因为变换不改变作用量 ⟹ J 在变分方向 δq 上的一阶变分为零 ⟹ EL 方程的某个组合变成全导数 ⟹ 某个量沿任何真实运动保持常数。

  • 时间平移不变 → 能量守恒（Q = 哈密顿量）。
  • 空间平移不变 → 动量守恒（Q = 广义动量）。
  • 旋转不变 → 角动量守恒。
  • 规范不变 → 电荷守恒。

这是变分法在物理学中最灿烂的应用：一条纯数学的"对称性→守恒量"机制，同时解释力学、电磁学与粒子物理里的全部守恒定律。

九、带约束的变分——拉格朗日乘子与反例

若泛函 J[y] 在约束 G[y]=0 下取极值，不能直接令 δJ=0。正确定法：构造 F = L + λ·G，对 F 应用 EL 方程，λ 为拉格朗日乘子。为什么 λ 是必要的？ 因为在约束流形上，极小元处的变分不必对一切 η 消失，而只对"保持约束的方向"消失——λ 正是用来吸收约束曲面的"法向贡献"的。

经典例子：在长度固定的曲线中找面积最大者（等周问题）→ 答案是圆。这是"约束变分"最著名的结果，其证明对任意曲线族成立。

病理例子：泛函 J[y]=∫y²dx 在约束 ∫(y')²dx=1 下，极小元不存在（可达下确界 0 但无函数达到）——说明约束变分可能需要放宽到函数空间之外（分布、测度）。这个例子展示了变分法的边界：极值问题不一定有光滑解，需要把空间扩大。

十、Pontryagin 最大值原理——最优控制的变分法

变分法在控制论中的推广：最小化 J=∫L(x,u)dt，约束 ẋ=f(x,u)。最优控制满足 Hamiltonian 边界值问题——把 EL 方程改造成"状态 + 协态"的两点边值系统。阿波罗登月轨迹优化和现代机器人运动规划的数学基础。

为什么变分法不够用？ 经典变分假设"控制"是光滑函数；工程里的最优控制常是开关式的（bang-bang），不可微。Pontryagin 原理用"哈密顿量最大"代替"变分为零"，允许不可微的最优控制，并给出必要条件。

十一、Plateau 问题——极小曲面

给定空间闭合曲线为边界，存在以其为边界的极小面积曲面吗？Douglas 和 Rado（1930-31）独立解决了二维 Plateau 问题→1936年Fields奖。三维以上——几何测度论（Almgren, Federer, Fleming）用整流和电流给出了解答。

为什么 Plateau 是变分法的"深水区"？ 极小曲面的面积泛函不是严格凸的、解可能有奇点、允许的曲面类（分片光滑? Lipschitz? 整流?）本身就需要设计。这里"直接法"（极小化序列 + 弱收敛）第一次需要真正硬的分析工具——几何测度论由此诞生。

十二、直接法与近代方向——Sobolev 空间与弱解

并非所有问题都能解出欧拉-拉格朗日方程。近代直接法绕开方程，直接讨论泛函：

  • 取极小化序列 → 弱紧致性（Sobolev 嵌入）→ 弱下半连续性 → 极限是极小元。
  • 泛函要"弱下半连续"才能保证极限元不把 J 抬高——这是凸性条件的分析化身。
  • 解往往只在 Sobolev 空间 W^{k,p} 里（允许弱导数），不光滑。

这一路线把变分法从"解 ODE"升级为"非线性泛函分析"，是 Plateau 问题、最优传输、图像处理的公共工具箱。

题 2：最小旋转面——绕轴旋转连接两点的曲线，使其面积最小。（完整解答见例题 3。）

题 3：用变分法基本引理证明若 ∫ₐᵇ f(x)η(x)dx=0 对所有光滑 η 成立，则 f≡0。

显示解答

题 1：取弧长参数，L=√(1+y'²) 不显含 x，Beltrami：L−y'Ly'=1/√(1+y'²)=C ⟹ y'=const ⟹ y=ax+b，直线。∎

题 2：L=2πy√(1+y'²)。Beltrami 首积分 L−y'Ly' = 2πy/√(1+y'²) = 2πR ⟹ y/√(1+y'²)=R ⟹ dy/dx = √(y²−R²)/R，积分得 y=R·cosh((x−x₀)/R)——皂膜实验的形状。（完整计算见例题 3。）∎

题 3：若 f(x₀)≠0，取 η 在 x₀ 附近小邻域内取 f 同号的光滑鼓包，则积分非零，矛盾。∎

十五、试试看（每题附提示）

试试看 1（可解的具体泛函）。 求 J[y]=∫₀¹(y'²+y)dx 在 y(0)=y(1)=0 下的极小元。提示：∂L/∂y=1、∂L/∂y'=2y'，EL 给 1−2y''=0，即 y''=1/2；解 y=x²/4+Ax+B 再定 A、B，得 y=x(x−1)/4。

试试看 2（Beltrami 的再应用）。 把最速降线问题的前两步（得到 2R 常数）自己再做一遍，核对第六节。提示：L=√(1+y'²)/√(2gy)，L−y'L_{y'} = 1/(√(2gy)√(1+y'²)) = C ⟹ y(1+y'²) = 1/(2gC²)。

试试看 3（等周问题的乘子设置）。 最大化 A[y]=∫y dx，约束长度 ∫√(1+y'²)dx = ℓ。写出 F 与对应的 EL。提示：F = y + λ√(1+y'²)；∂F/∂y' = λy'/√(1+y'²)；EL: 1 − λ d/dx(y'/√(1+y'²)) = 0。左端可整理成"曲率 = 常数"，即圆。

试试看 4（Noether 验证）。 自由粒子 L = ẋ²/2 关于空间平移不变，验证动量守恒。提示：δq = ε（平移），K=0（L 不变），Q = (∂L/∂ẋ)·1 = ẋ，故速度 = 动量 = 常数。
