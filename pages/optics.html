〇、开场问题——干涉与衍射的三个具体数字

光学最深处的两个现象——干涉和衍射——先用三个能亲手验算的数字开场：

第一个：波长为 546 nm（绿）的光通过缝距 0.25 mm 的双缝、在 1.2 m 外的屏上，亮纹间距是 2.6 mm——一条条看得见、量得出的条纹。第二个：宽度只有 0.10 mm 的单缝，把 632.8 nm 的激光在 2 m 外拉开成 12.7 mm 的第一暗环。第三个：每毫米刻 600 条线的光栅，把红光以 22.3° 的方向"拐"到一边。三个例子用同一个公式家族 λ = (几何)×(角度) 描述。

为什么这些数字值得算？因为它们演示了光学最深刻的一件事：光不只走直线（几何光学），它还会"弯曲"和"叠加"（波动光学）。两个缝、一条缝、一千条缝，表面上是不同实验，实际上是同一个波动原理的三个尺码。理解 λ 与缝的尺寸谁大谁小，就理解了光学从"光线"到"波"的整套升级。

核心思想：光在两点间走"用时最少"的路（Fermat 原理）——一条规则解释反射、折射、成像；而一旦尺度与波长可比（双缝、单缝、光栅），光的"波性"接管一切，条纹间距、衍射角都能精确计算。只想懂核心思想，看到〇到七节就够。

建议先掌握：电磁学与 Maxwell 方程组。

〇·一、光波的两个数字——波长与频率

谈干涉衍射前，先给光波装上两把尺子。波长 λ：相邻两个波峰的距离；频率 f：每秒振动的次数。两者由光速相连：c = fλ，c ≈ 3.0×10⁸ m/s。

可见光只占极窄的一段：波长约 380–760 nm（1 nm = 10⁻⁹ m）。用数字感受：红光的 λ ≈ 700 nm，蓝光 λ ≈ 450 nm。换算成频率：红光 f = c/λ = 3×10⁸/7×10⁻⁷ ≈ 4.3×10¹⁴ Hz，蓝光 ≈ 6.7×10¹⁴ Hz——每秒振动几百万亿次。激光（如 He-Ne，λ = 632.8 nm）和 LED 的"颜色"就是由这个波长决定的。

为什么这两把尺子重要？因为"波动现象是否可见"取决于一个无量纲的比值：特征尺寸 ÷ 波长。镜子、透镜的尺寸（厘米级）比波长（微米级）大一万倍，光表现为直线；双缝的缝距（0.25 mm）只比波长大四百倍，条纹已经清晰可见；当缝缩到与波长同量级（100 nm 纳米孔），光是"绕"过去的——衍射主宰一切。这个比值是整门课的分界标尺。

光波的两把尺子：λ ≈ 380–760 nm（可见）、f ≈ 4–7×10¹⁴ Hz。一切"波动现象看不看得见"都取决于"尺寸/波长"这个比值——它就是几何光学与波动光学的分界线。

一、光学的四百年——从 Fermat 到量子

光学史是一部"模型的接力"，每一站都留下一个今天仍在用的公式。

几何光学（17 世纪）。Fermat 原理：光在两点间实际走过的路径使光程取极值，

Snell 定律 n₁ sinθ₁ = n₂ sinθ₂ 是它的直接推论（第三节把这条路走完）。这一站看"光线"，适合解释成像、反射、折射。

波动光学（19 世纪）。Young 双缝干涉（1801）证明光是波；Fresnel 衍射把波动图像定量化；Maxwell（1865）把光统一为电磁波——c = 1/√(μ₀ε₀)，光从此从"光线"升级为"波"。这一站解释条纹、衍射、偏振。

量子光学（20 世纪至今）。光子是电磁场的量子化粒子，统计性质（Poisson 还是 sub-Poisson）成了新的观测量。这一站连接了干涉实验与量子纠缠。

Fermat 原理 ⇔ 最小作用量原理；衍射 ⇔ 路径积分。这个光学-力学类比是 Feynman 路径积分量子化的灵感来源——狄拉克在 1930 年代就注意到这个深刻的联系：光走的每条"路径"在量子力学里就是一条几率幅。

四、教科书例题 2——薄膜与增透膜：为什么厚度是 λ/4n

问题：相机镜头要镀一层增透膜（MgF₂，n = 1.38），对 550 nm 的可见光中心波长减反射。求最小膜厚，并解释"半波损失"的作用。

第 1 步：两束反射光。光在膜的上表面（空气→MgF₂）和下表面（MgF₂→玻璃）各反射一次。两次反射的反射光在膜内走的额外路程是 2nt（来回穿过膜厚 t，膜内波长 λ/n）。

第 2 步：半波损失（关键）。光从折射率小的介质射向大的介质（空气 1.0 → 膜 1.38，膜 1.38 → 玻璃 ≈1.5）时，反射光都要"翻半个相位"（相当于多走 λ/2）。两次反射都翻相位，翻的相位抵消，所以真正决定干涉的是路程差 2nt。

薄膜干涉的两句口诀：先查"半波损失"（光密界面上反射翻相位），再套 2nt = mλ 或 (m+½)λ。增透膜取 λ/4n ≈ 100 nm，因为 ¼ 波长厚度让两束反射光相消——一个数字，解释镜头的蓝紫色。

八、量子光学（1900s–现在）

干涉实验把光当成波用到了极致，但光子是量子化的——它的统计性质成了新一代观测量，也是连接光学与量子信息的桥梁。

三种光子统计。光场的"涨落大小"可以精确分类：理想激光（相干态）的光子数服从 Poisson 分布（涨落最小、经典极限）；热光（如白炽灯）服从 super-Poisson（涨落更大，玻色子聚堆）；而压缩态、单光子态等非经典光服从 sub-Poisson（涨落小于 Poisson——量子特征，经典光不可能）。测出 sub-Poisson 涨落，就等于证明了光场处于非经典态。

数字上的用处：LIGO。引力波探测要求干涉仪的灵敏度突破"散粒噪声"极限（每个光子到达的 Poisson 涨落）。LIGO 在干涉仪里注入压缩光，把其中一个正交分量的涨落压下去，从而在低频段压低量子噪声——这是 sub-Poisson 光第一次真正进入精密测量。

2023 年诺贝尔奖。L'Huillier、Agostini、Krausz 因阿秒物理获奖：用强激光的电场在气体里拉出、回收电子（高次谐波产生 HHG），合成几百阿秒（1 as = 10⁻¹⁸ s）的光脉冲，把电子运动的快照拍到"阿秒"尺度——光本身成了测量物质最快的秒表。

量子光学把"光子数怎么涨落"变成测量对象：Poisson（激光）、super-Poisson（热光）、sub-Poisson（压缩/单光子）。LIGO 用压缩光压量子噪声，阿秒脉冲用光拍电子运动——量子光学是"光的最精细语言"。

九、非线性光学——从倍频到阿秒脉冲

弱光下介质极化与电场成正比（线性），但强光（激光）下极化变成 E 的幂级数：

非线性项 χ⁽²⁾E²、χ⁽³⁾E³ 带来一系列"光改变光"的新效应：

  • 二次谐波（倍频）。χ⁽²⁾ 项把频率 ω 的场"平方"出 2ω 成分——红外激光（1064 nm）穿过倍频晶体变绿光（532 nm）。这是激光笔里最常见的颜色转换。
  • 自发参量下转换（SPDC）。一个泵浦光子被 χ⁽²⁾ 拆成两个光子（信号光+闲置光），它们纠缠（能量、动量守恒绑在一起）——SPDC 是量子光学实验的标准纠缠源，也是量子密钥分发的基础。
  • 高次谐波产生（HHG）。χ⁽³⁾ 及以上项的极端形式：强激光把惰性气体原子里的电子拉出来、加速、再撞回去，每次碰撞发出一个高次谐波光子，几十上百个谐波合成阿秒脉冲。2023 年诺贝尔物理学奖（L'Huillier, Agostini, Krausz）正是这一项。

为什么这些效应以前"看不见"？因为 E 的平方项只在电场接近原子内电场（约 5×10¹¹ V/m）时才有可观测大小，而普通光远达不到——只有激光能把电场集中到这么强。非线性光学是激光时代的专属学科。

非线性光学 = 极化对 E 的多项式展开的产物：倍频（ω→2ω）、SPDC（纠缠源）、HHG（阿秒脉冲）。它们都要求强到接近原子内电场的激光——激光发明之前，这门课不存在。

十、超分辨率显微术——突破 Abbe 极限

第七节的反例里，Abbe 判据 Δr = 0.61λ/NA 给光学显微设了约 200 nm 的"分辨率天花板"（用 λ=550 nm、NA≈1.4 算：0.61×550/1.4 ≈ 240 nm）。细胞里的许多结构比这更小，于是整个 20 世纪的生物显微都被这层"雾"挡着。

2014 年诺贝尔化学奖的三种方法，用不同方式绕开这层雾，把分辨率从 200 nm 推到 20 nm：

  • STED（受激发射损耗）。一束激发光 + 一束环形"耗尽"光：环形光把周围的荧光分子全部熄灭，只留中心一个衍射极限以下的发光点，再逐点扫描。分辨率由耗尽光的强度决定，可到几十纳米。
  • PALM / STORM（单分子定位）。让荧光分子"稀疏地"随机点亮，每次只拍下几个分子——每个分子在图像里是一个可精确到纳米级的亮点（拟合它的 Airy 中心），重复上千次，把所有分子的位置拼成超分辨图像。
  • STORM 的变体（SMLM 家族）。原理统一：单分子定位 = 用"时间换空间"——牺牲一次成像的速度，换来远超衍射极限的定位精度。

数字对比：普通显微镜看 200 nm 的突触小泡是一团糊，STED 能数出小泡的个数与位置。突破的不是光学定律，而是"所有分子同时亮着"这个隐含假设——把同时性换成时序性，雾就散了。

超分辨的核心思想：Abbe 极限限制的是"同时点亮"的成像，不是单分子的定位。STED 用光束修剪发光区、PALM/STORM 用单分子时序点亮——两条路都绕开衍射极限，把分辨率从 ~200 nm 推到 ~20 nm。

十一、光子晶体——光的"半导体"

第七节说"亚波长结构让几何光学失效"，光子晶体正是把这个"失效"变成工具：给光制造一个"禁带"。

做法：在介质里周期性地挖孔（介电常数周期变化），尺度与波长相当。光在周期结构里传播时会发生 Bragg 散射，某些频率（以及某些传播方向）的波被完全禁止——这就是光子带隙（photonic band gap）：像半导体里的电子能隙一样，有一整段频率的光"不存在"。

Yablonovitch（1987）提出这一思想，第二年就在微波波段实验验证（"Yablonovite"）。今天的光子晶体光纤、光子晶体激光器已经实用化：光子晶体光纤用周期微结构把光关在空芯里，能承受比普通光纤高得多的功率；光子晶体激光器用带隙反射光，做出更小更稳的激光腔。

为什么这条路线重要？因为它把"电子能带论"整套数学（Bloch 定理、带隙、缺陷态）搬到光子上——光子的"能带工程"从此成为可能。电子在晶格里有能带，光子在介电晶格里有光子带隙，同一套 Bloch 定理统治两者。光子带隙 = 电子能隙的光学类比。

光子晶体 = 光的"半导体"：周期介电结构形成光子带隙，特定频率的光不能传播。Bloch 定理在光子学中的再现——电子能带论的全部数学武器，原封不动搬给光子。

十四、试试看（每题附提示）

1. 双缝间距减半，条纹间距怎么变？

提示：Δy = λL/d ∝ 1/d。d 减半则 Δy 加倍。这不只是算术——它意味着"测量条纹间距"就能反推缝距，双缝因此是一把"波长尺子"。

2. 用水做增透膜（n = 1.33）对 550 nm 减反射，膜厚多少？

提示：t = λ/(4n) = 550/(4×1.33) ≈ 103 nm。膜厚几乎与 MgF₂ 相同——因为两者的 n 接近。注意必须满足"膜折射率介于两侧介质之间"才有减反效果（半波损失条件）。

3. 红光（700 nm）与蓝光（450 nm）哪个更易被"绕过"障碍物？

提示：衍射显著的条件是"障碍物尺寸 ~ λ"。同一障碍物，红光的 λ 更大，更接近障碍物尺寸，衍射更明显——这也是为什么"红眼"、远红光信号灯穿透雾的能力与散射/衍射尺度有关。

4. 用 Abbe 判据算油浸物镜的分辨率。NA = 1.4，λ = 550 nm。

提示：Δr = 0.61×550/1.4 ≈ 240 nm。这就是"光学显微镜极限约 200 nm"的来源。把 Δr 换成 STED 的 20 nm，需要耗尽光强高到把受激辐射压过自发辐射——分辨率由光强"借用"。

5. 光纤的全反射临界角。光纤芯 n₁ = 1.50、包层 n₂ = 1.46，求全反射临界角。

提示：θ_c = arcsin(n₂/n₁) = arcsin(0.973) ≈ 76.7°。只要光在芯里的入射角超过 76.7°，就全反射一路传下去——光纤"关住光"靠的就是这个"解不存在"的奇点。

6. 为什么 Fraunhofer 衍射 = Fourier 变换？

提示：远场近似的相位因子 e^{−ik r̂·r′} 恰好是"透过函数 × 平面波 e^{−ik·r′}"的积分——这正是 Fourier 变换的定义式（k = (2π/λ)r̂ 扮演"频率"）。透镜后焦面放的就是这个频谱，所以"傅里叶光学"可以直接用透镜做光学计算器。

十五、工作题

题 1（折射角计算）。光从空气(n₁ = 1.00)以 θ₁ = 60° 入射到玻璃(n₂ = 1.50)，求折射角；若光反向从玻璃入射空气，求全内反射临界角。

显示解答

由 Snell 定律：sinθ₂ = (n₁/n₂)sinθ₁ = (1/1.5)sin 60° = 0.5774，故 θ₂ = arcsin(0.5774) ≈ 35.3°。临界角 θ_c = arcsin(n₂/n₁) = arcsin(1/1.5) = arcsin(0.6667) ≈ 41.8°。当入射角超过 41.8° 时发生全反射。

题 2（单缝衍射极小位置）。宽 a = 0.10 mm 的单缝，用波长 λ = 632.8 nm 的 He–Ne 激光照明，屏距缝 L = 2.00 m。求第一级暗纹距中心的距离。

显示解答

单缝衍射暗纹条件：a sinθ = mλ。第一级极小 m = 1：sinθ = λ/a = 632.8×10⁻⁹/1.0×10⁻⁴ = 6.328×10⁻³。因 θ 很小，y₁ ≈ L tanθ ≈ Lλ/a = 2.00×6.328×10⁻³ ≈ 1.27×10⁻² m = 12.7 mm。屏上第一级暗纹位于中心两侧 12.7 mm 处。

题 4（双缝 + 白光）。双缝 d = 0.50 mm、屏距 L = 2.0 m，用白光照明。中央亮纹为什么是白色的？它两侧第一道彩色是什么颜色、离中心多远（取 λ = 450 nm 与 650 nm）？

显示解答

中央亮纹（m=0）对所有波长都满足 d sinθ = 0（路程差为零），各色光叠加即白色。第一级亮纹按波长散开：y(λ) = λL/d。蓝光：450×10⁻⁹×2.0/5.0×10⁻⁴ = 1.8 mm；红光：650×10⁻⁹×2.0/5.0×10⁻⁴ = 2.6 mm。所以紧贴中央白纹两侧的第一道彩色条纹是"内蓝外红"的彩虹，蓝端在 1.8 mm、红端在 2.6 mm 处。这正是"白光双缝图案"中每级亮纹都是迷你彩虹的原因。
