〇、开场问题——数轴上"每一段都有长度"，但能不能量出所有集合？

先用具体数字感受我们要做什么。闭区间 [0,1] 的长度是 1；[2,5] 的长度是 3；[a,b] 的长度是 b−a。这些都不需要争论。现在问你：

这个集合"几乎看不见"——数轴上把它画出来，是一个个孤立的点（1/2, 1/3, 1/4, 2/3, …），但点太多，多到数不清。直觉告诉你它的长度该是 0。可它不是有限个点，甚至不是可数个"整齐"的点。怎么严格地算？

更糟的还在后面。1905 年，Vitali 用下面这个手法造出一个集合 V⊂[0,1]：把 [0,1] 里的数按"差是有理数"分成一堆等价类（x~y ⟺ x−y∈ℚ），每个等价类都像筛子一样密密麻麻地洒在整条数轴上；然后用选择公理从每个等价类里挑一个代表元，收集起来。

这个 V 集合，你会惊奇地发现：它无法被赋予任何长度。假设它有长度 ℓ：把 V 平移一个有理数 q 得到 V+q，长度应该不变（还是 ℓ）。可 0 到 1 之间能用可数个这样的平移把整个 [0,1] 盖住，同时每个平移彼此不相交——于是"所有 V+q 的总长"既要把 [0,1] 全部盖住（总长 ≥ 1），又不超过 [−1,2]（总长 ≤ 3）。可数个 ℓ 相加要么是 0（若 ℓ=0），要么是无穷（若 ℓ>0），永远落不进 [1,3]。矛盾。

这就是测度论要回答的问题：不是所有集合都能量出长度。有些集合（Vitali 集）想量，就会算出矛盾。于是我们必须划清界限：哪些集合"配"有长度？以及如何给"长度、面积、体积、概率"立一套统一、永不打架的规矩？这就是测度论。只想懂核心思想，看到本课〇和第三节即可。

一、起点：区间有长度——把"长度"推广到更多集合

我们有的素材是：每个区间 I=[a,b] 有长度 |I|=b−a。要从这个素材出发，推算出任何"长得还行"的集合的长度。想让"长度"像真长度，至少得满足几条不证自明的要求：

  • 平移不变：整个集合挪一个位置，长度不变（λ(A+t)=λ(A)）。
  • 单调：大集合长度 ≥ 小集合长度。
  • 可数可加：可数多个互不相交的集合，总长度等于各自长度之和（两个不重叠的区间拼起来，长度当然相加）。

Vitali 的例子已经宣告：这三条加上"所有集合都能量"，四条同时成立会打架。所以必须牺牲一条。最自然的牺牲是"所有集合都能量"——我们只给一部分集合（叫可测集）定义长度，其余的不碰。这就是 Lebesgue 测度的思路。

先看第一条能用素材直接得出的结论——"太稀疏"的集合长度是 0：

命题（可数集测度为 0）。任何可数集合（如 ℚ、ℤ、有限集）的 Lebesgue 测度为 0。

例 1（一步步算：ℚ∩[0,1] 的长度 = 0）。把 ℚ∩[0,1] 的数排成序列 r₁, r₂, r₃, …（可数）。对每个 rₙ，用一个小区间 Iₙ 把它盖住，Iₙ 的长度取 ε/2ⁿ（随便给一个很小的 ε）。这些小区间的总长度：

由于 ℚ∩[0,1] ⊂ ∪ₙ Iₙ，它的长度至多是 ε。而 ε 可以取任意小（1/2、1/100、10⁻⁹…），所以它的长度只能是 0。∎ 方法的名字叫"用一串任意小的盖子去盖"——这正是外测度的雏形，下一节严格化。

先记一个惊人对比：[0,1] 里的有理数长度是 0（可数），[0,1] 里的无理数长度是 1（补集）；Cantor 集（见例 4）不可数，但长度也是 0。所以"不可数"和"有长度"毫不相干——测度论度量的是集合的"占据度"，不是"个数"。

二、外测度：先给"每一个集合"发一个候选长度

例 1 的做法值得推广：用可数多个区间盖住集合 A，把"盖子总长度"的下确界当作 A 的候选长度。盖子的选择自由，谁盖得越省，越接近真实长度。

这个 m* 对所有集合 A 都有定义（可能是 ∞）。它能自动满足：单调性（A⊂B ⇒ m*A ≤ m*B）、次可数可加（m*(∪Aₙ) ≤ Σm*Aₙ，因为可以把各自的最优盖子拼起来，略微加宽一点）。它也自动满足平移不变性（把盖子一起平移即可）。

听起来一切完美，那问题出在哪？出在可数可加性。m* 只保证"次"可加（≤），不保证"等号"。Vitali 集正是让可数可加性翻车的集合：可数可加性若对所有集合成立，V 的所有平移加起来就该等于 1~3 之间的某个数，但它等于 0 或 ∞——矛盾。所以外测度只能当作"候选"，还要再挑出一批集合，让 m* 限制在它们身上真的可数可加。

例 2（外测度的计算：m*(ℚ∩[0,1])=0）。就是例 1 换一个词：对任意 ε>0 构造总长 ε 的覆盖，故 m* ≤ ε，令 ε→0 得 m*=0。∎

例 3（外测度区间吻合：m*([0,1])=1）。 ① 下界：对任何覆盖 ∪Iₙ ⊃ [0,1]，由有限覆盖与区间长度次可加可证 Σ|Iₙ| ≥ 1，故 m* ≥ 1。② 上界：用单个区间 (0−ε, 1+ε) 就能盖住，总长 1+2ε，令 ε→0 得 m* ≤ 1。合起来 m*([0,1])=1。∎ 这是"外测度没有辜负区间长度"的基本验证。

三、σ-代数：为什么可测集合要"关起门来"，不能要所有集合？

先回答一个最常被问的问题：为什么用 σ-代数，而不是"干脆所有集合"？答：因为测度必须有可数可加性，而可数可加性会强迫一些集合不可测（Vitali 已经证明）。数学家的选择是：把"能放心量的集合"关进一个遵守纪律的家族，家族要足够大、足够封闭，让可数可加性成立且不再打架。

这个家族需要具备的性质，全部来自"测度要能算"的自然要求：

  • 整个空间要能量（X∈𝓜）；
  • 能量的集合取补集也要能量（A∈𝓜 ⇒ Aᶜ∈𝓜，否则 λ(A)+λ(Aᶜ)=λ([0,1])=1 无从谈起）；
  • 可数多个能量的集合的并也要能量（∪ₙAₙ∈𝓜，否则可数可加性没地方使）。

定义（σ-代数）。满足上述三条（含可数并封闭，因此也含可数交、差集）的集族 𝓜 叫 σ-代数。由开区间生成的 σ-代数叫 Borel σ-代数 𝓑，其成员叫 Borel 集。Lebesgue 要做的，是把 Borel σ-代数再放大一点（吸收零测集的所有子集），得到 Lebesgue σ-代数——它"大"到包含你能想到的一切正常集合，又"小"到躲开 Vitali 的陷阱。

为什么 σ-代数：测度要在"并、交、补、可数极限"这些操作下保持可用，就需要一个在这些操作下封闭的集合家族。Vitali 告诉我们的正是：这个家族不能是全集合（否则矛盾），但可以是"几乎全"的 σ-代数。

直觉：A 是"一把干净的刀"，无论切哪块"肉" E，切出来的两半长度恰好等于整块的长度——A 不会"藏"任何质量，不会让外测度的加性吃亏。反过来，Vitali 集是"脏刀"：用 (0,1) 去切它，两半总长和跟整块对不上。

例 5（可测性判断）。判断几个集合是否可测：ℚ∩[0,1] 可测且测度 0（可数）；Cantor 集可测且测度 0（例 4，它是紧致完备集）；Vitali 集 V 不可测；V∪{π} 不可测（否则减掉单点 {π} 得 V 可测，矛盾）；V∩C 可测且测度 0——因为它是零测集 C 的子集，而 Lebesgue 测度完备（零测集的子集都可测），这正是 Lebesgue σ-代数比 Borel σ-代数大的原因。

为什么 Carathéodory 判据真的能把外测度变成测度？这是本课最重的一步，标准证明（Carathéodory 延拓定理）分五步：① 外测度（已做）；② 可测性判据（已做）；③ 可测集构成 σ-代数且 m* 限制在其上是完备测度（Carathéodory 引理）；④ 原来的代数 𝒜 里的集合都可测；⑤ σ-有限保证唯一性。完整证明见附：定理证明一节，它同时构造出 Lebesgue、Hausdorff、乘积等一切标准测度。

五、可测函数与 Lebesgue 积分——测出来之后怎么"用"

有了"能测量的集合"，下一步是"能测量的函数"——可测函数。直觉：一个函数 f 如果能被我们量出来的集合"描述"，它就可测。严格说：对任何实数区间，f 的原像（那些 x 使得 f(x) 落在区间里）必须是可测集。为什么几乎所有函数都可测？因为连续函数、逐点极限的连续函数（Baire 类）、取正负部、取极限——这些操作都保持可测性，所以实际中遇到的函数几乎都可测。

六、收敛定理的完整谱系——MCT→Fatou→DCT→Egorov→Lusin

横切积分最大的红利是：极限与积分在极宽松的条件下可以交换。三条主力定理，称为"三级阶梯"：

  • 单调收敛定理 (MCT)：0 ≤ fₙ ↗ f ⇒ ∫fₙ ↗ ∫f。要求单调，不要求任何控制。
  • Fatou 引理：∫liminf fₙ ≤ liminf ∫fₙ。要求非负，只给不等号。
  • 控制收敛定理 (DCT)：|fₙ| ≤ g∈L¹ 且 fₙ → f a.e. ⇒ ∫fₙ → ∫f。用一块"可积的布"罩住所有 fₙ。

为什么需要这么多收敛概念？因为在无穷世界里"收敛"有太多含义，它们捕捉的侧面不同：依测度收敛看"集合"（测度大的集合上离得近），a.e. 收敛看"点"（每个点最终都靠近，允许零测集上的点捣乱），Lᵖ 收敛看"大小"（整体能量差趋于 0）。这三个互不蕴含，必须各有名字。它们的层次（蕴含方向）：

  • 强 Lᵖ 收敛 ⇒ 依测度收敛（Chebyshev 不等式）；
  • 有限测度空间上 λ-a.e. 收敛 ⇒ 依测度收敛（Egorov 的推论）；
  • 依测度收敛 ⇒ 存在子列 λ-a.e. 收敛；
  • 弱 Lᵖ 收敛与依测度收敛互不蕴含（如 fₙ(x)=e^{inx} 弱收敛于 0 却不依测度收敛）。

还有两条"把抽象测度拉回经典分析"的闭合回路：Egorov 定理（有限测度上 a.e. 收敛 ⇒ 在任意小测度的集合外一致收敛）与 Lusin 定理（可测函数"几乎连续"：对任意 ε>0 存在闭集 F 使 λ(ℝⁿ∖F)<ε 且 f 在 F 上连续）。

例 8（一步步算：Fatou 的不等号为什么取不到等号）。设 fₙ(x) = n·1_{(0,1/n)}(x)。对任意固定的 x>0，当 n > 1/x 时 x∉(0,1/n)，故 fₙ(x)=0，所以逐点 fₙ → 0，∫liminf fₙ = 0。但

于是 0 = ∫liminf fₙ ≤ liminf ∫fₙ = 1，严格不等号。为什么 Fatou 拿不到等号？因为质量"逃逸"了：fₙ 的峰越来越高（n）、越来越窄（1/n），峰的面积恒为 1，但峰尖不断跑向 x=0 这个单点，把质量"漏"进了极限函数的缝隙里。这正是"极限与积分不交换"的机制，也是 DCT 要防的事故。∎

例 9（一步步算：用 DCT 求极限）。计算 L = lim∫₀¹ (1−x/n)ⁿ dx。

① 逐点极限：对每个固定的 x∈(0,1]，(1−x/n)ⁿ → e⁻ˣ（基本极限）。

② 找控制：利用 e⁻ᵘ ≥ 1−u（u≥0），有 (1−x/n)ⁿ ≤ e⁻ˣ ≤ 1，故被 1∈L¹[0,1] 控制。✓

③ 用 DCT 交换：L = ∫₀¹ lim(1−x/n)ⁿ dx = ∫₀¹ e⁻ˣ dx = 1−e⁻¹。∎

三步走——"求逐点极限 → 找 L¹ 控制 → 交换"——是 DCT 的看家套路。

七、乘积测度与 Fubini-Tonelli

为什么 σ-有限性不可或缺？没有它，累次积分可以差很多。经典例子：取 X=Y=[0,1]，对角集上的非平凡测度会造成"先积 x 得 1，先积 y 得 0"的荒唐局面。σ-有限保证每个乘积测度能被可数块"有限矩形"拼出来，交换才安全。

例 10（一步步算：换序积分的算到底）。令 f(x,y) = e⁻ʸ·1_{0≤x≤y} 在 (0,∞)² 上，f≥0，用 Tonelli 两个方向都算一遍：

  • 先积 x：对固定 y，f 在 0<x<y 上等于 e⁻ʸ，宽 y，故 ∫₀^∞ f(x,y)dx = y e⁻ʸ。再积 y：∫₀^∞ y e⁻ʸ dy = [−y e⁻ʸ]₀^∞ + ∫₀^∞ e⁻ʸ dy = 0+1 = 1（分部积分）。
  • 先积 y：对固定 x，f 在 y>x 上等于 e⁻ʸ，∫ₓ^∞ e⁻ʸ dy = e⁻ˣ。再积 x：∫₀^∞ e⁻ˣ dx = 1。

两个方向都得到 1。∎ 这个 f 定义的区域是 y 轴上方的等腰直角三角形（斜边 y=x），换序时区域从"竖切"变"横切"，但面积不变——Tonelli 保证这点永远成立。

Kolmogorov 延拓定理：相容的有限维分布在 ℝ^T 上唯一确定测度 → 无穷乘积空间上的概率测度。这是随机过程理论的数学基石——Wiener 测度（Brownian 运动）、Poisson 随机测度均由此构造。

九、两条通向一般测度的路：Carathéodory 框架与 Riesz 表示

Lebesgue 测度只是一切的样板，两条更一般的生产线已经建好：

第一条：Carathéodory 构造（"盖盖子"路线）。任意集合 X 上，只要先给代数 𝒜 上的 σ-有限预测度 μ₀，就能依"外测度 → 可测性判据 → σ-代数"的标准流程得到 σ(𝒜) 上的唯一测度。Lebesgue 测度、Hausdorff 测度、乘积测度都是这个模板的特例。

第二条：Riesz 表示定理（"期望算子"路线）。紧致 Hausdorff 空间 X 上的正线性泛函，一一对应正则 Borel 测度：测度 = 线性泛函。这是泛函分析到测度论的桥梁——每个"期望算子"对应一个概率测度；Lebesgue 积分的泛函分析版本叫 Daniell 积分。

两者在局部紧 Hausdorff 空间上汇合：Radon 测度 = 在每个紧致集上有限的正 Borel 测度，且 Riesz 表示在该设定下成立（正线性泛函 ⟺ Radon 测度）。这是概率论（CDF 对应 Stieltjes 测度）和表示论（Haar 测度）的基础。

1. 外测度的几何意义。计算 m*((0,1))、m*([0,1])、m*((0,1)∪{2})，并解释它们为什么符合直觉。

2. 平移不变与可测性。证明：若 A 可测，则 A+q 可测且测度相同。

提示：外测度平移不变（把最优盖子整体平移即可验证 m*(E+q)=m*(E)），再用可测性判据：验证 m*(F)=m*(F∩(A+q))+m*(F∩(A+q)ᶜ) 时，把 F 整体平移 −q 化归到 A 的可测性。

3. 简单函数逼近。把 f(x)=x² 在 [0,1] 上切成 n 层（值域分层），写出对应简单函数 sₙ，并用 MCT 求 ∫₀¹ x² dx。

提示：第 k 层集合 {x : x²∈[k/n,(k+1)/n)} = [√(k/n), √((k+1)/n))，测度 = √((k+1)/n)−√(k/n)。对 sₙ 积分并对 n 求和——或更省事：既然分层集合的测度能算，可用黎曼-斯蒂尔杰斯/直接代入，或直接用"横切"思想验证答案 1/3。若分层求和繁琐，可换用单调逼近 1_{[0,1]}·x² 的上台阶，等价于 1/3。

提示：例 8 的"质量逃逸"就是答案——fₙ = n·1_{(0,1/n)} 让 ∫lim = 0 而 ∫ 恒为 1。换个方向让质量"从无到有"（比如移动的峰），结论对称。

5. DCT 的失败。设 fₙ(x)=n²·1_{[0,1/n]}(x)。说明为什么 DCT 不适用，并分别求 ∫lim fₙ 与 lim∫fₙ。

提示：∫lim = 0（每个点最终被甩出支撑）；∫fₙ = n²·(1/n)=n→∞。supₙ fₙ 无处有界，L¹ 控制函数不存在——DCT 前提被破坏，这正是"交换有代价"的示范。

6. Fubini 的边界。f(x,y)=e⁻ˣʸ·1_{0<x<y<∞} 非负。用 Tonelli 换序并求积分。

提示：先积 x：∫₀^y e⁻ˣʸ dx = (1−e⁻ʸ²)/y，于是积分为 ∫₀^∞ (1−e⁻ʸ²)/y dy——这个发散的比值提示：该函数在乘积空间上可能不可积（∫∫ = ∞），此时 Tonelli 仍成立（等式，两边都 ∞）。若要有限例子，把区域换成 x<y<1 试算。

7. 为什么 σ-代数而不是代数？把"可数并封闭"换成"有限并封闭"（即只要求代数），Vitali 的矛盾还成立吗？

提示：矛盾来自把可数个平移 V+q 拼在一起，这用到可数并。若只对有限并可测，Vitali 论证在有限个平移上不产生矛盾——正因为这样，测度论必须坚持可数（而不是有限）封闭，可数可加性才有意义。

附：反例——Vitali 不可测集与 Banach-Tarski 悖论

构造（Vitali, 1905）。在 [0,1] 上定义等价关系 x~y ⟺ x−y ∈ ℚ。每个等价类都稠密。用选择公理在每个等价类中选一个代表元，收集成集合 V（Vitali 集）。

证明 V 不可测。取可数集 Q = ℚ∩(−1,1)。可数并 {V+q : q∈Q} 互不相交，且

若 V 可测，则由平移不变性 λ(V+q)=λ(V)，测度可数可加给出 1 ≤ Σ_{q∈Q}λ(V) ≤ 3。但该和要么为 0（若 λ(V)=0，与 1≤Σ 矛盾），要么为 ∞（若 λ(V)>0，与 Σ≤3 矛盾）。故 λ(V) 不存在——V 不可测。∎

Banach-Tarski 悖论（陈述）。ℝ³ 中单位球 B 可分解为有限（5 块）互不相交的部分，各部分经刚体运动（平移+旋转）重新拼接后可得到两个与 B 全等的球。它是选择公理的惊人后果：那些"部分"全是不可测集——正因为 Lebesgue 测度无法对全体子集定义，体积才会"翻倍"。反之，若 Lebesgue 测度能延拓到一切子集，该悖论不可能出现。

附：工作题（带解答）

题 1（判断可测性）。设 V 是 [0,1] 中的 Vitali 集，C 是 Cantor 集。判断下列集合是否 Lebesgue 可测；可测的求测度：(a) V；(b) V∪{π}；(c) ℚ∩[0,1]；(d) C；(e) V∩C。

显示解答

(a) 不可测——由构造，若可测则 1 ≤ Σλ(V) ≤ 3 矛盾。(b) 不可测：若 V∪{π} 可测，则 V = (V∪{π})∖{π} 是可测集之差，可测，矛盾。(c) 可测，测度 0——可数集。(d) 可测，测度 0——Cantor 集是紧致完备不可数集且 λ(C)=0（删除区间总长 1）。(e) V∩C 是 Cantor 集（零测集）的子集；Lebesgue 测度完备，故可测，测度 0。注：零测集的所有子集都可测——这正是 Lebesgue σ-代数大于 Borel σ-代数之处。

题 2（MCT）。用单调收敛定理计算 lim∫₀^∞ x·e⁻ˣ·1_{[0,n]}(x) dx，并说明为何可用 MCT。

显示解答

fₙ(x) = x·e⁻ˣ·1_{[0,n]}(x) 非负且 fₙ ↗ x·e⁻ˣ，故 MCT 适用。分部积分：∫₀^∞ x·e⁻ˣ dx = [−xe⁻ˣ]₀^∞ + ∫₀^∞ e⁻ˣ dx = 0 + 1 = 1。因此极限 = 1。

题 3（Fatou 严格性）。设 fₙ = n·1_{(0,1/n)}(x)（μ 为 Lebesgue 测度）。计算 ∫liminf fₙ 与 liminf ∫fₙ，说明 Fatou 引理为何取不到等号。

显示解答

对任意 x>0，当 n>1/x 时 fₙ(x)=0，故 fₙ→0 逐点，∫liminf fₙ = 0。但 ∫fₙ = n·(1/n) = 1，liminf ∫fₙ = 1。严格不等号 0 < 1——Fatou 的下极限性质不能加强为等式，除非附加条件（单调性 MCT 或受控性 DCT）。

题 4（DCT）。计算 lim∫₀¹ (1 − x/n)ⁿ dx，并验证控制条件。

显示解答

由 (1−x/n)ⁿ ≤ e⁻ˣ ≤ 1，被积函数被常函数 1∈L¹[0,1] 控制，DCT 适用。逐点极限 (1−x/n)ⁿ → e⁻ˣ。故原式 = ∫₀¹ e⁻ˣ dx = 1 − e⁻¹。

题 5（极限与积分交换）。设 fₙ(x) = n²·1_{[0,1/n]}(x) 在 (0,1] 上。判断 ∫lim fₙ 与 lim ∫fₙ 是否相等。

显示解答

对任意 x>0，当 n > 1/x 时 x ∉ (0,1/n]，fₙ(x)=0，故 fₙ→0 逐点，∫lim fₙ = 0。但 ∫fₙ = n²·(1/n) = n → ∞。故 lim∫fₙ = ∞ ≠ 0：没有 L¹ 控制函数（supₙ fₙ 无上界），DCT 前提被破坏，极限与积分不可交换。这正是 Fatou 不等号（0 ≤ ∞）的来源。
