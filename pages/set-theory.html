第1章　开场问题：包含所有"不含自己的集合"的集合，存在吗？

集合是什么？1900 年的数学家长这样回答：集合就是"一堆对象"。你可以随意收集：所有奇数是一个集合，所有素数是一个集合，所有"小于 10 的正偶数"是一个集合。只要给出一个条件，就能收集出一批对象——这叫"概括原则"（comprehension）。

看起来无懈可击。直到 1901 年罗素（Russell）问了一个看似恶作剧的问题：如果什么都能收集，那么"所有集合的集合"也是一个集合吗？更狠的是下面这个——

考虑 R = {x : x ∉ x}，即"所有不包含自己的集合"组成的集合。问：R ∈ R 吗？

→ 如果 R ∈ R，那么按 R 的定义（R 的每个成员都不包含自己），R ∉ R——矛盾。
→ 如果 R ∉ R，那么 R 满足定义条件（"不包含自己"），所以 R ∈ R——还是矛盾。

两种假设都爆炸。这就是罗素悖论（理发师悖论的数学版：一个理发师只给"不给自己刮胡子的人"刮胡子，那他给自己刮吗？）。

它摧毁了"随意收集就是集合"的朴素观念。数学必须为"什么是集合"立下严格规则，防止自我指涉爆炸——这直接催生了 1908 年 Zermelo 的公理清单（后经 Fraenkel 补充，成为今天的 ZFC 公理系统）。

所以本课的两大任务很明确：① 学会集合的基本语言和运算（第 2、3 章）；② 回答"ZFC 公理为什么必须存在、为什么是这十条"（第 4 章，教科书式的推演）。

本课路线图：从罗素悖论出发（第 1 章）→ 集合的基本语言（第 2 章）→ 集合的运算（第 3 章）→ ZFC 十条公理的教科书式推演（第 4 章）→ 用集合造数：Von Neumann 自然数（第 5 章）→ 无穷：可数与不可数（第 6 章）→ 连续统假设（第 7 章）→ 选择公理（第 8 章）→ 关键公式与大基数（第 9 章）→ 反例（第 10 章）→ 工作题（第 11 章）。

第2章　集合的基本语言——元素、相等、子集

先把话说清楚。集合（set）就是一些对象的整体，里面的对象叫元素（element）。约定：大写字母表示集合（A, B, C），小写字母表示元素（a, b, c）。

怎么描述一个集合？ 两种方式：

→ 列举法：把元素都写出来，如 A = {1, 2, 3}，B = {红, 蓝, 绿}。
→ 描述法：用规则描述，如 C = {x : x 是小于 10 的正偶数} = {2, 4, 6, 8}。

元素与集合的关系： 1 ∈ A（1 属于 A），5 ∉ A（5 不属于 A）。

两个基本事实：

→ 集合相等：A = B 当且仅当 A 和 B 的元素完全相同（不看顺序、不管重复）。所以 {1,2,3} = {3,1,2} = {1,1,2,3}。
→ 子集：A ⊆ B 表示 A 的每个元素也都是 B 的元素。例如 {1,2} ⊆ {1,2,3}。每个集合都是自己的子集（A ⊆ A），空集是任何集合的子集（∅ ⊆ A）。

例 2.1（一步步算）。 设 A={1,2,3}，B={{1}, {1,2}}，C={x∈A : x 是奇数}={1,3}。
问：1∈A？是。{1}∈B？是——B 的元素本身就是"袋子"{1}。1∈B？不是——B 的元素是 {1} 和 {1,2}，没有"裸的 1"。元素和子集不是一回事：1 ∈ {1,2,3}，但 1 ∉ {{1},{2}}——那里的元素是 {1} 这个"袋子"本身。C⊆A？是，且 C⊊A（真子集）。

例 2.2（描述法变列举法）。 把 {x∈ℤ : −2 ≤ x < 2} 列举出来：−2,−1,0,1。把 {x∈ℤ : x²=1} 列举出来：1 和 −1（两个！别忘了负数）。

试试看 2.1。 {∅, {∅}, {{∅}}} 里有几个元素？

试试看的提示

数"袋子"的数量，不是袋子里的东西。这里有 3 个元素：∅、{∅}、{{∅}}。

第3章　集合的运算——怎么把袋子组合起来

有了集合，还要能组合它们。类比"袋子"最容易理解：

→ 并集 A ∪ B：把两个袋子倒在一起（重复的只留一份）。例：{1,2} ∪ {2,3} = {1,2,3}。相当于"至少属于一个"。
→ 交集 A ∩ B：两个袋子里都有的东西。例：{1,2} ∩ {2,3} = {2}。相当于"同时属于两个"。
→ 差集 A \ B：从 A 里拿走 B 的东西。例：{1,2,3} \ {2} = {1,3}。相当于"属于 A 但不属于 B"。
→ 空集 ∅：什么都没有的集合。例：{1,2} ∩ {3,4} = ∅。
→ 幂集 P(A)：A 的所有子集组成的集合。例：P({1,2}) = {∅, {1}, {2}, {1,2}}，共 4 个元素。一般地，如果 A 有 n 个元素，P(A) 有 2ⁿ 个元素（每个元素"选或不选"两种可能）。

例 3.1（一步步算）。 设 A={1,2,3}，B={2,3,4}。
A∪B={1,2,3,4}（并集，重复只留一份）；A∩B={2,3}；A\B={1}（从 A 里去掉也在 B 里的 2,3）；B\A={4}。注意 A\B ≠ B\A——差集不交换。
再算 P({1})={∅,{1}}，共 2=2¹ 个；P(∅)={∅}，共 1=2⁰ 个。幂集里永远装着空集。

例 3.2（分配律，用具体集合核对）。 取 A={1,2}，B={2,3}，C={1,3}。
左边 A∩(B∪C)：B∪C={1,2,3}，交集={1,2}。
右边 (A∩B)∪(A∩C)：A∩B={2}，A∩C={1}，并集={1,2}。
两边相等。这些律和数的运算很像，还有德摩根律 A \ (B ∪ C) = (A \ B) ∩ (A \ C) 等。这就是集合论也叫"布尔代数"的原因——它和逻辑运算（或、且、非）一一对应。

试试看 3.1。 计算 P({1,2,3}) 的元素个数，并写出其中所有含 2 的子集。

试试看的提示

每个元素"选或不选"，所以总子集数 = 2³ = 8。含 2 的子集：把 2 定下来，其余 {1,3} 各可选可不选，共 2² = 4 个：{2},{1,2},{2,3},{1,2,3}。

第4章　ZFC 公理为什么存在——十条规则的教科书式推演

这一章回答全课最重要的问题：为什么需要公理？为什么恰好是这十条？推演思路如下。我们给自己设定两个必须同时满足的目标——

目标一：杀死罗素悖论（不许"随便收集"）。
目标二：保住数学的全部必需品（自然数、函数、实数……照样造得出来）。

公理就是同时满足这两个目标的"最小规则集"。下面一步步推演，每引入一条公理都说明：它解决哪个问题。

4.1 第一步：只加"分离公理"，就能杀死罗素悖论。 把概括原则（"任意条件都可收集"）削弱为：只能从已有集合里筛——给定集合 A 和性质 φ，存在 {x ∈ A : φ(x)}。这就是分离公理模式。

为什么这能杀死罗素悖论？例 4.1（一步步证）。 对任意集合 A，定义 R_A = {x∈A : x∉x}。断言 R_A ∉ A。
反设 R_A∈A。则 R_A∈R_A ⟺（按定义）R_A∉R_A，矛盾。所以 R_A∉A。∎
也就是说：想造"所有不包含自己的集合"，在分离公理下只能造出"某个已有集合里不包含自己的那些"——而它永远跑不出那个已有集合。"所有集合的集合"根本造不出来，因为要造它需要先有一个装着全部集合的集合 A，而分离公理永远造不出这样的 A。罗素悖论被正规地化解了。

4.2 第二步：没有"原料"，分离公理筛不出东西。 分离公理说"从已有的 A 里筛"，但最初连一个 A 都没有。所以还需要"最初的点火器"：

空集公理： 存在不含任何元素的集合 ∅。这是全部数学的起点。
配对公理： 对任意 x、y，存在 {x,y}。于是能造 {∅}（=1）、{∅,{∅}}（=2）……从空集出发，一层层搭出最初的小集合。
这两条公理的"为什么"：没有空集就没有起点，没有配对就连 {∅} 都造不出来。

4.3 第三步：越造越大，需要"合并"和"更大的"。

并集公理： 给一袋"袋子们"，存在它们所有元素的并集。为什么需要：我们要造自然数全集 {0,1,2,3,…}，它得是 0,1,2,3,… 的并——这需要一条公理保证"并"永远合法。

幂集公理： 给定 X，存在 X 的所有子集组成的集合 P(X)。为什么需要：Cantor 证明了 |P(X)| > |X|，幂集是"造出更大无穷"的关键（第 6 章）。没有它，无穷只能停留在一个层级。

4.4 第四步：自然数必须存在。 无穷公理： 存在一个集合包含 ∅，且每当它含 n 就含 n∪{n}——于是它含 0,1,2,3,… 无穷多个。为什么需要：没有这条，只能造出有限集合，数学"破产"。这条同时解决"存在无限集合"和"自然数集合存在"两个问题。

4.5 第五步：函数式的对应要能变成集合。 替换公理模式： 如果有一条规则把 A 的每个元素 a 对应到 b（且对应是"函数的"），那么所有 b 的全体仍是一个集合。为什么需要：比如"把 n 对应到 2ⁿ"、"把每个序数对应到它的后继"，许多构造（超限递归、基数算术）离不开它。

4.6 第六步：外延公理——"相等"的意思。 A = B 当且仅当 A 和 B 的元素完全相同。这条规定"集合相等"，不看形状不看标签。平凡但必要：没有它，连"相等"都没法谈（第 2 章的相等事实就是它在生效）。

4.7 第七步：正则公理——袋子不能自己装自己。 每个非空集合都有一个"最里面的元素"，不会出现 x ∈ x 或无穷嵌套 x ∈ x₁ ∈ x₂ ∈ …。为什么需要：防止"自指"式的病态集合，让"集合的层数"（秩，见第 10 章）总有定义——数学里我们只想和"一层层造出来的"集合打交道。

4.8 第八步：选择公理 AC——唯一"保证存在却给不出构造"的公理。 给一袋非空集合，能从每个里面各挑一个元素组成新集合。为什么需要且为什么有争议，见第 8 章。ZFC 里的 C 就是 Choice（选择）。

ZFC 的精髓一句话：只允许"从已知出发，一步步合法地造"——空集点火，配对、并、幂、分离、替换增长，无穷保底，外延定相等，正则防病态，选择保选择。禁止"凭空收集所有××"。这就是罗素悖论在 ZFC 里不可能出现的原因：那个"自爆的集合"根本造不出来。

试试看 4.2。 为什么"所有集合的集合"在 ZFC 里不存在？

试试看的提示

如果 V 是所有集合的集合，对 V 用分离公理造 R_V={x∈V:x∉x}，用例 4.1 的论证推出 R_V∉V；但 R_V 是集合，所以应该在 V 里——矛盾。故 V 不存在。

第5章　从集合长出数——Von Neumann 的自然数

你可能觉得奇怪："自然数 1,2,3 不是很自然吗，干嘛要从集合造？"——因为集合论要当数学的地基，就得证明"数"这个观念本身也能用集合表达。而且注意：第 4 章的推演已经给我们造数的全部工具（空集、配对、无穷、并）。现在动工：

→ 0 = ∅（空集，"什么都没有"）
→ 1 = {∅} = {0}（一个袋子，装着 0）
→ 2 = {∅, {∅}} = {0, 1}（装着 0 和 1 的袋子）
→ 3 = {0, 1, 2}（装着 0, 1, 2 的袋子）
→ 一般地：n+1 = n ∪ {n}（新数 = 把所有比它小的数装进一个袋子）

例 5.1（一步步算，看透"数字 n 有 n 个元素"）。
0=∅，元素个数 0。
1={∅}，元素个数 1（成员是 0）。
2={∅,{∅}}，元素个数 2（成员是 0 和 1）。
3={∅,{∅},{∅,{∅}}}，元素个数 3（成员是 0,1,2）。
每一步 n 的元素恰好是 {0,1,…,n−1}，所以 数字 n 恰好有 n 个元素。而且数字之间天然有"包含"关系：1 ∈ 2 ∈ 3 ∈ 4，且 1 ⊆ 2 ⊆ 3 ⊆ 4——"小"就是"是前面那些的成员"。

加法和乘法定义好之后，小学学的所有算术规则（1+1=2、乘法交换律）都能从集合公理证明出来——这就是"数学基础"的含义。

试试看 5.1。 写出 4 和 5 的定义（用 n+1=n∪{n}），并数 4 有 4 个元素。

试试看的提示

4=3∪{3}={0,1,2}∪{3}={0,1,2,3}；5=4∪{4}={0,1,2,3,4}。数 4 的元素：0,1,2,3 共 4 个。

第6章　无穷——可数的和不可数的（Cantor 对角线）

集合论真正"炸开"数学的地方，是它严肃对待了无穷。Cantor（1874）问了第一个深刻的问题：所有无穷一样大吗？答案：不是。

可数无穷（ℵ₀）：能跟自然数 N={1,2,3,…} 一一对应的集合。自然数、整数、有理数都是可数的——尽管有理数密密麻麻挤在数轴上，你还是能"排成队"一个一个数完。

不可数无穷（2^ℵ₀）：实数集 ℝ 不能排成队。直觉（Cantor 对角线）：假如把所有 0 到 1 之间的实数排成一列，总能构造一个不在列表里的新数——第 1 位和第 1 个数不同、第 2 位和第 2 个数不同、……这样造出的数，和列表里每一个都不相同。

结论：|N| < |ℝ|。还更进一步：|P(N)| = |ℝ|，且对任何集合 X，|P(X)| > |X|——无穷的层级永无止境（ℵ₀ < 2^ℵ₀ < 2^(2^ℵ₀) < …）。

例 6.1（手工构造对角线新数，一步步）。 假设下面三行是"所有 0-1 串"的前三行：
a₁ = 0.100110…
a₂ = 0.010011…
a₃ = 0.110101…
我们构造 b：取第 1 位 ≠ a₁ 的第 1 位 → b₁=0；取第 2 位 ≠ a₂ 的第 2 位 → b₂=1；取第 3 位 ≠ a₃ 的第 3 位 → b₃=0。得 b=0.010…。对任何 n，b 的第 n 位 ≠ aₙ 的第 n 位，所以 b≠aₙ 对一切 n——b 不在列表里。这就是"对角线"。

严格定理（Cantor 对角线论证）。 对任何集合 X，|P(X)|>|X|。特别地 |ℝ|=2^ℵ₀ 不可数。

证明。 第一步：反设存在满射 f: X→P(X)。第二步：由分离公理模式定义

D 是 X 的子集，故 D∈P(X)。由 f 满射，存在 d∈X 使 f(d)=D。第三步：问"d∈D?"——若 d∈D=f(d)，则由 D 的定义 d∉f(d)=D，矛盾；若 d∉D=f(d)，则由 D 的定义 d∈D，矛盾。两种情况都矛盾，故满射不存在。第四步：存在单射 X→P(X)（x↦{x}）但无满射，故 |P(X)|>|X|。∎

严格化要点： 论证只用分离公理（构造 D）+ 排中律（d∈D 或 d∉D），不依赖选择公理。取 X=ℕ 得 |P(ℕ)|=2^ℵ₀>ℵ₀；由 |ℝ|=2^ℵ₀（二进制小数或 Dedekind 分割）得实数不可数。

试试看 6.1。 证明 {0,1}^ℕ（全体 0-1 无穷串）不可数。

试试看的提示

把例 6.1 的"三行"改成"任意可数多行"：反设枚举 f₀,f₁,f₂,…，构造 g 的第 n 位取 1−f_n(n)，则 g 和每个 f_n 在第 n 位不同。

第7章　连续统假设——无穷之间还有没有"中间层"？

第 6 章知道无穷有大小：|ℕ|=ℵ₀ 和 |ℝ|=2^ℵ₀，且 |ℝ|>|ℕ|。Cantor 接着问：有没有大小介于两者之间的无穷？

连续统假设（CH）说：没有。Cantor 一辈子都在尝试证明它，没有成功。

这件事难在哪？ 通常的做法是：要么证明"存在中间层"，要么证明"不存在"。但 CH 很奇怪——

→ Gödel（1940）证明：在 ZFC 的公理框架内，无法证伪 CH（不存在中间层的设定不会导致矛盾）。
→ Cohen（1963）证明：在 ZFC 内，也无法证明 CH（存在中间层的设定同样不会导致矛盾）。

也就是说：CH 和"它的反面"都能和 ZFC 和平共处——在现有规则下，这个问题既不能证明也不能推翻。这就叫"CH 独立于 ZFC"（independent）。

Cohen 为此发明了 forcing（强迫法）——一种"强行造出更丰富模型"的技术，让"存在中间层"成为可能。这是 20 世纪数理逻辑最伟大的技术发明，Cohen 因此获 1966 年 Fields 奖。

前沿：Woodin 的终极-L 纲领。 Woodin（2010s）提出"Ultimate L"——一个可能包含所有大基数的可构成宇宙。如果成功——连续统假设在 Ultimate L 中为真。这可能是 Gödel 纲领的最终实现。仍开放：Ultimate L 的存在性和唯一性。

连续统假设的"既不能证明也不能否证"是数学里最让人不安的结论之一：它意味着集合论的公理没把问题说死，留下了两种"平行世界"都能成立的空间。

第8章　选择公理——数学基础设施中最有争议的一条

第 4 章的"C"就是选择公理（Choice）：给你一袋非空的集合，你能从每个集合里各挑一个元素，组成一个新集合。听起来理所当然——但仔细想：如果袋子有无限多个、每个又大得没法指明规则，你"怎么选"？

争议的根源：它是唯一一条"保证存在、却不告诉你怎么构造"的公理。它的反面也逻辑自洽（存在不满足 AC 的集合论宇宙），所以数学家分裂成"用 AC"和"拒绝 AC"两派。

用 AC 会得到这些看似"显然"的结果（其实都依赖 AC）：Zorn 引理、良序定理、Tychonoff 定理（任意紧致空间的积紧致）、每个向量空间有基。没有 AC：Hahn-Banach 可能不成立、存在没有基的向量空间。

AC 也有惊人后果：Banach-Tarski 悖论——单位球可以分成五块，仅通过旋转和平移重组成两个大小一样的单位球。这违反物理直觉，但它是"不可测集合存在"的戏剧性展示（那些切出来的块，体积根本没法定义）。

定理（ZF 内）。 下列命题彼此等价：(i) 选择公理 AC；(ii) 良序原理（每个集合可被良序）；(iii) Zorn 引理（偏序集中每个链有上界 ⟹ 有极大元）。

证明概要（三个方向）。

AC ⟹ 良序原理。 设 X 为集合，取选择函数 c: P(X)\{∅}→X（c(A)∈A）。沿序数做超限递归：若 X∖{x_β:β<α}≠∅，令 x_α=c(X∖{x_β:β<α})。由替换公理，过程必在某序数 α₀ 终止（否则全体序数都嵌入 P(X)，矛盾于 Hartogs 数），得良序 (x_β)_{β<α₀}。

良序原理 ⟹ Zorn。 设 (P,≤) 每链有上界。给 P 一个良序，沿良序做超限递归逐步选入元素，保证每步"不被已选元素阻塞"；因链有上界，递归终点给出极大元（否则可继续选）。

Zorn ⟹ AC。 对族 {X_i}_{i∈I}，考察部分选择函数 f（定义域 I′⊆I，f(i)∈X_i），按包含偏序。每链的上界是其并（仍为部分选择函数）。由 Zorn 得极大元 f_max；若定义域≠I，取 i∉dom f_max 并扩展 f_max∪{(i,x)}（x∈X_i）得更大元素，矛盾。故 f_max 是全选择函数。∎

三方向均在 ZF 内可证；"哪一步悄悄用了选择"是分析证明的必备技能。

选择公理是"能选但说不清怎么选"的数学化身。接受它，数学变得好用但偶尔反直觉；拒绝它，数学变干净但很多工具失效。

第9章　关键公式与可测基数

可测基数与大基数层级。 可测基数 = 存在非平凡可数可加的二值测度的基数。存在可测基数 → ZFC 一致但 V≠L（可构成宇宙）。大基数公理构成一致性强度的线性层级——从不达到、可测、到巨大、到 Woodin 基数。每个新的大基数公理"解决"更多独立于 ZFC 的问题。

第10章　反例——不可数集构造与秩函数

反例不是"反面教材"，而是定义和定理的边界线。它们告诉你：哪些直觉在无穷世界里会失效。

反例 1：测度零却不可数。 康托尔三分集 C⊂[0,1]：反复"去掉中段开区间"后剩余。|C|=2^ℵ₀ 不可数，但 Lebesgue 测度为零——打破"大小=测度"的直觉。

反例 2：秩函数的良定义。 冯诺依曼序数 rank(α)=α。一般集合的秩递归定义为

故 rank(∅)=0, rank({∅})=1, rank({ℕ})=ω+1（因 rank(ℕ)=ω）。正则公理（∈ 良基）保证该递归合法——没有正则公理，秩可能无定义，这是秩作为"集合的建造层数"的严格依据。

反例 3：可数性的反直觉。 ℤ、ℚ 均可数（Cantor 之对角线编列给出双射 ℚ→ℕ），尽管 ℚ 在 ℝ 中稠密。可数性依赖"存在双射"而非"几何大小"。

反例 4： 贝尔空间 ℕ^ℕ 与康托尔空间 2^ℕ 均与 ℝ 等势（基数 2^ℵ₀），且 ℕ^ℕ 同胚于无理数空间 ℝ∖ℚ——同基数的不可数集可有完全不同的拓扑结构。

第11章　工作题——判断基数与构造双射（带提示）

工作题 1（判断基数）。 判断基数：(a) {0,1}^*（有限二元串全体）；(b) {0,1}^ℕ；(c) ℤ^ℕ；(d) ℝ^ℕ。

试试看的提示

(a) 有限二元串全体是可数多个有限集的并（第 n 层有 2ⁿ 个串）；(b) 特征函数 ↔ 子集（回忆 P(ℕ)）；(c) ℤ 和 ℕ 一样可数；(d) 用 (b) 和指数律 (2^ℵ₀)^ℵ₀ = 2^(ℵ₀·ℵ₀) = 2^ℵ₀。

显示解答

(a) 可数：{0,1}^* = ∪_n {0,1}^n，可数并仍可数，基数 ℵ₀。
(b) 连续统：{0,1}^ℕ 与 P(ℕ) 双射（子集↔特征函数），基数 2^ℵ₀。
(c) 连续统：ℤ^ℕ ≅ ℕ^ℕ ≅ 2^ℵ₀（二进制编码/对角线），基数 2^ℵ₀。
(d) 仍为 2^ℵ₀：ℝ^ℕ ≅ (2^ℵ₀)^ℵ₀ = 2^(ℵ₀·ℵ₀) = 2^ℵ₀。

工作题 2（构造双射）。 构造显式双射：(a) ℚ→ℕ；(b) (0,1)→ℝ；(c) ℕ×ℕ→ℕ。

试试看的提示

(a) 按"分子分母绝对值之和"分层，每层内编号，只取既约分数；(b) 想想哪个函数把 (0,1) 映满全实轴——正切；(c) Cantor 配对函数：按 m+n 分层、同层按 m 递增。

显示解答

(a) 按"分子分母绝对值之和"分层，每层内按序编号，只取既约分数，逐层不重复地编完所有有理数。
(b) f(x)=tan(π(x−1/2))：把 (0,1) 拉伸到 (−π/2,π/2) 再由正切映到 ℝ，双射。
(c) Cantor 配对函数 p(m,n)=(m+n)(m+n+1)/2+m：按 m+n 逐层、同层按 m 递增编号，是 ℕ×ℕ→ℕ 的双射。

工作题 3（对角线变体）。 用对角线法证明：不存在从 ℕ 到 {f:ℕ→{0,1}} 的满射。

试试看的提示

反设枚举 f₀,f₁,f₂,…。构造 g(n)=1−f_n(n)。g 和每个 f_n 在第 n 位都不同。

显示解答

反设 f₀,f₁,f₂,… 枚举了全部 {0,1}-值函数。构造 g(n)=1−f_n(n)（翻转第 n 个函数在 n 处的值）。g 是 {0,1}-值函数，但对每个 n 有 g(n)≠f_n(n)，故 g≠f_n 对一切 n——g 不在枚举中，矛盾。此"翻转对角线"是 Cantor 法的标准变体。

关键论文

  • Cantor (1874/1895)：基数与超穷集合论（对角线、幂集）——集合论开端。
  • Zermelo (1904/1908)：选择公理与公理化集合论（Z）。
  • Fraenkel–Skolem (1922)：替换公理与 ZFC 成型。
  • Gödel (1938) / Cohen (1963)：CH 的一致性与独立性（→ 本库力迫课）。
  • 教材：Jech, Set Theory；Kunen, Set Theory。

关联课程

→ 实分析：集合的基数和序型为分析学提供了严格的基础——实数构造（Dedekind分割、Cauchy序列）都建立在集合论之上，不可数性和测度论直接相通。

→ Gödel 不完备：连续统假设的独立性直接启发了不完备性证明的方向——Gödel证明了CH不能从ZFC被否证，Cohen用forcing法证明了CH也不能被证明。

→ 证明论：Gentzen用序数分析证明了PA的一致性——序数是集合论的核心概念，而证明论正是将"证明"本身作为数学对象来研究。

→ 伴随函子：集合范畴Set是范畴论的逻辑基础——Yoneda引理、极限和余极限、Topos理论都从Set出发做范畴化推广。
