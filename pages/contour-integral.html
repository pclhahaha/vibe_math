〇、一个具体的问题——绕单位圆走一圈，∫ 1/z dz 为什么等于 2πi？

先不谈任何抽象理论。给你一个能直接动手算的积分：函数 f(z) = 1/z，沿着单位圆 |z| = 1 逆时针走完整的一整圈。我们把"沿着闭合曲线 γ 的积分"记作 ∮γ f(z) dz，读作"围道积分"。

一个闭合路径积分居然可以等于 2πi 而非零——这是复分析全部魔力的起点。接下来我们把这个 2πi 彻底搞清楚，再让它长成一套强大的计算方法。

一、先把工具造好：复平面上的"路径积分"怎么定义？

为了确认上一节的 2πi 不是巧合，先给"沿着曲线的积分"一个严格定义。回忆实数里的黎曼积分：把区间 [a, b] 切成 n 个小区间，在每个小区间里挑一个代表点 xi*，把"代表高度 × 小区间宽度" f(xi*)·Δxi 累加，再令 n → ∞ 取极限，得到 ∫ab f(x) dx。复平面上的路径积分是同一个想法，只多了两个差别：

差别一：路径是一条曲线 γ，不是直线。复平面（横轴为实部、纵轴为虚部）是二维的，"从 A 到 B"有无穷多条路：直线、半圆、任意弯弯曲曲的路线。我们给曲线一个参数化 z(t)（t 从 α 到 β），它描述每一步落在哪个点。

差别二：每一步 Δz 是一个复数。它既带大小（这一步走了多长）也带方向（往哪个方向走）。于是每一步 f(zi)·Δzi 都是复数，累加后整体仍是复数：

实践中的等价定义（更重要）。把 z = z(t) 代入，dz = z′(t) dt，围道积分就变成一个普通的一元积分：

这一行是一切围道积分手算的入口——上一节我们正是用它（z(t) = eit，z′(t) = ieit）算出 2πi 的。

两个立即的推论（整章都要用）。（1）若把 γ 反向走（倒着走），积分变号：因为 z′(t) 变成 −z′(t)。（2）若把 γ 首尾相接分成 γ₁ 与 γ₂ 两段，积分等于两段积分之和：∫ = ∫γ₁ + ∫γ₂。这两条让"把一条大曲线拆成几段算"永远合法。

围道积分的"干活版定义"就一句：把 z = z(t) 代进去，∫_γ f dz = ∫ f(z(t)) z′(t) dt。后面所有手算都从这一行开始。

三、为什么闭合积分可以不等于 0？——原函数、多值性与"绕圈数"

数学里最老实的工具是原函数：如果存在 F 使 F′ = f，那么沿着任意曲线（不闭合也成立）

于是闭合路径（终点 = 起点）的积分自动等于 0。这就是"闭合积分归零"的唯一机制。反过来：闭合积分不归零，说明被积函数找不到单值原函数。

现在看 1/z。它的"原函数"是 log z。问题是：log z 在复平面上绕一圈会怎样？

对 z = Reit，log z = log R + it。当 t 从 0 转到 2π，z 回到了原来的点，但 log z 的虚部从 0 长到了 2πi——没有回到原来的值。这正是 ∮ dz/z = 2πi 的来历：

换句话说：1/z 绕一圈的积分，等于 log z 绕一圈时虚部的总增量 2πi。多绕一圈就再多贡献 2πi，于是

这个整数圈数有正式名字，叫卷绕数（winding number），记 ind(γ, 0)。它回答"闭合曲线把 0 包在中心转了几圈"。而"log z 多值"这件事，正是一切"闭合不归零"的总根源——奇点的存在，破坏了原函数的单值性。

把一个点换成任意点 a。同理，1/(z−a) 绕 a 转一圈也是 2πi。若奇点处不只是 1/(z−a)，而是 c·1/(z−a)（c 为某个数），绕一圈就留下 2πi·c。这个 c 就是后文的留数。

闭合积分 ≠ 0 的唯一原因：圈内藏着"奇点"，使被积函数没有单值原函数。绕一圈，每个奇点贡献 2πi × 卷绕数 × 它的"强度"。

四、Cauchy 积分定理——圈里没有奇点：绕一圈等于 0

第三节给了我们一把尺子：只要圈内没有奇点（函数处处全纯，处处有单值原函数），闭合积分就必然是 0。这正是复分析的第一条奇迹定理：

定理（Cauchy 积分定理）。设 f 在单连通区域 Ω（像圆盘那样没有洞、任意闭合曲线都能缩成一个点）上全纯，γ 是 Ω 内任意闭合可求长曲线，则

为什么直觉上必然如此？在单连通区域里，任何闭合曲线都能"缩成一个点"；收缩全程不撞上奇点（全纯），积分可以一路变形而数值不变；缩成一点后积分自然是 0。等价的说法是：单连通区域内全纯函数必有单值原函数 F(z) = ∫z₀z f(ζ) dζ，于是闭合积分 = F(终点) − F(起点) = 0。

这在实数里没有对应物。实函数的线积分一般依赖路径、一般不为零。复数里"全纯"这个条件强大到让积分的几何形状无关紧要——同一起点终点，走什么形状都一样；闭合了就必然归零。这是全纯函数"刚性"的第一个信号。

Cauchy 定理等价于：单连通区域内全纯函数有原函数。它把"积分与路径形状无关"变成精确的定理——为后面"绕奇点提取信息"铺好了路。严格的 Goursat 证明见文末附一。

六、留数——为什么"绕一圈"只在乎奇点处的一个系数？

Cauchy 积分公式只能处理 f(z)/(z−a) 这种"恰好一个 1/(z−a) 因子"的形式。更一般的问题是：f 在奇点附近可以任意复杂（既有 1/(z−a)²、1/(z−a)³ 这种负幂项，也有无数正幂项），绕一圈到底剩什么？

答案：只剩 1/(z−a) 的系数。原因我们已经在例题 1 见过了——只有 1/(z−a) 绕一圈不归零。

把 f 在奇点附近"摊开"：Laurent 展开。在全纯点附近函数能展开成幂级数（全是正幂项）；在孤立奇点 a 附近，展开成"负幂项 + 正幂项"的双边级数：

例如 e1/z = 1 + 1/z + 1/(2!z²) + 1/(3!z³) + ⋯，围绕 z = 0 有无穷多负幂项——这类奇点叫本性奇点。

绕一圈后逐项只剩 c₋₁。用单条积分公式 ∮ (z−a)ⁿ dz = 2πi·δn,−1（例题 1）：

正幂项（n ≥ 0）有原函数、归零；负幂项 n ≤ −2 也有原函数、归零；唯独 n = −1 的系数 c₋₁ 乘以 2πi 幸存。

这个 c₋₁ 就叫留数（residue），记 Res(f, a)：

为什么留数只关心奇点？因为"非奇点部分"——Laurent 展开里所有 n ≥ 0 与 n ≤ −2 的项——在任意闭合曲线上积分恒为 0：它们都能写成某个函数的导数，绕一圈回到起点自动抵消。于是圈里没有奇点时整个积分是 0（Cauchy 定理）；圈里每藏一个奇点，就多出一条 2πi·Res 的账。复杂的曲线积分，就这样被压缩成"数几个点、各记一个数"。

留数定理的美妙之处：把整个围道积分化为求几个点的数——积分变成了"在奇点处求导数的极限"。

检验。取 a → ∞：被积函数 ≈ 1/a，积分 ≈ 2π/a；公式 2π/√(a²−1) ≈ 2π/a，吻合。✓ 取 a = 1：被积函数在 θ = π 处发散，公式中 a²−1 → 0 也发散，方向一致。

附一：Cauchy 积分定理（Goursat 定理）——完整证明

定理（Goursat，1900）。设 f 在开集 Ω ⊂ ℂ 上全纯（复可微，不假设 f′ 连续），γ 是 Ω 内可求长的闭曲线，则

证明分三层。

① 三角形版本（Goursat）。若 f 在三角形 T 上全纯，则 ∮_{∂T} f dz = 0。思路：四等分 T，取使积分模最大的子三角形 T₁（此时 ∮_{∂T} f dz = 4·∮_{∂T₁} f dz），递归得到三角形序列收缩到一点 z₀。由全纯性 f(z) = f(z₀) + f′(z₀)(z − z₀) + ε(z)(z − z₀)，其中 ε(z) → 0。常数项与线性项的围道积分均为 0（∮ dz = 0、∮ z dz = 0），剩余项随三角形周长缩小而任意小，趋于 0。故原积分为 0。

② 同伦版本。由三角形结果推出 f 在凸域上有原函数（F(z) = ∫ f(ζ) dζ 良定义且 F′ = f），进而"同伦形变的闭曲线围道积分不变"——两条同伦曲线围成的带状区域可分成小三角形，边界的公共部分互相抵消，因此积分之差为零。

③ 一般可求长曲线。用内接多边形逼近 γ，取极限。∎

要点。Goursat 的贡献是删去"f′ 连续"这一多余假设——只要 f 复可微即可。它是全纯函数最纯粹的结构定理，也是后面积分公式与留数定理的基石。

附三：高阶极点：留数的极限公式

若 f 在 a 有 m 阶极点（m ≥ 1），即 (z−a)^m f(z) 在 a 解析且非零，则

证明。设 g(z) = (z−a)^m f(z) = Σ_{k=0}^{∞} b_k (z−a)^k 在 a 解析（b₀ = g(a) ≠ 0）。则 f(z) = Σ_k b_k (z−a)^{k−m}。Res(f, a) 是 (z−a)^{−1} 的系数，即 k − m = −1 ⟹ k = m − 1 ⟹ Res(f, a) = b_{m−1} = g^{(m−1)}(a)/(m−1)! = 极限公式右边。∎

标准应用与陷阱。① 比值公式：f = P/Q，Q 在 a 有一阶零点（Q′(a) ≠ 0），则 Res(f, a) = P(a)/Q′(a)。② 陷阱：(m−1)! 与求导阶数必须严格对应——常见错误是误用 m 阶导数（丢掉因子）。③ 例：f(z) = 1/(z²+1)²，a = i，m = 2：Res(f, i) = lim_{z→i} d/dz[1/(z+i)²] = −2/(2i)³ = −2/(−8i) = 1/(4i) = −i/4。

附四：Jordan 引理——衰减与振荡的分离（完整证明）

Jordan 引理。设 f 在上半平面 Im z ≥ 0 的圆弧 C_R = {z = Re^{iθ}: 0 ≤ θ ≤ π} 上满足 f(z) → 0（R → ∞，关于 θ 一致），则对 a > 0：

证明。参数化 z = Re^{iθ}，|e^{iaz}| = e^{−aR sinθ}。于是

用 sinθ ≥ 2θ/π（θ ∈ [0, π/2]）：R∫₀^{π/2} e^{−aR sinθ} dθ ≤ R∫₀^{π/2} e^{−2aRθ/π} dθ = (π/2a)(1 − e^{−aR}) ≤ π/2a。故整个积分 ≤ 2·max|f|·π/2a = π·max|f|/a → 0。∎

要点。① 仅需 f → 0，不需要 R·|f| → 0（强于直接估计）；② 指数因子 e^{iaz} 的振荡与衰减（a > 0）起关键作用——这是处理 ∫ sin x/x、Fourier 变换、Kramers–Kronig 关系时圆弧贡献消失的根本原因；③ 对下半圆（a < 0）改用 e^{−iaz}。

附五：标准反例

反例 1（非单连通区域需多围道/卷绕数）。f(z) = 1/z 在 ℂ ∖ {0} 全纯，但该区域不单连通。绕原点 k 圈的闭曲线给出 ∮ dz/z = 2πi·k ≠ 0——单连通条件不可省。在环带 1 < |z| < 2 中，边界由内外两圆组成，积分等于内圆与外圆积分的差，必须按定向逐段相加。

反例 2（本性奇点 e^{1/z} 的留数）。f(z) = e^{1/z} 在 z = 0 有本性奇点（Laurent 展开含无穷多负幂项）。展开：

留数仍为单个数 c₋₁ = 1，故 ∮_{|z|=1} e^{1/z} dz = 2πi。要点：本性奇点处留数由 Laurent 展开唯一决定，但函数在该奇点附近没有极点行为——它遍历所有复值（Picard 大定理）。

附六：标准反例——本性奇点与无穷远点的留数

反例 1（本性奇点的留数由 Laurent 系数定义，与"函数值"无关）。f(z) = e^{1/z} 在 z = 0 有本性奇点，展开给出 Res(f, 0) = 1（上文已证 ∮_{|z|=1} e^{1/z} dz = 2πi）。但 f 在 0 的任一去心邻域内取到除一个例外外的所有复值（Picard 大定理）——留数 ≠ 函数"留在"该点的值，它只是 Laurent 系数 c₋₁。

反例 2（无穷远点的留数与定向）。把 ℙ¹ = ℂ ∪ {∞} 视为流形，无穷远点的留数定义为

（负号来自换坐标 w = 1/z 的定向反转）。例：f(z) = 1/z ⟹ Res(1/z, ∞) = −Res(w²·(1/w), 0) = −Res(w, 0) = 0；但 ∮_{|z|=R} dz/z = 2πi ≠ 0——∞ 点不在有限区域内部，留数定理必须计及 ∞ 的留数：∮_γ f dz = 2πi·(Σ_有限 Res + Res(f, ∞))。

反例 3（留数为零 ≠ 函数消失）。g(z) = e^{1/z}·(1/z)：Res(g, 0) = 0，但 g 在 0 附近振荡到无穷。留数是复结构对象，不是函数值对象——本性奇点处留数定理仍适用（按 Laurent 系数），但所有正则性结论（有界性、极限）完全失效。

附七：工作题

题 1：用留数定理计算实积分 I = ∫₋∞^∞ dx/(1+x²)。（上半平面半圆围道 + Jordan 引理。）

题 2：求 f(z) = 1/(z²+1)² 在 z = i（二阶极点）处的留数，并计算 ∮_{|z|=2} f(z) dz。

显示解答

题 1：取围道 Γ_R = [−R, R] + 上半圆弧 C_R。f(z) = 1/(z²+1) 在 Im z > 0 内仅有极点 z = i（一阶），Res(f, i) = lim_{z→i} (z−i)/((z−i)(z+i)) = 1/(2i) = −i/2。留数定理：∮ f dz = 2πi·(−i/2) = π。圆弧估计（R > 1）：|f| ≤ 1/(R²−1)，弧长 πR，故 |∫_{C_R} f dz| ≤ πR/(R²−1) → 0。令 R → ∞ 得 ∫₋∞^∞ dx/(1+x²) = π。∎

题 2：二阶极点留数公式：Res(f, i) = lim_{z→i} d/dz[(z−i)²·1/(z²+1)²] = lim_{z→i} d/dz[1/(z+i)²] = lim_{z→i} −2/(z+i)³ = −2/(2i)³ = −2/(−8i) = 1/(4i) = −i/4。圆 |z| = 2 内部含两个奇点 i 与 −i：Res(f, −i) = lim_{z→−i} −2/(z−i)³ = −2/(−2i)³ = −2/(8i) = −1/(4i) = i/4。两留数之和为 0 ⟹ ∮_{|z|=2} f dz = 2πi·0 = 0。（若只取上半平面计算实积分：∫₋∞^∞ dx/(x²+1)² = 2πi·Res(f, i) = 2πi·(−i/4) = π/2。）

附八：工作题——∫ sin x/x 与有理函数积分

题 1：用留数方法计算 I = ∫₋∞^∞ sin x/x dx。给出完整围道构造（含绕 z = 0 的小圆弧处理）与每一步的依据。

题 2：计算 J = ∫₋∞^∞ dx/((x²+a²)(x²+b²))，其中 a, b > 0 且 a ≠ b。

题 3：用锁孔（keyhole）围道证明 ∫₀^∞ x^{s−1}/(1+x) dx = π/sin(πs)，0 < s < 1（留数定理 + 割线）。

显示解答

题 1：取 f(z) = e^{iz}/z。围道 Γ_{R,ε} = [−R, −ε] ∪ [ε, R]（实轴）+ 小半圆 C_ε（上半平面绕 0，顺时针）+ 大半圆 C_R（上半平面）。① 上半平面内 f 全纯（0 被绕开）⟹ ∮ = 0。② 小半圆：f = e^{iz}/z = 1/z + O(1)，C_ε 绕 0 半圈顺时针，∫_{C_ε} dz/z = −πi ⟹ ∫_{C_ε} f dz → −πi·Res(f, 0) = −πi（O(1) 项积分 → 0）。③ 大半圆：Jordan 引理（a = 1，|f| → 0）⟹ 贡献 → 0。④ 总方程：0 = P.V.∫ e^{ix}/x dx − πi ⟹ P.V.∫ e^{ix}/x dx = πi。取虚部：P.V.∫ sin x/x dx = π；因 sin x/x 在 0 可去，P.V. = 普通积分 ⟹ I = π。∎

题 2：上半平面极点为 ia, ib（一阶）。Res(f, ia) = 1/((2ia)(ia−ib)(ia+ib)) = 1/(2ia(b²−a²))；Res(f, ib) = 1/(2ib(a²−b²))。留数定理（上半平面半圆 + Jordan 引理，|f|·R → 0）：J = 2πi[Res(ia) + Res(ib)] = 2πi·[1/(2i(b²−a²))·(1/a − 1/b)] = π/(ab(a+b))。∎

题 3：取 f(z) = z^{s−1}/(1+z)，分支割线沿 [0, ∞)，arg z ∈ (0, 2π)。锁孔围道：大小圆弧 + 割线上、下边。① 大圆弧 |f| ≤ R^{s−1}/(R−1) → 0（s < 1）；小圆弧 ~ ε^{s−1}·ε → 0（s > 0）。② 上下边：上边（arg 0）贡献 ∫_ε^R t^{s−1}/(1+t) dt；下边（arg 2π）从 R 到 ε 贡献 −e^{i2π(s−1)}∫_ε^R t^{s−1}/(1+t) dt。③ 内部唯一极点 z = e^{iπ} = −1，Res(f, −1) = e^{iπ(s−1)}。④ 留数定理（ε→0, R→∞）：(1 − e^{i2π(s−1)})·I = 2πi·e^{iπ(s−1)}。因 e^{i2π(s−1)} = e^{i2πs}，左因子 = −2i·e^{iπs}·sin(πs)，右端 = −2πi·e^{iπs}，解得 I = π/sin(πs)。∎

物理应用——Kramers–Kronig 关系

因果律要求响应函数 χ(ω) 在上半平面全纯——实部和虚部通过 Hilbert 变换关联：Re χ(ω) = (1/π) P ∫ Im χ(ω′)/(ω′−ω) dω′。这是"因果律 = 复平面上半平面全纯性"的物理表达——留数定理在物理学中最优雅的应用之一。

前沿：多重围道积分与费曼积分

多圈费曼积分 = 多重围道积分。Cutkosky 规则（1960）将虚部与物理阈值关联。现代"微分方程方法"（Henn 2013）将费曼积分化简为 Chen 迭代积分的线性组合。仍开放：超越标准模型的五圈计算和椭圆多对数的一般理论。
