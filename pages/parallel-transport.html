〇、具体动机——把箭头从北极搬到赤道再搬回来，它转了多少度？

先不看抽象定义，先看一个带数字的具体问题。拿一个单位球（R = 1），在北极放一支箭头，指向东。现在做三件事：

  • 第 1 步：沿经线把箭头"平移"到赤道上的 A 点（经度 0°）——搬的时候让箭头始终贴住球面、始终与路径保持平行，绝不让它绕自身的轴转。
  • 第 2 步：再沿赤道把它"平移"到 B 点（经度 90°）。
  • 第 3 步：再沿经线把它"平移"回北极。

一路上你都小心翼翼地"平移"，一步都没有让箭头自转。可是回到北极后，箭头却指向了南——相对出发时的"指向东"，整整转了 90° = π/2。

这不是手抖，是几何。这个三角形的内角和是 270°（比平面多 90°），而"多出来的 90°"恰好就是箭头转过的角度。再给两个带数字的判例：

  • 沿赤道绕一整圈：箭头回到起点方向不变，转角 = 0；
  • 沿北纬 60° 的纬圈绕一整圈：转角 = 2π(1 − cos60°) = π = 180°——箭头最后指向反方向。
核心洞察：在弯曲的面上"平移"方向，绕一圈回来后方向会悄悄改变；转了多少度，正好量出这片面弯了多少。这个"搬方向"的规则叫平行移动，转过的角度叫和乐（holonomy）。只想懂核心思想，看到这里就够了。
⚠️ 背景提示：本课属于 核心 级别，正文较深。

建议先掌握：测地线、曲率。

高级章节（证明、前沿、工作题）需要相应背景，未掌握可先看「〇、具体动机」了解核心思想，或回到前置课程补基础。

一、平行移动的直觉——从平桌到球面

在平桌上：把一支箭头从桌角搬到另一个角，你毫不怀疑它"没转向"——因为平面有全局的方向：每个点都可以说"这是北、那是东"。搬的过程就是把同一个方向复制过去。

在球面上：麻烦来了。球面上没有全局方向——北极点的"东"指向所有经线的方向，到了南极点的"东"又变成另一个意思。你想知道"这个点的方向搬到那个点算几个意思"，必须先定一条规则：沿着什么路径、怎么一步一步搬。

为什么需要"一步一步"？ 因为球面没有"两点之间方向怎么平移"的天然答案——搬的方向 取决于路径（〇节已经演示：绕不同圈回到同一点，箭头朝向不同）。所以平行移动只能是"沿一条给定路径、逐点搬运"的局部规则，而不是"一次性把方向搬到远方"。

规则是什么？ 直觉版的规则：搬的时候，箭头永远"贴着面"（不离开切平面），并且与搬运方向的夹角保持不变。在平面上，这条规则退化成普通的平移；在球面上，它给出〇节的 90° 结果。下面把这句直觉写成方程。

为什么在乎这个？ 三件大事都靠它：

  • 微分几何：曲率 = 平行移动绕闭合路径一圈的净旋转 ÷ 所围面积（Gauss-Bonnet 的局部版本，第四节）；
  • 广义相对论：自由落体 = 四维速度沿 Levi-Civita 联络的平行移动；
  • 规范场论：带电粒子 = 其 U(1) 相位沿路径的平行移动——Aharonov-Bohm 效应证明这个"相位搬运"有物理实在性。

四、为什么绕一圈会转角——曲率 = holonomy（小环路定理）

第三节的转角 2π(1−cosθ₀) 不是巧合，它来自一条深刻定理：转过的角 = 曲率积分。为什么？因为平行移动的"偏差"本来就是在度量曲率。

定理（无穷小 holonomy）：设 X, Y ∈ T_pM，取以 p 为顶点、边沿 X 与 Y 方向的小平行四边形（边长 ε，即 exp_p(εX), exp_p(εY) 张成的四边形）。把向量 V 沿此环路平行移动一圈回到 p，所得线性同构为

其中 R 为黎曼曲率张量（约定 R(X,Y)Z = ∇_X∇_YZ − ∇_Y∇_XZ − ∇_{[X,Y]}Z）。

为什么平方项？ 平直空间里平行移动一圈是恒等变换（Id）。弯曲空间里，偏差的首阶出现在 ε²——一阶 ε 项被"绕一圈走回去"抵消掉，剩下的正是 曲率×面积（ε² 即小四边形的面积量级）。这解释了第三节的 2π(1−cosθ₀) 为什么正比于面积：转角的单位是"曲率×面积"。

证明思路（法坐标计算）：取 p 点处的法坐标，使 Γ^k_{ij}(p) = 0。

  • 1. 沿单边移动：平行移动方程 dV/dt = −Γ(x(t))·ẋ·V。因 Γ(p) = 0，沿长为 ε 的边，V 改变量首阶为 ε²（导数 ∂Γ 项）。
  • 2. 四次移动串联：依次沿 εX、εY、−εX、−εY 移动。平行移动沿两条"路径"的差正比于 ∂ⱼΓ − ∂ᵢΓ + ΓΓ 项——这正是 R 的定义（在法坐标中 [X,Y] 项为零，R^k_{\;lij} = ∂ᵢΓ^k_{lj} − ∂ⱼΓ^k_{li} + ΓΓ − ΓΓ）。
  • 3. 展开到 ε²：交叉项合并后得 P_□ = Id + ε²R(X, Y) + O(ε³)。□

即平行移动绕小环路的净旋转角 = 曲率积分 ≈ K·A。这与 Gauss-Bonnet 衔接：把区域分割为无数小环路，周游角相加 = ∫K dA。第三节的纬圈结果就是积出来的：∫_{球冠} (1/R²)dA = (1/R²)·2πR²(1−cosθ₀)。

更一般（Ambrose-Singer 定理局部版）：平行移动沿全部闭合环路产生的变换构成和乐群 Hol_p(M) ⊆ O(T_pM)。其李代数由曲率张量生成——曲率是和乐群的"无穷小生成元"。这正是规范理论中"Wilson 圈 = exp(∮A)"与"场强 F = 曲率"的几何对应：局部曲率决定沿环路的全局相位（holonomy）。

一句话：平行移动为什么绕圈会转角？因为弯曲空间里"往东再往北"和"往北再往东"不是一回事，差多少由曲率 R 决定。曲率是"转角的无穷小版本"，holonomy 是"转角本身"。

转角只取决于"围住了多少曲率"（K×面积），与路径本身的形状无关——这是 holonomy 最反直觉也最有用的性质：路径越绕，转得越多，但多出来的总是"里面的曲率总量"。

七、反例辨析——球面的旋转 vs 圆柱的不旋转

反例 1（球面：绕纬圈一圈后向量旋转）：球面 S²(R)，纬圈 C 位于余纬 θ₀（半径 R sinθ₀），把向量沿 C 平行移动一圈。由"旋转角 = ∫K dA"（K = 1/R² 常数，围成球冠面积 A = 2πR²(1−cosθ₀)）：

赤道（θ₀ = π/2）周游角 = 2π ≡ 0（mod 2π）：向量沿赤道回到起点方向不变——holonomy 平凡。北极附近小圈（θ₀ → 0）周游角 → 0。中间纬圈有非平凡净旋转，旋转角 = K·A。经典表述："沿纬圈平行移动后向量相对初始方向旋转 2πcosθ₀（按 ODE 求解的符号约定），这与 2π(1−cosθ₀) 相差整圈，是同一旋转。"

反例 2（圆柱：曲率为零故无旋转）：圆柱 R²/2π 的度规 ds² = R²dθ² + dz² 与坐标无关，Christoffel 符号全为零，曲率 R = 0。平行移动方程 dV/dt = 0 ⟹ V 的坐标分量不变。沿任何闭合环路（包括绕一整圈回到原点）平行移动 = 恒等，无旋转。几何原因：圆柱可展成平面（等距），平面上平行移动 = 保持方向，而等距保持平行移动 ⟹ 圆柱平行移动同样保持"坐标方向"。这直观验证 K = 0 ⟹ holonomy 平凡。对比第三节：同一个"旋转角 = K×面积"公式，在球面给非零、在圆柱给零——K 是唯一判据。

反例 3（测地三角的净旋转）：球面上取测地三角（三条大圆劣弧），沿边平行移动一个向量回到起点：沿测地线段向量与速度夹角不变（∇_{ẋ}ẋ = 0），但绕完闭合回路后向量相对起点旋转了 A/R²（角盈）。这正是曲率存在的最直接表现——holonomy 不依赖于"路径的曲率"，只依赖于"空间的曲率 × 所围面积"（第六节的完整计算）。

对比总结：球面（K ≠ 0）绕闭合圈有净旋转（正比于所围面积）；圆柱（K = 0）无净旋转。周游角把局部曲率与沿路径的整体效应联系起来，是"局部几何 ⟹ 全局结论"的机制。

八、和乐群——所有闭合回路的净效果

把"绕一条路转多少角"升级成"绕所有可能的路，能产生哪些变换"——这个集合不是杂乱无章，而是一个群。

定义：固定基点 p，把平行移动沿所有以 p 为起点终点的闭合回路得到的变换全体收集起来，构成和乐群 Hol_p(M) ⊆ O(T_pM)（保内积的线性变换群）。它是 O(T_pM) 的一个李子群。Ambrose–Singer 定理说：和乐群的李代数由曲率张量在所有点上的值生成——曲率是"无穷小和乐"，和乐是"曲率的有限版本"。

为什么曲率决定和乐群？ 第四节的小环路定理：任何闭合回路可以切成许多小平行四边形，每个贡献 Id + ε²R，串起来乘积就得到整个 P_γ。反过来，凡是和乐群里的变换都来自曲率的"积累"。所以"和乐平凡 ⟺ 平坦"（K = 0，圆柱），"和乐群由曲率撑大"（K ≠ 0，球面）。

Berger(1955) 分类：紧致单连通黎曼流形的和乐群只有几种可能：

它们分别对应一般黎曼流形、Kähler、Calabi–Yau、超 Kähler、四元 Kähler、G₂（7 维）与 Spin(7)（8 维）流形。这是微分几何中最伟大的分类定理之一：空间的对称类型（和乐群）被限制在极少数名单里，而 Calabi–Yau 流形正是弦论紧化的舞台。

一句话：平行移动绕一圈的转角是小风景（holonomy），绕遍所有圈的变换全体是大格局（和乐群）。曲率是它的"无穷小生成元"，而整幅大格局总共只有七种可能。

1. 为什么沿赤道平行移动向量回到起点方向不变，而沿北纬 60° 的纬圈却转 180°？
提示：转角 = K × 所围面积。赤道围住半球，K·A = (1/R²)(2πR²) = 2π ≡ 0；北纬 60° 围住球冠，面积只有 πR²。差别全在"围住了多少面积"。

2. 在圆锥上平行移动向量绕顶点一圈，会转多少度？
提示：去掉顶点后圆锥可展成平面扇形。展开后"绕顶点一圈"变成"绕扇形顶点 2π(1−sin 半顶角) 角度"；平行移动对应平面上的平移（不转），所以还原回锥面后向量相对起点转了 2π(1−sin 半顶角)。这个角也叫顶点的"集中曲率"。

3. 为什么圆柱没有 holonomy，而圆锥（在顶点处）有？
提示：圆柱处处 K = 0 且无顶点；圆锥去掉顶点后也处处 K = 0，但顶点把曲率"集中"了——绕顶点的圈围住了顶点，就围住了曲率。这呼应《曲率》课里"顶点集中曲率 2π(1−sin半角)"的说法。

前沿：Aharonov-Bohm效应与拓扑量子场论

AB效应证明联络A具有物理实在性——不仅是曲率F的辅助量。这启发了Chern-Simons理论(Schwarz 1978,Witten 1989)——纯拓扑作用量产生物理可观测量。Jones多项式=Chern-Simons的Wilson圈期望值。仍开放:CS理论在4D的推广(Donaldson理论)。

工作题——球面上沿纬圈的平行移动

题 1（直接 ODE 求解）：球面度规 ds² = R²(dθ² + sin²θ dφ²)。写出非零 Christoffel 符号；对纬圈 φ(t) = ωt（θ = θ₀ 常数）写出平行移动方程，解出向量 V(t)，并证明绕一整圈后向量相对初始方向旋转角 = 2π(1 − cosθ₀)（即等于球冠面积，K = 1/R²）。

题 2（两种理解）：用题 1 的解求：(a) 向量与经线单位切向 e_θ 的夹角随时间的变化率；(b) 解释为什么"沿赤道回到原点向量不变，而沿小纬圈有净旋转"。

题 3（Gauss-Bonnet 复核）：由"旋转角 = ∫_球冠 K dA"反推球冠面积 A = 2πR²(1 − cosθ₀)，并用直接积分 A = ∫₀^{θ₀}∫₀^{2π} R² sinθ dφ dθ 核对。

题 4（圆柱对照）：在圆柱 R²/2π 上沿水平圆 θ(t) = ωt（z 固定）平行移动向量 V = (V_θ, V_z)。求 V(t)，证明绕一圈后无旋转，并与题 1 对比说明"曲率为零 ⟹ 无 holonomy"。

显示解答

题 1：非零 Christoffel：Γ^θ_{φφ} = −sinθcosθ，Γ^φ_{θφ} = Γ^φ_{φθ} = cotθ。沿纬圈 ẋ = (0, ω)（θ̇ = 0, φ̇ = ω），平行移动方程分量：
θ 分量：dV^θ/dt − sinθ₀cosθ₀·ω·V^φ = 0 ⟹ dV^θ/dt = ω sinθ₀cosθ₀·V^φ；
φ 分量：dV^φ/dt + cotθ₀·ω·V^θ = 0 ⟹ dV^φ/dt = −ω cotθ₀·V^θ。
合并：d²V^θ/dt² = ω sinθ₀cosθ₀·(−ω cotθ₀ V^θ) = −ω²cos²θ₀·V^θ，故 V^θ(t) = A cos(ωt cosθ₀) + B sin(ωt cosθ₀)，V^φ = (dV^θ/dt)/(ω sinθ₀cosθ₀) = (−A sin(ωt cosθ₀) + B cos(ωt cosθ₀))/sinθ₀。初值 V(0) = (1, 0)：A = 1, B = 0 ⟹ V^θ(t) = cos(ωt cosθ₀)，V^φ(t) = −sin(ωt cosθ₀)/sinθ₀。物理向量 = V^θ e_θ + R sinθ₀·V^φ e_φ = (cos(ωt cosθ₀), −sin(ωt cosθ₀))。绕一圈 T = 2π/ω：向量相对初始方向旋转角 = 2πcosθ₀。由于旋转 mod 2π 意义下 2πcosθ₀ ≡ −(2π(1−cosθ₀))，即净旋转（按面积约定）为 2π(1 − cosθ₀) = K·(球冠面积) ✓。方向与环路取向相关（北半球取逆时针为正）。

题 2：(a) 向量与 e_θ 的夹角 = ωt cosθ₀（线性增长），即向量相对经线方向以角速度 ωcosθ₀ 旋转——每绕一圈相对经线转过 2πcosθ₀。(b) 赤道 θ₀ = π/2：cosθ₀ = 0 ⟹ 旋转角 0，向量恒为 (1, 0)（沿经线），回到起点完全不变 ✓；北极附近 θ₀ → 0：cosθ₀ → 1，向量相对经线每圈转过 2π——向量被"拖着"几乎随纬圈一起转动。这正是"纬度越高，旋转越明显"的几何直觉。

题 3：由题 1，旋转角 = 2π(1 − cosθ₀)；由公式旋转角 = ∫_球冠 K dA = (1/R²)·A，故 A = R²·2π(1 − cosθ₀) = 2πR²(1 − cosθ₀)。直接积分核对：A = ∫₀^{θ₀}∫₀^{2π} R² sinθ dφ dθ = 2πR²(1 − cosθ₀) ✓。两者自洽——"周游角 = K×面积"与球冠面积公式互相印证。

题 4：圆柱联络 Γ = 0，平行移动方程 dV/dt = 0 ⟹ V(t) = V(0) 恒为常数。绕一圈回到原处向量不变，旋转角 = 0。由公式旋转角 = K·A 且 K = 0，自然得 0。对比题 1：同一公式"旋转角 = K·A"在球面给非零、在圆柱给零——K 是唯一判据。这也解释了为何可展曲面（K = 0）上平行移动无 holonomy，而球面（K ≠ 0）上必有净旋转。
