〇、具体动机——一个没解的方程，和一个"画数"的地图

先看一个带数字的具体问题。方程

在实数里没有解：任何实数的平方都是非负的——(−2)² = 4，(0.5)² = 0.25，0² = 0——永远不可能等于 −1。这个"没解"让数学家别扭了几个世纪：明明所有方程都该有解，为什么偏偏这一个例外？

但如果你同意一个大胆的约定——允许一个新数 i，规定 i² = −1——那么 x = i 和 x = −i 立刻就是这个方程的解。一个新数，解锁一个方程。而真正奇妙的事情还在后面：把 i 画在平面上，它的乘法会表现出一种非常具体的几何行为——每乘一次 i，就是把一个点绕原点旋转 90°。于是 i × i = −1 不再是"正负号游戏"，而是"转 90° 再转 90° = 转 180°"。

本课沿着一条教科书式的主线回答两件事：① 复数是什么、怎么算、怎么画（一张叫复平面的地图，一个复数就是地图上的一个点/箭头）；② 为什么"乘以 i 是旋转 90°"，更进一步，为什么神秘的 e^{iθ} 其实就是"旋转 θ 角"——这两件事最终会合并成同一条规则：复数的乘法 = 模相乘 + 角相加。

复数把"旋转"翻译成了"乘法"：乘以一个模长为 1 的复数，就是纯旋转；而 e^{iθ} 正是"旋转 θ 角"的代数符号。如果你想理解核心思想，看到这里就够了。

一、i 是什么？——为"没有解的方程"造一个新数

小学你就知道，任何实数（real number，平时见到的普通数，比如 1、−3、0.5）的平方都不可能是负数：正数乘正数是正数，负数乘负数也是正数，0 的平方是 0。所以方程 x² = −1 在实数里没有解——翻遍所有实数，都找不到一个数，平方之后等于 −1。

数学家不甘心让这个方程永远无解，索性规定一个新数 i，并约定它的平方就是 −1：

规定之后，x² = −1 立刻有了解：x = i 或 x = −i（因为 (−i)² = i² = −1）。i 读作"虚数单位"（imaginary unit），"虚"并不是说它"不存在"，而是说它"不在实数轴上"——它是专门为方程 x² = −1 量身定制的一格新数。

有了 i，就能写出更大的一类数：复数（complex number）。一个复数是"一个普通数加上 i 的若干倍"：

其中 a 叫实部（real part），b 叫虚部（imaginary part）。比如 3+4i 就是一个复数，实部是 3，虚部是 4。当 b=0 时，a+0i = a 就是普通实数——所以实数只是复数的一个特殊情况，复数把实数"装"进了自己里面。

i 是"平方等于 −1"的新数，它让方程 x² = −1 有解；复数是 a+bi 的形式，实数藏在里面（b=0 的时候）。下一节先学怎么算，再学怎么画。

二、复数的加法与乘法——先学会算

有了复数，第一件事是定义运算。规则只有一个宗旨：i 就是一个遵守"i²=−1"的普通代数符号，其余一切照常。

加法：实部加实部、虚部加虚部。

例：(3+4i)+(1+2i) = (3+1)+(4+2)i = 4+6i。加法平凡到有点无聊——但它的几何意义（箭头首尾相接）要到下一节才登场。

乘法：把括号全部乘开，再用 i²=−1 收拾。

注意那个醒目的 −bd：它来自 bdi² = bd·(−1) = −bd。所以复数乘法的结果不是"四个积都相加"，而是实部相减、虚部相加。这个奇怪的结构，正是后面"模相乘、角相加"几何定律的代数种子。

手算一个具体的：(1+2i)(3−i)，一步步来——

（最后一步用 i²=−1：−2i² = −2·(−1) = +2。）结果 5+5i：实部 3+2=5，虚部 −1+6=5。先把代数算顺，几何马上就来。

复数运算的独门诀窍只有一条：i²=−1。乘法展开后，把含 i² 的项换成 −1，实部和虚部分开收拾即可。乘法的公式 (ac−bd)+(ad+bc)i 先背下来，第七节会证明它就是在"模相乘、角相加"。

三、复数怎么画？——一个复数就是一个点，也是一个箭头

一个复数 a+bi 里有两块信息：实部 a 和虚部 b。正好，平面上的一个点也有两个坐标。于是数学家把复数直接画到平面上：

画法很简单：横轴叫实轴（real axis），用来放实部 a；纵轴叫虚轴（imaginary axis），用来放虚部 b。比如复数 3+4i，就在横轴走 3 步、竖轴走 4 步，落在点 (3,4)。

几个特殊位置：实数 1 = 1+0i 在实轴上，即点 (1,0)；虚数单位 i = 0+1i 在虚轴上，即点 (0,1)；0 在原点。也就是说，整条实轴上的点都是实数，整条虚轴上的点都是纯虚数（a=0、b≠0 那种），而平面其余地方全是一般复数。

这张画着复数的平面就叫复平面（complex plane）。把 (a,b) 再向前想一步：它也可以看成从原点指出去的一个箭头——这样，第二节的加法立刻有了图像：

两个箭头首尾相接：从原点出发，先沿 (3,4) 走，再沿 (1,2) 走，到达 (4,6)。这正好是向量加法（平行四边形法则）——坐标分别相加。减法同理，只是方向反过来。于是"代数"和"几何"在第一处成功接头：复数的加减 = 箭头的加减。

复数 a+bi 就是平面上的点 (a,b)，也是从原点指出去的箭头：横轴放实部，竖轴放虚部。加减法就是箭头首尾相接。从此复数有了"图像"，下一节就用它来看乘法——看"乘以 i 为什么是旋转"。

怎么确定这是旋转而不是别的？两件事缺一不可：

① 长度不变。新点到原点的距离 √((−b)²+a²) = √(a²+b²) 和原来一模一样——是旋转，不是缩放。

② 方向转了 90°。两个箭头的内积 a·(−b)+b·a = 0，互相垂直；再看 a=1、b=0 时 (1,0) 落到 (0,1)，方向是逆时针。所以乘 i 就是逆时针转 90°、长度不变。

乘以 i = 逆时针旋转 90°（且不改变长度）。这是复数与旋转的第一次接头，也是第七节"乘法=模乘+角加"的雏形：i 的模长是 1（不缩放），辐角是 90°（转 90°）。

十、全纯映射保持角度——复分析的第一奇迹

还记得第七节的结论吗——复数乘法是"旋转 + 缩放"，直角永远保持直角。在复平面上处处都能求导的函数，有个正式名字叫全纯函数（holomorphic function，可简单理解成"复可微"）。它最著名的共同点，正是前面预告过的那件事：保持角度。拿 f(z)=z² 作例：

f(z)=z² 把蓝色网格变成红色网格，原本正交的网格线映射后仍然正交——这就是全纯函数是共形映射（conformal=angle-preserving，保持角度）的可视化证据。

Cauchy–Riemann 方程（简称 CR 方程，判断复函数能不能"算导数"的两条偏导等式：∂u/∂x=∂v/∂y，∂u/∂y=−∂v/∂x）强制全纯函数在每一点的 Jacobian（变换的"局部缩放系数"）都是旋转+均匀缩放。两个方向的缩放倍数相同→角度被保持。这是复可微⇒共形的数学根源。

十一、复可微 ⇒ 自动无穷可微——实数做梦都得不到的性质

实数中：可微一次≠可微两次≠C^∞（任意阶都可导）≠解析（能展开成收敛幂级数）。存在处处连续但处处不可微的函数（Weierstrass函数）。存在C^∞但不是解析的函数（e−1/x²在x=0处所有导数=0，但不恒等于零）。

复数中：全纯（可微一次）⇒C^∞⇒有收敛幂级数展开⇒解析。全部等同。这是Cauchy积分公式强制的结果——一旦知道边界上的值，内部所有阶导数都被确定。复数世界没有实数中那种"可微层次的阶梯"。

十二、z²的共形映射——手算验证

f(z)=z²=(x+iy)²=(x²−y²)+2ixy。实部u=x²−y²，虚部v=2xy。Cauchy-Riemann: ∂u/∂x=2x=∂v/∂y ✓, ∂u/∂y=−2y=−∂v/∂x ✓。z²在ℂ上处处全纯（整函数）。

z²的映射效果：以原点为中心的圆→等半径的圆（双重覆盖）。射线→双重角度的射线。水平线y=k→抛物线。垂直线x=k→另一组抛物线。两组抛物线处处正交——因为z²保持直角。

十三、共形映射的物理应用

二维静电学、二维流体力学、二维热传导——这些物理问题在单连通区域内都可以通过共形映射转化为简单区域（如单位圆或上半平面）上的问题求解。这就是为什么复分析在工程中如此实用——一个共形映射把复杂的边界变成简单的边界。

提示：i = e^{iπ/2}，模长 1、辐角 90°。乘以它不改变模、只把辐角加 90°。(2−i)·i = 2i − i² = 1+2i，即点 (2,−1) 逆时针转 90° 到 (1,2)。

2. 用 de Moivre 公式求 (1+i)³ 和 (√3+i)⁶。
提示：1+i = √2 e^{iπ/4}，故 (1+i)³ = (√2)³ e^{i3π/4} = 2√2·(−√2/2 + i√2/2) = −2+2i。√3+i = 2 e^{iπ/6}，故 (√3+i)⁶ = 2⁶ e^{iπ} = −64。

3. 计算 (1−i)/(1+i)，先用共轭法，再用极坐标法（模相除、角相减）。
提示：共轭法乘上 (1−i)/(1−i)：(1−i)²/2 = (−2i)/2 = −i。极坐标法：1−i = √2 e^{−iπ/4}，1+i = √2 e^{iπ/4}，相除 = e^{−iπ/2} = −i。

4. 验证 e^{iπ} + 1 = 0：把 π 代入欧拉公式，一步步写出 cosπ 与 sinπ。
提示：cos π = −1，sin π = 0，故 e^{iπ} = −1 + i·0 = −1，移项即得。

5. 试求 i^i（答案居然是个实数，大胆用极坐标）。
提示：i = e^{iπ/2}，所以 i^i = (e^{iπ/2})^i = e^{i·iπ/2} = e^{−π/2} ≈ 0.208——一个实数！这是欧拉公式最著名的"惊吓"。

7. f(z)=ez把水平线映射成什么？垂直线呢？

反例：f(z) = z̄ 与 f(z) = |z|²

f(z) = z̄ = x − iy 处处不可导，但满足"一半"CR 方程。

u = x，v = −y。偏导：uₓ = 1，u_y = 0，vₓ = 0，v_y = −1。检查 CR：uₓ = 1 ≠ v_y = −1（第一式不成立）；u_y = 0 = −vₓ（第二式成立）。故 f 只满足第二个方程、不满足第一个——不满足全纯。

直接用定义：差商 [z̄+h̄ − z̄]/h = h̄/h = e−2i·arg h——随 h 的方向变化！沿实轴 h 取 +1，沿虚轴 h = iΔt 取 −1，极限不存在。故 f 处处不可导。同时 z̄ 是反射而非旋转+缩放，与全纯映射的共形性冲突（不保角）。

f(z) = |z|² = x² + y² 只在 z = 0 一点可导。

u = x² + y²，v = 0。偏导：uₓ = 2x，u_y = 2y，vₓ = 0，v_y = 0。CR：uₓ = v_y ⟹ 2x = 0 ⟹ x = 0；u_y = −vₓ ⟹ 2y = 0 ⟹ y = 0。故 CR 只在原点成立。

验证导数：在 z₀ = 0，差商 = |h|²/h = h̄ → 0，故 f'(0) = 0 存在。在 z₀ ≠ 0，差商 = (|z₀+h|² − |z₀|²)/h = (z₀h̄ + z̄₀h + |h|²)/h = z̄₀ + z₀·(h̄/h) + o(1)，含方向项 h̄/h，极限不存在。故 f 只在原点可导，在任何非空开集上不解析——"单点可导"与"开集上全纯"天差地别。

工作题：全纯性判断与 CR 方程验证

题1。 验证 f(z) = ez 满足 CR 方程并求 f'(z)。

显示解答

ez = ex(cos y + i sin y)，故 u = eˣcos y，v = eˣsin y。偏导：uₓ = eˣcos y，u_y = −eˣsin y，vₓ = eˣsin y，v_y = eˣcos y。CR：uₓ = v_y ✓，u_y = −vₓ ✓。偏导连续，故 ez 在 ℂ 上全纯，f'(z) = uₓ + ivₓ = eˣcos y + ieˣsin y = ez——导数仍是自身。

题2。 判断 f(z) = z̄² 在哪些点全纯。

显示解答

z̄² = (x−iy)² = (x²−y²) − 2ixy，故 u = x²−y²，v = −2xy。偏导：uₓ = 2x，u_y = −2y，vₓ = −2y，v_y = −2x。CR：uₓ = v_y ⟹ 2x = −2x ⟹ x = 0；u_y = −vₓ ⟹ −2y = 2y ⟹ y = 0。故 CR 只在原点成立，f 只在 z = 0 可导，在任何非空开集上不全纯。结论：f 不是全纯函数。

题3。 验证 f(z) = 1/z 在 ℂ∖{0} 上全纯并求其导数。

显示解答

1/z = z̄/|z|² = x/(x²+y²) − i y/(x²+y²)（z ≠ 0）。用商法则求偏导：uₓ = (y²−x²)/(x²+y²)²，u_y = −2xy/(x²+y²)²，vₓ = 2xy/(x²+y²)²，v_y = (y²−x²)/(x²+y²)²。CR：uₓ = v_y ✓，u_y = −vₓ ✓。故 1/z 在挖掉原点的平面上全纯，f'(z) = uₓ + ivₓ = (y²−x² − 2ixy)/(x²+y²)² = −(x−iy)²/(x²+y²)² = −1/z²。与幂法则一致——全纯函数的求导法则在形式上与实变一致。

题4。 设 f(z) = u(x,y) + iv(x,y) 全纯且 u = x² − y² + x。求 f 的表达式。

显示解答

由 CR：uₓ = 2x + 1 = v_y ⟹ v = 2xy + y + φ(x)。再由 u_y = −2y = −vₓ = −(2y + φ'(x)) ⟹ φ'(x) = 0，φ 为常数（取 0）。故 v = 2xy + y，f = (x²−y²+x) + i(2xy+y) = z² + z。核验：z² + z = (x+iy)² + (x+iy) = (x²−y²+x) + i(2xy + y) ✓。此题型展示：已知实部（或虚部），可由 CR 方程唯一重构全纯函数——这是调和函数理论的核心技巧。

关键论文

  • Gauss (1799, 1831)：代数基本定理的复平面证明与复数几何表示——"复数即平面"的现代观点。
  • Cauchy (1821/1825)：Cours d'Analyse 与复函数积分理论——全纯函数的系统奠基（柯西-黎曼方程、积分定理）。
  • Riemann (1851)：博士论文《单复变函数的一般理论基础》——黎曼映射定理与狄利克雷原理，把复分析与几何焊接。
  • Weierstrass (1840s–)：幂级数与解析延拓的严谨化——把全纯函数确立为幂级数对象。
  • Carathéodory (1912)：黎曼映射定理的拓扑证明（边界行为研究）——映射定理现代叙述的标准来源。
  • 教材：Ahlfors, Complex Analysis（经典）；Stein–Shakarchi, Complex Analysis。
