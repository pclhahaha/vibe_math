〇、直觉入门——把球放在碗里：凸性 = 只有一个谷底

最优化问题无处不在：训练神经网络要最小化损失、公司要最大化利润、路由器要最小化延迟、物理系统要最小化能量。它们共享一个几何图景：在"曲面"上找最低点。若曲面是凸的（像一口碗，任意两点连线都在碗内），最优化就有了一个奢侈的保证：

非凸曲面（连绵山丘）里"站在小坑底"无法知道外面有没有更深的谷；凸碗则不同——看得见的最低点就是最低点。更妙的是，这个几何性质带来可证明的算法性能：梯度下降（顺着"最陡下降"方向滚球）的收敛率有精确上界，步长、条件数、加速方法都有完整理论。凸优化因此是现代"可保证的最优化"的脊梁：线性规划、SVM、逻辑回归、最优传输（→ 最优传输 课）、压缩感知、以及量子信息里的半定规划，全是凸问题。

洞察：凸优化的口号是"结构换保证"——承认目标函数形状好，就换来全局性 + 收敛率 + 对偶间隙为零。梯度下降的收敛有三档：光滑凸 ~1/k、强凸线性 (1−μ/L)^k、Nesterov 加速 ~1/k²（对一阶方法最优，无可再快）。画布上滚球时，你会看到这三档速率以不同斜率呈现。
⚠️ 背景提示：本课属于 核心 级别。

建议先掌握：梯度与方向导数（下山的方向）、线性变换（Hessian 与特征值）、最优传输（可选的经典应用）。与 凸几何、高维几何 深度相连。

一、一个具体问题——"我到底在优化什么"：凸问题的版图与两场革命

按结构分类。

  • 无约束光滑： min f(x)，f 光滑（梯度可用）。
  • 线性规划（LP）： min cᵀx s.t. Ax≤b——多面体上的线性目标。Kantorovich（1939）与 Dantzig（1947 单纯形法）；1979 Khachiyan 椭圆法证明 LP 多项式时间；1984 Karmarkar 内点法给出实用多项式算法。
  • 凸二次与半定规划（SDP）： 目标/约束含二次型或矩阵半正定锥——谱范数、特征值问题、量子态区分都能写成 SDP。
  • 通用凸问题： 机器学习损失（岭回归、逻辑回归、SVM）、最优传输、稀疏恢复（LASSO）。

两场"革命"。 第一场：1980 年代的内点法把 LP 从"组合味道"变成"连续优化"（自协调障碍函数，Nesterov–Nemirovskii 统一框架）；第二场：21 世纪机器学习把"大而简单"的凸问题（亿万变量、结构稀疏）变成一阶方法（SGD 及其方差缩减）的主场——规模改变方法：算出足够好的解比算"精确解"更重要。

诚实声明。 深度学习的目标非凸；但现代实践表明其地形在过参数化下远比随机函数温和（鞍点而非坏局部极小主导，→ 高维几何）。凸优化提供的是理解与下限：无结构问题不能指望多项式步内求解（Nemirovsky–Yudin oracle 下界）——结构（凸、光滑、强凸、稀疏、低秩）是效率的唯一来源。

二、先直觉后严格——梯度下降的收敛几何

算法。 x_{k+1}=x_k−η∇f(x_k)。对 L-光滑凸 f（‖∇f(x)−∇f(y)‖≤L‖x−y‖），取 η=1/L：

若 f 还强凸（f−μ‖·‖²/2 凸，条件数 κ=L/μ）：

直觉。 L 限制"一步能走多远"，μ 保证"每走一步谷底必被拉近固定比例"；κ=L/μ 决定椭圆谷的瘦长程度——预条件/坐标变换（把椭圆变圆）因此是一切加速的几何母题。

Nesterov 加速。 只加一项动量（重球）就能把光滑凸提升到 O(1/k²)；Nemirovsky–Yudin 证明：对只用一阶 oracle 的算法，1/k² 是信息论最优。动量 = 让轨迹沿"抛物线"而非"直线"逼近——画布上对比两条路径一目了然。

三、例题 1——一维梯度下降的精确速率（一步步算完）

题目。 f(x)=½(x−3)²（L=μ=1，κ=1）。从 x₀=0 出发、η=0.5，迭代 5 步并核对收敛率。

第一步：迭代式。 ∇f=x−3 ⟹ x_{k+1}=x_k−0.5(x_k−3)=0.5x_k+1.5。

第二步：数值表。

第三步：核对几何率。 |x_k−3|=3·(0.5)^k：误差每步精确减半 ⟹ 线性收敛；f(x_k)−f*=½(3·0.5^k)²=½·9·0.25^k。∎

第四步：κ 的作用。 一般 f 的收敛率是 (1−1/κ)^k：κ=100 时每步只乘 0.99，把误差压 100 倍要 ~460 步；κ=1 时几步即达。条件数决定一切——预条件与牛顿方向的存在理由。∎

四、例题 2——对偶：从约束到影子价格（一步步算完）

题目。 求解 min (x−2)² s.t. x≤1，并构造拉格朗日对偶验证强对偶。

第一步：原始解。 无约束最小在 x=2（不可行）；可行集 x≤1 上 f 递减，故 x*=1、f*=1。

第二步：对偶函数。 L(x,λ)=(x−2)²+λ(x−1)（λ≥0）；g(λ)=min_x L：2(x−2)+λ=0 ⟹ x=2−λ/2：

第三步：对偶解与强对偶。 g′(λ)=1−λ/2=0 ⟹ λ=2、g(2)=1：

第四步：影子价格。 λ*=2：约束放宽为 x≤1+ε 时最优值约下降 2ε（KKT 互补松弛 λ(x−1)=0 在 x=1 处自动满足）。对偶乘子 = "资源的边际价值"——这就是经济学里对偶的用途。∎

五、严格陈述——核心定理清单

  • 凸性判据： f 凸 ⟺ f(y)≥f(x)+∇f(x)·(y−x)（一阶）⟺ ∇²f⪰0（光滑时）；Jensen：f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y)。
  • 全局最优： 凸 f 的驻点即全局最优；最优解集为凸集。
  • GD 收敛： L-光滑凸 O(1/k)；L-光滑 + μ-强凸线性 (1−μ/L)^k。
  • 加速最优性： Nesterov 动量 O(1/k²)；Nemirovsky–Yudin oracle 下界证明一阶方法无法更快。
  • 对偶： 弱对偶恒成立；Slater 约束资格 ⟹ 强对偶；KKT（平稳、原始/对偶可行、互补松弛）刻画最优。
  • LP 复杂度： 单纯形实用但最坏指数；椭圆法（1979）/内点法（1984）多项式。

七、延伸——凸优化是现代科学的通用语言

  • 机器学习。 岭回归/逻辑回归/SVM 的目标都凸；核方法进"凸的再生核空间"；LASSO/压缩感知用 ℓ₁ 松弛做稀疏恢复（→ 傅里叶变换）；SGD（Robbins–Monro 1951）+ 方差缩减（SVRG 等）支撑亿万样本训练。
  • 最优传输。 Kantorovich 对偶正是凸对偶：min 运输成本 = max 势函数差——最优传输 课的对偶理论全是本课对偶的化身。
  • 物理与变分。 最小作用量（→ 经典力学）、熵最大（→ 熵）、弹性能量极小都是（近）凸变分问题；"自然趋近能量最低"= 物理版梯度流（Wasserstein 梯度流：扩散 = 熵的梯度流！）。
  • 量子信息。 态区分、纠缠见证、信道容量都写成 SDP——半定规划是量子理论的"计算后端"（→ Bloch、纠缠 课）。
  • 经济学。 对偶 = 影子价格；均衡（Arrow–Debreu）用不动点与凸分离定理证存在性——凸性在"看不见的手"的数学里。

八、反例与陷阱——五个"优化想当然"

陷阱 1："非凸 = 不可能优化"？ 非凸但有结构（低秩恢复、相位恢复满足 RIP/景观条件）仍可高效求解；深度学习过参数化下"坏局部极小罕见"。凸是充分保证，不是优化全部。

陷阱 2："梯度下降总收敛到全局最小"？ 只在凸（或好景观）下成立；步长过大发散、过小龟速；非凸下 GD 只保证到驻点（可能卡鞍点，需扰动逃出）。

陷阱 3："对偶总是强对偶"？ 需要 Slater 等约束资格。反例：min x s.t. x²≤0——可行集 {0} 非 Slater，对偶有间隙。弱对偶恒真，强对偶要资格。

陷阱 4："机器学习损失都是凸的"？ 线性模型 + 凸损失才凸；深度网络损失几乎必然非凸。"凸损失"是 SVM/逻辑回归时代的说法，别套到深度学习上。

陷阱 5："1/k² 最快 = 一阶方法到头"？ 1/k² 是"只用梯度、无更多结构"的下界；牛顿/拟牛顿用二阶信息局部二次收敛，随机/坐标方法在各自场景更优。下界属于方法类，不是全世界的边界。

九、当前状态——优化理论的前沿

  1. 大规模一阶与随机优化。 SGD 方差缩减（SVRG/SAGA/SARAH）、随机坐标下降、mini-batch 理论——"每次只摸一个样本"的收敛保证是现代 ML 引擎。
  2. 加速与分裂的统一点。 O(1/k²) 加速推广到算子分裂（加速 ADMM/原始对偶）、随机与复合情形；"动量为何快"的变分/几何解释是热点。
  3. 非凸景观理论。 矩阵感知、相位恢复、张量分解的"无坏极小"证明——landscape 分析成为信号处理与 ML 的共同语言。
  4. 量子与分布式。 量子优化下界、联邦学习的通信-精度权衡、差分隐私优化——工具箱仍在扩张。

关键论文

  • Cauchy (1847)：梯度下降（最陡下降）——最优化第一算法。
  • Kantorovich (1939/42)：运输问题与 LP 对偶的开端。
  • Dantzig (1947)：单纯形法。
  • Robbins–Monro (1951)：随机逼近（SGD 之祖）。
  • Khachiyan (1979)：LP 的椭圆法（首次多项式时间）。
  • Karmarkar (1984)：LP 内点法（实用多项式）。
  • Nesterov (1983)：加速梯度法 O(1/k²)。
  • Nemirovsky–Yudin (1983)：信息复杂度与 oracle 下界。
  • Johnson–Zhang (2013)：SVRG——方差缩减线性收敛。
  • Boyd–Vandenberghe (2004)：Convex Optimization（标准教材）。

试试看——练习与提示

试试看 1（画布滚球）。 把 a、b 从 (1,1) 拖到 (1,30)：椭圆谷变瘦、路径变锯齿、收敛变慢——条件数 30 的实感。开"动量"对比路径与到 ε 的步数。
