〇、动机：GPS 和直觉，谁更可信？

你的手机屏幕显示"我在这里，精确到 3 米"。但仔细想想：GPS 卫星信号穿越电离层、被大楼反射，测距误差常常有几十米；手机里的惯性传感器又不停地漂移。真正靠谱的定位，是把两类都不准的信息——"卫星说我在这"和"传感器说我上一刻在这、大概往那边动"——按各自的靠谱程度加权融合。

先看一个最小的例子。我猜你此刻在 x = 100 米处，但我的猜测很不确定：方差 P = 4 m²（标准差 2 米）。GPS 读数说你在 x = 110 米处，GPS 的测量方差 R = 9 m²（标准差 3 米）。两股信息，哪个更可信？我自己的猜测更可信（方差 4 < 9），但 GPS 也不该完全忽略。合理的折中：

答案 103.1 米，离我的猜测 100 更近、离 GPS 的 110 稍远——正因为我自己的估计"更准"。这个加权平均，就是 Kalman 滤波的核心动作，只是它每时每刻都在做，并且随着信息累积，它的猜测越来越准（方差不断缩小）。火箭、手机导航、自动驾驶都在用这套"猜真相"的功夫。

一句话：Kalman 滤波 = 把"不太准的测量"和"大致规律"按可信度加权融合，越猜越准。只想懂核心思想，看到这里就够了。

一、状态空间模型：把"它大概怎么动"写下来

Kalman 滤波处理的对象不是孤立的数字，而是状态空间模型——两条方程：一条说"状态怎么演化"，一条说"观测怎么来"。

记号逐个解释：x_k 是第 k 时刻的真实状态（比如位置，未知）；F 是状态转移矩阵（描述"上一刻的状态怎么变成这一刻的"）；w 是过程噪声（模型不准的部分，协方差 Q）；y_k 是我们实际读到的测量；H 是观测矩阵（状态怎么映射成测量）；v 是测量噪声（协方差 R）。

为什么需要两条方程？因为"真实状态"和"我们能测到的量"常常不是一回事：汽车的真实速度测不到，我们只能测到轮速、GPS 位置、加速度计读数——它们都只是状态的部分反映。H 就是这个"反映方式"。而 F 是系统的动力学，它让我们在没有新测量时也能推断（预测），有了新测量再修正（更新）。

GPS 一维例子：位置 x_k 在短时间近似不动（F = 1），位置等于自身加一点随机扰动（Q = 0.01 m²）；GPS 直接量位置（H = 1），测量噪声方差 R = 9 m²。两条方程就完整描述了"位置 + GPS"这个系统。

四、Kalman 增益：为什么 K 是这样选

增益公式

读起来绕，但它的两个极端很有直觉：

① 若测量非常可靠（R → 0），则 K → 1（对 H = 1 时），更新结果几乎完全采信测量；② 若先验非常不可靠（P → ∞），则 K → 1，同样几乎采信测量；③ 反过来，若测量噪声极大（R → ∞），则 K → 0，更新几乎不动——测量被完全忽略。

为什么取这个"中间值"？因为 Kalman 增益选的是使更新后方差 P_{k|k} 最小的那个权重。一维情形：把后验写成加权平均 x̂ = (1−K)x̂_p + Ky，后验方差是 (1−K)²P + K²R，关于 K 求导为 0，解出 K = P/(P+R)——正是那个"按精度加权"的比例。高维情形道理相同，只是求导对象从标量变成矩阵（正交投影定理，见第八节）。

为什么"预测要加 Q、更新要乘 (I−KH)"？预测时，模型的不确定性（过程噪声 Q）必须叠加进协方差，否则我们会对"没把握的演化"过分自信；更新后，增益已经把一部分测量信息吸收进来，剩余的不确定性是 (I−KH)P——正是"没被测量消掉的那部分方差"。这两条就是信息流动的账本：不确定性只增（预测）只减（更新），从不清零。

每一步只需上一次估计 + 新观测——不需要存储全部历史数据。阿波罗登月舱的导航计算机只有 64KB 内存——Kalman 滤波使它实时估计位置、速度和姿态。这种"递推、无记忆"正是它成为工程标准的根本原因。

八、为什么 Kalman 是最优线性估计

Kalman 的"最优性"有两层，取决于假设：

第一层（高斯 + 线性 → 无条件最优）。若系统线性、噪声高斯，则每个后验 p(x_k|y_{1:k}) 仍是高斯，完全由均值 x̂ 与协方差 P 刻画。此时条件期望 E[x_k|y_{1:k}] 是均方误差意义下所有（非线性也算）估计器里最优的，而 Kalman 递推恰好精确算出了这个条件期望。任何其他估计（粒子滤波、非线性滤波器）都做不到更好。

第二层（去掉高斯假设 → 在线性估计类中最优）。即使噪声不是高斯，只要限定估计器必须是状态观测的线性函数，Kalman 增益仍是使均方误差最小的那个权重——这叫最小均方误差线性估计（LMMSE），由正交投影定理保证：最优线性估计就是状态在先验估计与新息张成的子空间上的正交投影，而 K 正是这个投影系数。

这就是"为什么 Kalman 是最优的"：在高斯世界它是全局最优，在非高斯世界它是"线性军团"里的最优。同时它还是所有贝叶斯滤波中唯一有闭型递推解的——不需要数值积分，几十行代码就能跑。

九、与最小二乘和贝叶斯估计的关系

Kalman 更新的信息形式 P⁻¹ 与 HᵀR⁻¹H 揭示了它的三重身份：

(1) 加权最小二乘（WLS）——信息阵逐项累加观测 HᵀR⁻¹H，正是 WLS 正规方程 HᵀW⁻¹Hθ = HᵀW⁻¹y 的结构，权重 W = R；(2) 贝叶斯更新——先验信息 P_p⁻¹ 与观测信息相加得到后验，即高斯先验 × 高斯似然 = 高斯后验（第二节的"精度相加"）；(3) LMMSE——即使去掉高斯假设，K 仍是在线性估计类中最小化均方误差的唯一最优（第八节）。

为什么一个公式三重身份？因为三者共享同一套"信息代数"：方差小 = 信息多 = 权重高。最小二乘按噪声方差加权残差、贝叶斯按先验/似然精度相乘、LMMSE 按协方差投影，殊途同归。

无过程模型（F = I、Q = 0，状态恒定）时 Kalman 退化为经典递归最小二乘 RLS——〇节和三节的"测恒定长度"正是这个退化情形。Kalman 是"递推化的 Gauss–Markov 定理"。

十、反例——非高斯噪声下滤波失效

Kalman 的最优性依赖高斯假设。反例 1（厚尾）：噪声为 Cauchy 分布或含离群点时，后验不再是高斯，均值与协方差不足以刻画它；Kalman 仍给出最佳线性估计，但远非最佳非线性估计，且一个巨大的离群观测 y_k 会把估计拉偏、甚至使滤波器发散——此时需要鲁棒滤波（Huber、中位数型）或粒子滤波。反例 2（多峰）：状态后验呈双峰时，Kalman 的单峰近似完全丢失结构——贝叶斯意义上最优的是完整后验传播，而非均值 ± 方差。反例 3（线性化失效）：对强非线性系统，EKF 的 Jacobian 线性化在转弯或强非高斯时误差放大，需换 UKF 或粒子滤波（见第十一节）。

十二、从阿波罗到自主驾驶

1960 年 Kalman 发表《A New Approach to Linear Filtering and Prediction Problems》。仅仅九年后的 1969 年，阿波罗 11 号登月舱的导航计算机（64KB 内存）用 Kalman 滤波实时估计位置、速度、姿态——在人类第一次登月任务里承担核心导航职责。今天：GPS + IMU 融合是每部手机的标准动作，特斯拉 Autopilot 融合摄像头 + 雷达 + GPS，无人机用 Kalman/SLAM 同时定位和建图，金融时间序列从噪声价格中提取趋势。Kalman 滤波无处不在。

十五、前沿：深度 Kalman——神经网络 + 状态空间模型

状态空间模型（SSM）与 Kalman 的血缘在深度学习里重新长出了枝干：S4（2022）、Mamba（2023）用 Kalman 滤波的连续时间版本替代 Transformer 的自注意力——线性时间在长序列上击败了二次方时间，成为大语言模型高效序列建模的新范式。为什么这与 Kalman 有关？SSM 的核心是"隐藏状态线性演化 + 观测映射"，结构上就是第 1 节的 (F, H) 方程；而 Mamba 的"选择机制"让 F 依赖输入，相当于一个输入依赖的时变线性系统。仍开放的问题：SSM 的理论极限（能否媲美注意力在"关联定位"任务上的能力）和它在强化学习中的应用。

十六、试试看（每题附提示）

1. 标量系统：先验 x̂ = 5，P = 2；观测 y = 7，R = 1。求 K、更新后的 x̂ 与 P。

提示：K = P/(P+R) = 2/3；x̂ = 5 + (2/3)(7−5) = 5 + 4/3 ≈ 6.33；P = (1−2/3)·2 = 2/3。

2. 若把上题的 R 从 1 增大到 100（测量很不可信），K 变成多少？更新后的 x̂ 还接近 5 还是接近 7？

提示：K = 2/(2+100) ≈ 0.0196，几乎为 0，更新几乎不动，x̂ ≈ 5 + 0.0196×2 ≈ 5.04——测量被忽略。

3. 验证信息形式与增益形式等价：P = 2、R = 1 时，用 1/P₀ + 1/R 算后验方差，并与第 1 题的 P 比较。

提示：后验精度 = 1/2 + 1/1 = 1.5，后验方差 = 1/1.5 = 2/3，与第 1 题的 P = 2/3 完全一致。

4. 二维：P₀ = diag(1, 1)，R = diag(4, 4)，观测 y = (3, −1)ᵀ，先验 (0, 0)ᵀ。求 K 与 x̂。

提示：每维 K = 1/(1+4) = 0.2，x̂ = (0.6, −0.2)ᵀ。因为先验方差 1 < 测量方差 4，结果偏向先验。

5. 解释：为什么当 R → 0（测量完全可靠）时，更新后的 x̂ 趋近于测量值 y_k？

提示：K → P/(P+0) = 1（标量情形），x̂ = x̂_p + 1·(y − x̂_p) = y。

6. EKF：对 f(x) = x²，x̂ = 1，线性化用到的 Jacobian 是多少？

提示：∂f/∂x = 2x，在 x̂ = 1 处取值为 2，故 F ≈ 2。

预测：x̂_{k|k−1} = F·2 = 2，P_{k|k−1} = 1²·1 + 0.5 = 1.5。增益：K = 1.5/(1.5+1) = 0.6。更新：x̂_{k|k} = 2 + 0.6×(5−2) = 3.8，P_{k|k} = (1−0.6)×1.5 = 0.6。验算：x̂ 比 x̂_p 更接近观测 5，且 P 由 1.5 降至 0.6——信息融合降低了不确定性。

关键论文

  • Kalman (1960)：A New Approach to Linear Filtering and Prediction Problems, J. Basic Eng. 82——卡尔曼滤波的开创论文（离散时间）。
  • Kalman–Bucy (1961)：连续时间版本（Riccati 方程驱动的最优滤波）。
  • Wiener (1949)：Extrapolation, Interpolation, and Smoothing of Stationary Time Series——最优线性滤波的频域前史。
  • Kolmogorov (1941)：平稳序列预测的奠基（与 Wiener 独立）——滤波的统计根源。
  • 教材：Anderson–Moore, Optimal Filtering；Simon, Optimal State Estimation。

前置知识

学习本课前，建议先掌握：概率论基础、线性变换。

关联课程

→ 线性变换：Kalman滤波的预测步骤x̂k|k−1=Fx̂k−1是状态转移矩阵F的线性变换——整个滤波过程就是线性变换和贝叶斯更新的交替迭代。

→ SVD：协方差矩阵P的条件数决定滤波数值稳定性——SVD分解在Kalman滤波的平方根算法和UD分解中用于缓解数值病态问题。

→ 梯度：扩展Kalman滤波(EKF)对非线性函数做一阶Taylor展开——用Jacobian矩阵(梯度向量)线性化，本质上是最陡梯度下降在状态空间中的动态版本。

→ 概率论相关：Kalman滤波是高斯-马尔可夫假设下的最优贝叶斯递推——先验(预测)和似然(观测)都是高斯分布，后验(更新)仍是高斯，一切由均值和协方差完全刻画。
