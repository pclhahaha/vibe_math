🏛 研究生资格考试问题集

对标北美数学系博士生资格考试（Qualifying Exam）的水准。每道题附完整解答——先独立思考，再展开答案。难度标记：◆=资格考试基础题，◆◆=综合题，◆◆◆=研究入口题。

使用建议：资格考试通常限时 3 小时。建议每科选 5-8 题，限时 45 分钟/题。做不出的题先标记，对照解答学习后重做一遍——这是最有效的博士数学训练方式。

实分析 Real Analysis

题 1（◆）：证明 Lebesgue 单调收敛定理。MCT· → 📏 测度论
显示解答

设 0 ≤ f₁ ≤ f₂ ≤ ... 逐点收敛到 f，令 f = lim f_n。先对每个 n 取简单函数逼近 f_n，利用简单函数的 MCT（上确界的积分性质）得到 ∫f_n → sup ∫f_n。再由 ∫f_n ≤ ∫f（单调性）且对任意简单函数 s ≤ f，s ∧ f_n ↑ s，∫s = lim ∫(s∧f_n) ≤ lim∫f_n，取 sup 得 ∫f ≤ lim∫f_n。反向不等式显然。∎

题 2（◆）：构造一个黎曼不可积但勒贝格可积的函数。Riemann vs Lebesgue· → 📏 测度论
显示解答

Dirichlet 函数 f(x)=1 若 x 有理，0 若 x 无理（在 [0,1] 上）。任何区间分割的 Darboux 上和 = 1（每个小区间含有理数），下和 = 0（每个小区间含无理数），故黎曼积分不存在。但 f = 1_ℚ∩[0,1] 是可测简单函数，∫f = 0（ℚ 可数，测度 0）。

题 3（◆◆）：证明 Fatou 引理并给出严格不等式成立的例子。Fatou· → 📏 测度论
显示解答

对非负可测 f_n，∫(liminf f_n) ≤ liminf ∫f_n。证明：g_n = inf_{k≥n} f_k ↑ liminf f_n，用 MCT：∫liminf = lim ∫g_n ≤ liminf ∫f_n（因 g_n ≤ f_n）。严格例：取 X=[0,1]，f_{2k}=1_{[0,1/2]}，f_{2k+1}=1_{[1/2,1]}。则 liminf f_n=0（每点无穷多次取 0），但 ∫f_n=1/2 恒，liminf ∫f_n=1/2 > 0。

题 4（◆◆）：证明 Vitali 覆盖引理并解释在 Hardy-Littlewood 极大函数定理中的作用。Covering· → 📏 测度论
显示解答

Vitali 覆盖引理：设 {B_j} 是有限族球，则存在不交子族 {B_k} 使 ∪B_j ⊂ ∪3B_k（半径放大 3 倍的球）。贪心：选最大球，删去与其相交的球，重复。每个被删球 ⊂ 所选球的 3 倍。应用：极大函数 Mf(x) 的次水平集 {Mf > t} 被 {3B} 覆盖，故 |{Mf>t}| ≤ (3^n/t)∫|f|——即弱 (1,1) 不等式，进而极大函数的 L^p 有界性。

泛函分析 Functional Analysis

题 5（◆◆）：陈述并证明 Hahn-Banach 定理的几何形式。Separation· → 📊 泛函分析
显示解答

几何形式：设 A, B 是局部凸空间中两个不交的凸集，其中一个紧、另一个闭，则存在连续线性泛函 f 和实数 α 使 sup f(A) < α < inf f(B)（严格分离）。证明框架：从解析形式（延拓有界线性泛函）经 Minkowski 泛函 p(x)=inf{λ>0: x∈λ·A} 和 Minkowski 分离定理（先用一点与开凸集分离，再用平移和仿射变换得到两个凸集的分离）。

题 6（◆）：证明开映射定理。Open mapping· → 📊 泛函分析
显示解答

设 T: X→Y 是 Banach 空间之间的满连续线性算子。由 Baire 范畴定理，∪_n nT(B_X) = Y，某 nT(B_X) 有内点 ⟹ T(B_X) 含以 r 为中心的开球。平移得 T(B_X) 含原点某邻域 V。对任意 y∈V/2，T 的满射性 + 完备性可把 y 写成 T(x) 且 ‖x‖≤2（级数求和），即 T 把开球映到开球 ⟹ T 是开映射。

题 7（◆）：证明一致有界原理（Banach-Steinhaus）。Uniform boundedness· → 📊 泛函分析
显示解答

设 {T_α} ⊂ B(X,Y)（Banach 到赋范空间）逐点有界：sup_α ‖T_α x‖ < ∞ 对每个 x。定义闭集 F_n = {x: sup_α‖T_αx‖ ≤ n} = ∩_α T_α^{-1}(n·闭球)。由逐点有界，∪_n F_n = X。Baire 范畴定理：某 F_n 有内点，含平移的开球 B(x₀,δ)。则 ‖T_α‖ 一致有界（用范数不等式三角分解）。

抽象代数 Abstract Algebra

题 8（◆）：证明有限群的 Lagrange 定理并给出逆命题的反例。Lagrange· → 🧮 抽象代数
显示解答

设 H ≤ G，|G|<∞。左陪集 gH 两两不交（若 g₁H∩g₂H≠∅ 则 g₁H=g₂H），且每个陪集大小 = |H|（映射 h↦gh 双射）。故 |G| = [G:H]·|H|，即 |H| 整除 |G|。逆命题反例：交错群 A₄ 有 12 阶，但无 6 阶子群（否则指数 2 的正规子群，矛盾 A₄ 无阶 6 的正规子群）。

题 9（◆◆）：证明 S₅ 不是可解群，从而一般五次方程无根式解。Solvability· → 🔗 伽罗瓦理论
显示解答

S₅ 的导序列：S₅ ⊃ A₅ ⊃ A₅（A₅ 是导子群，因 A₅ 简单）。A₅ 非阿贝尔，故导序列稳定在 A₅，永不达到 {e}。故 S₅ 不可解。一般五次方程（不变量为对称多项式）的伽罗瓦群是 S₅，由伽罗瓦理论，方程根式可解 ⟺ 伽罗瓦群可解。因此一般五次无根式解（Abel-Ruffini）。

题 10（◆）：证明 Zorn 引理（陈述并说明与选择公理的关系）。Zorn· → 📐 集合论
显示解答

Zorn 引理：若偏序集 P 的每条链都有上界，则 P 有极大元。证明依赖于选择公理：假设无极大元，则可用选择函数沿每链构造严格递增长链，其长度超过 |P|（Hartogs 数）——矛盾。关系：Zorn 引理 ⟺ 选择公理 ⟺ 良序定理（在 ZF 中互相等价）。应用：Hahn-Banach、极大理想存在、基的存在。

代数拓扑 Algebraic Topology

题 11（◆）：证明 π₁(S¹,*) ≅ ℤ。Fundamental group· → 🕳️ 基本群
显示解答

用万有覆盖 p: ℝ → S¹, t ↦ e^{2πit}。给定以基点为起点的回路 γ，路径提升性质给出唯一提升 γ̃（γ̃(0)=0）。映射 γ ↦ γ̃(1) ∈ ℤ 良定义（同伦回路提升终点相同）且为群同构。逆映射：n ↦ [t ↦ e^{2πint}]。提升的唯一性来自 ℝ 的单连通性。

题 12（◆◆）：用 Mayer-Vietoris 序列计算环面 T² 的同调群。Homology of torus· → 🕳️ 同调论
显示解答

T² 分解为两个开圆盘 D₁, D₂ 交于开环带 S¹×(0,1)。Mayer-Vietoris：H₂(D₁)⊕H₂(D₂) → H₂(T²) → H₁(S¹×(0,1)) → H₁(D₁)⊕H₁(D₂) → H₁(T²) → H₀(交) → H₀(D₁)⊕H₀(D₂) → H₀(T²) → 0。代入已知：H₂(T²)≅ℤ，H₁(T²)≅ℤ²，H₀(T²)≅ℤ。边界映射 H₂(T²)→H₁(交)≅ℤ 是同构（交是生成元 1-圈）。

微分几何 Differential Geometry

题 13（◆）：证明 Gauss-Bonnet 定理在球面上的验证。Gauss-Bonnet· → 📐 曲率
显示解答

对单位球面 S²（曲率 K=1），取测地三角形（三个角 α,β,γ 在赤道上，顶点在北极），则 ∫K dA = 面积 = 角盈 = α+β+γ−π（球面角盈公式）。Gauss-Bonnet：∫K dA = 2πχ(S²) = 4π。对测地三角形 ∫_三角形 K dA = 角盈，求和覆盖整个球面得 4π ✓。

题 14（◆）：证明测地线方程（Christoffel 符号形式）。Geodesic equation· → 🌐 测地线
显示解答

测地线 = 能量泛函 E[γ]=½∫g(γ̇,γ̇)dt 的临界点。变分 δE=0 得 Euler-Lagrange：d/dt(∂L/∂ẋ^μ) − ∂L/∂x^μ = 0，其中 L=½g_{μν}ẋ^μẋ^ν。展开得 ẍ^μ + Γ^μ_{αβ}ẋ^αẋ^β = 0，其中 Christoffel 符号 Γ^μ_{αβ} = ½g^{μσ}(∂_αg_{βσ}+∂_βg_{ασ}−∂_σg_{αβ})。这是测地线的标准方程，也是广义相对论中自由落体的运动方程。

题 15（◆）：证明球极投影的转移映射 φ_S∘φ_N⁻¹(u,v)=(u,v)/(u²+v²) 光滑且自逆，并说明 S² 是 2 维光滑流形。Transition map· → 🗺️ 光滑流形
显示解答

由 φ_N(x,y,z)=(x/(1−z),y/(1−z)) 与其逆 φ_N⁻¹(u,v)=(2u/(1+r²),2v/(1+r²),(r²−1)/(1+r²))（r²=u²+v²），代入 φ_S(x,y,z)=(x/(1+z),y/(1+z))，利用 1+z=2r²/(1+r²) 得 φ_S∘φ_N⁻¹(u,v)=(u/r²,v/r²)。分量为有理函数、分母 r²≠0，故在 ℝ²∖{0} 上 C^∞；两次复合：u↦u/r²↦(u/r²)/(r²/r⁴)=u，自逆。两图卡 U_N=S²∖{N}、U_S=S²∖{S} 覆盖 S²，转移映射光滑，故 {S², (U_N,φ_N), (U_S,φ_S)} 是 2 维光滑图册，S² 为 2 维光滑流形。∎

复分析 Complex Analysis

题 15（◆）：证明 f(z)=z̄ 处处不可导。CR equations· → 🔄 复平面与全纯函数
显示解答

f(z)=z̄=x−iy。CR 方程：∂u/∂x=1，∂v/∂y=−1，1≠−1，CR 方程处处不满足 ⟹ f 无处全纯。更直接：差商 (f(z+h)−f(z))/h = (z̄+h̄−z̄)/h = h̄/h。沿 h=实数 趋于 1，沿 h=纯虚数 趋于 −1，极限不存在（不唯一）。

题 16（◆◆）：用留数定理计算 ∫₀^∞ dx/(1+x⁴)。Residue· → ⭕ 围道积分与留数
显示解答

∫_{-∞}^∞ dx/(1+x⁴) = 2πi·Σ(上半平面留数)。极点：x₀ = e^{iπ/4}, e^{3iπ/4}（上半平面；另两个在下半平面）。留数公式：Res 1/(1+x⁴) 在 x₀ = 1/(4x₀³)。Res(e^{iπ/4}) = 1/(4e^{3iπ/4}) = e^{-3iπ/4}/4 = (−√2/2 − i√2/2)/4。Res(e^{3iπ/4}) = 1/(4e^{9iπ/4}) = e^{-9iπ/4}/4 = e^{-iπ/4}/4 = (√2/2 − i√2/2)/4。两留数之和 = −i√2/4（实部相消）。故 ∫_{-∞}^∞ = 2πi·(−i√2/4) = π√2/2。由被积函数偶性，∫₀^∞ = π√2/4。

概率论 Probability

题 17（◆）：证明 Markov 不等式和 Chebyshev 不等式。Inequalities· → 🎲 概率论基础
显示解答

Markov：对 X≥0，a>0，E[X] ≥ a·P(X≥a)（因 X ≥ a·1_{X≥a}，取期望）。Chebyshev：P(|X−μ|≥ε) = P((X−μ)²≥ε²) ≤ E[(X−μ)²]/ε² = Var(X)/ε²（用 Markov 于 (X−μ)²）。

题 18（◆◆）：用特征函数证明中心极限定理。CLT· → 🎰 大数定律与中心极限定理
显示解答

设 X₁,...,X_n i.i.d.，E[X]=0，Var=1。S_n/√n 的特征函数：φ(t) = [φ_X(t/√n)]^n。展 φ_X(u) = 1 − u²/2 + o(u²)。则 log φ(t) = n·log(1 − t²/(2n) + o(1/n)) → −t²/2。故 φ(t) → e^{-t²/2} = 标准正态特征函数。由 Lévy 连续性定理，S_n/√n → N(0,1)。

量子力学 Quantum Mechanics

题 19（◆）：推导谐振子的能级 E_n=ħω(n+½)。Oscillator· → 🪩 谐振子
显示解答

定义 a = √(mω/2ħ)(x + ip/(mω))，a† 共轭。验证 [a,a†]=1，H=ħω(a†a+½)。N=a†a 有非负整数谱（N|n⟩=n|n⟩，n∈ℤ≥₀，因 a|n⟩ 是 N 的特征向量特征值 n−1，非负性截断于 n=0）。故 E_n = ħω(n+½)。基态 a|0⟩=0 解得 ψ₀ ∝ e^{-mωx²/2ħ}。

题 20（◆）：推导氢原子能级 E_n=−13.6/n² eV。Hydrogen· → ⚛️ 氢原子轨道
显示解答

径向方程在有效势 V_eff = −e²/(4πε₀r) + l(l+1)ħ²/(2mr²) 下求解。对角量子数 n=1,2,...，能级 E_n = −(me⁴)/(2(4πε₀)²ħ²n²) = −13.6/n² eV。推导要点：将束缚态条件 + 拉盖尔多项式收敛（截断）得 n 为整数，代入里德伯常数 R_∞ = me⁴/(2(4πε₀)²ħ²) = 13.6 eV。简并度 n²（含磁量子数 ±l,...,+l）。

题 22（◆）：证明 S¹ 的不可约酉表示是一维的 χ_k(e^{iθ})=e^{ikθ}，并验证正交性。Peter–Weyl / Fourier· → 🎻 紧李群表示与 Peter–Weyl

代数数论与 p-adic Number Theory

题 23（◆）：在 ℤ[√−5] 中展示 6 的两种不可约分解并用范数证明因子不可约。Non-UFD· → 🏰 代数数论：数域与理想类
显示解答

6 = 2·3 = (1+√−5)(1−√−5)。范数 N(a+b√−5)=a²+5b² 乘性。若 2=αβ（非单位）则 N(α)N(β)=4；N=2 需 a²+5b²=2 无整数解 ⟹ 无真因子 ⟹ 2 不可约；3 同理（N=3 无解）；N(1±√−5)=6 且 6 的分拆 2·3 均不可实现（N=2、3 无解）⟹ 也不可约。四个不可约给出两种本质不同分解 ⟹ 非 UFD；理想 (2,1+√−5) 非主 ⟹ 类数 2。

题 24（◆）：用 Hensel 引理判定 x² = −1 在 ℚ₅ 与 ℚ₃ 是否可解。Hensel lift· → 🥟 p-adic 数与局部域
显示解答

f(x)=x²+1。ℚ₅：x²≡−1≡4 (mod 5) 有根 x₀=±2；f′(x₀)=2x₀≢0 (mod 5)（2·2=4≠0），简单根 ⟹ Hensel ⟹ 唯一提升到 ℤ₅：ℚ₅ 有 √−1。ℚ₃：需 x²≡−1≡2 (mod 3)，而 2 非 mod 3 平方剩余，无 mod p 根 ⟹ Hensel 前提失败，ℚ₃ 无 √−1。整体：ℚ 无 √−1（−1 非平方）——局部条件严格区分 ℚ₅ 与 ℚ₃。

图论与概率深化 Graph / Martingales / RMT

题 25（◆）：证明连通图有欧拉回路 ⟺ 每个顶点度数为偶。Euler· → 🕸️ 图论与网络
显示解答

(⟹) 回路每进入一个顶点一次必离开一次，故每点度 = 2×(经过次数)（起点在闭环中亦如此）为偶。(⟸) 从任意点沿未用边走，因每次进入一个点都有边可出（偶度 + 已用边成对），必回到起点得回路；若未覆盖全部边，连通性保证存在与回路共享顶点的未用边，从该点再走回路并嫁接进原回路，扩张；有限步后含全部边。这是 Hierholzer 的构造性证明。∎

题 26（◆◆）：公平随机游走从 i 元到 {0,N}：用停时定理求破产概率。Gambler's ruin· → ♟️ 鞅与随机游走
显示解答

S_n 对称随机游走是鞅；τ=首次到 {0,N}（Eτ<∞，可用 τ∧T 截断再取极限）。停时定理：E[S_τ]=S₀=i。S_τ=0·P(破产)+N·P(到 N)，且 P(破产)+P(到 N)=1 ⟹ N·P(到 N)=i ⟹ P(破产)=1−i/N=(N−i)/N。N→∞ 时 →1：一维常返的"以小博大必死"。

题 27（◆◆）：用积分证明半圆律密度的二阶矩 m₂=1，并说明它与 Catalan C₁ 的关系。Wigner / Catalan· → 🎱 随机矩阵与半圆律

m₂=∫_{−2}^{2}x²·(1/2π)√(4−x²)dx。换元 x=2sinθ：dx=2cosθ dθ，√(4−x²)=2cosθ：m₂=(16/2π)∫_{−π/2}^{π/2}sin²θcos²θ dθ。sin²cos²=sin²2θ/4，∫sin²2θ=π/2 ⟹ 积分为 π/8：m₂=(16/2π)(π/8)=1。半圆矩 m_{2k}=Catalan C_k（C₁=1）：Wigner 矩阵 E[(1/N)Tr M²]→1 与之一致。

题 28（◆◆◆）：用 Leray–Serre 谱序列证明 H*(S³;ℤ) ≅ H*(S⁰)。Hopf fibration· → 🛰️ 谱序列与同伦论
显示解答

Hopf S¹→S³→S²：E₂^{p,q}=H^p(S²;H^q(S¹))，非零格点 (0,0),(0,1),(2,0),(2,1) 各一 ℤ。可能差分只有 d₂:(0,1)→(2,0)（其余越出第一象限）。若 d₂=0，则 H¹(S³)、H²(S³) 各含 ℤ，矛盾（S³ 是 3-流形，H¹=H²=0）。故 d₂ 同构，E₃=E_∞ 只剩 (0,0)、(2,1)：H⁰=ℤ、H³=ℤ。即 H*(S³)=ℤ 于 0、3 度、其余 0。transgression d₂ 编码 Hopf 非平凡性。

题 35（◆◆）：陈述 CH 的独立性定理（Gödel 与 Cohen 两方向）。Forcing / L· → 🌩️ 集合论 II：力迫与连续统假设
显示解答
