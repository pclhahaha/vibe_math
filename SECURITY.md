# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in Vibe Math,
please **do not** open a public issue. Instead, report it privately so we can fix
it before disclosure.

**How to report:**
- Open a private security advisory via GitHub → Settings → Security → "New security advisory"
- Or email the maintainers directly (see repository owner)

## What to include
- Affected component / file
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Scope
This project is a static educational site built with Vite, p5.js, and KaTeX.
It has no backend, database, or authentication. Most "vulnerabilities" would be
content issues (incorrect math) rather than security issues.

## Policy
- We will acknowledge reports within 7 days
- We aim to triage within 14 days
- We will coordinate disclosure after a fix is released
